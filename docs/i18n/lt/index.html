Teismų praktika ir teisės aktai jūsų DI programai, skaitomi tiesiogiai iš teismų ir valstybės institucijų svetainių.

Beta · nemokamas · atvirasis kodas · šaltiniai tikrinami kasdien

Fontes yra nemokamas atvirojo kodo MCP serveris. Jis veikia bet kurioje programoje, galinčioje paleisti vietinį Model Context Protocol serverį: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio ir kitose. Užduokite teisinį klausimą paprasta kalba: jūsų DI programa tiesiogiai ieško teismų sprendimų ir teisės aktų valstybės institucijų ir teismų svetainėse 125 jurisdikcijų ir tarptautinių teismų bei pateikia kiekvieno rezultato originalo nuorodą. Jis taip pat gali parodyti įstatymo redakciją, galiojusią praeities datai, ir skaityti teisės aktus dar iš 91 valstybės iš Lexifina duomenų rinkinio (ne oficialaus leidėjo). Jis sukurtas teisininkams ir teisės tyrėjams bei visiems, kurie nori skaityti teisę iš jos šaltinio.

Ką jis daro

  • Ieško teismų praktikos ir teisės aktų tą akimirką, kai klausiate, paties leidėjo svetainėje ar API.
  • Kiekvienas rezultatas nurodo savo šaltinį ir pateikia nuorodą į jį, kad galėtumėte patikrinti originalą.
  • Fontes nesaugo duomenų bazės ir jam nereikia paskyros. Jūsų klausimai siunčiami į ieškomą šaltinį; dėl ankstesnių įstatymų redakcijų ir dar 91 šalies (bei Indijos įstatymų) jie siunčiami į viešąją Lexifina paslaugą, kartu su oficialia svetaine arba vietoj jos. Nustatykite WLM_LEXIFINA=0, kad tai išjungtumėte. Naudojimo skaičiai ir klaidų ataskaitos veikia tik jums sutikus (opt-in).

Fontes yra tyrimų pagalbininkas, o ne teisinė konsultacija, ir jo naudojimas nesukuria advokato ir kliento santykių. Jis teikiamas „tokia, kokia yra“ („as is“), be garantijų (žr. Apache 2.0 licenciją). Kai kurie šaltiniai yra aiškiai neoficialios versijos, ir kiekvienas turi savo naudojimo sąlygas; Fontes tai nurodo savo atsakymuose. Prieš remdamiesi perskaitykite visą sprendimą ar nuostatą. Fontes yra nepriklausomas ir nesusijęs su jokiu teismu, vyriausybe ar leidėju.

Diegimas

  • Claude Desktop: atsisiųskite Fontes .mcpb failą iš naujausios versijos, dukart jį spustelėkite, tada spustelėkite Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline ir kitos programos: pridėkite Fontes prie programos MCP nustatymų. Dauguma priima šį įrašą; diegimo vadove nurodytas kiekvienos programos failas ir fragmentas.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx pateikiamas kartu su uv. macOS arba Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Tada paleiskite programą iš naujo ir paklauskite: „Kuriose jurisdikcijose gali ieškoti Fontes?“

Mac arba Windows kompiuteryje diegimo programa vienu spustelėjimu nustato Fontes programose Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio ir Cline – kiekvienoje, kuri yra jūsų kompiuteryje, – ir pasiūlo pridėti jūsų raktus. Atsisiųskite diegimo programą savo kompiuteriui iš naujausios laidos ir, prieš ją paleisdami, uždarykite tas programas. Išsamiau – diegimo vadove. Kai kuriems šaltiniams reikia nemokamo rakto: žr. KEYS.md.

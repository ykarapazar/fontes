# Fontes: မေးခွန်းများနှင့် အဖြေများ

## Fontes ဆိုသည်မှာ အဘယ်နည်း

အခမဲ့ open-source MCP server တစ်ခု (Apache 2.0)။ ၎င်းသည် Model Context Protocol ကို အသုံးပြုသော မည်သည့်အက်ပ်ကိုမဆို
(Claude, Codex, Cursor, VS Code, Gemini CLI နှင့် အခြား) စီရင်ပိုင်ခွင့်နယ်မြေနှင့် နိုင်ငံတကာတရားရုံး 120+ ရှိ
တရားရုံးနှင့် အစိုးရ ဝက်ဘ်ဆိုက်များပေါ်တွင် တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို တိုက်ရိုက် ရှာဖွေနိုင်စေသည် (adapter 124 ခု)။
ရလဒ်တိုင်းသည် ၎င်း၏ရင်းမြစ်ကို ဖော်ပြပြီး မူရင်းသို့ လင့်ခ်ချိတ်သည်။

## စာသားများသည် တရားဝင်ပါသလား

အများအားဖြင့် ဟုတ်သည်၊ သို့သော် အမြဲတမ်း မဟုတ်ပါ။

- ရင်းမြစ်အများစုကို တရားရုံး၊ ဝန်ကြီးဌာန သို့မဟုတ် တရားဝင်ပြန်တမ်းက လည်ပတ်သည်။
- ပြင်ဆင်ချက်များ ပေါင်းစည်းထားသော စာသားအချို့ကို အစိုးရက ထုတ်ဝေသော်လည်း တရားဝင်မဟုတ်ကြောင်း ထင်ရှားစွာ ဖော်ပြထားသည်: တရားဝင်ပြန်တမ်းသာ
  စစ်မှန်သည်။
- ရင်းမြစ်အနည်းငယ်မှာ အစိုးရဆိုက်များ လုံးဝမဟုတ်ပါ (ဥပမာ LexiVox, LawPhil, Maqam,
  Wikisource)။

Fontes သည် ဤရင်းမြစ်များထဲမှ တစ်ခုမှ လာသော အဖြေတိုင်းတွင် "တရားဝင်မဟုတ်သော ရင်းမြစ်" သတိပေးချက်ကို ထည့်သည်။ မည်သည့်အရာကိုမဆို
မကိုးကားမီ တရားဝင်ထုတ်ဝေချက်ကို စစ်ဆေးပါ။ [README](README.md#လွှမ်းခြုံမှု) ရှိ လွှမ်းခြုံမှုဇယားနှင့်
`list_jurisdictions` က စီရင်ပိုင်ခွင့်နယ်မြေတစ်ခုချင်းစီ၏ ရင်းမြစ်ကို ဖော်ပြသည်။

## မည်သည့် စီရင်ပိုင်ခွင့်နယ်မြေများကို မည်မျှကောင်းစွာ လွှမ်းခြုံသနည်း

adapter 124 ခု: ကုလသမဂ္ဂအဖွဲ့ဝင်နိုင်ငံ 108 ခု၊ ဟောင်ကောင်၊ ကိုဆိုဗို၊ ပါလက်စတိုင်း၊ ထိုင်ဝမ်၊ DIFC Courts နှင့်
နိုင်ငံတကာတရားရုံးနှင့် အဖွဲ့အစည်း 11 ခု (ဥပမာ ဥရောပ လူ့အခွင့်အရေးတရားရုံး၊ EU၊
ICJ နှင့် WTO)။

လွှမ်းခြုံမှုသည် အလွန်ကွာခြားသည်။ တင်းကျပ်သော စည်းမျဉ်းအောက်တွင် (အမြင့်ဆုံး အထွေထွေတရားရုံး၏ စီရင်ထုံးများ၊ သို့မဟုတ်
ဖွဲ့စည်းပုံအခြေခံဥပဒေနှင့် အခြေခံဥပဒေများကို အပြည့်အဝ ရောက်ရှိခြင်း) 124 ခုအနက် 72 ခုကို လွှမ်းခြုံထားသည်ဟု သတ်မှတ်သည်။
[COVERAGE.md](../../COVERAGE.md) က စီရင်ပိုင်ခွင့်နယ်မြေတစ်ခုချင်းစီအတွက် Fontes ရောက်ရှိသည့်အရာ၊ မရောက်ရှိသည့်အရာနှင့်
အကြောင်းရင်းကို စာရင်းပြုထားသည်။

## API ကီး လိုအပ်ပါသလား

စီရင်ပိုင်ခွင့်နယ်မြေ အားလုံးနီးပါးအတွက် မလိုပါ။ ရင်းမြစ်အချို့သည် အခမဲ့ကီး လိုအပ်သည်: [KEYS.md](KEYS.md) ကို ကြည့်ပါ။

- **ပြင်သစ်:** လိုအပ်သည်။ `WLM_FR_PISTE_CLIENT_ID` နှင့်
  `WLM_FR_PISTE_CLIENT_SECRET` ကို သတ်မှတ်မချင်း ပြင်သစ်ကို ပိတ်ထားသည်။ ၎င်းတို့သည် Judilibre နှင့် Légifrance သို့
  subscribe လုပ်ထားသော အက်ပ်ပါသည့် အခမဲ့ PISTE အကောင့် (piste.gouv.fr) မှ လာသည်။
- **အမေရိကန်ပြည်ထောင်စု:** မဖြစ်မနေ မဟုတ်ပါ။ တရားရုံးစီရင်ထုံး ရှာဖွေမှုသည် ကီးမပါဘဲ အလုပ်လုပ်သော်လည်း မျှဝေသုံး demo ကီးသည်
  IP လိပ်စာတစ်ခုလျှင် တစ်နေ့ ရှာဖွေမှု 10 ခုခန့်သာ ခွင့်ပြုသည်။ `WLM_US_GOVINFO_KEY` တွင် အခမဲ့ api.data.gov ကီးတစ်ခု
  ထည့်ခြင်းက ၎င်းကို မြှင့်တင်ပေးသည်။

၎င်းတို့ကို သင့်အက်ပ်၏ MCP ဆက်တင်များတွင် Fontes server အတွက် environment variable များအဖြစ် သတ်မှတ်ပါ။
တပ်ဆင်ရေးပရိုဂရမ် ထွက်ရှိပြီးနောက် ၎င်းသည် တပ်ဆင်ပြီးနောက် ၎င်းတို့ကို မေးမည်ဖြစ်ပြီး ၎င်း၏ **Add or change keys** launcher က
နောက်ပိုင်းတွင် ၎င်းတို့ကို ပြောင်းလဲပေးသည်။

သီးခြားအနေဖြင့် ရင်းမြစ်အနည်းငယ်က ၎င်းတို့၏ စည်းကမ်းချက်များတွင် အလိုအလျောက်ဝင်ရောက်မှုသည် ထုတ်ဝေသူ၏
ခွင့်ပြုချက် လိုအပ်သည်ဟု ဆိုထားသည်။ ၎င်းတို့ကို OFF ဟု အမှတ်အသားပြုထားပြီး ပိတ်ထားဆဲ ဖြစ်သည်။ ကီးတစ်ခုက ထိုအရာကို မပြောင်းလဲပါ၊
ထုတ်ဝေသူ၏ ခွင့်ပြုချက်ကသာ ပြောင်းလဲသည် (ထို့နောက် `WLM_PERMITTED=<codes>` ကို သတ်မှတ်ပါ)။

## ကျွန်ုပ်၏ကွန်ပျူတာမှ မည်သည့်အရာ ထွက်သွားသနည်း

သင်၏ ရှာဖွေမှုများသည် ရှာဖွေနေသော ရင်းမြစ်သို့သာ သွားသည်။ Fontes သည် ဒေတာဘေ့စ် မထားပါ၊
အကောင့်လည်း မလိုပါ။

ရင်းမြစ်များအပြင် Fontes သည် ဗားရှင်းအသစ် ရှိမရှိကို PyPI ကို တစ်နေ့တစ်ကြိမ် မေးသည် (၎င်းကို
`FONTES_NO_UPDATE_CHECK=1` ဖြင့် ပိတ်ပါ)။ အသုံးပြုမှုအရေအတွက်များကို သင်မဖွင့်မချင်း ပိတ်ထားပြီး ချို့ယွင်းချက်အစီရင်ခံစာကို
သင်မြင်ပြီး အတည်ပြုမှသာ ပေးပို့သည်။ သင်၏ AI အက်ပ်သည် သင်၏စကားဝိုင်းကို ၎င်း၏ကိုယ်ပိုင်စည်းကမ်းချက်များအောက်တွင်
မြင်ရသည်။

အသေးစိတ်အပြည့်အစုံ: [PRIVACY.md](PRIVACY.md)။

## ဤအရာသည် ဥပဒေဆိုင်ရာ အကြံဉာဏ်လား

မဟုတ်ပါ။ Fontes သည် သုတေသနကိရိယာ ဖြစ်သည်။ ၎င်းသည် စာသားများကို ရှာပေးသည်၊ ၎င်းတို့သည် သင့်အမှုအတွက် မည်သည့်အဓိပ္ပာယ်ရှိသည်ကို
မပြောပါ၊ ၎င်းကို အသုံးပြုခြင်းသည် မည်သူနှင့်မျှ ရှေ့နေ–အမှုသည် ဆက်ဆံရေး မဖန်တီးပါ။ AI အက်ပ်သည်
စာသားကို မှားယွင်းစွာ ဖတ်နိုင်သောကြောင့် အားမကိုးမီ စီရင်ချက် သို့မဟုတ် ပြဋ္ဌာန်းချက်အပြည့်အစုံကို ဖတ်ပါ။ အကြံဉာဏ်အတွက်
သင့်မေးခွန်း ပေါ်ပေါက်သည့်နေရာတွင် အရည်အချင်းပြည့်မီသော ရှေ့နေကို မေးပါ။

## မည်သူ ထိန်းသိမ်းသနည်း။ ၎င်းသည် ဆက်လက်အလုပ်လုပ်မည်လား

လူတစ်ဦးတည်း: Yüce Karapazar။ Fontes နောက်ကွယ်တွင် ကုမ္ပဏီ မရှိပါ၊ ပံ့ပိုးမှုစာချုပ် မရှိပါ၊
ဝန်ဆောင်မှုအဆင့် ကတိကဝတ် မရှိပါ။ ဥပဒေဆိုင်ရာ ဝန်ဆောင်မှု မည်သည့်အရာမျှ မပေးပါ။

ရင်းမြစ်များကို တစ်နေ့တစ်ကြိမ် စစ်ဆေးပြီး ရလဒ်များကို
[အခြေအနေစာမျက်နှာ](https://ykarapazar.github.io/fontes/status/) တွင် ထုတ်ဝေသည်။ တရားရုံးနှင့် အစိုးရ ဝက်ဘ်ဆိုက်များသည်
ကြိုတင်အသိပေးချက်မရှိဘဲ ပြောင်းလဲသောကြောင့် ရင်းမြစ်တစ်ခုသည် အချိန်မရွေး ပျက်စီးနိုင်သည်။ မည်သည့်ရင်းမြစ်ကမျှ သို့မဟုတ်
Fontes ကိုယ်တိုင်က ဆက်လက်အလုပ်လုပ်မည်ဟု အာမခံချက် မရှိပါ။ Fontes ကို "ရှိသည့်အတိုင်း" (as is) အာမခံချက်မပါဘဲ ပေးထားသည် ([LICENSE](../../../LICENSE) ၏
အပိုင်း 7 နှင့် 8)။

## စာသားတစ်ခု မှားနေသည်၊ ခေတ်နောက်ကျနေသည် သို့မဟုတ် ရင်းမြစ်တစ်ခု ပျက်နေသည်။ မည်သို့ အစီရင်ခံရမည်နည်း

- "Broken or wrong source" ဖောင်ဖြင့် issue တစ်ခု ဖွင့်ပါ:
  <https://github.com/ykarapazar/fontes/issues/new/choose>။ မည်သည့် စီရင်ပိုင်ခွင့်နယ်မြေ၊ သင်ဘာမေးခဲ့သည်၊
  သင်ဘာရခဲ့သည်နှင့် မှန်ကန်သောစာသားကို ပြသော တရားဝင်စာမျက်နှာကို ဖော်ပြပါ။
- သို့မဟုတ် သင်၏ AI အက်ပ်ကို "report a Fontes bug" ဟု မေးပါ (သို့မဟုတ် `fontes report-bug` ကို run ပါ)။ မည်သည့်အရာမဆို မပို့မီ
  သင်သည် အစီရင်ခံစာကို မြင်ရသည်။
- သို့မဟုတ် fontesmcp@proton.me သို့ အီးမေးလ်ပို့ပါ။

အစီရင်ခံစာတွင် အမှုသည်၏ အသေးစိတ်များ သို့မဟုတ် လျှို့ဝှက်အချက်အလက်များ မထည့်ပါနှင့်။

**သင်သည် ရင်းမြစ်များထဲမှ တစ်ခုကို လည်ပတ်သူဖြစ်ပြီး** တစ်စုံတစ်ရာ မှားယွင်းနေပါက (သင်၏စည်းကမ်းချက်များ၊ သင်၏ robots.txt၊ သင်၏ rate

## Fontes သည် host လုပ်ထားသော ဥပဒေသုတေသန ကိရိယာများနှင့် မည်သို့ကွာခြားသနည်း

- **၎င်းသည် သင့်ကွန်ပျူတာပေါ်တွင် run သည်။** Fontes server မရှိပါ၊ အကောင့် မရှိပါ။ ထို့ကြောင့်လည်း ၎င်းသည်
  local MCP server ကို စတင်နိုင်သော အက်ပ်များတွင်သာ (Claude Desktop, Codex, Cursor, VS Code
  နှင့် ဆင်တူသည်များ) အလုပ်လုပ်ပြီး host လုပ်ထားသော connector များကိုသာ လက်ခံသော web-only အက်ပ်များတွင် အလုပ်မလုပ်ပါ။
- **၎င်းတွင် ဒေတာဘေ့စ် မရှိပါ။** ရှာဖွေမှုတိုင်းသည် ထုတ်ဝေသူ၏ ကိုယ်ပိုင်ဝက်ဘ်ဆိုက် သို့မဟုတ် API သို့ တိုက်ရိုက်သွားသောကြောင့်
  ရလဒ်များသည် ရင်းမြစ်ကဲ့သို့ ခေတ်မီပြီး ရှာဖွေမှုအရည်အသွေးသည် ရင်းမြစ်၏ကိုယ်ပိုင် ဖြစ်သည်။ ရွေးချယ်စုစည်းထားသော
  index ပေါ်တွင် semantic ရှာဖွေမှု (အဓိပ္ပာယ်အခြေပြု ရှာဖွေမှု) မရှိပါ။
- **၎င်းသည် အသုံးပြုမှုကန့်သတ်ချက် မသတ်မှတ်ပါ။** Fontes တွင် လစဉ်ခေါ်ဆိုမှု ကန့်သတ်ချက် မရှိပါ။ ၎င်းသည်
  ဝက်ဘ်ဆိုက်တစ်ခုချင်းစီသို့ ၎င်း၏တောင်းဆိုမှုများကို အကွာအဝေးခြားပြီး ရင်းမြစ်အချို့က ၎င်းတို့ကို မည်မျှမြန်မြန် သို့မဟုတ်
  မည်မျှမကြာခဏ query လုပ်နိုင်သည်ကို ကန့်သတ်သည်။
- **၎င်းသည် open source ဖြစ်သည်။** adapter တိုင်းကို ဖတ်ပြီး စာသားတစ်ခုချင်းစီ မည်သည့်နေရာမှ လာသည်ကို အတိအကျ မြင်နိုင်သည်။
- **၎င်းနောက်ကွယ်တွင် vendor မရှိပါ။** စာချုပ်၊ ပံ့ပိုးမှုဌာန သို့မဟုတ် uptime ကတိကဝတ် မရှိပါ ("မည်သူ
  ထိန်းသိမ်းသနည်း" ကို ကြည့်ပါ)။

## မည်သည့်အက်ပ်များနှင့် စနစ်များနှင့် အလုပ်လုပ်သနည်း

local (stdio) server ကို run နိုင်သော မည်သည့် MCP အက်ပ်မဆို၊ ဥပမာ Claude Desktop, Claude Code,
Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio နှင့် Cline။ Fontes
သည် macOS, Windows နှင့် Linux တွင်၊ uv run နိုင်သည့် မည်သည့်နေရာတွင်မဆို (Python 3.13+) run သည်။ ၎င်းသည် PyPI တွင် မရှိသေးပါ၊
ရှိလာပြီးနောက် အက်ပ်အများစုသည် command တစ်ခု သို့မဟုတ် config entry တစ်ခုသာ လိုအပ်ပြီး Claude Desktop သည်
နှစ်ချက်နှိပ်ထားသော `.mcpb` ဖိုင်ကို လက်ခံသည်။ Mac နှင့် Windows အတွက် တစ်ချက်နှိပ် တပ်ဆင်ရေးပရိုဂရမ် လာမည်ဖြစ်သည်။ ၎င်းသည်
Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio နှင့်
Cline ကို တစ်ကြိမ်တည်းဖြင့် စနစ်ထည့်သွင်းပေးသည်။ အက်ပ်တစ်ခုချင်းစီအတွက် အဆင့်များ: [INSTALL.md](INSTALL.md)။

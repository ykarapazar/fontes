Fontes သည် အခမဲ့ open-source MCP server တစ်ခု ဖြစ်သည်။ ၎င်းသည် local Model Context Protocol server ကို run နိုင်သော မည်သည့်အက်ပ်တွင်မဆို အလုပ်လုပ်သည်: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio နှင့် အခြားအက်ပ်များ။ ဥပဒေဆိုင်ရာ မေးခွန်းကို သာမန်ဘာသာစကားဖြင့် မေးပါ: သင်၏ AI အက်ပ်သည် စီရင်ပိုင်ခွင့်နယ်မြေ 125 ခုနှင့် နိုင်ငံတကာတရားရုံးများရှိ အစိုးရနှင့် တရားရုံး ဝက်ဘ်ဆိုက်များပေါ်တွင် တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို တိုက်ရိုက် ရှာဖွေပြီး ရလဒ်တစ်ခုချင်းစီကို မူရင်းသို့ လင့်ခ်ချိတ်သည်။ ဥပဒေကို အတိတ်ရက်စွဲတစ်ခုတွင် ရှိခဲ့သည့်အတိုင်း ပြသနိုင်ပြီး၊ နိုင်ငံ 91 ခုထပ်၏ ဥပဒေများကို Lexifina ၏ record မှ ဖတ်နိုင်သည် (တရားဝင် ထုတ်ဝေသူ မဟုတ်ပါ)။ ၎င်းကို ရှေ့နေများနှင့် ဥပဒေသုတေသီများအတွက်နှင့် ဥပဒေကို ၎င်း၏ရင်းမြစ်မှ ဖတ်လိုသူ မည်သူမဆိုအတွက် ပြုလုပ်ထားသည်။

၎င်းလုပ်ဆောင်သည့်အရာ

  • သင်မေးသည့်အချိန်တွင် ထုတ်ဝေသူ၏ ကိုယ်ပိုင်ဝက်ဘ်ဆိုက် သို့မဟုတ် API မှ တရားရုံးစီရင်ထုံးများနှင့် ဥပဒေများကို ရှာဖွေသည်။
  • ရလဒ်တိုင်းသည် ၎င်း၏ရင်းမြစ်ကို ဖော်ပြပြီး မူရင်းကို စစ်ဆေးနိုင်ရန် ၎င်းသို့ လင့်ခ်ချိတ်သည်။
  • Fontes သည် ဒေတာဘေ့စ် မထားပါ၊ အကောင့်လည်း မလိုပါ။ သင်၏ မေးခွန်းများသည် ရှာဖွေနေသော ရင်းမြစ်သို့ သွားသည်၊ ဥပဒေများ၏ အတိတ်ဗားရှင်းများနှင့် နိုင်ငံ 91 ခုထပ် (နှင့် အိန္ဒိယ အက်ဥပဒေများ) အတွက်မူ Lexifina ၏ အများပြည်သူသုံးဝန်ဆောင်မှုသို့ သွားသည်၊ တရားဝင်ဆိုက်နှင့်အတူ သို့မဟုတ် ၎င်း၏ အစားဖြစ်သည်။ ထိုအရာကို ပိတ်လိုပါက WLM_LEXIFINA=0 ကို သတ်မှတ်ပါ။ အသုံးပြုမှုအရေအတွက်များနှင့် ချို့ယွင်းချက်အစီရင်ခံစာများသည် opt-in ဖြစ်သည်။

Fontes သည် သုတေသနအကူအညီ ဖြစ်ပြီး ဥပဒေဆိုင်ရာ အကြံဉာဏ် မဟုတ်ပါ၊ ၎င်းကို အသုံးပြုခြင်းသည် ရှေ့နေ–အမှုသည် ဆက်ဆံရေး မဖန်တီးပါ။ ၎င်းကို "ရှိသည့်အတိုင်း" (as is) အာမခံချက်မပါဘဲ ပေးထားသည် (Apache 2.0 လိုင်စင် ကို ကြည့်ပါ)။ ရင်းမြစ်အချို့သည် တရားဝင်မဟုတ်သော ဗားရှင်းများဟု ထင်ရှားစွာ ဖော်ပြထားပြီး ရင်းမြစ်တစ်ခုချင်းစီတွင် ၎င်း၏ကိုယ်ပိုင် အသုံးပြုမှုစည်းကမ်းချက်များ ရှိသည်၊ Fontes သည် ၎င်း၏အဖြေများတွင် ဤအရာကို ဖော်ပြသည်။ စီရင်ချက် သို့မဟုတ် ပြဋ္ဌာန်းချက်အပြည့်အစုံကို အားမကိုးမီ ဖတ်ပါ။ Fontes သည် လွတ်လပ်ပြီး မည်သည့်တရားရုံး၊ အစိုးရ သို့မဟုတ် ထုတ်ဝေသူနှင့်မျှ ဆက်နွယ်မှု မရှိပါ။

တပ်ဆင်ခြင်း

  • Claude Desktop: Fontes .mcpb ဖိုင်ကို နောက်ဆုံးထုတ်ဝေမှု မှ ဒေါင်းလုဒ်လုပ်ပါ၊ ၎င်းကို နှစ်ချက်နှိပ်ပါ၊ ထို့နောက် Install ကို နှိပ်ပါ။
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline နှင့် အခြားအက်ပ်များ: Fontes ကို အက်ပ်၏ MCP ဆက်တင်များတွင် ထည့်ပါ။ အများစုသည် ဤ entry ကို လက်ခံသည်၊ တပ်ဆင်ခြင်း လမ်းညွှန် တွင် အက်ပ်တစ်ခုချင်းစီအတွက် ဖိုင်နှင့် snippet ပါရှိသည်။
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx သည် uv နှင့်အတူ ပါလာသည်။ macOS သို့မဟုတ် Linux တွင်: curl -LsSf https://astral.sh/uv/install.sh | sh။ Windows (PowerShell) တွင်: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"။

> ဤသည်မှာ စက်အကူအညီဖြင့် ဘာသာပြန်ထားခြင်း ဖြစ်သည်။ အင်္ဂလိပ်ဗားရှင်းသာ အတည်ဖြစ်သည်။

# Fontes ကို တပ်ဆင်ခြင်း

Fontes သည် သင်၏ AI အက်ပ်အား စီရင်ပိုင်ခွင့်နယ်မြေ 120 ကျော်ရှိ တရားရုံးနှင့် အစိုးရ ဝက်ဘ်ဆိုက်များပေါ်တွင်
တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို တိုက်ရိုက် ရှာဖွေနိုင်စေသည်။ ရလဒ်တိုင်းသည် မူရင်းသို့ လင့်ခ်ချိတ်သည်။ ၎င်းသည် စံ MCP
server ဖြစ်သောကြောင့် local MCP server ကို run နိုင်သော မည်သည့်အက်ပ်တွင်မဆို အလုပ်လုပ်သည်: Claude Desktop, Codex, Claude
Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline နှင့် အခြားအက်ပ်များ။

သင့်အက်ပ်ကို ရွေးပါ၊ ၎င်း၏အဆင့်များကို လိုက်နာပါ၊ ထို့နောက် [အလုပ်လုပ်ကြောင်း စစ်ဆေးပါ](#အလုပ်လုပ်ကြောင်း-စစ်ဆေးခြင်း)။

## Claude Desktop

1. Fontes `.mcpb` ဖိုင်ကို
   [နောက်ဆုံးထုတ်ဝေမှု](https://github.com/ykarapazar/fontes/releases/latest) မှ ဒေါင်းလုဒ်လုပ်ပါ။
2. ၎င်းကို နှစ်ချက်နှိပ်ပါ။ Claude Desktop က ၎င်းကို ဖွင့်သည်။
3. **Install** ကို နှိပ်ပါ။

## Codex

terminal တွင်:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI နှင့် Codex IDE extension သည် ဤဆက်တင်ကို မျှဝေသုံးသည် (`~/.codex/config.toml`)။
[uv](#uv-လိုအပ်သည်) လိုအပ်သည်။

## Claude Code

terminal တွင်:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

[uv](#uv-လိုအပ်သည်) လိုအပ်သည်။

## အခြားအက်ပ်များ

ဤအက်ပ်တစ်ခုချင်းစီသည် [uv](#uv-လိုအပ်သည်) လိုအပ်သည်။ entry ကို ထည့်ပါ၊ သိမ်းပါ၊ ထို့နောက် အက်ပ်ကို ပိတ်ပြီး ပြန်ဖွင့်ပါ။

**Cursor:** `~/.cursor/mcp.json` (project အားလုံး) သို့မဟုတ် `.cursor/mcp.json` (project တစ်ခု) တွင်:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette မှ **MCP: Add Server** ကို run ပါ၊
**Command (stdio)** ကို ရွေးပါ၊ `uvx fontes-mcp` ကို ထည့်ပြီး server ကို `fontes` ဟု အမည်ပေးပါ။ သို့မဟုတ် ဤအရာကို
`~/.copilot/mcp-config.json` တွင် ထည့်ပါ:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code ၏ ယခင်စနစ်ထည့်သွင်းမှုများသည် `.vscode/mcp.json` ကို အသုံးပြုပြီး ထိုနေရာတွင် top-level key မှာ `mcpServers` အစား
`servers` ဖြစ်သည်။

**Gemini CLI:** terminal တွင် `gemini mcp add -s user fontes uvx fontes-mcp`။ သို့မဟုတ် ဤအရာကို
`~/.gemini/settings.json` တွင် ထည့်ပါ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** သင်၏ ဆက်တင်ဖိုင်ကို ဖွင့်ပါ (**zed: open settings file**) ပြီး ထည့်ပါ:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** ညာဘက် sidebar တွင် **Program** tab ကို ဖွင့်ပါ၊ **Install → Edit
mcp.json** ကို နှိပ်ပြီး ထည့်ပါ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** icon ကို နှိပ်ပါ၊ **Configure** tab ကို ဖွင့်ပါ၊ **Configure MCP
Servers** ကို နှိပ်ပြီး LM Studio အတွက်ကဲ့သို့ တူညီသော `mcpServers` entry ကို ထည့်ပါ။

**Claude Desktop၊ လက်ဖြင့်** (`.mcpb` ဖိုင်အစား): တူညီသော `mcpServers` entry ကို
`claude_desktop_config.json` တွင် ထည့်ပါ (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`)။

**အခြားမည်သည့် MCP အက်ပ်မဆို** (Windsurf နှင့် အခြား): ၎င်း၏ကိုယ်ပိုင် documentation က ၎င်း၏ MCP server များကို
မည်သည့်နေရာတွင် သိမ်းသည်ကို ဖော်ပြသည်။ အများစုသည် တူညီသော entry ကို လက်ခံသည်: command `uvx`, argument `fontes`။

အက်ပ်က `uvx` ကို ရှာမတွေ့ပါက ၎င်း၏ လမ်းကြောင်းအပြည့်အစုံကို အသုံးပြုပါ (macOS နှင့် Linux တွင် `which uvx` က ၎င်းကို ပြသည်)။

## uv လိုအပ်သည်

Codex, Claude Code နှင့် အခြားအက်ပ်များသည် Fontes ကို `uvx` ဖြင့် စတင်ပြီး ၎င်းသည် Astral ၏ အခမဲ့ ကိရိယာငယ်တစ်ခု ဖြစ်သော
**uv** နှင့်အတူ ပါလာသည်။ ၎င်းကို တပ်ဆင်ရန်
[Astral ၏ လမ်းညွှန်](https://docs.astral.sh/uv/getting-started/installation/) ကို ကြည့်ပါ၊ သို့မဟုတ် run ပါ:

- macOS သို့မဟုတ် Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## ကီးများ

ရင်းမြစ်အချို့သည် အခမဲ့ကီး လိုအပ်သည်: [KEYS.md](KEYS.md) ကို ကြည့်ပါ။

## အလုပ်လုပ်ကြောင်း စစ်ဆေးခြင်း

chat အသစ်တစ်ခုတွင် မေးပါ: *"Fontes က မည်သည့် စီရင်ပိုင်ခွင့်နယ်မြေများတွင် ရှာဖွေနိုင်သနည်း။"* အက်ပ်သည် နိုင်ငံများစာရင်းဖြင့်
ဖြေသင့်သည်။ မဖြေပါက အက်ပ်ကို နောက်တစ်ကြိမ် ပိတ်ပြီး ပြန်ဖွင့်ပါ။

## တစ်ချက်နှိပ် တပ်ဆင်ရေးပရိုဂရမ် (Mac)

Mac တပ်ဆင်ရေးပရိုဂရမ်သည် Fontes ကို သင့်အက်ပ်အားလုံးတွင် တစ်ပြိုင်နက် စနစ်ထည့်သွင်းပေးသည်- Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio နှင့် Cline။
Windows တပ်ဆင်ရေးပရိုဂရမ် လာမည်ဖြစ်သည်။ ထိုအချိန်အထိ အထက်ပါ သင့်အက်ပ်အတွက် အဆင့်များကို အသုံးပြုပါ။

**မစတင်မီ:** ဤအက်ပ်တစ်ခုချင်းစီကို လုံးဝပိတ်ပါ။ ဤအချက်သည် Claude Code အတွက် အရေးကြီးဆုံး ဖြစ်သည်:
၎င်း run နေစဉ် ၎င်းသည် `~/.claude.json` ကို ပြန်ရေးပြီး တပ်ဆင်ရေးပရိုဂရမ်၏ ပြောင်းလဲမှုကို ပြန်ဖျက်နိုင်သည်။ Claude Code ကို
မပိတ်နိုင်ပါက ၎င်းအစား `claude mcp add` ဖြင့် Fontes ကို ထည့်ပါ ([Claude Code](#claude-code) ကို ကြည့်ပါ)။

**Mac**

1. Mac တပ်ဆင်ရေးပရိုဂရမ် (`Fontes-Installer-…-mac.zip`) ကို [နောက်ဆုံးထုတ်ဝေမှု](https://github.com/ykarapazar/fontes/releases/latest) မှ
   ဒေါင်းလုဒ်လုပ်ပြီး ဇစ်ဖြည်ရန် ၎င်းကို နှစ်ချက်နှိပ်ပါ။
2. **Fontes Installer** ကို နှစ်ချက်နှိပ်ပါ။ အင်တာနက်မှ ဒေါင်းလုဒ်လုပ်ထားသော အက်ပ်ကို ဖွင့်မလား သင့် Mac က မေးပါက
   **Open** ကို နှိပ်ပါ။
3. **တပ်ဆင်ရန်** ကို ရွေးပြီး **OK** ကို နှိပ်ပါ။ စနစ်ထည့်သွင်းခြင်းသည် တစ်မိနစ်ခန့် ကြာသည်။
4. စနစ်ထည့်သွင်းပေးခဲ့သော အက်ပ်များကို မက်ဆေ့ချ်တစ်ခုက ဖော်ပြသည်။ **ပြီးပါပြီ** ကို နှိပ်ပြီး ထိုအက်ပ်များကို ပြန်ဖွင့်ပါ။
   ရွေးချယ်နိုင်သော အခမဲ့ကီးများကို ဦးစွာ ထည့်လိုပါက ၎င်းအစား **ကီးများ ထည့်ရန်** ကို နှိပ်ပါ၊
   [ကီးထည့်သည့်အဆင့်](#ကီးထည့်သည့်အဆင့်) ကို ကြည့်ပါ။

**Windows** (Windows တပ်ဆင်ရေးပရိုဂရမ် ထွက်ရှိပြီးနောက်)

1. ဒေါင်းလုဒ်လုပ်ထားသော **Fontes Installer** ကို unzip လုပ်ပါ (right-click → Extract All)။
2. **Install Fontes.cmd** ကို နှစ်ချက်နှိပ်ပါ။
   - Windows က "Windows protected your PC" ဟု ပြပါက: **More info** ကို နှိပ်ပါ၊ ထို့နောက် **Run anyway** ကို နှိပ်ပါ။
3. အမည်မဖော်သော အသုံးပြုမှုအရေအတွက်များ ပေးပို့မလား မေးသည့်အခါ မပို့လိုပါက Enter ကို နှိပ်ပါ။
4. ၎င်းသည် ကီးများကို ယခု ထည့်မလား မေးသည်။ ကျော်ရန် Enter ကို နှိပ်ပါ၊ [ကီးထည့်သည့်အဆင့်](#ကီးထည့်သည့်အဆင့်) ကို ကြည့်ပါ။
5. ၎င်းက **Done** ဟု ပြသည့်အခါ သင်၏ AI အက်ပ်များကို ပြန်ဖွင့်ပါ။ တစ်ခုခု run နေဆဲဖြစ်ခဲ့ပါက ၎င်းကို
   လုံးဝပိတ်ပါ (နာရီအနီးရှိ system tray မှလည်း) ပြီး ပြန်ဖွင့်ပါ။

အဆုံးတွင် တပ်ဆင်ရေးပရိုဂရမ်သည် ၎င်းစနစ်ထည့်သွင်းခဲ့သော အက်ပ်များကို စာရင်းပြသည်။

### မည်သည့်အက်ပ်များကို စနစ်ထည့်သွင်းသနည်း

အက်ပ်တစ်ခု၏ ဆက်တင်ဖိုင်တွဲသည် သင့်ကွန်ပျူတာပေါ်တွင် ရှိပြီးသားဖြစ်မှသာ ၎င်းကို စနစ်ထည့်သွင်းသည်။ Claude Code ကို
`~/.claude.json` ရှိမှသာ စနစ်ထည့်သွင်းသည်။ Claude Desktop ကို အမြဲ စနစ်ထည့်သွင်းသည်။ အက်ပ်တစ်ခုချင်းစီသည် ဤဖိုင်တွင်
entry တစ်ခု၊ `fontes` ကို ရရှိသည်:

| အက်ပ် | ဖိုင် (Mac နှင့် Linux) | ဖိုင် (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`၊ နှင့် Microsoft Store ဗားရှင်း၏ ကိုယ်ပိုင်မိတ္တူ |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`၊ သို့မဟုတ် ယခင်ဗားရှင်းများတွင် `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json`၊ သို့မဟုတ် `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

`~/.copilot` သို့မဟုတ် VS Code ၏ ကိုယ်ပိုင်ဆက်တင်ဖိုင်တွဲ ရှိပါက VS Code ကို စနစ်ထည့်သွင်းသည်။

အက်ပ်နှစ်ခုသည် နောက်ထပ်အဆင့်တစ်ခု လိုအပ်သည်:

- **Windsurf:** ၎င်းကို ပြန်ဖွင့်ပြီးနောက် Cascade တွင် refresh ကို နှိပ်ပါ။
- **ယခင် VS Code extension အတွင်းရှိ Cline:** Fontes ကို လက်ဖြင့် ထည့်ပါ ([Cline](#အခြားအက်ပ်များ) ကို ကြည့်ပါ)။

### ကီးထည့်သည့်အဆင့်

တပ်ဆင်ပြီးချင်း တပ်ဆင်ရေးပရိုဂရမ်သည် ပြင်သစ်နှင့် US အခမဲ့ကီးများကို ထည့်ရန် ကမ်းလှမ်းသည်။ ၎င်းတို့ကို နောက်မှ ထည့်ရန် သို့မဟုတ်
ပြောင်းရန်:

- **Mac:** **Fontes Installer** ကို ပြန်ဖွင့်ပြီး **ကီးများ ထည့်ရန် သို့မဟုတ် ပြောင်းရန်** ကို ရွေးပါ။
- **Windows:** တပ်ဆင်ရေးပရိုဂရမ်ဖိုင်တွဲရှိ **Add or change keys.cmd** ကို နှစ်ချက်နှိပ်ပါ။

ရိုက်ထည့်သည့်စာသားကို ဖုံးကွယ်ထားသည်။ ကီးများသည် Fontes ရှိပြီးသား အက်ပ်တိုင်းထဲသို့ ရောက်သွားသည်။ ထို့နောက် အက်ပ်များကို
ပိတ်ပြီး ပြန်ဖွင့်ပါ။ ကီးများကို မည်သည့်နေရာမှ ရယူရမည်နှင့် ၎င်းတို့က မည်သည်ကို ဖွင့်ပေးသည်: [KEYS.md](KEYS.md)။

### Backup များ၊ ထပ်မံ run ခြင်းနှင့် ဖယ်ရှားခြင်း

တပ်ဆင်ရေးပရိုဂရမ်သည် `fontes` entry ကိုသာ ပြောင်းလဲသည်။ အခြားဆက်တင်နှင့် comment အားလုံးသည် မူလအတိုင်း ရှိနေသည်။
ဖိုင်တစ်ခုကို မပြောင်းမီ ၎င်းသည် `<file>.fontes-backup-<date>` အမည်ဖြင့် မိတ္တူတစ်ခုကို ၎င်းဘေးတွင် သိမ်းသည်။ သင်ကီးများ
ထည့်ပြီးနောက် ပြုလုပ်ထားသော မိတ္တူများတွင် ထိုကီးများ ပါဝင်သည်: မလိုအပ်တော့သည့်အရာများကို ဖျက်ပါ။ ၎င်းသည် uv ကိုလည်း
တပ်ဆင်သည်။ ၎င်းကို ထပ်မံ run ခြင်းသည် ဘေးကင်းသည်: ၎င်းသည် စနစ်ထည့်သွင်းမှုကို ပြုပြင်ပြီး အခြားမည်သည့်အရာကိုမျှ မပြောင်းလဲပါ။

Fontes ကို ဖယ်ရှားရန် **Fontes Installer** ကို ဖွင့်ပြီး **ဖယ်ရှားရန်** ကို ရွေးပါ (Mac)၊ သို့မဟုတ် **Uninstall Fontes.cmd**
(Windows) ကို နှစ်ချက်နှိပ်ပါ။ ၎င်းသည် `fontes` entry ကို ကီးများအပါအဝင် အက်ပ်တိုင်းမှ ဖယ်ရှားသည်။ သင်၏ အခြားဆက်တင်များနှင့်
backup မိတ္တူများ ဆက်ရှိနေသည်။

## အပ်ဒိတ်များ

- **တပ်ဆင်ရေးပရိုဂရမ်နှင့် `.mcpb` ဖိုင်:** သင် ဘာမှ လုပ်စရာမလိုပါ။ တစ်နေ့တစ်ကြိမ်၊ အက်ပ်
  စတင်သည့်အခါ Fontes သည် ဗားရှင်းအသစ်ကို နောက်ကွယ်တွင် စစ်ဆေးပြီး အသင့်ပြင်ထားသည်၊ နောက်တစ်ကြိမ်
  အက်ပ်စတင်သည့်အခါ ၎င်းကို အသုံးပြုသည်။ အပ်ဒိတ်ကို ဒေါင်းလုဒ်လုပ်၍မရပါက သို့မဟုတ် အလုပ်မလုပ်ပါက Fontes သည်
  အလုပ်လုပ်ခဲ့သော ဗားရှင်းကို ဆက်သုံးသည်။
- **`uvx`:** ဗားရှင်းအသစ် ရရှိနိုင်သည့်အခါ Fontes သည် ၎င်း၏ စီရင်ပိုင်ခွင့်နယ်မြေစာရင်း၏ ထိပ်တွင် သင့်ကို
  အသိပေးသည်။ နောက်ဆုံးဗားရှင်းကို အမြဲ run ရန် `fontes-mcp` အစား `fontes-mcp@latest` ကို အသုံးပြုပါ။

ဤအတွက် သင် သို့မဟုတ် သင်၏ ရှာဖွေမှုများနှင့်ပတ်သက်သည့် မည်သည့်အချက်အလက်ကိုမျှ မည်သည့်နေရာသို့မျှ မပို့ပါ။

## ကိုယ်ရေးအချက်အလက် လုံခြုံမှု

Fontes သည် မူလအားဖြင့် သင် သို့မဟုတ် သင်၏ ရှာဖွေမှုများနှင့်ပတ်သက်၍ ဘာမှ မပို့ပါ။ အသုံးပြုမှုအရေအတွက်များသည် opt-in ဖြစ်ပြီး ချို့ယွင်းချက်
အစီရင်ခံစာကို သင်မြင်ပြီး အတည်ပြုမှသာ ပေးပို့သည်။ အသေးစိတ်: [PRIVACY.md](PRIVACY.md)။

## ဖယ်ရှားခြင်း

သင့်အက်ပ်၏ MCP ဆက်တင်များမှ `fontes` entry ကို ဖယ်ရှားပါ (Claude Code တွင်:
`claude mcp remove fontes`)၊ ထို့နောက် အက်ပ်ကို ပိတ်ပြီး ပြန်ဖွင့်ပါ။

## သိထားသင့်သည်များ

Fontes သည် အများပြည်သူ ရင်းမြစ်များကို ဖတ်သည်၊ အများစုမှာ တရားရုံးနှင့် အစိုးရ ဝက်ဘ်ဆိုက်များ ဖြစ်သည်။ ၎င်းသည် တရားဝင်မဟုတ်သော ရင်းမြစ်များကို
၎င်း၏အဖြေများတွင် အမှတ်အသားပြုသည်။ စီရင်ချက် သို့မဟုတ် ပြဋ္ဌာန်းချက်တစ်ခုကို အားမကိုးမီ ရင်းမြစ်လင့်ခ်ကို အမြဲဖွင့်ပါ။

တစ်စုံတစ်ရာ မှားယွင်းပါက သင်လုပ်ခဲ့သည့်အရာနှင့် သင်မြင်ခဲ့သော error ကို fontesmcp@proton.me သို့ အီးမေးလ်ပို့ပါ။

## ၎င်းကို အားမကိုးမီ

- ၎င်းကို "ရှိသည့်အတိုင်း" (as is) မည်သည့်အာမခံချက်မျှ မပါဘဲ ပေးထားပြီး ၎င်း၏ ရေးသားသူများသည် ဥပဒေက ခွင့်ပြုသလောက်
  ၎င်းကို မည်သို့အသုံးပြုသည်အတွက် တာဝန်မရှိပါ။ စည်းကမ်းချက်အပြည့်အစုံသည် [လိုင်စင်](../../../LICENSE) (Apache 2.0) တွင် ရှိသည်။

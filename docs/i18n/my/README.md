Fontes သည် အခမဲ့ open-source MCP server တစ်ခု ဖြစ်သည်။ ၎င်းသည် သင်၏ AI အက်ပ်အား စီရင်ပိုင်ခွင့်နယ်မြေနှင့်
နိုင်ငံတကာတရားရုံး 120 ကျော်ရှိ **အစိုးရနှင့် တရားရုံး ဝက်ဘ်ဆိုက်များပေါ်တွင် တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို
တိုက်ရိုက် ရှာဖွေနိုင်စေသည်**။ ရလဒ်တိုင်းတွင် မူရင်းသို့ လင့်ခ် ပါရှိသည်။ ၎င်းသည် စံ Model Context Protocol (MCP)
server ဖြစ်သောကြောင့် local MCP server ကို run နိုင်သော မည်သည့်အက်ပ်တွင်မဆို အလုပ်လုပ်သည်: Claude Desktop, Claude Code,
OpenAI Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio နှင့် အခြားအက်ပ်များ။

- **ရှေ့နေများနှင့် သုတေသီများအတွက်:** သာမန်ဘာသာစကားဖြင့် မေးပါ။ သင်၏ AI အက်ပ်သည် တရားဝင်ရင်းမြစ်တွင်
  ရှာဖွေပြီး တွေ့ရှိသည့်အရာမှ ရင်းမြစ်လင့်ခ်နှင့်အတူ ကိုးကားဖော်ပြသည်။
- **Developer များအတွက်:** ပုံသေ သုတေသနကိရိယာ ခုနစ်ခု (နှင့် `report_bug`) ပါသော MCP server တစ်ခု၊ စီရင်ပိုင်ခွင့်နယ်မြေသည်
  parameter တစ်ခု ဖြစ်သောကြောင့် နိုင်ငံများ ထပ်ထည့်ခြင်းက ကိရိယာများကို မတိုးစေပါ။ Python, Apache 2.0။

## အမြန်စတင်ရန်

Fontes သည် **PyPI တွင် မရှိသေးပါ**။ အောက်ပါအဆင့်များသည် ပထမဆုံး ထုတ်ဝေမှု ထွက်ရှိပြီးမှ အလုပ်လုပ်ပါမည်။

1. **Fontes ကို သင့်အက်ပ်သို့ ထည့်ပါ။**
   - **Claude Desktop:** Fontes `.mcpb` ဖိုင်ကို
     [နောက်ဆုံးထုတ်ဝေမှု](https://github.com/ykarapazar/fontes/releases/latest) မှ ဒေါင်းလုဒ်လုပ်ပါ၊ ၎င်းကို နှစ်ချက်နှိပ်ပါ၊
     ထို့နောက် **Install** ကို နှိပ်ပါ။
   - **Codex:** `codex mcp add fontes -- uvx fontes-mcp`
   - **Claude Code:** `claude mcp add fontes -- uvx fontes-mcp`
   - **Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline နှင့် အခြားအက်ပ်များ:** သင့်အက်ပ်အတွက် snippet ကို
     [INSTALL.md](INSTALL.md#အခြားအက်ပ်များ) မှ ကူးထည့်ပါ။

   `uvx` သည် [uv](https://docs.astral.sh/uv/getting-started/installation/) နှင့်အတူ ပါလာသည်။ macOS သို့မဟုတ် Linux တွင်
   uv ကို တပ်ဆင်ရန်: `curl -LsSf https://astral.sh/uv/install.sh | sh`။ Windows
   (PowerShell) တွင်: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`။
2. **အက်ပ်ကို ပြန်စတင်ပါ။** ၎င်းကို လုံးဝပိတ်ပြီး ပြန်ဖွင့်ပါ။
3. **မေးပါ:** *"Fontes က မည်သည့် စီရင်ပိုင်ခွင့်နယ်မြေများတွင် ရှာဖွေနိုင်သနည်း။"* ၎င်းသည် နိုင်ငံများကို စာရင်းပြသင့်သည်။

Mac နှင့် Windows အတွက် တစ်ချက်နှိပ် တပ်ဆင်ရေးပရိုဂရမ် လာမည်ဖြစ်သည်။ ၎င်းသည် Fontes ကို Claude Desktop,
Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio နှင့် Cline တွင် — သင့်ကွန်ပျူတာပေါ်ရှိ
တစ်ခုချင်းစီတွင် — စနစ်ထည့်သွင်းပေးပြီး ထို့နောက် သင့်ကီးများကို ထည့်ရန် ကမ်းလှမ်းသည်။ ၎င်းကို run မီ ထိုအက်ပ်များကို ပိတ်ပါ။
အသေးစိတ်: [INSTALL.md](INSTALL.md#တစ်ချက်နှိပ်-တပ်ဆင်ရေးပရိုဂရမ်-လာမည်)။

## လုပ်ဆောင်သည့်အရာနှင့် မလုပ်ဆောင်သည့်အရာ

- **လုပ်ဆောင်သည်:** သင်မေးသည့်အချိန်တွင် ထုတ်ဝေသူ၏ ကိုယ်ပိုင်ဝက်ဘ်ဆိုက် သို့မဟုတ် API မှ တိုက်ရိုက်ရယူသည်။ ရလဒ်
  တိုင်းသည် ၎င်း၏ရင်းမြစ်ကို ဖော်ပြပြီး မူရင်းကို ဖွင့်နိုင်ရန် ၎င်း၏ URL သို့မဟုတ် တရားဝင် identifier
  ပါရှိသည်။
- **မလုပ်ဆောင်ပါ:** ဒေတာဘေ့စ် မထားပါ၊ အစုလိုက် ဒေါင်းလုဒ် မလုပ်ပါ၊ စာသားများကို disk ပေါ်တွင် cache မလုပ်ပါ၊ သင်၏
  မေးခွန်းများကို ရှာဖွေနေသော ရင်းမြစ်မှလွဲ၍ မည်သည့်နေရာသို့မျှ မပို့ပါ။ အကောင့် မလိုပါ။ ရင်းမြစ်များအပြင်
  Fontes သည် PyPI နှင့် တစ်နေ့တစ်ကြိမ် ဗားရှင်းစစ်ဆေးမှု ပြုလုပ်သည် (`FONTES_NO_UPDATE_CHECK=1` ဖြင့် ပိတ်နိုင်သည်)၊
  အခြားမည်သည့်အရာမဆို (အသုံးပြုမှုအရေအတွက်၊ ချို့ယွင်းချက်အစီရင်ခံစာ) သည် opt-in ဖြစ်ပြီး သင့်ကို ဦးစွာ မေးမြန်းသည်။
- **မပေးပါ:** ဥပဒေဆိုင်ရာ အကြံဉာဏ် မပေးပါ၊ စာသားတစ်ခု၏ မည်သည့်ဗားရှင်းက အတည်ဖြစ်သည်ကိုလည်း မဆုံးဖြတ်ပါ။
  လွှမ်းခြုံမှုသည် နိုင်ငံအလိုက် အလွန်ကွာခြားသည်: အချို့တွင် တရားရုံးစီရင်ထုံးအပြည့်အစုံနှင့် ပြင်ဆင်ချက်များ ပေါင်းစည်းထားသော
  ဥပဒေများ ရှိပြီး အချို့တွင် တရားရုံးတစ်ခုတည်း သို့မဟုတ် မူလထုတ်ဝေသည့်အတိုင်းသာ ဥပဒေများ ရှိသည်။ အောက်ပါဇယားများနှင့်
  `list_jurisdictions` က တစ်ခုချင်းစီ အတိအကျ မည်သည်တို့ကို လွှမ်းခြုံသည်ကို ဖော်ပြသည်။

### ရလဒ်တစ်ခုကို အားမကိုးမီ ဤအရာကို ဖတ်ပါ

- **ရင်းမြစ်တိုင်းသည် တရားဝင်၊ စစ်မှန်သော ဗားရှင်း မဟုတ်ပါ။** အများစုမှာ အစိုးရ သို့မဟုတ် တရားရုံး
  ဆိုက်များ ဖြစ်သော်လည်း ပြင်ဆင်ချက်များ ပေါင်းစည်းထားသော စာသားအချို့သည် တရားဝင်မဟုတ်ကြောင်း ထင်ရှားစွာ ဖော်ပြထားပြီး (တရားဝင်ပြန်တမ်းသာ
  စစ်မှန်သည်)၊ ရင်းမြစ်အနည်းငယ်မှာ အစိုးရမဟုတ်သော ရင်းမြစ်များ ဖြစ်သည် (ဥပမာ LexiVox, LawPhil, Maqam, Wikisource)။
  Fontes သည် ၎င်းတို့ကို ၎င်း၏အဖြေများတွင် "တရားဝင်မဟုတ်သော ရင်းမြစ်" သတိပေးချက်ဖြင့် အမှတ်အသားပြုသည်။ မကိုးကားမီ
  တရားဝင်ထုတ်ဝေချက်ကို စစ်ဆေးပါ။
- **ရင်းမြစ်တစ်ခုချင်းစီတွင် ၎င်း၏ကိုယ်ပိုင် စည်းကမ်းချက်များ ရှိသည်။** ဒေတာသည် ၎င်း၏ထုတ်ဝေသူ၏ လိုင်စင်အောက်တွင် ဆက်ရှိသည်၊ အချို့က
  စီးပွားဖြစ်အသုံးပြုမှုကို တားမြစ်သည်၊ အချို့က ရင်းမြစ်ဖော်ပြရန် လိုအပ်သည် (ဥပမာ CC BY ရင်းမြစ်များ)၊ အနည်းငယ်က
  ခွင့်ပြုချက်မရှိဘဲ အလိုအလျောက်ဝင်ရောက်မှုကို တားမြစ်သည်။ ခွင့်ပြုချက်လိုအပ်သော ရင်းမြစ်များကို မူလအားဖြင့် **ပိတ်ထားသည်**
  (အောက်တွင် OFF ဟု အမှတ်အသားပြုထား)။ [ရင်းမြစ်များ၊ စည်းကမ်းချက်များနှင့် robots.txt](#ရင်းမြစ်များ-စည်းကမ်းချက်များနှင့်-robotstxt) ကို ကြည့်ပါ။
- **AI သည် မှားယွင်းစွာ ဖတ်နိုင်သည်။** အားမကိုးမီ စီရင်ချက် သို့မဟုတ် ပြဋ္ဌာန်းချက်အပြည့်အစုံကို ဖတ်ပါ၊ ရှာဖွေမှု
  အပိုင်းအစ သို့မဟုတ် AI ၏ အနှစ်ချုပ်တစ်ခုတည်းမှ ဘယ်တော့မှ မကိုးကားပါနှင့်။
- **ရင်းမြစ်များသည် နောက်ကျပြီး ကွက်လပ်များ ရှိသည်။** တရားရုံးတစ်ခုသည် နောက်ကျ၍ သို့မဟုတ် ၎င်း၏စီရင်ချက်အချို့ကိုသာ ထုတ်ဝေနိုင်ပြီး
  ပြင်ဆင်ချက်များ ပေါင်းစည်းထားသော စာသားတွင် နောက်ဆုံးပြင်ဆင်ချက် မပါသေးနိုင်ပါ။ စာသား၏ ရက်စွဲနှင့်
  ထိုစီရင်ပိုင်ခွင့်နယ်မြေအတွက် `list_jurisdictions` က စာရင်းပြုထားသော ကွက်လပ်များကို စစ်ဆေးပါ။
- **ဥပဒေဆိုင်ရာ အကြံဉာဏ် မဟုတ်ပါ။** Fontes သည် သုတေသနကိရိယာ ဖြစ်သည်။ ၎င်းကို အသုံးပြုခြင်းသည် မည်သူနှင့်မျှ ရှေ့နေ–အမှုသည်
  ဆက်ဆံရေး မဖန်တီးပါ၊ သင့်မေးခွန်း ပေါ်ပေါက်သည့်နေရာတွင် အရည်အချင်းပြည့်မီသော ရှေ့နေ၏ အကြံဉာဏ်ကိုလည်း
  အစားမထိုးပါ။
- **အာမခံချက် မရှိပါ။** Fontes ကို "ရှိသည့်အတိုင်း" (as is) မည်သည့်အာမခံချက်မျှ မပါဘဲ ပေးထားပြီး ၎င်း၏ ရေးသားသူများသည်
  ဥပဒေက ခွင့်ပြုသလောက် ၎င်းကို မည်သို့အသုံးပြုသည်အတွက် တာဝန်မရှိပါ။ စည်းကမ်းချက်အပြည့်အစုံသည် [LICENSE](../../../LICENSE) (Apache 2.0) ၏
  အပိုင်း 7 နှင့် 8 တွင် ရှိသည်။
- Fontes သည် လွတ်လပ်သော open-source စီမံကိန်း ဖြစ်သည်။ ၎င်းဖတ်ရှုသော တရားရုံးများ၊ အစိုးရများ သို့မဟုတ် ထုတ်ဝေသူများနှင့်
  ဆက်နွယ်မှု မရှိဘဲ ၎င်းတို့၏ ထောက်ခံချက်လည်း မရှိပါ။

## ဤအရာကို အဘယ်ကြောင့် တည်ဆောက်ခဲ့သနည်း

Fontes ကို ရှေ့နေတစ်ဦးက ရှေ့နေများအတွက် ပြုလုပ်ခဲ့သည်။ =) ထို့အပြင် မိမိအပေါ် သက်ရောက်သော ဥပဒေကို ဖတ်ရန် တစ်ချိန်ချိန်တွင် လိုအပ်ခဲ့ဖူးသူ အခြားလူတိုင်းအတွက်လည်း ဖြစ်သည်။

ဥပဒေသည် လူထုပိုင် ဖြစ်သည်။ တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို လူများ ဖတ်ရှုနိုင်စေရန် တရားရုံးများနှင့် အစိုးရများက ထုတ်ပြန်ကြသည်။ သို့သော် နိုင်ငံတိုင်းသည် ကိုယ်ပိုင်နည်းလမ်းဖြင့်၊ ကိုယ်ပိုင်ဝက်ဘ်ဆိုက်ပေါ်တွင်၊ ကိုယ်ပိုင်ဘာသာစကားဖြင့် ထုတ်ပြန်ကြပြီး ထိုဝက်ဘ်ဆိုက်အများစုကို မည်သည့်နေရာတွင် ရှာရမည်ကို သိပြီးသားသူများအတွက် တည်ဆောက်ထားသည်။ AI အကူများက ကူညီနိုင်သော်လည်း ရင်းမြစ်ကို မမြင်နိုင်သည့်အခါ ခန့်မှန်းကြသည်။

Fontes သည် သင်၏ AI အက်ပ်ကို ထိုတရားဝင်ရင်းမြစ်များနှင့် ချိတ်ဆက်ပေးသည်။ ၎င်းသည် တရားရုံးစီရင်ချက်များနှင့် ဥပဒေများကို ထုတ်ပြန်သည့် တရားရုံးများနှင့် အစိုးရများထံမှ တိုက်ရိုက် ရယူပြီး ရလဒ်တိုင်းကို မူရင်းသို့ လင့်ခ်ချိတ်ပေးကာ ကိုယ်ပိုင်ဒေတာဘေ့စ် မထားပါ။

ရှေ့နေတိုင်းနှင့် နိုင်ငံသားတိုင်းသည် မည်သည့်နေရာတွင်မဆို မိမိတို့ကို အုပ်ချုပ်သော ဥပဒေကို ရှာဖွေကြည့်ရှုနိုင်ပြီး မိမိတို့၏ အခွင့်အရေးများကို ကာကွယ်ရန် အသုံးပြုနိုင်သင့်သည်ဟု ကျွန်ုပ် ယုံကြည်သည်။ ထို့ကြောင့် Fontes သည် ဥပဒေကျင့်သုံးသူများနှင့် နိုင်ငံသားများ နှစ်ဦးစလုံးအတွက် အခမဲ့ဖြစ်ပြီး open source ဖြစ်သည်။

တစ်ခုခု ပျက်နေပါက သို့မဟုတ် သင်လိုအပ်သော နိုင်ငံတစ်ခု မပါဝင်ပါက ကျေးဇူးပြု၍ [issue တစ်ခု ဖွင့်ပါ](https://github.com/ykarapazar/fontes/issues)။ ၎င်းသည် အကောင်းဆုံး အကူအညီ ဖြစ်သည်။

## တပ်ဆင်ခြင်း

အက်ပ်တစ်ခုချင်းစီအတွက် အဆင့်ဆင့် (Claude Desktop, Codex, Claude Code, Cursor, VS Code, Gemini CLI,
Zed, LM Studio, Cline): [INSTALL.md](INSTALL.md)။ Fontes သည် PyPI တွင် မရှိသေးပါ၊ ထိုအဆင့်များသည်
ရှိလာပြီးမှ အလုပ်လုပ်ပါမည်။

**Developer များ:** [uv](https://docs.astral.sh/uv/getting-started/installation/) လိုအပ်သည်။

```bash
uvx fontes-mcp                 # from PyPI, once published
uvx --from git+https://github.com/ykarapazar/fontes fontes   # straight from GitHub
uvx fontes-mcp --only nl,gb    # expose only some jurisdictions
```

Fontes သည် stdio MCP server ဖြစ်သည်: MCP client က ၎င်းကို စတင်ပေးပြီး သင်ကိုယ်တိုင် run စရာမလိုပါ။
`nl-legal-mcp` နှင့် `uk-legal-mcp` (ယခင်အမည်များ) သည် `fontes --only nl` / `--only gb` ၏ alias များ ဖြစ်သည်။

## စီရင်ပိုင်ခွင့်နယ်မြေ ထည့်ခြင်း

စာချုပ်အပြည့်အစုံမှာ [docs/ADAPTER_SPEC.md](../../ADAPTER_SPEC.md) ဖြစ်သည်၊ ၎င်းကို `base.py` နှင့်
`models.py` နှင့်တွဲ၍ ဖတ်ပါ။ အတိုချုပ်:

<details>
<summary>အဆင့်များနှင့် စည်းမျဉ်းများ</summary>

1. ကုဒ်ကို ရွေးပါ: ISO 3166-1 alpha-2 စာလုံးအသေး (`de`)၊ နိုင်ငံအောက်အဆင့် `us-ca`၊ နိုင်ငံတကာ
   `eu`, `echr`။ `src/world_legal_mcp/jurisdictions/<code>.py` ကို ဖန်တီးပါ (မှန်ကန်သော module
   အမည်ကို သုံးပါ၊ ဥပမာ `code = "us-ca"` နှင့် `us_ca.py`)။ ၎င်းကို အလိုအလျောက် ရှာဖွေတွေ့ရှိသည်။
2. `Jurisdiction` ကို subclass လုပ်ပြီး `code`, `name`, `languages`, `aliases`, `notes`, `samples`,
   `min_interval = {host: seconds}` နှင့် `sources` ကို သတ်မှတ်ပါ: `Source` တစ်ခုချင်းစီအတွက် ၎င်း၏လိုင်စင်၊
   `commercial_use`, `ai_use`, `auth`, `rate_limit` (နှင့် သင်မည်သို့သိသည်) နှင့် `terms_url`။
3. တရားဝင်ရင်းမြစ်က ပံ့ပိုးသော async method များကိုသာ အကောင်အထည်ဖော်ပါ (`search_caselaw`,
   `get_decision`, `search_legislation`, `get_legislation_toc`, `get_legislation_provision`,
   `get_legislation_text`)။ markdown မဟုတ်ဘဲ `models.py` မှ record များကို ပြန်ပေးပါ၊ မအောင်မြင်လျှင်
   `NotFound` / `BadRequest` / `SourceError` ကို raise လုပ်ပါ။ မပါသော method များကို
   မပံ့ပိုးဟု အစီရင်ခံသည်။
4. အပို ရှာဖွေမှု option များကို `caselaw_filters` / `legislation_filters` တွင် ကြေညာပြီး ၎င်းတို့ကို
   `filters` မှ ဖတ်ပါ။ `_http.get/post` (စီမံကိန်း၏ ကိုယ်ပိုင် User-Agent၊ host အလိုက် throttle) နှင့်
   မျှဝေထားသော `_http` helper များကို သုံးပါ။
5. `tests/live/test_<code>.py` ကို ထည့်ပြီး
   `uv run pytest tests/test_registry.py -q` နှင့်
   `uv run pytest tests/live/test_conformance.py -k "[<code>]" -s` ကို run ပါ (လေးထောင့်ကွင်းဖြင့်: ရိုးရိုး
   `-k <code>` သည် အခြား test များနှင့်ပါ ကိုက်ညီသွားသည်)။

စည်းမျဉ်းများ: တရားဝင် သို့မဟုတ် အများပြည်သူအဖွဲ့အစည်း ရင်းမြစ်များသာ၊ robots.txt သို့မဟုတ် စည်းကမ်းချက်များက တားမြစ်သည့်အရာကို
ဘယ်တော့မှ scrape မလုပ်ပါနှင့်၊ identifier များသည် ရင်းမြစ်မှ လာပြီး ဘယ်တော့မှ တီထွင်မထားပါ။ အလိုအလျောက်အသုံးပြုမှုအတွက်
စည်းကမ်းချက်များအရ ခွင့်ပြုချက်လိုအပ်သော ရင်းမြစ်သည် `needs_permission=True` နှင့် `warning` ကို ရရှိသည်: operator က
`WLM_PERMITTED` တွင် ကုဒ်ကို စာရင်းမသွင်းမချင်း server သည် ၎င်းကို ဘယ်တော့မှ မခေါ်ပါ (ဥပမာ `WLM_PERMITTED=in,de`)။

</details>

## ဤ Beta ဗားရှင်းတွင် သိရှိထားသော ပြဿနာများ

2026 ခုနှစ် နိုဝင်ဘာလ 12 ရက် အခြေအနေ။ [အခြေအနေစာမျက်နှာ](https://ykarapazar.github.io/fontes/status/?lang=my) သည် ရင်းမြစ်တိုင်း၏ ယနေ့အခြေအနေကို ပြသည်။

- **ပျက်နေခြင်း သို့မဟုတ် ပိတ်ဆို့ခံထားရခြင်း။** ဆွစ်ဇာလန် ဖက်ဒရယ်တရားရုံးချုပ် ဆိုက်သည် bot စစ်ဆေးမှုကို ပြသည်၊ Fontes သည် ရပ်လိုက်ပြီး
  browser တွင် ရှာဖွေနိုင်ရန် လင့်ခ်ကို သင့်အား ပေးသည်။ ဩစတြီးယားနှင့် ပါလက်စတိုင်းသည် server အမှားများ ပြန်ပေးသည်၊
  ဆီနီဂေါနှင့် ဂျော်ဒန်ကို မကြာခဏ ဆက်သွယ်၍ မရပါ၊ လာအိုသည် အလွန်နှေးသည်။
- **မူရင်းအားဖြင့် ပိတ်ထားသည်။** ဘာရိန်းနှင့် ကိုလံဘီယာ၏ စည်းကမ်းချက်များက ခွင့်ပြုချက်မရှိဘဲ
  အလိုအလျောက် ဝင်ရောက်ခြင်းကို တားမြစ်ထားသဖြင့် သင်ဖွင့်မှသာ Fontes က ၎င်းတို့ကို ထိတွေ့သည်။
- **ဥပဒေရင်းမြစ် မရှိပါ။** အီဂျစ်၊ အိုက်စလန်၊ လာအိုနှင့် မွန်ဂိုလီးယား- တရားရုံးစီရင်ထုံးများသာ။
- **မျှော်လင့်ထားသည်ထက် ရှာဖွေမှု အားနည်းသည်။** နိုင်ဂျီးရီးယား၊ ထရီနီဒက်နှင့်တိုဘက်ဂို၊ ဖိလစ်ပိုင်နှင့် ဘလိဇ်တို့သည်
  ခေါင်းစဉ်များကိုသာ ရှာဖွေသဖြင့် စာကိုယ်ထဲရှိ စကားလုံးကို ရှာတွေ့မည် မဟုတ်ပါ။ ဘီနင်နှင့် ဘာဘေးဒိုးသည် စကင်ဖတ်ထားသော
  PDF များကို ထုတ်ပြန်သဖြင့် စာသား ပျောက်နေခြင်း သို့မဟုတ် ပုံပျက်နေခြင်း ရှိနိုင်သည်။ နိုင်ငံအတော်များများတွင် (ယူနိုက်တက်ကင်းဒမ်းနှင့် ဂျာမနီ အပါအဝင်)
  ရလဒ်အချို့သည် သင်၏ စကားလုံးများကို ဖြတ်ကနဲသာ ဖော်ပြသည်၊ Fontes သည် ဖြစ်နိုင်သည့်နေရာတွင် ၎င်းတို့ကို အမှတ်အသားပြုသည်။
- **ခေတ်မမီတော့နိုင်သော စာသားများ။** ဖိလစ်ပိုင်ဥပဒေများသည် ပထမဆုံး အတည်ပြုခဲ့သည့်အတိုင်း ဖြစ်ပြီး နောက်ပိုင်း
  ပြင်ဆင်ချက်များ မပါဝင်ပါ (Fontes သည် ပုဒ်မတိုင်းတွင် ထိုသို့ ဖော်ပြသည်)။ ချီလီ၏ ပေါင်းစည်းထားသော စာသားသည် နောက်ကျနိုင်သည်၊ Fontes သည်
  ၎င်းတွေ့ရှိသော နောက်ပိုင်း ပြင်ဆင်ဥပဒေများကို အမှတ်အသားပြုသည်။ မွန်ဂိုလီးယား၏ ရင်းမြစ်သည် စီရင်ချက်အချို့တွင် ရက်စွဲမှားများ ပြသည်။
- **နှေးကွေးသော ရှာဖွေမှုများ။** ချက် တရားရုံးစီရင်ထုံး ရှာဖွေမှုအချို့သည် စက္ကန့် 60 အထိ ကြာပြီး သင်၏ AI အက်ပ်က
  ထိုမတိုင်မီ လက်လျှော့နိုင်သည်။ တူရကီသည် စီရင်ချက်တိုင်း၏ အကြောင်းအရာကို စစ်ဆေးသည့်အခါ စက္ကန့် 40 ခန့်အထိ ကြာသည်။

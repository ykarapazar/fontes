> ဤသည်မှာ စက်အကူအညီဖြင့် ဘာသာပြန်ထားခြင်း ဖြစ်သည်။ အင်္ဂလိပ်ဗားရှင်းသာ အတည်ဖြစ်သည်။

# Fontes ကိုယ်ရေးအချက်အလက် လုံခြုံမှု အသိပေးချက်

Fontes သည် သင့်ကွန်ပျူတာပေါ်တွင် run သည်။ သင်၏ ရှာဖွေမှုများနှင့် သင်ဖွင့်သော စာရွက်စာတမ်းများသည် သင့်ကွန်ပျူတာ၊
သင်ရှာဖွေသော တရားဝင်ရင်းမြစ်များနှင့် သင်အသုံးပြုသော AI အက်ပ် (ထိုအက်ပ်၏ ကိုယ်ပိုင်စည်းကမ်းချက်များအောက်တွင်) ကြားတွင်သာ
ရှိနေသည်။ Fontes ကိုယ်တိုင်သည် Fontes developer များထံသို့ **မူလအားဖြင့် ဘာမှ မပို့ပါ**။

## သင့်ကွန်ပျူတာမှ မည်သည့်အရာ ထွက်သွားနိုင်ပြီး မည်သည့်အချိန်တွင်နည်း

**1. အပ်ဒိတ်စစ်ဆေးမှု (မူလအားဖြင့် ဖွင့်ထားသည်)။** တစ်နေ့တစ်ကြိမ် Fontes သည် အများသုံး Python package index ဖြစ်သော
PyPI ကို မည်သည့်ဗားရှင်းက နောက်ဆုံးဖြစ်သည်ကို မေးသည်။ ဤတောင်းဆိုမှုတွင် သင် သို့မဟုတ် သင့်အလုပ်နှင့်ပတ်သက်သည့် မည်သည့်အရာမျှ မပါပါ၊ PyPI
သည် မည်သည့်ဒေါင်းလုဒ်တွင်မဆိုကဲ့သို့ သင်၏ IP လိပ်စာကို မြင်ရသည်။ ၎င်းကို ပိတ်ရန် `FONTES_NO_UPDATE_CHECK=1`
(အက်ပ်အတွင်း အသိပေးချက်) နှင့် `FONTES_NO_AUTO_UPDATE=1` (တပ်ဆင်ရေးပရိုဂရမ်၏ အလိုအလျောက် အပ်ဒိတ်များ) ကို သတ်မှတ်ပါ။

**2. အသုံးပြုမှုအရေအတွက် (သင်ဖွင့်မှသာ ဖွင့်မည်)။** သင် opt in လုပ်ပါက တစ်နေ့တစ်ကြိမ် Fontes သည် ပေးပို့သည်:

- Fontes ဗားရှင်းနှင့် သင်၏ OS အမျိုးအစား (macOS, Windows, Linux)၊
- တစ်နေ့လျှင် စီရင်ပိုင်ခွင့်နယ်မြေကုဒ်တစ်ခုချင်းစီအတွက် ကိရိယာတစ်ခုချင်းစီကို အသုံးပြုခဲ့သည့် အကြိမ်အရေအတွက်၊ ဥပမာ
  "2026-11-10, nl, search_caselaw, 12"။

ဤသည်မှာ မက်ဆေ့ချ်တစ်ခုလုံး ဖြစ်သည်။ ၎င်းတွင် သင်၏ ရှာဖွေမှုများ၊ စာရွက်စာတမ်း သို့မဟုတ် အမှု id များ၊ စာရွက်စာတမ်း
စာသား၊ သင်၏အမည်၊ အကောင့်တစ်ခု သို့မဟုတ် သင် သို့မဟုတ် သင့်ကွန်ပျူတာအတွက် မည်သည့် id မျှ ဘယ်တော့မှ မပါပါ။ အရေအတွက်များသည်
ပေးပို့ခြင်းမပြုမီအထိ သင့်ကွန်ပျူတာပေါ်တွင် (Fontes ၏ cache ဖိုင်တွဲ၊ `stats.json` တွင်) စောင့်ဆိုင်းနေသည်၊ ပေးပို့ခြင်း မအောင်မြင်ပါက
နောက်တစ်နေ့အထိ စောင့်သည်။

- **Opt in**: တပ်ဆင်ရေးပရိုဂရမ်က မေးသည့်အခါ "y" ဟု ဖြေပါ၊ သို့မဟုတ် Fontes server အတွက် `FONTES_STATS=1` ကို သတ်မှတ်ပါ။
- **Opt out**: တပ်ဆင်ရေးပရိုဂရမ်ကို ထပ်မံ run ပြီး ထိုမေးခွန်းတွင် Enter ကို နှိပ်ပါ၊ သို့မဟုတ်
  `FONTES_STATS` ကို ဖယ်ရှားပါ။ `stats.json` ကို ဖျက်ခြင်းသည် မပို့ရသေးသည့် မည်သည့်အရာကိုမဆို ပယ်ဖျက်သည်။

**3. ချို့ယွင်းချက်အစီရင်ခံစာများ (သင်ပို့မှသာ)။** သင်တောင်းဆိုသည့်အခါ (`fontes report-bug`၊ သို့မဟုတ် သင်၏
AI အက်ပ်ကို Fontes ချို့ယွင်းချက်ကို အစီရင်ခံရန် မေးသည့်အခါ) Fontes သည် အစီရင်ခံစာအပြည့်အစုံကို သင့်အား ဦးစွာ ပြပြီး သင်အတည်ပြုမှသာ
ပေးပို့သည်။ ၎င်းတွင် Fontes ဗားရှင်း၊ သင်၏ OS အမျိုးအစား၊ နောက်ဆုံး မအောင်မြင်ခဲ့သော ကိရိယာခေါ်ဆိုမှု၏
စီရင်ပိုင်ခွင့်နယ်မြေကုဒ်၊ ကိရိယာအမည်နှင့် error မက်ဆေ့ချ် (သင်၏ ရှာဖွေစကားလုံးများနှင့် id များကို ဖြတ်ထုတ်ထားပြီး) နှင့်
သင်ရေးလျှင် မှတ်စုတစ်ခု ပါဝင်သည်။ မှတ်စုတွင် အမှုသည်၏ အသေးစိတ်များကို မထည့်ပါနှင့်။ ဤအရာကို ပံ့ပိုးရန် Fontes သည်
နောက်ဆုံး error ကို သင့်ကွန်ပျူတာပေါ်တွင် သိမ်းထားသည် (၎င်း၏ cache ဖိုင်တွဲရှိ `last-error.json`၊ အကြိမ်တိုင်း အစားထိုးသည်)၊
၎င်းကို သီးခြား ဘယ်တော့မှ မပို့ပါ။

## ၎င်းသည် မည်သည့်နေရာသို့ သွားပြီး မည်မျှကြာ သိမ်းထားသနည်း

အသုံးပြုမှုအရေအတွက်များနှင့် ချို့ယွင်းချက်အစီရင်ခံစာများသည် Fontes developer လည်ပတ်သော server ငယ်တစ်ခုသို့ သွားသည်
(`relay.kinetra.fit`)။ ၎င်းသည် IP လိပ်စာများကို မသိမ်းပါ: ၎င်းတို့ကို flood များကို တားဆီးရန် memory အတွင်း ခဏတာသာ
အသုံးပြုပြီး web server သည် ၎င်းအတွက် access log မထားပါ။ အရေအတွက်များကို နေ့စဉ်စုစုပေါင်းများထဲသို့
ပေါင်းထည့်သည်၊ တစ်ခုချင်း ပေးပို့မှုများကို မသိမ်းပါ။ စုစုပေါင်းများကို 2 နှစ်အထိ၊ ချို့ယွင်းချက်အစီရင်ခံစာများကို
1 နှစ်အထိ သိမ်းထားပြီး ထို့နောက် ဖျက်သည်။ မည်သည့်အရာကိုမျှ မရောင်းပါ၊ မမျှဝေပါ။

ထို server ကို ဆက်သွယ်၍မရပါက ဘာမှ မပို့ပါ: အရေအတွက်များသည် သင့်ကွန်ပျူတာပေါ်တွင် ဆက်ရှိပြီး ချို့ယွင်းချက်အစီရင်ခံစာများသည်
သင့်ကို issue tracker သို့ ညွှန်ပြသည်။

## မည်သူ တာဝန်ရှိပြီး မည်သည့်အခြေခံဖြင့်နည်း

အသုံးပြုမှုအရေအတွက်များနှင့် ချို့ယွင်းချက်အစီရင်ခံစာများအတွက် data controller မှာ Fontes ၏ developer ဖြစ်သော
Yüce Karapazar ဖြစ်သည်။ ဆက်သွယ်ရန်: fontesmcp@proton.me။

ဥပဒေနှင့်ညီသော အခြေခံမှာ သင်၏ သဘောတူညီချက် ဖြစ်သည် (UK GDPR နှင့် EU GDPR ၏ ပုဒ်မ 6(1)(a))။ အသုံးပြုမှုအရေအတွက်များကို
သင် opt in လုပ်မှသာ ပေးပို့ပြီး ချို့ယွင်းချက်အစီရင်ခံစာကို သင်အတည်ပြုပြီးမှသာ ပေးပို့သည်။ အထက်တွင် ဖော်ပြထားသည့်အတိုင်း
opt out လုပ်ခြင်းဖြင့် သဘောတူညီချက်ကို အချိန်မရွေး ရုပ်သိမ်းနိုင်သည်၊ ၎င်းသည် ယခင်က ပေးပို့ပြီးသည့်အရာကို
မထိခိုက်ပါ။

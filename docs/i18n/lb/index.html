Fontes ass e gratis Open-Source-MCP-Server. Et funktionéiert an all App, déi e lokale Model-Context-Protocol-Server lafe loosse kann: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio a méi. Stellt eng juristesch Fro an einfacher Sprooch: Är KI-App sicht live Geriichtsentscheedungen a Gesetzgebung op de Websäite vu Regierungen a Geriichter, a méi wéi 120 Rechtsuerdnungen an internationale Geriichter, a verlinkt all Resultat op d'Original. Et ass fir Juristen a juristesch Fuerscher gemaach, a fir jiddereen, deen d'Recht u senger Quell liese wëll.

Dëst ass eng maschinnegestëtzt Iwwersetzung. Déi englesch Versioun ass moossgeblech.

Wat et mécht

  • Sicht Rechtsprechung a Gesetzgebung am Moment, wou Dir frot, op der eegener Websäit oder API vum Editeur.
  • All Resultat nennt seng Quell a verlinkt drop, fir datt Dir d'Original kontrolléiere kënnt.
  • Fontes féiert keng Datebank a brauch kee Kont. Är Froe ginn just un d'Quell, an där gesicht gëtt. Notzungszuelen a Feelerberichter sinn Opt-in.

Fontes ass eng Recherchenhëllef, keng Rechtsberodung, a seng Notzung schaaft keng Bezéiung tëscht Affekot a Client. Et gëtt sou wéi et ass zur Verfügung gestallt, ouni Garantie (kuckt d'Lizenz Apache 2.0). E puer Quelle sinn ausdrécklech inoffiziell Versiounen, an all Quell huet hir eege Notzungskonditiounen; Fontes seet dat a sengen Äntwerten. Liest déi ganz Entscheedung oder Bestëmmung, ier Dir Iech drop verloosst. Fontes ass onofhängeg an net mat engem Geriicht, enger Regierung oder engem Editeur verbonnen.

Installatioun

  • Claude Desktop: Luet de Fontes-Fichier .mcpb aus der neister Release erof, klickt duebel drop a klickt dann op Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline an aner Apps: Setzt Fontes an d'MCP-Astellunge vun der App derbäi. Déi meescht huelen dës Entrée; den Installatiounsguide gëtt fir all App de Fichier an den Ausschnëtt.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx kënnt mat uv. Op macOS oder Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Op Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

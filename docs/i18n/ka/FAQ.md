# Fontes: კითხვები და პასუხები

## რა არის Fontes

უფასო, ღია კოდის MCP სერვერი (Apache 2.0). ის Model Context Protocol-ის მხარდამჭერ ნებისმიერ
აპს (Claude, Codex, Cursor, VS Code, Gemini CLI და სხვა) საშუალებას აძლევს, მოიძიოს სასამართლო
გადაწყვეტილებები და კანონმდებლობა რეალურ დროში, სასამართლო და სახელმწიფო ვებსაიტებზე, 120-ზე
მეტ იურისდიქციასა და საერთაშორისო სასამართლოში (124 ადაპტერი). ყოველი შედეგი ასახელებს თავის
წყაროს და ორიგინალზე მიუთითებს ბმულით.

## ოფიციალურია თუ არა ტექსტები

უმეტესად კი, მაგრამ არა ყოველთვის.

- წყაროების უმეტესობას მართავს სასამართლო, სამინისტრო ან ოფიციალური ბიულეტენი.
- ზოგიერთ კონსოლიდირებულ ტექსტს სახელმწიფო ორგანო აქვეყნებს, მაგრამ ისინი პირდაპირ
  არაოფიციალურია: ავთენტურია მხოლოდ ოფიციალური ბიულეტენი.
- რამდენიმე წყარო საერთოდ არ არის სახელმწიფო ვებსაიტი (მაგალითად, LexiVox, LawPhil, Maqam,
  Wikisource).

Fontes ყოველ პასუხს, რომელიც ამ წყაროებიდან რომელიმედან მოდის, ურთავს „Unofficial source“
შენიშვნას. რამის ციტირებამდე შეამოწმეთ ოფიციალური პუბლიკაცია. [README](README.md#დაფარვა)-ის
დაფარვის ცხრილი და `list_jurisdictions` ასახელებს თითოეული იურისდიქციის წყაროს.

## რომელ იურისდიქციებს ფარავს და რამდენად კარგად

124 ადაპტერი: გაეროს 108 წევრი სახელმწიფო, ჰონგკონგი, კოსოვო, პალესტინა, ტაივანი, DIFC-ის
სასამართლოები და 11 საერთაშორისო სასამართლო და ორგანო (მაგალითად, ადამიანის უფლებათა ევროპული
სასამართლო, ევროკავშირი, მართლმსაჯულების საერთაშორისო სასამართლო და მსოფლიო სავაჭრო
ორგანიზაცია).

დაფარვა მნიშვნელოვნად განსხვავდება. მკაცრი წესით (ზოგადი იურისდიქციის უმაღლესი სასამართლოს
პრეცედენტული გადაწყვეტილებები ან კონსტიტუცია და ძირითადი აქტები სრულად დაფარული) 124-დან 72
ითვლება დაფარულად. [COVERAGE.md](../../COVERAGE.md) თითოეული იურისდიქციისთვის ასახელებს, რას
ფარავს Fontes, რას არა და რატომ.

## მჭირდება თუ არა API გასაღები

თითქმის ყველა იურისდიქციისთვის არა. ზოგიერთ წყაროს უფასო გასაღები სჭირდება: იხილეთ
[KEYS.md](KEYS.md).

- **საფრანგეთი:** დიახ. საფრანგეთი გამორთულია, სანამ არ დააყენებთ `WLM_FR_PISTE_CLIENT_ID`-სა და
  `WLM_FR_PISTE_CLIENT_SECRET`-ს. მათ იღებთ უფასო PISTE ანგარიშიდან (piste.gouv.fr), აპით,
  რომელიც გამოწერილია Judilibre-სა და Légifrance-ზე.
- **ამერიკის შეერთებული შტატები:** არასავალდებულო. სასამართლო პრაქტიკის ძიება გასაღების
  გარეშეც მუშაობს, მაგრამ საერთო სადემონსტრაციო გასაღები IP მისამართზე დღეში დაახლოებით 10
  ძიებას უშვებს. უფასო api.data.gov გასაღები `WLM_US_GOVINFO_KEY`-ში ამ ლიმიტს ზრდის.

დააყენეთ ისინი Fontes სერვერის გარემოს ცვლადებად თქვენი აპის MCP კონფიგურაციაში. ინსტალერები
ინსტალაციის შემდეგ ითხოვენ მათ, ხოლო მათი **Add or change keys** გამშვები
მოგვიანებით ცვლის მათ.

ცალკე: რამდენიმე წყარო თავის პირობებში აცხადებს, რომ ავტომატიზებული წვდომა გამომცემლის
ნებართვას საჭიროებს. ისინი მონიშნულია OFF-ით და გამორთული რჩება. გასაღები ამას არ ცვლის; ამას
ცვლის მხოლოდ გამომცემლის ნებართვა (მაშინ დააყენეთ `WLM_PERMITTED=<codes>`).

## რა გადის ჩემი კომპიუტერიდან

თქვენი ძიებები მიდის მხოლოდ იმ წყაროში, რომელშიც ეძებთ. Fontes არ ინახავს მონაცემთა ბაზას და
ანგარიშს არ მოითხოვს.

წყაროების გარდა, Fontes დღეში ერთხელ ეკითხება PyPI-ს, არის თუ არა უფრო ახალი ვერსია (გამორთეთ

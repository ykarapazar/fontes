> ეს თარგმანი შესრულებულია მანქანური თარგმანის დახმარებით. განმსაზღვრელია ინგლისური ვერსია.

# Fontes-ის ინსტალაცია

Fontes თქვენს AI აპს საშუალებას აძლევს, მოიძიოს სასამართლო გადაწყვეტილებები და კანონმდებლობა
რეალურ დროში, სასამართლო და სახელმწიფო ვებსაიტებზე, 120-ზე მეტ იურისდიქციაში. ყოველი შედეგი
ორიგინალზე მიუთითებს ბმულით. ეს სტანდარტული MCP სერვერია, ამიტომ მუშაობს ნებისმიერ აპში,
რომელსაც ლოკალური MCP სერვერის გაშვება შეუძლია: Claude Desktop, Codex, Claude Code, Cursor,
VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline და სხვა.

აირჩიეთ თქვენი აპი, შეასრულეთ მისი ნაბიჯები, შემდეგ კი
[შეამოწმეთ, რომ მუშაობს](#შემოწმება-რომ-მუშაობს).

## Claude Desktop

1. ჩამოტვირთეთ Fontes-ის `.mcpb` ფაილი
   [უახლესი რელიზიდან](https://github.com/ykarapazar/fontes/releases/latest).
2. ორჯერ დააწკაპუნეთ მასზე. Claude Desktop გახსნის მას.
3. დააწკაპუნეთ **Install**-ზე.

## Codex

ტერმინალში:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI და Codex IDE გაფართოება ამ კონფიგურაციას იზიარებენ (`~/.codex/config.toml`).
დაგჭირდებათ [uv](#გჭირდებათ-uv).

## Claude Code

ტერმინალში:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

დაგჭირდებათ [uv](#გჭირდებათ-uv).

## სხვა აპები

თითოეულ მათგანს სჭირდება [uv](#გჭირდებათ-uv). დაამატეთ ჩანაწერი, შეინახეთ, შემდეგ დახურეთ და
ხელახლა გახსენით აპი.

**Cursor:** `~/.cursor/mcp.json`-ში (ყველა პროექტისთვის) ან `.cursor/mcp.json`-ში (ერთი
პროექტისთვის):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** ბრძანებების პალიტრიდან (Command Palette) გაუშვით **MCP: Add
Server**, აირჩიეთ **Command (stdio)**, შეიყვანეთ `uvx fontes-mcp` და სერვერს დაარქვით `fontes`. ან
დაამატეთ ეს `~/.copilot/mcp-config.json`-ში:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code-ის ძველი კონფიგურაციები იყენებს `.vscode/mcp.json`-ს, სადაც ზედა დონის გასაღებია
`servers` და არა `mcpServers`.

**Gemini CLI:** ტერმინალში: `gemini mcp add -s user fontes uvx fontes-mcp`. ან დაამატეთ ეს
`~/.gemini/settings.json`-ში:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** გახსენით თქვენი პარამეტრების ფაილი (**zed: open settings file**) და დაამატეთ:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** მარჯვენა გვერდით პანელში გახსენით **Program** ჩანართი, დააწკაპუნეთ
**Install → Edit mcp.json**-ზე და დაამატეთ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** დააწკაპუნეთ **MCP Servers** ხატულაზე, გახსენით **Configure** ჩანართი, დააწკაპუნეთ
**Configure MCP Servers**-ზე და დაამატეთ იგივე `mcpServers` ჩანაწერი, რაც LM Studio-სთვის.

**Claude Desktop, ხელით** (`.mcpb` ფაილის ნაცვლად): დაამატეთ იგივე `mcpServers` ჩანაწერი
`claude_desktop_config.json`-ში (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**ნებისმიერი სხვა MCP აპი** (Windsurf და სხვა): მისი საკუთარი დოკუმენტაცია მიუთითებს, სად
ინახავს ის თავის MCP სერვერებს. უმეტესობა იღებს იმავე ჩანაწერს: ბრძანება `uvx`, არგუმენტი
`fontes`.

თუ აპი ვერ პოულობს `uvx`-ს, გამოიყენეთ მისი სრული გზა (macOS-სა და Linux-ზე მას `which uvx`
ბეჭდავს).

## გჭირდებათ uv

Codex, Claude Code და სხვა აპები Fontes-ს უშვებენ `uvx`-ით, რომელიც მოყვება **uv**-ს, Astral-ის
პატარა უფასო ხელსაწყოს. მის დასაყენებლად იხილეთ
[Astral-ის სახელმძღვანელო](https://docs.astral.sh/uv/getting-started/installation/) ან გაუშვით:

- macOS ან Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

ზოგიერთ წყაროს უფასო გასაღები სჭირდება: იხილეთ [KEYS.md](KEYS.md).

## შემოწმება, რომ მუშაობს

ახალ საუბარში იკითხეთ: *„რომელ იურისდიქციებში შეუძლია Fontes-ს ძიება?“* აპმა ქვეყნების სიით
უნდა გიპასუხოთ. თუ ეს არ მოხდა, კიდევ ერთხელ დახურეთ და ხელახლა გახსენით აპი.

## ერთი დაწკაპუნებით ინსტალერი (Mac)

Mac-ის ინსტალერი Fontes-ს ერთბაშად აყენებს თქვენს ყველა აპში: Claude Desktop-ში, Codex-ში, Claude
Code-ში, Cursor-ში, VS Code-ში (GitHub Copilot), Windsurf-ში, Gemini CLI-ში, Zed-ში, LM Studio-სა და
Cline-ში. Windows-ის ინსტალერი მალე გამოვა; მანამდე გამოიყენეთ ზემოთ მოცემული ნაბიჯები თქვენი
აპისთვის.

**დაწყებამდე:** მთლიანად დახურეთ თითოეული ეს აპი. ეს ყველაზე მნიშვნელოვანია Claude Code-ისთვის:
მუშაობისას ის ხელახლა წერს `~/.claude.json`-ს და შეიძლება გააუქმოს ინსტალერის მიერ შეტანილი
ცვლილება. თუ Claude Code-ს ვერ დახურავთ, დაამატეთ მას Fontes `claude mcp add`-ით (იხილეთ
[Claude Code](#claude-code)).

**Mac**

1. ჩამოტვირთეთ Mac-ის ინსტალერი (`Fontes-Installer-…-mac.zip`) [უახლესი
   რელიზიდან](https://github.com/ykarapazar/fontes/releases/latest) და ამოსაარქივებლად ორჯერ
   დააწკაპუნეთ მასზე.
2. ორჯერ დააწკაპუნეთ **Fontes Installer**-ზე. თუ თქვენი Mac გკითხავთ, გსურთ თუ არა ინტერნეტიდან
   ჩამოტვირთული აპის გახსნა, დააწკაპუნეთ **Open**-ზე.
3. აირჩიეთ **დაყენება** და დააწკაპუნეთ **OK**-ზე. დაყენებას დაახლოებით ერთი წუთი სჭირდება.
4. შეტყობინებაში ჩამოთვლილი იქნება აპები, რომლებშიც ის დაყენდა. დააწკაპუნეთ **მზადაა**-ზე, შემდეგ
   ხელახლა გახსენით ეს აპები. თუ ჯერ არასავალდებულო უფასო გასაღებების დამატება გსურთ, ამის ნაცვლად
   დააწკაპუნეთ **გასაღებების დამატება**-ზე; იხილეთ [გასაღებების ნაბიჯი](#გასაღებების-ნაბიჯი).

**Windows** (როცა Windows-ის ინსტალერი გამოვა)

1. გახსენით ჩამოტვირთული **Fontes Installer** არქივი (მარჯვენა დაწკაპუნება → Extract All).
2. ორჯერ დააწკაპუნეთ **Install Fontes.cmd**-ზე.
   - თუ Windows აჩვენებს „Windows protected your PC“: დააწკაპუნეთ **More info**-ზე, შემდეგ
     **Run anyway**-ზე.
3. როცა გკითხავთ, გაგზავნოს თუ არა გამოყენების ანონიმური სტატისტიკა, „არა“-ს საპასუხოდ
   დააჭირეთ Enter-ს.
4. ის გკითხავთ, დაამატოს თუ არა გასაღებები ახლა. გამოსატოვებლად დააჭირეთ Enter-ს; იხილეთ
   [გასაღებების ნაბიჯი](#გასაღებების-ნაბიჯი).
5. როცა ის აჩვენებს **დასრულდა**, ხელახლა გახსენით თქვენი AI აპები. თუ რომელიმე მათგანი ჯერ
   კიდევ მუშაობდა, მთლიანად დახურეთ ის (სისტემური უჯრიდანაც, საათის გვერდით) და ხელახლა
   გახსენით.

ბოლოს ინსტალერი ჩამოთვლის მის მიერ დაყენებულ აპებს.

### რომელ აპებს აყენებს

ის აპს აყენებს მხოლოდ მაშინ, თუ ამ აპის პარამეტრების საქაღალდე უკვე არსებობს თქვენს კომპიუტერზე.
Claude Code ყენდება მხოლოდ მაშინ, თუ `~/.claude.json` არსებობს. Claude Desktop ყოველთვის ყენდება.
თითოეული აპი იღებს ერთ ჩანაწერს, `fontes`, ამ ფაილში:

| აპი | ფაილი (Mac და Linux) | ფაილი (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` და Microsoft Store-ის ვერსიის საკუთარი ასლი |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`, ან ძველ ვერსიებში `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` ან `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code ყენდება, თუ არსებობს `~/.copilot` ან VS Code-ის საკუთარი პარამეტრების საქაღალდე.

ორ აპს კიდევ ერთი ნაბიჯი სჭირდება:

- **Windsurf:** ხელახლა გახსნის შემდეგ Cascade-ში დააწკაპუნეთ განახლებაზე (refresh).
- **Cline VS Code-ის ძველ გაფართოებაში:** დაამატეთ Fontes ხელით (იხილეთ
  [Cline](#სხვა-აპები)).

### გასაღებების ნაბიჯი

ინსტალაციისთანავე ინსტალერი გთავაზობთ საფრანგეთისა და აშშ-ის უფასო გასაღებების დამატებას.
მოგვიანებით მათი დამატების ან შეცვლისთვის:

- **Mac:** ხელახლა გახსენით **Fontes Installer** და აირჩიეთ **გასაღებების დამატება ან შეცვლა**.
- **Windows:** ინსტალერის საქაღალდეში ორჯერ დააწკაპუნეთ **Add or change keys.cmd**-ზე.

აკრეფილი დამალულია. გასაღებები იწერება ყველა აპში, რომელსაც უკვე აქვს Fontes. ამის შემდეგ
დახურეთ და ხელახლა გახსენით აპები. საიდან მიიღოთ გასაღებები და რას ხსნიან ისინი:
[KEYS.md](KEYS.md).

### სარეზერვო ასლები, ხელახალი გაშვება და წაშლა

ინსტალერი ცვლის მხოლოდ `fontes` ჩანაწერს. ყველა სხვა პარამეტრი და კომენტარი უცვლელი რჩება.
ფაილის შეცვლამდე ის მის გვერდით ინახავს ასლს `<file>.fontes-backup-<date>` სახელით. გასაღებების
დამატების შემდეგ შექმნილი ასლები ამ გასაღებებს შეიცავს; წაშალეთ ის ასლები, რომლებიც აღარ
გჭირდებათ. ის ასევე აყენებს uv-ს. ხელახლა გაშვება უსაფრთხოა: ის აღადგენს კონფიგურაციას და სხვა
არაფერს ცვლის.

Fontes-ის წასაშლელად გახსენით **Fontes Installer** და აირჩიეთ **წაშლა** (Mac), ან ორჯერ დააწკაპუნეთ **Uninstall Fontes.cmd**-ზე (Windows). ის ყველა აპიდან შლის `fontes` ჩანაწერს, გასაღებების
ჩათვლით. თქვენი სხვა პარამეტრები და სარეზერვო ასლები რჩება.

## განახლებები

- **ინსტალერი და `.mcpb` ფაილი:** არაფრის გაკეთება არ გჭირდებათ. დღეში ერთხელ, აპის გაშვებისას,
  Fontes ფონურ რეჟიმში ამოწმებს, არის თუ არა უფრო ახალი ვერსია, და ამზადებს მას; აპის შემდეგი
  გაშვებისას ის გამოიყენება. თუ განახლების ჩამოტვირთვა ვერ ხერხდება ან ის არ მუშაობს, Fontes
  აგრძელებს იმ ვერსიის გამოყენებას, რომელიც მუშაობდა.

# ⴰⵙⵔⵙ ⵏ Fontes

Fontes ⵉⵜⵜⴰⴵⵊⴰ ⴰⵙⵏⵙ ⵏⵏⴽ ⵏ AI ⴰⴷ ⵉⵔⵣⵓ ⵜⵉⴳⵜⵜⴰⵡⵉⵏ ⵏ ⵜⵎⵃⴽⵎⵉⵏ ⴷ ⵉⵣⵔⴼⴰⵏ ⵙ ⵜⵉⵙⵙⵓⵜⵔⴰ ⵜⵓⵔⴷⵉⵜ ⴳ ⵉⵙⵉⵜⵏ ⵏ
ⵜⵎⵃⴽⵎⵉⵏ ⴷ ⵜⵏⴱⴰⴹⵉⵏ ⴳ ⵓⴳⴳⴰⵔ ⵏ 120 ⵜⵙⴳⴰ ⵜⴰⵣⵔⴼⴰⵏⵜ. ⴽⵓ ⵜⴰⵢⴰⴼⵓⵜ ⵜⵇⵇⵏ ⵖⵔ ⵓⴹⵕⵉⵚ ⴰⵏⵚⵍⵉ. ⴷ ⴰⵎⵥⵍⴰ MCP

Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline ⴷ ⵡⵉⵢⵢⴰⴹ.

## ⵉⵙⵏⵙⵏ ⵢⴰⴹⵏ

ⴽⵓ ⵢⴰⵏ ⵙⴳ ⵉⵙⵏⵙⵏ ⴰⴷ ⵉⵔⴰ [uv](#ⵜⵔⵉⴷ-uv). ⵔⵏⵓ ⴰⵃⵔⵉⴼ, ⵃⴹⵓ, ⵙⴳ ⵎⴰⵏ ⴼⴼⵖ ⵙⴳ ⵓⵙⵏⵙ ⵜⵕⵥⵎⴷ ⵜ ⵜⵉⴽⴽⵍⵜ ⵢⴰⴹⵏ.

**Cursor:** ⴳ `~/.cursor/mcp.json` (ⴰⴽⴽ ⵉⵙⵏⴼⴰⵔⵏ) ⵏⵖ `.cursor/mcp.json` (ⵢⴰⵏ ⵓⵙⵏⴼⴰⵔ):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** ⵙⵙⵡⵓⵔⵉ **MCP: Add Server** ⵙⴳ Command Palette, ⵙⵜⵢ
**Command (stdio)**, ⴰⵔⴰ `uvx fontes-mcp` ⵜⵙⵎⵎⴰⴷ ⴰⵎⵥⵍⴰ `fontes`. ⵏⵖ ⵔⵏⵓ ⴰⵢⴰ ⵖⵔ
`~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

ⵉⵙⵖⵜⴰⵢⵏ ⵉⵇⴱⵓⵔⵏ ⵏ VS Code ⵙⵎⵔⴰⵙⵏ `.vscode/mcp.json`, ⵍⵍⵉ ⴳ ⵜⴳⴰ ⵜⵙⴰⵔⵓⵜ ⵜⴰⵏⴼⵍⵉⵜ `servers` ⴳ ⵓⵎⴽⴰⵏ
ⵏ `mcpServers`.

**Gemini CLI:** ⴳ ⵢⴰⵏ ⵓⵎⵙⵜⴰⵢ, `gemini mcp add -s user fontes uvx fontes-mcp`. ⵏⵖ ⵔⵏⵓ ⴰⵢⴰ ⵖⵔ
`~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** ⵕⵥⵎ ⴰⴼⴰⵢⵍⵓ ⵏ ⵉⵙⵖⵜⴰⵢⵏ ⵏⵏⴽ (**zed: open settings file**) ⵜⵔⵏⵓⴷ:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** ⴳ ⵜⵙⴳⴰ ⵏ ⵜⴼⴰⵙⵙⵉⵜ, ⵕⵥⵎ ⴰⵙⴰⵜⵍ **Program**, ⴽⵍⵉⴽⵉ ⴼ **Install → Edit
mcp.json**, ⵜⵔⵏⵓⴷ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** ⴽⵍⵉⴽⵉ ⴼ ⵜⵎⴰⵜⴰⵔⵜ **MCP Servers**, ⵕⵥⵎ ⴰⵙⴰⵜⵍ **Configure**, ⴽⵍⵉⴽⵉ ⴼ **Configure MCP
Servers**, ⵜⵔⵏⵓⴷ ⴰⵃⵔⵉⴼ `mcpServers` ⵏⵏⵉⵜ ⴰⵎⵎ ⵏ LM Studio.

**Claude Desktop, ⵙ ⵓⴼⵓⵙ** (ⴳ ⵓⵎⴽⴰⵏ ⵏ ⵓⴼⴰⵢⵍⵓ `.mcpb`): ⵔⵏⵓ ⴰⵃⵔⵉⴼ `mcpServers` ⵏⵏⵉⵜ ⵖⵔ
`claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**ⴽⵓ ⴰⵙⵏⵙ MCP ⵢⴰⴹⵏ** (Windsurf ⴷ ⵡⵉⵢⵢⴰⴹ): ⵜⵉⵎⵓⵔⵉⵡⵉⵏ (documentation) ⵏⵏⵙ ⴰⵢⴷ ⵉⵙⵙⵓⵖⵓⵍⵏ ⵎⴰⵏⵉ ⴳ ⵉⵃⴹⴰ
ⵉⵎⵥⵍⴰ MCP ⵏⵏⵙ. ⵓⴳⴳⴰⵔⵏ ⵇⴱⵍⵏ ⴰⵃⵔⵉⴼ ⵏⵏⵉⵜ: ⵜⴰⵏⴹⴹⵉⵜ (command) `uvx`, ⴰⵙⵖⵜⵉ (argument) `fontes`.

ⵎⴽ ⵓⵔ ⵉⵣⵎⵉⵔ ⵓⵙⵏⵙ ⴰⴷ ⵢⴰⴼ `uvx`, ⵙⵎⵔⵙ ⴰⴱⵔⵉⴷ ⵏⵏⵙ ⵎⴰⵔⵔⴰ (ⴳ macOS ⴷ Linux, `which uvx` ⴰⵢⴷ ⵜ ⵉⵙⵎⴷⵢⴰⵏ).

3. ⵙⵜⵢ **ⵙⵔⵙ** ⵜⴽⵍⵉⴽⵉⴷ ⴼ **ⵡⴰⵅⵅⴰ**. ⴰⵙⵔⵙ ⵉⵜⵜⴰⵡⵉ ⵎⴰ ⵢⵇⵔⴱⵏ ⵉ ⵢⴰⵜ ⵜⵓⵙⴷⵉⴷⵜ.
4. ⵢⴰⵏ ⵓⵣⵏ ⴰⴷ ⵉⵙⵎⴰⵍ ⵉⵙⵏⵙⵏ ⵍⵍⵉ ⵉⵙⵔⵙ. ⴽⵍⵉⴽⵉ ⴼ **ⵉⴽⵎⵍ**, ⵙⴳ ⵎⴰⵏ ⵕⵥⵎ ⵉⵙⵏⵙⵏ ⴰⴷ ⵜⵉⴽⴽⵍⵜ ⵢⴰⴹⵏ. ⵎⴰ ⵜⵔⵉⴷ ⴰⴷ

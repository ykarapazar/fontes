# ⵜⵉⵙⴰⵔⵓⵜⵉⵏ API

ⵎⴰⵙⵙⴰ ⴽⵓ ⴰⵙⴰⴳⵎ ⴳ Fontes ⵉⵜⵜⵅⴷⴰⵎ ⴱⵍⴰ ⵜⴰⵙⴰⵔⵓⵜ. ⵙⵉⵏ ⵔⴰⵏ ⵢⴰⵜ ⵜⵙⴰⵔⵓⵜ ⵜⴰⵍⵍⴰⵡⴰⵏⵜ:

| ⵜⴰⵙⴰⵔⵓⵜ | ⵎⴰⴷ ⵜⵔⵥⵎ | ⴱⵍⴰ ⵜⴰⵙⴰⵔⵓⵜ |
|---|---|---|
| `WLM_FR_PISTE_CLIENT_ID` + `WLM_FR_PISTE_CLIENT_SECRET` | ⴼⵔⴰⵏⵚⴰ: Judilibre (ⵜⵉⴳⵜⵜⴰⵡⵉⵏ ⵏ ⵜⵎⵃⴽⵎⵉⵏ) ⴷ Légifrance (ⵉⵣⵔⴼⴰⵏ) | ⴼⵔⴰⵏⵚⴰ ⵜⵇⵇⵏ. `list_jurisdictions` ⵉⵙⵎⴰⵍⴰ ⵜⵜ ⵓⵔ ⵜⵅⴷⴷⵎ. |
| `WLM_US_GOVINFO_KEY` | ⵜⵉⵡⵉⵍⴰⵢⵉⵏ ⵉⵎⵓⵏⵏ: ⴰⵔⵣⵣⵓ ⴳ govinfo (ⵜⵉⴳⵜⵜⴰⵡⵉⵏ ⵏ ⵜⵎⵃⴽⵎⵉⵏ ⵜⵉⴼⵉⴷⵉⵔⴰⵍⵉⵏ, Statutes at Large, public laws) | Fontes ⵉⵙⵙⵎⵔⴰⵙ `DEMO_KEY` ⵉⵜⵜⵓⴱⴹⴰⵏ: ⵎⴰⵙⵙⴰ 10 ⵏ ⵓⵔⵣⵣⵓ ⴳ ⵡⴰⵙⵙ ⵉ ⴽⵓ ⵜⴰⵏⵙⴰ IP. ⴰⵕⵥⵎ ⵏ ⵢⴰⵜ ⵜⴳⵜⵜⴰⵡⵜ ⵉⵜⵜⵓⵙⵙⵏⵏ ⴷ US Code ⵓⵔ ⵔⴰⵏ ⵜⴰⵙⴰⵔⵓⵜ. |

ⵜⵉⵙⴰⵔⵓⵜⵉⵏ ⵓⵔ ⴳⵉⵏⵜ ⵜⵉⵎⵍⵣⴰⵎⵉⵏ. ⵜⵣⵎⵔⴷ ⴰⴷ ⵜⵏⵜ ⵜⵔⵏⵓⴷ ⴷⴼⴼⵉⵔ.

## ⴰⵔⵏⵓ ⵏ ⵢⴰⵜ ⵜⵙⴰⵔⵓⵜ

**ⵙ ⵓⵎⵙⵔⵙ.** ⴳ ⵓⵙⵔⵙ, ⴰⵎⵙⵔⵙ ⵉⵙⵇⵙⴰ ⴽ ⵉⵙ ⵜⵔⵉⴷ ⴰⴷ ⵜⵔⵏⵓⴷ ⵜⵉⵙⴰⵔⵓⵜⵉⵏ. ⵙⵜⵢ **Not now** (ⵏⵖ ⴷⴼⵄ Enter)
ⵎⴰ ⵜⵔⵉⴷ ⴰⴷ ⵜⵣⵔⵉⴷ. ⵉ ⵓⵔⵏⵓ ⵏⵖ ⴰⴱⴷⴷⵍ ⵏ ⵜⵙⴰⵔⵓⵜⵉⵏ ⴷⴼⴼⵉⵔ, ⵙⵙⵓⵙⵔ **Add or change keys**:

- Mac: ⵕⵥⵎ ⴰⵙⵏⵙ Fontes Installer ⵜⵉⴽⴽⵍⵜ ⵢⴰⴹⵏ ⵜⵙⵜⵢⴷ **Add or change keys**, ⵏⵖ ⴽⵍⵉⴽⵉ ⵙⵉⵏ ⵏ ⵜⵉⴽⴽⴰⵍ ⴼ
  `Add or change keys.command` ⴳ ⵓⵙⴰⴷⵓⵔ ⵏ ⵓⵎⵙⵔⵙ.
- Windows: ⴽⵍⵉⴽⵉ ⵙⵉⵏ ⵏ ⵜⵉⴽⴽⴰⵍ ⴼ `Add or change keys.cmd` ⴳ ⵓⵙⴰⴷⵓⵔ ⵏ ⵓⵎⵙⵔⵙ. ⴰⵎⵙⵔⵙ ⵏ Windows, ⵎⵍⵎⵉ ⴰ ⵢⵉⵍⵉ,
  ⵔⴰⴷ ⵜ ⵉⴳ ⵓⵍⴰ ⴳ Start menu > Fontes.

ⵎⴰⴷ ⵜⴰⵔⴰⴷ ⵓⵔ ⵉⵜⵜⴱⴰⵢⴰⵏ. ⵉ ⴽⵓ ⵜⴰⵙⴰⵔⵓⵜ: ⵙⵙⵏⴹⵢ ⵜⵜ, ⴷⴼⵄ Enter ⵎⴰ ⵜⵔⵉⴷ ⴰⴷ ⵜⵃⴹⵓⴷ ⵜⵉⵏ ⵍⵍⴰⵏ, ⵏⵖ ⴰⵔ `-` ⴰⴷ ⵜⵜ ⵜⴽⴽⵙⴷ.
ⵜⵉⵙⴰⵔⵓⵜⵉⵏ ⴽⵛⵛⵎⵏⵜ ⵖⵔ ⴽⵓ ⴰⵙⵏⵙ ⵍⵍⵉ ⴳ ⵉⵍⵍⴰ Fontes.

**ⵙ ⵓⵙⵖⵣⴼ ⵏ Claude Desktop (.mcpb).** ⵕⵥⵎ Claude > Settings > Extensions > Fontes ⵜⴰⵔⴰⴷ ⵉⴳⵔⴰⵏ.
ⴽⵓⵍⵍⵓ ⵓⵔ ⴳⵉⵏ ⵉⵎⵍⵣⴰⵎⵏ.

**ⵙ ⵓⴼⵓⵙ.** ⵔⵏⵓ ⵉⵎⵙⵏⴼⴰⵍⵏ ⵖⵔ ⵓⵃⵔⵉⴼ `env` ⵏ ⵓⴽⵛⵛⵓⵎ `fontes` ⴳ ⵓⴼⴰⵢⵍⵓ ⵏ ⵜⵡⵍⴰ MCP ⵏ ⵓⵙⵏⵙ ⵏⵏⴽ:

```json
"fontes": {
  "command": "...",
  "args": ["..."],
  "env": { "WLM_US_GOVINFO_KEY": "your-key" }
}
```

ⴰⵍⵙ ⴰⵙⵏⵙ ⴷⴼⴼⵉⵔ ⴽⵓ ⴰⵙⵏⴼⵍ.

Hukum dari 120+ yurisdiksi, cukup dengan satu pertanyaan.

Beta · gratis · sumber terbuka · sumber diperiksa setiap hari

Fontes adalah server MCP gratis dan bersumber terbuka. Fontes berfungsi di aplikasi apa pun yang dapat menjalankan server Model Context Protocol lokal: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, dan lainnya. Ajukan pertanyaan hukum dengan bahasa sehari-hari: aplikasi AI Anda mencari putusan pengadilan dan peraturan perundang-undangan secara langsung di situs web pemerintah dan pengadilan, di lebih dari 120 yurisdiksi dan pengadilan internasional, dan menautkan setiap hasil ke dokumen aslinya. Fontes dibuat untuk advokat dan peneliti hukum, serta untuk siapa pun yang ingin membaca hukum langsung dari sumbernya.

Ini adalah terjemahan berbantuan mesin. Versi bahasa Inggris adalah yang berlaku.

Apa yang dilakukannya

  • Mencari putusan pengadilan dan peraturan perundang-undangan pada saat Anda bertanya, dari situs web atau API milik penerbit itu sendiri.
  • Setiap hasil menyebutkan sumbernya dan menautkannya, sehingga Anda dapat memeriksa dokumen aslinya.
  • Fontes tidak menyimpan basis data dan tidak memerlukan akun. Pertanyaan Anda hanya dikirim ke sumber yang sedang dicari. Jumlah penggunaan dan laporan bug bersifat opt-in.

Fontes adalah alat bantu riset, bukan nasihat hukum, dan menggunakannya tidak menciptakan hubungan advokat–klien. Fontes disediakan sebagaimana adanya, tanpa jaminan (lihat lisensi Apache 2.0). Beberapa sumber secara tegas merupakan versi tidak resmi, dan setiap sumber memiliki ketentuan penggunaannya sendiri; Fontes menyebutkannya dalam jawabannya. Baca putusan atau ketentuan secara lengkap sebelum Anda mengandalkannya. Fontes bersifat independen dan tidak berafiliasi dengan pengadilan, pemerintah, atau penerbit mana pun.

Instalasi

  • Claude Desktop: unduh berkas .mcpb Fontes dari rilis terbaru, klik dua kali berkas itu, lalu klik Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline, dan aplikasi lain: tambahkan Fontes ke pengaturan MCP aplikasi. Sebagian besar menerima entri ini; panduan instalasi memuat berkas dan cuplikan untuk setiap aplikasi.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx disertakan dengan uv. Di macOS atau Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Di Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Lalu mulai ulang aplikasi dan tanyakan: "Yurisdiksi mana saja yang dapat dicari oleh Fontes?"

Penginstal sekali klik untuk Mac dan Windows sedang disiapkan. Penginstal ini menyiapkan Fontes di Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio, dan Cline, di setiap aplikasi tersebut yang ada di komputer Anda, lalu menawarkan untuk menambahkan kunci Anda. Tutup aplikasi-aplikasi itu sebelum Anda menjalankannya. Rincian ada di panduan instalasi. Beberapa sumber memerlukan kunci gratis: lihat KEYS.md.

Fontes bersumber terbuka di bawah lisensi Apache 2.0. Teks hukum tetap berada di bawah lisensi masing-masing penerbit.

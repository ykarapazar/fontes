حقوق بیش از ۱۲۰ حوزه قضایی، به فاصله یک پرسش.

Beta · رایگان · متن‌باز · منابع روزانه بررسی می‌شوند

Fontes یک سرور MCP رایگان و متن‌باز است. در هر برنامه‌ای که بتواند یک سرور Model Context Protocol محلی اجرا کند کار می‌کند: Claude Desktop، Claude Code، Codex، Cursor، VS Code (GitHub Copilot)، Gemini CLI، Windsurf، Zed، LM Studio و دیگران. یک پرسش حقوقی را به زبان ساده بپرسید: برنامه هوش مصنوعی رویه قضایی و قوانین و مقررات را به‌صورت زنده در وب‌سایت‌های دولت‌ها و دادگاه‌ها، در بیش از ۱۲۰ حوزه قضایی و دادگاه بین‌المللی، جست‌وجو می‌کند و هر نتیجه را به نسخه اصلی پیوند می‌دهد. برای وکلا و پژوهشگران حقوقی ساخته شده است، و برای هر کسی که می‌خواهد قانون را از منبع آن بخواند.

چه می‌کند

  • رویه قضایی و قوانین و مقررات را در همان لحظه‌ای که می‌پرسید، از وب‌سایت یا API خود ناشر جست‌وجو می‌کند.
  • هر نتیجه منبع خود را نام می‌برد و به آن پیوند دارد، تا بتوانید نسخه اصلی را بررسی کنید.
  • Fontes هیچ پایگاه داده‌ای نگه نمی‌دارد و به حساب کاربری نیاز ندارد. پرسش‌های شما فقط به منبعی می‌روند که در آن جست‌وجو می‌شود. آمار استفاده و گزارش‌های خطا اختیاری (opt-in) هستند.

Fontes یک ابزار کمکی برای پژوهش است، نه مشاوره حقوقی، و استفاده از آن رابطه وکیل و موکل ایجاد نمی‌کند. «همان‌گونه که هست» و بدون هیچ ضمانتی ارائه می‌شود (ببینید مجوز Apache 2.0). برخی منابع صراحتاً نسخه‌های غیررسمی هستند و هر کدام شرایط استفاده خود را دارند؛ Fontes این را در پاسخ‌هایش ذکر می‌کند. پیش از تکیه بر یک رأی یا یک ماده، متن کامل آن را بخوانید. Fontes مستقل است و به هیچ دادگاه، دولت یا ناشری وابسته نیست.

نصب

  • Claude Desktop: فایل .mcpb مربوط به Fontes را از آخرین نسخه دریافت کنید، روی آن دوبار کلیک کنید، سپس روی Install کلیک کنید.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor، VS Code، Gemini CLI، Zed، LM Studio، Cline و برنامه‌های دیگر: Fontes را به تنظیمات MCP برنامه اضافه کنید. بیشتر آن‌ها این مدخل را می‌پذیرند؛ راهنمای نصب فایل و قطعه کد مربوط به هر برنامه را دارد.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx همراه با uv می‌آید. در macOS یا Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. در Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

سپس برنامه را دوباره راه‌اندازی کنید و بپرسید: «Fontes در کدام حوزه‌های قضایی می‌تواند جست‌وجو کند؟»

روی Mac یا Windows، یک نصب‌کننده تک‌کلیکی Fontes را در Claude Desktop، Codex، Claude Code، Cursor، VS Code، Windsurf، Gemini CLI، Zed، LM Studio و Cline، در هر کدام که روی رایانه شما باشد، راه‌اندازی می‌کند، سپس پیشنهاد می‌دهد کلیدهای شما را اضافه کند. نصب‌کننده را برای رایانه‌تان از آخرین نسخه دریافت کنید و پیش از اجرای آن، آن برنامه‌ها را ببندید. جزئیات در راهنمای نصب. برخی منابع به یک کلید رایگان نیاز دارند: ببینید KEYS.md.

Fontes تحت مجوز Apache 2.0 متن‌باز است. متن‌های حقوقی تحت مجوز هر ناشر باقی می‌مانند.

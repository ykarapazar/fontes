# Fontes: پوښتنې او ځوابونه

## Fontes څه شی دی؟

یو وړیا، خلاصې سرچینې MCP سرور (Apache 2.0). دا هر هغه اپ ته چې په Model Context
Protocol خبرې کوي (Claude، Codex، Cursor، VS Code، Gemini CLI او نور) اجازه ورکوي چې د محکمو فیصلې او
قوانین او مقررې په ژوندۍ بڼه د محکمو او حکومتونو په وېبپاڼو کې، په 120+ قضايي حوزو او نړیوالو
محکمو کې (124 adapters) ولټوي. هره پایله خپله سرچینه نوموي او له اصلي متن سره لینک لري.

## ایا متنونه رسمي دي؟

ډېری یې، خو تل نه.

- ډېرې سرچینې د یوې محکمې، یوې وزارت یا یوې رسمي جریدې له خوا چلېږي.
- ځینې تلفیقي متنونه د حکومت له خوا خپرېږي خو په ښکاره توګه غیر رسمي دي: یوازې
  رسمي جریده معتبره ده.
- یو شمېر سرچینې هېڅ حکومتي وېبپاڼې نه دي (د بېلګې په توګه LexiVox، LawPhil، Maqam،
  Wikisource).

Fontes هر هغه ځواب ته چې له دې څخه له یوې څخه راځي، د "Unofficial source" (غیر رسمي سرچینه) خبرتیا ور زیاتوي. مخکې له دې چې
له څه شي استناد وکړئ، رسمي خپرونه وګورئ. په [README](README.md#پوښښ) کې د پوښښ جدول
او `list_jurisdictions` د هرې قضايي حوزې سرچینه نوموي.

## کومې قضايي حوزې پوښي، او څومره ښه؟

124 adapters: د ملګرو ملتونو 108 غړي هېوادونه، هانګ کانګ، کوسوو، فلسطین، تایوان، د DIFC محکمې او
11 نړیوالې محکمې او ادارې (لکه د بشري حقونو اروپايي محکمه، اروپايي اتحادیه، د عدالت نړیواله
محکمه (ICJ) او د سوداګرۍ نړیوال سازمان (WTO)).

پوښښ ډېر توپیر لري. د یوه سخت قاعدې له مخې (د تر ټولو لوړې عمومي محکمې سابقې، یا
اساسي قانون او لومړني قوانین، په بشپړه توګه رسېدلي)، له 124 څخه 72 پوښل شوې ګڼل کېږي.
[COVERAGE.md](../../COVERAGE.md) د هرې قضايي حوزې لپاره لېست کوي چې Fontes څه ته رسېږي، څه ته نه رسېږي،
او ولې.

## ایا API کیلي ته اړتیا لرم؟

د نږدې هرې قضايي حوزې لپاره، نه. ځینې سرچینې یوې وړیا کیلي ته اړتیا لري: [KEYS.md](KEYS.md) وګورئ.

- **فرانسه:** هو. فرانسه تر هغه بنده ده چې تاسو `WLM_FR_PISTE_CLIENT_ID` او
  `WLM_FR_PISTE_CLIENT_SECRET` وټاکئ. دا له یوه وړیا PISTE حساب (piste.gouv.fr) څخه راځي چې یو
  اپ یې په Judilibre او Légifrance کې ګډون لري.
- **متحده ایالات:** اختیاري. د قضايي رویې لټون پرته له کیلي کار کوي، خو ګډه demo کیلي
  د هرې IP پتې لپاره په ورځ کې یوازې شاوخوا 10 لټونونو ته اجازه ورکوي. په `WLM_US_GOVINFO_KEY` کې یوه وړیا api.data.gov کیلي
  دا حد لوړوي.

دا د Fontes سرور لپاره د چاپېریالي متغیرونو په توګه ستاسو د اپ په MCP تنظیماتو کې وټاکئ. کله چې
نصبوونکی خپور شي، له نصبولو وروسته به یې وغواړي، او د هغه **Add or change keys** پیلوونکی (launcher)
وروسته یې بدلوي.

جلا له دې، یو شمېر سرچینې په خپلو شرطونو کې وايي چې اتومات لاسرسی د خپرونکي
اجازې ته اړتیا لري. هغه په OFF نښه شوې او بندې پاتې کېږي. کیلي دا نه بدلوي؛ یوازې د
خپرونکي اجازه یې بدلوي (بیا `WLM_PERMITTED=<codes>` وټاکئ).

## زما له کمپیوټر څخه څه وځي؟

ستاسو لټونونه یوازې هغې سرچینې ته ځي چې لټون پکې کېږي. Fontes هېڅ ډېټابېس نه ساتي او هېڅ
حساب ته اړتیا نه لري.

له سرچینو پرته، Fontes په ورځ کې یو ځل له PyPI پوښتي چې ایا نوې نسخه شته (د
`FONTES_NO_UPDATE_CHECK=1` په واسطه یې بند کړئ). د کارونې شمېرې بندې دي مګر دا چې تاسو یې روښانه کړئ، او د تېروتنې راپور
یوازې هغه وخت لېږل کېږي چې تاسو یې لیدلی او تایید کړی وي. ستاسو AI اپ ستاسو خبرې اترې د خپلو
شرطونو لاندې ویني.

بشپړ جزئیات: [PRIVACY.md](PRIVACY.md).

## ایا دا حقوقي مشوره ده؟

نه. Fontes یوه څېړنیزه وسیله ده. متنونه مومي؛ تاسو ته نه وايي چې ستاسو د قضیې لپاره څه معنا لري،
او کارول یې له هېچا سره د وکیل او موکل اړیکه نه جوړوي. AI اپ کېدای شي یو متن غلط ولولي، نو
مخکې له دې چې پرې تکیه وکړئ، بشپړه فیصله یا ماده ولولئ. د مشورې لپاره، له هغه وکیل څخه وپوښتئ چې
هلته واجد شرایط وي چېرې چې ستاسو پوښتنه رامنځته کېږي.

## څوک یې ساتي؟ ایا کار به ته دوام ورکړي؟

یو کس: Yüce Karapazar. د Fontes تر شا هېڅ شرکت، هېڅ د ملاتړ تړون او هېڅ
د خدمت د کچې ژمنه نشته. هېڅ حقوقي خدمتونه نه وړاندې کېږي.

سرچینې په ورځ کې یو ځل کتل کېږي او پایلې یې په
[حالت پاڼه](https://ykarapazar.github.io/fontes/status/?lang=ps) کې خپرېږي. د محکمو او حکومتونو وېبپاڼې
پرته له خبرتیا بدلېږي، نو یوه سرچینه هر وخت ماتېدای شي. هېڅ تضمین نشته چې کومه سرچینه،
یا پخپله Fontes، به کار ته دوام ورکړي. Fontes «لکه څنګه چې دی» (as is)، پرته له تضمینه وړاندې کېږي (د [LICENSE](../../../LICENSE) 7
او 8 برخې).

## Fontes له کوربه شویو (hosted) حقوقي څېړنیزو وسایلو څخه څه توپیر لري؟

- **ستاسو په کمپیوټر کې چلېږي.** هېڅ Fontes سرور او هېڅ حساب نشته. دا په دې معنا هم ده چې
  یوازې په هغو اپونو کې کار کوي چې محلي MCP سرور پیلولای شي (Claude Desktop، Codex، Cursor، VS Code
  او ورته)، نه په هغو یوازې-وېب اپونو کې چې یوازې کوربه شوي connectors مني.
- **هېڅ ډېټابېس نه لري.** هر لټون په ژوندۍ بڼه د خپرونکي خپلې وېبپاڼې یا API ته ځي، نو
  پایلې هغومره تازه دي لکه سرچینه، او د لټون کیفیت د سرچینې خپل دی. په یوه غوره شوي (curated) index باندې
  هېڅ معنايي (semantic) لټون نشته.
- **د کارونې هېڅ حد نه ټاکي.** Fontes هېڅ میاشتنی د غوښتنو حد نه لري. هرې وېبپاڼې ته خپلې
  غوښتنې په واټن لېږي، او ځینې سرچینې محدودوي چې څومره ژر یا څو ځله ترې پوښتنه کېدای شي.
- **خلاصې سرچینې دی.** تاسو کولای شئ هر adapter ولولئ او دقیقاً ووینئ چې هر متن له کومه راځي.
- **تر شا یې هېڅ پلورونکی (vendor) نشته.** هېڅ تړون، د ملاتړ مېز یا د فعال پاتې کېدو ژمنه نشته ("څوک
  یې ساتي؟" وګورئ).

## له کومو اپونو او سیسټمونو سره کار کوي؟

هر MCP اپ چې محلي (stdio) سرور چلولای شي، د بېلګې په توګه Claude Desktop، Claude Code،
Codex، Cursor، VS Code (GitHub Copilot)، Gemini CLI، Windsurf، Zed، LM Studio او Cline. Fontes
په macOS، Windows او Linux کې چلېږي، هر چېرې چې uv چلېږي (Python 3.13+). په Mac یا Windows PC کې، یو یو-کلیک نصبوونکی
Claude Desktop، Codex، Claude Code، Cursor، VS Code، Windsurf، Gemini CLI، Zed، LM Studio او
Cline په یو ځل جوړوي. د هر اپ ګامونه: [INSTALL.md](INSTALL.md).

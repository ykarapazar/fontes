څه کوي

  • په همغه شېبه کې چې تاسو پوښتنه کوئ، د خپرونکي له خپلې وېبپاڼې یا API څخه قضايي رویه او قوانین او مقررې لټوي.
  • هره پایله خپله سرچینه نوموي او له هغې سره لینک لري، څو تاسو اصلي متن وګورئ.
  • Fontes هېڅ ډېټابېس نه ساتي او هېڅ حساب ته اړتیا نه لري. ستاسو پوښتنې هغې سرچینې ته ځي چې لټون پکې کېږي؛ د قوانینو د پخوانیو نسخو او 91 نورو هېوادونو (او د هندوستان د قوانینو) لپاره، د Lexifina عامه خدمت ته ځي، د رسمي سایټ سربېره یا پر ځای یې. د دې بندولو لپاره WLM_LEXIFINA=0 تنظیم کړئ. د کارونې شمېرې او د تېروتنو راپورونه اختیاري (opt-in) دي.

Fontes د څېړنې مرستندویه وسیله ده، نه حقوقي مشوره، او کارول یې د وکیل او موکل اړیکه نه جوړوي. «لکه څنګه چې دی» (as is)، پرته له هر ډول تضمینه وړاندې کېږي (وګورئ Apache 2.0 جواز). ځینې سرچینې په ښکاره توګه غیر رسمي کاپي دي، او هره یوه د کارونې خپل شرطونه لري؛ Fontes دا په خپلو ځوابونو کې وايي. مخکې له دې چې پر یوې فیصلې یا مادې تکیه وکړئ، بشپړ متن یې ولولئ. Fontes خپلواک دی او له هېڅ محکمې، حکومت یا خپرونکي سره تړاو نه لري.

نصب

  • Claude Desktop: د Fontes .mcpb فایل له وروستۍ خپرونې څخه ښکته کړئ، پرې دوه ځله کلیک وکړئ، بیا پر Install کلیک وکړئ.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor، VS Code، Gemini CLI، Zed، LM Studio، Cline او نور اپونه: Fontes د اپ MCP تنظیماتو ته ور زیات کړئ. ډېری یې همدا ننوتنه مني؛ د نصب لارښود د هر اپ فایل او ټوټه (snippet) ورکوي.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

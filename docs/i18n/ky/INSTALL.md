# Fontes'ти орнотуу

Fontes сиздин AI тиркемеңизге 120дан ашык юрисдикцияда сот чечимдерин жана мыйзамдарды сот
жана мамлекеттик сайттардан түз издөөгө мүмкүндүк берет. Ар бир натыйжа түп нускага шилтеме
берет. Бул стандарттуу MCP сервери, ошондуктан ал жергиликтүү MCP серверин иштете алган ар
кандай тиркемеде иштейт: Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub Copilot),
Gemini CLI, Windsurf, Zed, LM Studio, Cline жана башкалар.

Тиркемеңизди тандап, анын кадамдарын аткарыңыз, андан кийин
[иштеп жатканын текшериңиз](#иштеп-жатканын-текшерүү).

## Claude Desktop

1. Fontes `.mcpb` файлын [акыркы релизден](https://github.com/ykarapazar/fontes/releases/latest)
   жүктөп алыңыз.
2. Аны эки жолу басыңыз. Claude Desktop аны ачат.
3. **Install** басыңыз.

## Codex

Терминалда:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI жана Codex IDE кеңейтүүсү бул жөндөөнү бирге колдонушат (`~/.codex/config.toml`).
Сизге [uv](#uv-керек) керек.

## Claude Code

Терминалда:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Сизге [uv](#uv-керек) керек.

## Башка тиркемелер

Булардын ар бирине [uv](#uv-керек) керек. Жазууну кошуп, сактаңыз, андан кийин тиркемени
жаап, кайра ачыңыз.

**Cursor:** `~/.cursor/mcp.json` (бардык долбоорлор) же `.cursor/mcp.json` (бир долбоор)
файлында:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette'тен **MCP: Add Server** иштетиңиз,
**Command (stdio)** тандаңыз, `uvx fontes-mcp` киргизиңиз жана серверге `fontes` деп ат бериңиз.
Же муну `~/.copilot/mcp-config.json` файлына кошуңуз:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code'дун эски жөндөөлөрү `.vscode/mcp.json` колдонот, анда жогорку деңгээлдеги ачкыч
`mcpServers` эмес, `servers` болот.

**Gemini CLI:** терминалда `gemini mcp add -s user fontes uvx fontes-mcp`. Же муну
`~/.gemini/settings.json` файлына кошуңуз:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** жөндөөлөр файлыңызды ачыңыз (**zed: open settings file**) жана кошуңуз:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** оң жактагы каптал панелде **Program** өтмөгүн ачыңыз, **Install → Edit
mcp.json** басыңыз жана кошуңуз:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** сүрөтчөсүн басыңыз, **Configure** өтмөгүн ачыңыз, **Configure MCP
Servers** басыңыз жана LM Studio үчүн болгон ошол эле `mcpServers` жазуусун кошуңуз.

**Claude Desktop, кол менен** (`.mcpb` файлынын ордуна): ошол эле `mcpServers` жазуусун
`claude_desktop_config.json` файлына кошуңуз (macOS: `~/Library/Application Support/Claude/`,
Windows: `%APPDATA%\Claude\`).

**Башка ар кандай MCP тиркемеси** (Windsurf жана башкалар): анын өз документтеринде MCP
серверлерин кайда сактаары айтылат. Көпчүлүгү ошол эле жазууну кабыл алат: буйрук `uvx`,
аргумент `fontes`.

Эгер тиркеме `uvx` таба албаса, анын толук жолун колдонуңуз (macOS жана Linux'та `which uvx`
аны көрсөтөт).

## uv керек

Codex, Claude Code жана башка тиркемелер Fontes'ти `uvx` менен ишке киргизет, ал эми ал
Astral'дын чакан акысыз куралы болгон **uv** менен бирге келет. Аны орнотуу үчүн
[Astral'дын колдонмосун](https://docs.astral.sh/uv/getting-started/installation/) караңыз же
иштетиңиз:

- macOS же Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## Иштеп жатканын текшерүү

Жаңы маекте сураңыз: *“Fontes кайсы юрисдикцияларда издей алат?”* Тиркеме өлкөлөрдүн тизмеси
менен жооп бериши керек. Эгер бербесе, тиркемени дагы бир жолу жаап, кайра ачыңыз.

## Бир басуу менен орнотуучу (Mac жана Windows)

Орнотуучу Fontes'ти бардык тиркемелериңизде бир убакта орнотот: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio жана Cline.

**Баштоодон мурун:** бул тиркемелердин ар бирин толугу менен жабыңыз. Бул Claude Code үчүн
эң маанилүү: ал иштеп турганда `~/.claude.json` файлын кайра жазат жана орнотуучунун
өзгөртүүсүн жокко чыгарышы мүмкүн. Эгер Claude Code'ду жаба албасаңыз, анын ордуна Fontes'ти
ага `claude mcp add` менен кошуңуз ([Claude Code](#claude-code) караңыз).

**Mac**

1. Mac орнотуучусун (`Fontes-Installer-…-mac.zip`) [акыркы релизден](https://github.com/ykarapazar/fontes/releases/latest)
   жүктөп алыңыз жана архивин ачуу үчүн аны эки жолу басыңыз.
2. **Fontes Installer** тиркемесин эки жолу басыңыз. Эгер Mac интернеттен жүктөлүп алынган
   тиркемени ачуу керекпи деп сураса, **Open** басыңыз.
3. **Орнотуу** тандаңыз жана **OK** басыңыз. Орнотуу болжол менен бир мүнөт созулат.
4. Билдирүүдө ал орноткон тиркемелердин тизмеси чыгат. **Даяр** басыңыз, андан кийин ошол
   тиркемелерди кайра ачыңыз. Адегенде кошумча акысыз ачкычтарды кошуу үчүн анын ордуна
   **Ачкычтарды кошуу** басыңыз; [Ачкычтар кадамы](#ачкычтар-кадамы) караңыз.

**Windows**

1. Windows орнотуучусун (`Fontes-Setup-….exe`) [акыркы релизден](https://github.com/ykarapazar/fontes/releases/latest) жүктөп алыңыз жана эки жолу басыңыз.
   - Эгер Windows “Windows protected your PC” деп көрсөтсө: **More info**, андан кийин
     **Run anyway** басыңыз.
2. **Орнотуу** басыңыз. Терезе ачылып, Fontes'ти орнотот.
3. Анонимдүү колдонуу сандарын жөнөтүү керекпи деп суралганда, “жок” үчүн Enter басыңыз.
4. Ал ачкычтарды азыр кошуу керекпи деп сурайт. Өткөрүп жиберүү үчүн Enter басыңыз;
   [Ачкычтар кадамы](#ачкычтар-кадамы) караңыз.
5. **Даяр** деп чыкканда, AI тиркемелериңизди кайра ачыңыз. Эгер алардын бири дагы эле иштеп
   жатса, аны толугу менен жабыңыз (системалык лотоктон да, сааттын жанынан) жана кайра ачыңыз.

Аягында орнотуучу өзү орноткон тиркемелердин тизмесин көрсөтөт.

### Кайсы тиркемелерди орнотот

Ал тиркемени ошол тиркеменин жөндөөлөр папкасы компьютериңизде мурунтан эле бар болсо гана
орнотот. Claude Code `~/.claude.json` бар болсо гана орнотулат. Claude Desktop ар дайым
орнотулат. Ар бир тиркеме ушул файлда бир жазууну, `fontes`, алат:

| Тиркеме | Файл (Mac жана Linux) | Файл (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` жана Microsoft Store версиясынын өз көчүрмөсү |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` же эски версияларда `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` же `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code `~/.copilot` же VS Code'дун өз жөндөөлөр папкасы бар болсо орнотулат.

Эки тиркемеге дагы бир кадам керек:

- **Windsurf:** аны кайра ачкандан кийин Cascade'де жаңыртуу баскычын басыңыз.
- **Эски VS Code кеңейтүүсүнүн ичиндеги Cline:** Fontes'ти кол менен кошуңуз
  ([Cline](#башка-тиркемелер) караңыз).

### Ачкычтар кадамы

Орнотуудан кийин дароо орнотуучу Франция жана АКШ үчүн акысыз ачкычтарды кошууну сунуштайт.
Аларды кийинчерээк кошуу же өзгөртүү үчүн:

- **Mac:** **Fontes Installer** тиркемесин кайра ачып, **Ачкычтарды кошуу же өзгөртүү** тандаңыз.
- **Windows:** Start менюсун ачып, **Fontes** → **Add or change keys** тандаңыз.

Терилген текст жашырылат. Ачкычтар Fontes мурунтан эле бар болгон ар бир тиркемеге
киргизилет. Андан кийин тиркемелерди жаап, кайра ачыңыз. Ачкычтарды кайдан алуу керек жана
алар эмнени ачат: [KEYS.md](KEYS.md).

### Камдык көчүрмөлөр, кайра иштетүү жана өчүрүү

Орнотуучу `fontes` жазуусун гана өзгөртөт. Башка бардык жөндөөлөр жана комментарийлер
мурункудай калат. Файлды өзгөртүүдөн мурун ал анын жанына `<file>.fontes-backup-<date>` деген
аталыштагы көчүрмөсүн сактайт. Ачкычтарды кошкондон кийин жасалган көчүрмөлөрдө ошол
ачкычтар болот: мындан ары керек эместерин өчүрүңүз. Ал uv'ди да орнотот. Аны кайра иштетүү
коопсуз: ал орнотууну оңдойт жана башка эч нерсени өзгөртпөйт.

Fontes'ти өчүрүү үчүн **Fontes Installer** тиркемесин ачып, **Өчүрүү** тандаңыз (Mac) же
**Fontes**'ти Settings → Apps аркылуу өчүрүңүз (Windows). Ал `fontes` жазуусун, ачкычтары менен кошо, бардык
тиркемелерден өчүрөт. Башка жөндөөлөрүңүз жана камдык көчүрмөлөр калат.

## Жаңыртуулар

- **Орнотуучу жана `.mcpb` файлы:** эч нерсе кылуунун кереги жок. Күнүнө бир жолу, тиркеме
  ачылганда, Fontes фондо жаңы версияны текшерип, аны даярдайт; тиркеме кийинки жолу
  ачылганда аны колдонот. Эгер жаңыртууну жүктөп алуу мүмкүн болбосо же ал иштебесе, Fontes
  иштеген версияны колдонууну улантат.
- **`uvx`:** жаңы версия чыкканда, Fontes бул тууралуу юрисдикциялар тизмесинин башында
  айтат. Ар дайым эң жаңы версияны иштетүү үчүн `fontes-mcp` ордуна `fontes-mcp@latest` колдонуңуз.

Бул үчүн сиз же издөөлөрүңүз тууралуу эч кандай маалымат эч жакка жөнөтүлбөйт.

## Купуялуулук

Fontes демейки шартта сиз же издөөлөрүңүз тууралуу эч нерсе жөнөтпөйт. Колдонуу сандары
сиздин макулдугуңуз менен гана жөнөтүлөт, ал эми ката тууралуу отчет сиз аны көрүп,
ырастагандан кийин гана жөнөтүлөт. Толук маалымат: [PRIVACY.md](PRIVACY.md).

## Өчүрүү

`fontes` жазуусун тиркемеңиздин MCP жөндөөлөрүнөн өчүрүңүз (Claude Code'до:
`claude mcp remove fontes`), андан кийин тиркемени жаап, кайра ачыңыз.

## Билүү пайдалуу

Fontes ачык булактарды, негизинен сот жана мамлекеттик сайттарды окуйт. Ал расмий эмес
булактарды өз жоопторунда белгилейт. Сот чечимине же беренеге таянуудан мурун ар дайым
булактын шилтемесин ачыңыз.

Эгер бир нерсе туура эмес болсо, эмне кылганыңызды жана көргөн катаңызды
fontesmcp@proton.me дарегине жазыңыз.

## Таянуудан мурун

- Fontes изилдөө куралы, юридикалык кеңеш эмес. Аны колдонуу эч кимди сиздин адвокатыңыз
  кылбайт.
- Ал “болгондой” (“as is”), эч кандай кепилдиксиз берилет жана мыйзам уруксат берген
  чекте анын авторлору анын кантип колдонулушу үчүн жооптуу эмес. Толук шарттар
  [лицензияда](../../../LICENSE) (Apache 2.0).

Сот практикасы жана мыйзамдар сиздин AI тиркемеңиз үчүн, соттун жана мамлекеттик сайттардан түз окулат.

Бета · акысыз · ачык булак коддуу · булактар күн сайын текшерилет

Fontes — акысыз, ачык булак коддуу MCP сервери. Ал жергиликтүү Model Context Protocol серверин иштете алган ар кандай тиркемеде иштейт: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio жана башкалар. Юридикалык суроону жөнөкөй тилде бериңиз: AI тиркемеңиз 125 юрисдикцияда жана эл аралык соттордо сот чечимдерин жана мыйзамдарды мамлекеттик жана сот сайттарынан түз издейт жана ар бир натыйжаны түп нускага байланыштырат. Ал ошондой эле мыйзамды анын күчүнө кирген мезгилдеги абалы боюнча көрсөтө алат жана 91 башка өлкөнүн мыйзамдарын Lexifina жазуусунан окуй алат (расмий басмырлоочу эмес). Ал юристтер жана юридикалык изилдөөчүлөр үчүн, ошондой эле мыйзамды анын булагынан окугусу келген ар бир адам үчүн жасалган.

Эмне кылат

  • Сот практикасын жана мыйзамдарды сиз сураган учурда жарыялоочунун өз сайтынан же API'синен издейт.
  • Ар бир натыйжа өз булагын атайт жана ага шилтеме берет, ошондуктан түп нускасын текшере аласыз.
  • Fontes маалымат базасын сактабайт жана аккаунт талап кылбайт. Суроолоруңуз изделип жаткан булакка барат; мыйзамдардын мурунку версиялары жана 91 кошумча өлкө (жана Индия мыйзамдары) үчүн алар Lexifina ачык кызматына да барат, расмий сайтка кошумча же анын ордуна. Муну өчүрүү үчүн WLM_LEXIFINA=0 коюңуз. Колдонуу сандары жана ката тууралуу отчеттор сиздин макулдугуңуз менен гана жөнөтүлөт.

Fontes юридикалык кеңеш эмес, изилдөө үчүн көмөкчү курал, жана аны колдонуу адвокат-кардар мамилесин түзбөйт. Ал “болгондой” (“as is”), эч кандай кепилдиксиз берилет (Apache 2.0 лицензиясын караңыз). Айрым булактар ачык эле расмий эмес версиялар, жана алардын ар биринин өз колдонуу шарттары бар; Fontes муну өз жоопторунда айтат. Таянуудан мурун сот чечимин же беренени толук окуңуз. Fontes көз карандысыз жана эч бир сот, өкмөт же жарыялоочу менен байланышкан эмес.

Орнотуу

  • Claude Desktop: Fontes .mcpb файлын акыркы релизден жүктөп алып, аны эки жолу басыңыз, андан кийин Install басыңыз.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline жана башка тиркемелер: Fontes'ти тиркеменин MCP жөндөөлөрүнө кошуңуз. Көпчүлүгү ушул жазууну кабыл алат; орнотуу боюнча колдонмодо ар бир тиркеме үчүн файл жана үзүндү бар.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx uv менен бирге келет. macOS же Linux'та: curl -LsSf https://astral.sh/uv/install.sh | sh. Windows'то (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Андан кийин тиркемени кайра иштетип, сураңыз: “Fontes кайсы юрисдикцияларда издей алат?”

Mac же Windows компьютеринде бир басуу менен орнотуучу Fontes'ти Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio жана Cline'да, компьютериңиздеги алардын ар биринде жөндөйт, андан кийин ачкычтарыңызды кошууну сунуштайт. Аны компьютериңиз үчүн акыркы релизден жүктөп алыңыз жана иштетүүдөн мурун ошол тиркемелерди жабыңыз. Толук маалымат орнотуу боюнча колдонмодо. Айрым булактарга акысыз ачкыч керек: KEYS.md караңыз.

Fontes Apache 2.0 лицензиясы боюнча ачык булак коддуу. Юридикалык тексттер ар бир жарыялоочунун лицензиясы астында калат.

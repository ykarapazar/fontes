# Fontes: суроолор жана жооптор

## Fontes деген эмне?

Акысыз, ачык булак коддуу MCP сервери (Apache 2.0). Ал Model Context Protocol'ду колдогон ар
кандай тиркемеге (Claude, Codex, Cursor, VS Code, Gemini CLI жана башкалар) 120дан ашык
юрисдикцияда жана эл аралык соттордо (124 адаптер) сот чечимдерин жана мыйзамдарды сот жана
мамлекеттик сайттардан түз издөөгө мүмкүндүк берет. Ар бир натыйжа өз булагын атайт жана түп
нускага шилтеме берет.

## Тексттер расмийби?

Көбүнчө ооба, бирок дайыма эмес.

- Булактардын көпчүлүгүн сот, министрлик же расмий басылма башкарат.
- Бардык өзгөртүүлөр киргизилген айрым тексттерди өкмөт жарыялайт, бирок алар ачык эле
  расмий эмес: расмий басылма гана аныктыгы ырасталган деп эсептелет.
- Бир нече булак таптакыр мамлекеттик сайттар эмес (мисалы, LexiVox, LawPhil, Maqam,
  Wikisource).

Fontes ушулардын биринен келген ар бир жоопко “Unofficial source” эскертүүсүн кошот. Бир
нерсеге цитата келтирүүдөн мурун расмий басылманы текшериңиз. [README](README.md#камтуу)
файлындагы камтуу таблицасы жана `list_jurisdictions` ар бир юрисдикциянын булагын атайт.

## Кайсы юрисдикцияларды камтыйт жана канчалык жакшы?

124 адаптер: БУУга мүчө 108 мамлекет, Гонконг, Косово, Палестина, Тайвань, DIFC Courts жана
11 эл аралык сот жана орган (мисалы, Адам укуктары боюнча Европа соту, ЕБ, Эл аралык сот жана
ДСУ).

Камтуу абдан айырмаланат. Катуу эреже боюнча (эң жогорку жалпы соттун прецеденттери же
конституция жана негизги актылар толук жеткиликтүү болсо), 124түн 72си камтылган деп
эсептелет. [COVERAGE.md](../../COVERAGE.md) ар бир юрисдикция үчүн Fontes эмнеге жетерин,
эмнеге жетпесин жана эмне үчүн экенин көрсөтөт.

## Мага API ачкычы керекпи?

Дээрлик бардык юрисдикциялар үчүн керек эмес. Айрым булактарга акысыз ачкыч керек: [KEYS.md](KEYS.md)
караңыз.

- **Франция:** ооба. `WLM_FR_PISTE_CLIENT_ID` жана `WLM_FR_PISTE_CLIENT_SECRET` коймоюнча
  Франция өчүк. Алар Judilibre жана Légifrance'ка жазылган тиркемеси бар акысыз PISTE
  аккаунтунан (piste.gouv.fr) алынат.
- **Америка Кошмо Штаттары:** милдеттүү эмес. Сот практикасы боюнча издөө ачкычсыз иштейт,
  бирок жалпы демо ачкыч бир IP дарек үчүн күнүнө болжол менен 10 гана издөөгө уруксат
  берет. `WLM_US_GOVINFO_KEY` ичиндеги акысыз api.data.gov ачкычы бул чекти жогорулатат.

Буларды тиркемеңиздин MCP жөндөөлөрүндө Fontes сервери үчүн чөйрө өзгөрмөлөрү катары
коюңуз. Орнотуучу чыккандан кийин ал орнотуудан соң аларды сурайт, ал эми анын **Add or
change keys** ишке киргизгичи аларды кийин өзгөртөт.

Мындан тышкары, бир нече булак өз шарттарында автоматтык кирүү үчүн жарыялоочунун уруксаты
керек экенин айтат. Алар ӨЧҮК деп белгиленген жана өчүк бойдон калат. Ачкыч муну
өзгөртпөйт; муну жарыялоочунун уруксаты гана өзгөртөт (андан кийин `WLM_PERMITTED=<codes>`
коюңуз).

## Компьютеримден эмне чыгат?

Издөөлөрүңүз изделип жаткан булакка гана барат. Fontes маалымат базасын сактабайт жана
аккаунт талап кылбайт.

Булактардан тышкары, Fontes күнүнө бир жолу PyPI'дан жаңы версия бар-жогун сурайт (аны
`FONTES_NO_UPDATE_CHECK=1` менен өчүрүңүз). Колдонуу сандары өзүңүз күйгүзмөйүнчө өчүк, ал
эми ката тууралуу отчет сиз аны көрүп, ырастагандан кийин гана жөнөтүлөт. AI тиркемеңиз
сиздин сүйлөшүүңүздү өз шарттарына ылайык көрөт.

Толук маалымат: [PRIVACY.md](PRIVACY.md).

## Бул юридикалык кеңешпи?

Жок. Fontes — изилдөө куралы. Ал тексттерди табат; алар сиздин ишиңиз үчүн эмнени билдирерин
айтпайт, жана аны колдонуу эч ким менен адвокат-кардар мамилесин түзбөйт. AI тиркемеси
текстти туура эмес окушу мүмкүн, ошондуктан таянуудан мурун сот чечимин же беренени толук
окуңуз. Кеңеш алуу үчүн сурооңуз пайда болгон жерде квалификациясы бар адвокатка кайрылыңыз.

## Аны ким колдойт? Ал иштей береби?

Бир адам: Yüce Karapazar. Fontes'тин артында компания, колдоо келишими же кызмат деңгээли
боюнча убада жок. Эч кандай юридикалык кызматтар сунушталбайт.

Булактар күнүнө бир жолу текшерилет жана натыйжалар [абал барагында](https://ykarapazar.github.io/fontes/status/?lang=ky)
жарыяланат. Сот жана мамлекеттик сайттар эскертүүсүз өзгөрөт, ошондуктан булак каалаган
убакта бузулушу мүмкүн. Кайсы бир булак же Fontes өзү иштей берет деген кепилдик жок. Fontes
“болгондой” (“as is”), кепилдиксиз берилет ([LICENSE](../../../LICENSE) файлынын 7- жана
8-бөлүмдөрү).

## Текст туура эмес, эскирген же булак бузулган. Бул тууралуу кантип кабарлайм?

- “Broken or wrong source” формасы менен issue ачыңыз:
  <https://github.com/ykarapazar/fontes/issues/new/choose>. Кайсы юрисдикция, эмне сураганыңызды,
  эмне алганыңызды жана туура текстти көрсөткөн расмий баракты жазыңыз.
- Же AI тиркемеңизден “Fontes катасы тууралуу кабарлоону” сураңыз (же `fontes report-bug`
  иштетиңиз). Эч нерсе жөнөтүлгөнгө чейин отчетту көрөсүз.
- Же fontesmcp@proton.me дарегине жазыңыз.

Отчетко кардарлар тууралуу маалыматтарды же купуя фактыларды кошпоңуз.

**Эгер сиз ушул булактардын бирин башкарсаңыз** жана бир нерсе туура эмес болсо (колдонуу
шарттарыңыз, robots.txt, сурамдардын чектери), fontesmcp@proton.me дарегине жазыңыз. Булак
оңдолот же өчүрүлөт.

## Fontes булутта жайгашкан юридикалык изилдөө куралдарынан эмнеси менен айырмаланат?

- **Ал сиздин компьютериңизде иштейт.** Fontes сервери жана аккаунт жок. Бул ошондой эле ал
  жергиликтүү MCP серверин ишке киргизе алган тиркемелерде гана (Claude Desktop, Codex,
  Cursor, VS Code жана ушул сыяктуулар) иштей турганын билдирет, булутта жайгашкан
  коннекторлорду гана кабыл алган веб тиркемелерде иштебейт.
- **Анын маалымат базасы жок.** Ар бир издөө түз жарыялоочунун өз сайтына же API'сине барат,
  ошондуктан натыйжалар булактын өзүндөй жаңы, ал эми издөөнүн сапаты булактын өзүнүкү.
  Тандалып түзүлгөн индекс боюнча семантикалык издөө жок.
- **Ал колдонуу чегин койбойт.** Fontes'те айлык чакыруулардын чеги жок. Ал ар бир сайтка
  сурамдарын аралык менен жөнөтөт, ал эми айрым булактар аларга канчалык тез же канчалык көп
  кайрылууга болорун чектейт.
- **Ал ачык булак коддуу.** Ар бир адаптерди окуп, ар бир текст кайдан келерин так көрө
  аласыз.
- **Анын артында жеткирүүчү жок.** Келишим, колдоо кызматы же иштөө убактысы боюнча убада
  жок (“Аны ким колдойт?” караңыз).

## Кайсы тиркемелер жана тутумдар менен иштейт?

Жергиликтүү (stdio) серверди иштете алган ар кандай MCP тиркемеси, мисалы, Claude Desktop,
Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio жана
Cline. Fontes macOS, Windows жана Linux'та, uv иштеген ар кандай жерде иштейт (Python 3.13+).
Ал азырынча PyPI'да жок; ал пайда болгондон кийин көпчүлүк тиркемелерге бир буйрук же бир
конфигурация жазуусу жетиштүү, ал эми Claude Desktop эки жолу басылган `.mcpb` файлын кабыл
алат. Mac жана Windows үчүн бир басуу менен орнотуучу жакында чыгат. Ал Claude Desktop, Codex,
Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio жана Cline'ды бир жолу
жөндөйт. Ар бир тиркеме үчүн кадамдар: [INSTALL.md](INSTALL.md).

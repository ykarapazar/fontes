Jurisprudență și legislație pentru aplicația dumneavoastră de IA, citite în timp real de pe site-urile instanțelor și ale autorităților publice.

Beta · gratuit · open source · surse verificate zilnic

Fontes este un server MCP gratuit, cu sursă deschisă. Funcționează în orice aplicație care poate rula un server Model Context Protocol local: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio și altele. Puneți o întrebare juridică în limbaj obișnuit: aplicația dumneavoastră de IA caută hotărâri judecătorești și legislație în timp real pe site-urile autorităților publice și ale instanțelor, în 125 de jurisdicții și la instanțe internaționale, și oferă pentru fiecare rezultat un link către original. Poate, de asemenea, să arate o lege așa cum era la o dată din trecut și să citească legislația din alte 91 de țări, din registrul Lexifina (nu este editorul oficial). Este creat pentru juriști și cercetători în drept, precum și pentru oricine dorește să citească dreptul la sursă.

Ce face

  • Caută jurisprudență și legislație în momentul în care întrebați, pe site-ul sau API-ul propriu al editorului.
  • Fiecare rezultat își numește sursa și are un link către ea, ca să puteți verifica originalul.
  • Fontes nu păstrează nicio bază de date și nu necesită niciun cont. Întrebările dumneavoastră ajung la sursa în care se caută; pentru versiunile anterioare ale legilor și pentru cele 91 de țări suplimentare (și legile Indiei), ele ajung la serviciul public Lexifina, pe lângă site-ul oficial sau în locul acestuia. Setați WLM_LEXIFINA=0 pentru a dezactiva acest lucru. Contorizările de utilizare și rapoartele de eroare sunt opționale (opt-in).

Fontes este un instrument de sprijin pentru cercetare, nu consultanță juridică, iar folosirea lui nu creează o relație avocat–client. Este furnizat „ca atare”, fără garanție (vedeți licența Apache 2.0). Unele surse sunt versiuni declarate expres neoficiale și fiecare are propriile condiții de utilizare; Fontes precizează acest lucru în răspunsurile sale. Citiți hotărârea sau dispoziția integrală înainte de a vă baza pe ea. Fontes este independent și nu este afiliat niciunei instanțe, niciunui guvern și niciunui editor.

Instalare

  • Claude Desktop: descărcați fișierul .mcpb al Fontes din cea mai recentă versiune, faceți dublu clic pe el, apoi faceți clic pe Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline și alte aplicații: adăugați Fontes în setările MCP ale aplicației. Majoritatea acceptă această intrare; ghidul de instalare indică fișierul și fragmentul pentru fiecare aplicație.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx vine împreună cu uv. Pe macOS sau Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Pe Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Apoi reporniți aplicația și întrebați: „În ce jurisdicții poate căuta Fontes?”

Pe Mac sau PC Windows, un program de instalare cu un clic configurează Fontes în Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio și Cline, în fiecare dintre ele care se află pe computerul dumneavoastră, apoi se oferă să vă adauge cheile. Descărcați programul de instalare pentru computerul dumneavoastră din cea mai recentă versiune și închideți aceste aplicații înainte de a-l rula. Detalii în ghidul de instalare. Unele surse necesită o cheie gratuită: vedeți KEYS.md.

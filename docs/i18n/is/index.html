Beta · ókeypis · opinn hugbúnaður · heimildir athugaðar daglega

Fontes er ókeypis MCP-þjónn með opnum hugbúnaði. Hann virkar í hvaða forriti sem getur keyrt staðbundinn Model Context Protocol-þjón: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio og fleirum. Spyrðu lögfræðilegrar spurningar á venjulegu máli: gervigreindarforritið þitt leitar í dómum og löggjöf í rauntíma á vefsíðum stjórnvalda og dómstóla, í meira en 120 lögsögum og alþjóðlegum dómstólum, og tengir hverja niðurstöðu á frumritið. Hann er gerður fyrir lögfræðinga og fræðimenn í lögfræði, og fyrir alla sem vilja lesa lögin við upptökin.

Þetta er vélstudd þýðing. Enska útgáfan gildir.

Hvað það gerir

  • Leitar í dómaframkvæmd og löggjöf á því augnabliki sem þú spyrð, á eigin vefsíðu eða API útgefandans.
  • Hver niðurstaða nefnir heimild sína og tengir á hana, svo þú getir athugað frumritið.
  • Fontes heldur engan gagnagrunn og þarf engan aðgang. Spurningar þínar fara aðeins til heimildarinnar sem leitað er í. Notkunartölur og villuskýrslur eru valkvæðar (opt-in).

Fontes er hjálpartæki við heimildaleit, ekki lögfræðiráðgjöf, og notkun þess stofnar ekki til sambands lögmanns og skjólstæðings. Það er látið í té eins og það er, án ábyrgðar (sjá Apache 2.0-leyfið). Sumar heimildir eru beinlínis óopinberar útgáfur, og hver hefur sína eigin notkunarskilmála; Fontes bendir á þetta í svörum sínum. Lestu allan dóminn eða ákvæðið áður en þú treystir á það. Fontes er sjálfstætt og tengist engum dómstóli, stjórnvaldi eða útgefanda.

Uppsetning

  • Claude Desktop: sæktu .mcpb-skrá Fontes úr nýjustu útgáfunni, tvísmelltu á hana og smelltu svo á Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline og önnur forrit: bættu Fontes við MCP-stillingar forritsins. Flest taka þessa færslu; uppsetningarleiðbeiningarnar hafa skrána og kóðabútinn fyrir hvert forrit.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx fylgir uv. Á macOS eða Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Á Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Endurræstu svo forritið og spyrðu: „Í hvaða lögsögum getur Fontes leitað?“

Á Mac eða Windows-tölvu setur uppsetningarforrit með einum smelli Fontes upp í Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio og Cline, í hverju þeirra sem er á tölvunni þinni, og býðst síðan til að bæta við lyklunum þínum. Sæktu uppsetningarforritið fyrir tölvuna þína úr nýjustu útgáfunni og lokaðu þessum forritum áður en þú keyrir það. Nánar í uppsetningarleiðbeiningunum. Sumar heimildir þurfa ókeypis lykil: sjá KEYS.md.

Fontes er opinn hugbúnaður undir Apache 2.0-leyfinu. Lagatextarnir eru áfram háðir leyfi hvers útgefanda.

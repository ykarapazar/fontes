# Fontes: ຄຳຖາມ ແລະ ຄຳຕອບ

## Fontes ແມ່ນຫຍັງ?

ເຊີບເວີ MCP ທີ່ໃຊ້ຟຣີ ແລະ ເປັນໂອເພັນຊອດ (Apache 2.0). ມັນຊ່ວຍໃຫ້ແອັບໃດກໍຕາມທີ່ໃຊ້ Model Context
Protocol (Claude, Codex, Cursor, VS Code, Gemini CLI ແລະ ອື່ນໆ) ຄົ້ນຫາຄຳຕັດສິນຂອງສານ ແລະ
ນິຕິກຳແບບສົດ ເທິງເວັບໄຊຂອງສານ ແລະ ຂອງລັດ ໃນ 120+ ເຂດອຳນາດ ແລະ ສານສາກົນ
(125 ອະແດັບເຕີ). ທຸກຜົນລັບລະບຸແຫຼ່ງທີ່ມາຂອງມັນ ແລະ ມີລິ້ງໄປຫາຕົ້ນສະບັບ.

## ເນື້ອໃນເປັນສະບັບທາງການບໍ?

ສ່ວນຫຼາຍແມ່ນ, ແຕ່ບໍ່ແມ່ນສະເໝີໄປ.

- ແຫຼ່ງສ່ວນໃຫຍ່ດຳເນີນງານໂດຍສານ, ກະຊວງ ຫຼື ຈົດໝາຍເຫດທາງລັດຖະການ.
- ເນື້ອໃນສະບັບລວມບາງອັນເຜີຍແຜ່ໂດຍລັດຖະບານ ແຕ່ຖືກລະບຸຢ່າງຈະແຈ້ງວ່າບໍ່ເປັນທາງການ: ມີພຽງ
  ຈົດໝາຍເຫດທາງລັດຖະການເທົ່ານັ້ນທີ່ແທ້ຈິງ.
- ບາງແຫຼ່ງບໍ່ແມ່ນເວັບໄຊຂອງລັດເລີຍ (ຕົວຢ່າງ LexiVox, LawPhil, Maqam,
  Wikisource).

Fontes ເພີ່ມແຈ້ງການ "ແຫຼ່ງບໍ່ເປັນທາງການ" ໃສ່ທຸກຄຳຕອບທີ່ມາຈາກແຫຼ່ງໃດໜຶ່ງເຫຼົ່ານີ້. ກ່ອນທີ່
ທ່ານຈະອ້າງອີງສິ່ງໃດ, ກວດເບິ່ງສິ່ງພິມທາງການ. ຕາຕະລາງຄວາມຄອບຄຸມໃນ
[README](README.md#ຄວາມຄອບຄຸມ) ແລະ `list_jurisdictions` ລະບຸແຫຼ່ງຂອງແຕ່ລະເຂດອຳນາດ.

## ມັນຄອບຄຸມເຂດອຳນາດໃດແດ່, ແລະ ດີປານໃດ?

125 ອະແດັບເຕີ: 108 ລັດສະມາຊິກສະຫະປະຊາຊາດ, ຮົງກົງ, ໂກໂຊໂວ, ປາແລັດສະໄຕນ໌, ໄຕ້ຫວັນ, ສານ DIFC, ສານລັດຂອງສະຫະລັດ ແລະ
11 ສານ ແລະ ອົງການສາກົນ (ເຊັ່ນ ສານສິດທິມະນຸດເອີຣົບ, ສະຫະພາບເອີຣົບ, ICJ
ແລະ WTO).

ຄວາມຄອບຄຸມແຕກຕ່າງກັນຫຼາຍ. ພາຍໃຕ້ກົດເກນທີ່ເຂັ້ມງວດ (ຄຳພິພາກສາແບບຢ່າງຂອງສານທົ່ວໄປສູງສຸດ, ຫຼື
ລັດຖະທຳມະນູນ ແລະ ກົດໝາຍຫຼັກ, ທີ່ເຂົ້າເຖິງໄດ້ຄົບຖ້ວນ), 72 ໃນ 125 ຖືວ່າຄອບຄຸມ.
[COVERAGE.md](../../COVERAGE.md) ລາຍຊື່, ສຳລັບແຕ່ລະເຂດອຳນາດ, ສິ່ງທີ່ Fontes ເຂົ້າເຖິງ, ສິ່ງທີ່ມັນບໍ່ເຂົ້າເຖິງ,
ແລະ ເຫດຜົນ.

## ຂ້ອຍຕ້ອງການກະແຈ API ບໍ?

ສຳລັບເກືອບທຸກເຂດອຳນາດ, ບໍ່. ບາງແຫຼ່ງຕ້ອງການກະແຈຟຣີ: ເບິ່ງ [KEYS.md](KEYS.md).

- **ຝຣັ່ງ:** ແມ່ນ. ຝຣັ່ງຖືກປິດ ຈົນກວ່າທ່ານຈະຕັ້ງ `WLM_FR_PISTE_CLIENT_ID` ແລະ
  `WLM_FR_PISTE_CLIENT_SECRET`. ສິ່ງເຫຼົ່ານີ້ມາຈາກບັນຊີ PISTE ຟຣີ (piste.gouv.fr) ທີ່ມີ
  ແອັບທີ່ສະໝັກໃຊ້ Judilibre ແລະ Légifrance.
- **ສະຫະລັດ:** ເປັນທາງເລືອກ. ການຄົ້ນຫາຄຳພິພາກສາຂອງສານເຮັດວຽກໄດ້ໂດຍບໍ່ມີກະແຈ, ແຕ່ກະແຈສາທິດທີ່ໃຊ້ຮ່ວມກັນ
  ອະນຸຍາດພຽງປະມານ 10 ການຄົ້ນຫາຕໍ່ມື້ ຕໍ່ທີ່ຢູ່ IP. ກະແຈ api.data.gov ຟຣີ ໃນ
  `WLM_US_GOVINFO_KEY` ຈະເພີ່ມຂີດຈຳກັດນັ້ນ.
- **ສານລັດຂອງສະຫະລັດ:** ແມ່ນ. ຄຳພິພາກສາຂອງສານລັດ (`us-states`) ຖືກປິດ ຈົນກວ່າທ່ານຈະຕັ້ງ `WLM_US_COURTLISTENER_KEY` ເປັນ CourtListener API token ຟຣີຂອງທ່ານເອງ. CourtListener ດຳເນີນງານໂດຍອົງການບໍ່ຫວັງຜົນກຳໄລ Free Law Project; ມັນບໍ່ແມ່ນແຫຼ່ງທາງການ ແລະ ທຸກຄຳຕອບລະບຸເລື່ອງນີ້.

ຕັ້ງສິ່ງເຫຼົ່ານີ້ເປັນຕົວແປສະພາບແວດລ້ອມ ສຳລັບເຊີບເວີ Fontes ໃນການຕັ້ງຄ່າ MCP ຂອງແອັບທ່ານ. ໂປຣແກຣມຕິດຕັ້ງ
ຖາມຫາພວກມັນຫຼັງຈາກຕິດຕັ້ງ, ແລະ ຕົວເປີດ **Add or change keys** ຂອງພວກມັນ
ປ່ຽນພວກມັນໃນພາຍຫຼັງ.

ຕ່າງຫາກນັ້ນ, ບາງແຫຼ່ງລະບຸໃນເງື່ອນໄຂຂອງພວກເຂົາວ່າ ການເຂົ້າເຖິງແບບອັດຕະໂນມັດຕ້ອງໄດ້ຮັບ
ອະນຸຍາດຈາກຜູ້ເຜີຍແຜ່. ພວກມັນຖືກໝາຍ OFF ແລະ ຍັງປິດຢູ່. ກະແຈບໍ່ໄດ້ປ່ຽນແປງສິ່ງນັ້ນ; ມີພຽງ
ການອະນຸຍາດຂອງຜູ້ເຜີຍແຜ່ເທົ່ານັ້ນ (ແລ້ວຕັ້ງ `WLM_PERMITTED=<codes>`).

## ສິ່ງໃດອອກຈາກຄອມພິວເຕີຂອງຂ້ອຍ?

ການຄົ້ນຫາຂອງທ່ານໄປຫາແຫຼ່ງທີ່ກຳລັງຄົ້ນຫາເທົ່ານັ້ນ. Fontes ບໍ່ເກັບຖານຂໍ້ມູນ ແລະ ບໍ່ຕ້ອງມີ
ບັນຊີ.

ນອກຈາກແຫຼ່ງຕ່າງໆ, Fontes ຖາມ PyPI ມື້ລະເທື່ອວ່າມີເວີຊັນໃໝ່ກວ່າຫຼືບໍ່ (ປິດມັນໄດ້
ດ້ວຍ `FONTES_NO_UPDATE_CHECK=1`). ຈຳນວນການນຳໃຊ້ຖືກປິດໄວ້ ເວັ້ນເສຍແຕ່ທ່ານເປີດມັນ, ແລະ ລາຍງານຂໍ້ຜິດພາດ
ຈະຖືກສົ່ງ ກໍຕໍ່ເມື່ອທ່ານໄດ້ເບິ່ງ ແລະ ຢືນຢັນມັນແລ້ວເທົ່ານັ້ນ. ແອັບ AI ຂອງທ່ານເຫັນການສົນທະນາຂອງທ່ານ ພາຍໃຕ້
ເງື່ອນໄຂຂອງມັນເອງ.

ລາຍລະອຽດເຕັມ: [PRIVACY.md](PRIVACY.md).

## ນີ້ແມ່ນຄຳປຶກສາທາງກົດໝາຍບໍ?

ບໍ່. Fontes ເປັນເຄື່ອງມືຄົ້ນຄວ້າ. ມັນຊອກຫາເນື້ອໃນ; ມັນບໍ່ໄດ້ບອກທ່ານວ່າເນື້ອໃນເຫຼົ່ານັ້ນມີຄວາມໝາຍແນວໃດຕໍ່
ຄະດີຂອງທ່ານ, ແລະ ການໃຊ້ມັນບໍ່ໄດ້ສ້າງຄວາມສຳພັນທະນາຍຄວາມ–ລູກຄວາມກັບຜູ້ໃດ. ແອັບ AI ອາດ
ອ່ານເນື້ອໃນຜິດ, ສະນັ້ນ ອ່ານຄຳຕັດສິນ ຫຼື ບົດບັນຍັດທັງໝົດ ກ່ອນທີ່ທ່ານຈະເຊື່ອຖືມັນ. ສຳລັບຄຳປຶກສາ, ຖາມ
ທະນາຍຄວາມທີ່ມີຄຸນສົມບັດໃນບ່ອນທີ່ຄຳຖາມຂອງທ່ານເກີດຂຶ້ນ.

## ໃຜເປັນຜູ້ດູແລມັນ? ມັນຈະສືບຕໍ່ເຮັດວຽກບໍ?

ຄົນດຽວ: Yüce Karapazar. ບໍ່ມີບໍລິສັດຢູ່ເບື້ອງຫຼັງ Fontes, ບໍ່ມີສັນຍາການຊ່ວຍເຫຼືອ ແລະ ບໍ່ມີ
ຄຳໝັ້ນສັນຍາລະດັບການບໍລິການ. ບໍ່ມີການສະໜອງບໍລິການທາງກົດໝາຍໃດໆ.

ແຫຼ່ງຕ່າງໆຖືກກວດມື້ລະເທື່ອ ແລະ ຜົນລັບຖືກເຜີຍແຜ່ເທິງ
[ໜ້າສະຖານະ](https://ykarapazar.github.io/fontes/status/). ເວັບໄຊຂອງສານ ແລະ ຂອງລັດ
ປ່ຽນແປງໂດຍບໍ່ແຈ້ງລ່ວງໜ້າ, ສະນັ້ນ ແຫຼ່ງໃດໜຶ່ງອາດເສຍໄດ້ທຸກເວລາ. ບໍ່ມີການຮັບປະກັນວ່າແຫຼ່ງໃດ,
ຫຼື ຕົວ Fontes ເອງ, ຈະສືບຕໍ່ເຮັດວຽກ. Fontes ຖືກສະໜອງໃຫ້ "ຕາມສະພາບທີ່ເປັນຢູ່", ໂດຍບໍ່ມີການຮັບປະກັນ (ພາກທີ 7
ແລະ 8 ຂອງ [LICENSE](../../../LICENSE)).

## Fontes ແຕກຕ່າງຈາກເຄື່ອງມືຄົ້ນຄວ້າກົດໝາຍແບບໂຮສແນວໃດ?

- **ມັນແລ່ນຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ.** ບໍ່ມີເຊີບເວີ Fontes ແລະ ບໍ່ມີບັນຊີ. ນັ້ນກໍໝາຍຄວາມວ່າ ມັນ
  ເຮັດວຽກໄດ້ສະເພາະໃນແອັບທີ່ສາມາດເລີ່ມເຊີບເວີ MCP ໃນເຄື່ອງໄດ້ (Claude Desktop, Codex, Cursor, VS Code
  ແລະ ອື່ນໆທີ່ຄ້າຍກັນ), ບໍ່ແມ່ນໃນແອັບທີ່ມີແຕ່ເວັບ ທີ່ຮັບພຽງຕົວເຊື່ອມຕໍ່ແບບໂຮສ.
- **ມັນບໍ່ມີຖານຂໍ້ມູນ.** ແຕ່ລະການຄົ້ນຫາໄປແບບສົດຫາເວັບໄຊ ຫຼື API ຂອງຜູ້ເຜີຍແຜ່ເອງ, ສະນັ້ນ
  ຜົນລັບທັນສະໄໝເທົ່າກັບແຫຼ່ງ, ແລະ ຄຸນນະພາບການຄົ້ນຫາແມ່ນຂອງແຫຼ່ງເອງ. ບໍ່ມີ
  ການຄົ້ນຫາແບບຄວາມໝາຍ (semantic) ໃນດັດຊະນີທີ່ຄັດເລືອກໄວ້.
- **ມັນບໍ່ກຳນົດຂີດຈຳກັດການນຳໃຊ້.** Fontes ບໍ່ມີເພດານການເອີ້ນໃຊ້ລາຍເດືອນ. ມັນເວັ້ນໄລຍະຄຳຂໍໄປຫາແຕ່ລະ
  ເວັບໄຊ, ແລະ ບາງແຫຼ່ງຈຳກັດວ່າສາມາດສອບຖາມໄດ້ໄວ ຫຼື ເລື້ອຍປານໃດ.
- **ມັນເປັນໂອເພັນຊອດ.** ທ່ານສາມາດອ່ານທຸກອະແດັບເຕີ ແລະ ເຫັນຢ່າງແນ່ນອນວ່າແຕ່ລະເນື້ອໃນມາຈາກໃສ.
- **ບໍ່ມີຜູ້ຂາຍຢູ່ເບື້ອງຫຼັງມັນ.** ບໍ່ມີສັນຍາ, ໂຕະຊ່ວຍເຫຼືອ ຫຼື ຄຳໝັ້ນສັນຍາເວລາເຮັດວຽກ (ເບິ່ງ "ໃຜເປັນ
  ຜູ້ດູແລມັນ?").

# ແຈ້ງການຄວາມເປັນສ່ວນຕົວຂອງ Fontes

Fontes ແລ່ນຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ. ການຄົ້ນຫາຂອງທ່ານ ແລະ ເອກະສານທີ່ທ່ານເປີດ ຍັງຢູ່
ລະຫວ່າງຄອມພິວເຕີຂອງທ່ານ, ແຫຼ່ງທາງການທີ່ທ່ານຄົ້ນຫາ ແລະ ແອັບ AI ທີ່ທ່ານໃຊ້ (ພາຍໃຕ້ເງື່ອນໄຂຂອງ
ແອັບນັ້ນເອງ). ຕົວ Fontes ເອງ **ບໍ່ສົ່ງຫຍັງເລີຍເປັນຄ່າເລີ່ມຕົ້ນ** ໄປຫາຜູ້ພັດທະນາ Fontes.

## ສິ່ງໃດອາດອອກຈາກຄອມພິວເຕີຂອງທ່ານ ແລະ ເມື່ອໃດ

**1. ການກວດອັບເດດ (ເປີດເປັນຄ່າເລີ່ມຕົ້ນ).** ມື້ລະເທື່ອ Fontes ຖາມ PyPI, ດັດຊະນີແພັກເກັດ Python
ສາທາລະນະ, ວ່າເວີຊັນໃດໃໝ່ທີ່ສຸດ. ຄຳຂໍນີ້ບໍ່ມີຂໍ້ມູນໃດໆກ່ຽວກັບທ່ານ ຫຼື ວຽກຂອງທ່ານ; PyPI
ເຫັນທີ່ຢູ່ IP ຂອງທ່ານ, ຄືກັບການດາວໂຫຼດໃດໆ. ເພື່ອປິດມັນ, ຕັ້ງ `FONTES_NO_UPDATE_CHECK=1`
(ແຈ້ງການພາຍໃນແອັບ) ແລະ `FONTES_NO_AUTO_UPDATE=1` (ການອັບເດດອັດຕະໂນມັດຂອງໂປຣແກຣມຕິດຕັ້ງ).

**2. ຈຳນວນການນຳໃຊ້ (ປິດໄວ້ ເວັ້ນເສຍແຕ່ທ່ານເປີດມັນ).** ຖ້າທ່ານເລືອກເຂົ້າຮ່ວມ, ມື້ລະເທື່ອ Fontes ຈະສົ່ງ:

- ເວີຊັນ Fontes ແລະ ປະເພດລະບົບປະຕິບັດການຂອງທ່ານ (macOS, Windows, Linux);
- ຕໍ່ມື້, ຈຳນວນເທື່ອທີ່ແຕ່ລະເຄື່ອງມືຖືກໃຊ້ ສຳລັບແຕ່ລະລະຫັດເຂດອຳນາດ, ຕົວຢ່າງ
  "2026-11-10, nl, search_caselaw, 12".

ນັ້ນແມ່ນຂໍ້ຄວາມທັງໝົດ. ມັນບໍ່ເຄີຍລວມເອົາການຄົ້ນຫາຂອງທ່ານ, id ຂອງເອກະສານ ຫຼື ຄະດີ, ເນື້ອໃນ
ເອກະສານ, ຊື່ຂອງທ່ານ, ບັນຊີ, ຫຼື id ໃດໆສຳລັບທ່ານ ຫຼື ຄອມພິວເຕີຂອງທ່ານ. ຈຳນວນເຫຼົ່ານັ້ນລໍຖ້າຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ
(ໃນໂຟນເດີແຄຊຂອງ Fontes, `stats.json`) ຈົນກວ່າພວກມັນຈະຖືກສົ່ງ; ຖ້າການສົ່ງລົ້ມເຫຼວ ພວກມັນຈະລໍຖ້າ
ມື້ຕໍ່ໄປ.

- **ເລືອກເຂົ້າຮ່ວມ**: ຕອບ "y" ເມື່ອໂປຣແກຣມຕິດຕັ້ງຖາມ, ຫຼື ຕັ້ງ `FONTES_STATS=1` ສຳລັບເຊີບເວີ Fontes.
- **ເລືອກບໍ່ເຂົ້າຮ່ວມ**: ແລ່ນໂປຣແກຣມຕິດຕັ້ງອີກຄັ້ງ ແລ້ວກົດ Enter ທີ່ຄຳຖາມນັ້ນ, ຫຼື ລຶບ
  `FONTES_STATS` ອອກ. ການລຶບ `stats.json` ຈະຍົກເລີກສິ່ງໃດກໍຕາມທີ່ຍັງບໍ່ທັນໄດ້ສົ່ງ.

**3. ລາຍງານຂໍ້ຜິດພາດ (ສະເພາະເມື່ອທ່ານສົ່ງມັນ).** ເມື່ອທ່ານຂໍລາຍງານ (`fontes report-bug`, ຫຼື ຂໍໃຫ້
ແອັບ AI ຂອງທ່ານລາຍງານຂໍ້ຜິດພາດຂອງ Fontes), Fontes ສະແດງລາຍງານທັງໝົດໃຫ້ທ່ານເບິ່ງກ່ອນ ແລະ ສົ່ງມັນ ກໍຕໍ່ເມື່ອ
ທ່ານຢືນຢັນເທົ່ານັ້ນ. ມັນມີເວີຊັນ Fontes, ປະເພດລະບົບປະຕິບັດການຂອງທ່ານ, ລະຫັດເຂດອຳນາດ, ຊື່ເຄື່ອງມື ແລະ ຂໍ້ຄວາມຂໍ້ຜິດພາດ
ຂອງການເອີ້ນໃຊ້ເຄື່ອງມືຄັ້ງສຸດທ້າຍທີ່ລົ້ມເຫຼວ (ໂດຍຕັດຄຳຄົ້ນຫາ ແລະ id ຂອງທ່ານອອກ), ແລະ
ບັນທຶກໜຶ່ງ ຖ້າທ່ານຂຽນ. ຢ່າໃສ່ລາຍລະອຽດຂອງລູກຄວາມໃນບັນທຶກ. ເພື່ອຮອງຮັບສິ່ງນີ້, Fontes ເກັບ
ຂໍ້ຜິດພາດຄັ້ງສຸດທ້າຍໄວ້ໃນຄອມພິວເຕີຂອງທ່ານ (`last-error.json` ໃນໂຟນເດີແຄຊຂອງມັນ, ຖືກແທນທີ່ທຸກເທື່ອ);
ມັນບໍ່ເຄີຍຖືກສົ່ງໄປຕ່າງຫາກ.

## ຂໍ້ມູນໄປໃສ ແລະ ຖືກເກັບໄວ້ດົນປານໃດ

ຈຳນວນການນຳໃຊ້ ແລະ ລາຍງານຂໍ້ຜິດພາດ ໄປຫາເຊີບເວີນ້ອຍໆທີ່ດຳເນີນງານໂດຍຜູ້ພັດທະນາ Fontes
(`relay.kinetra.fit`). ມັນບໍ່ເກັບທີ່ຢູ່ IP: ທີ່ຢູ່ເຫຼົ່ານັ້ນຖືກໃຊ້ພຽງແຕ່ໃນໜ່ວຍຄວາມຈຳ, ໃນເວລາສັ້ນໆ, ເພື່ອ
ຢຸດການສົ່ງຫຼັ່ງໄຫຼ, ແລະ ເວັບເຊີບເວີບໍ່ເກັບບັນທຶກການເຂົ້າເຖິງສຳລັບມັນ. ຈຳນວນຖືກບວກເຂົ້າໃນຍອດລວມ
ປະຈຳວັນ; ການສົ່ງແຕ່ລະເທື່ອບໍ່ຖືກເກັບໄວ້. ຍອດລວມຖືກເກັບໄວ້ເຖິງ 2 ປີ, ລາຍງານຂໍ້ຜິດພາດເຖິງ
1 ປີ, ຈາກນັ້ນຈະຖືກລຶບ. ບໍ່ມີສິ່ງໃດຖືກຂາຍ ຫຼື ແບ່ງປັນ.

ຖ້າບໍ່ສາມາດເຂົ້າເຖິງເຊີບເວີນັ້ນໄດ້, ບໍ່ມີຫຍັງຖືກສົ່ງ: ຈຳນວນຍັງຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ ແລະ ລາຍງານຂໍ້ຜິດພາດ
ຈະນຳທ່ານໄປຫາລະບົບຕິດຕາມບັນຫາ (issue tracker) ແທນ.

ຖືກສົ່ງ ກໍຕໍ່ເມື່ອທ່ານເລືອກເຂົ້າຮ່ວມ, ແລະ ລາຍງານຂໍ້ຜິດພາດ ກໍຕໍ່ເມື່ອທ່ານຢືນຢັນມັນແລ້ວເທົ່ານັ້ນ. ທ່ານສາມາດຖອນ

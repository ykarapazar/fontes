# Fontes privacidad willakuy

Fontesqa computadoraykipim purin. Maskasqaykikuna, kichasqayki qillqakunapas
computadorayki, maskasqayki oficial pukyukuna, llamk'achisqayki IA aplicación (chay
aplicacionpa kikin condicionninkunaman hina) chaykunallapim qhipakun. Fontesqa kikinmanta
Fontes desarrolladorkunaman **ñawpaqmantapachaqa manam imatapas** kachanchu.

## Ima computadoraykimanta lluqsinman, hayk'aq

**1. Musuqchay qhaway (ñawpaqmantapacha hap'isqa).** P'unchawpi huk kutita Fontesqa PyPI
nisqata, Python paquetekunap público índicenta, mayqin versión aswan musuq kasqanta tapun.
Mañakuyqa manam qammanta nitaq llamk'asqaykimanta imatapas apanchu; PyPIqa IP direcciónniykitam
rikun, mayqin uraykuchiypipas hina. Wañuchinaykipaq, `FONTES_NO_UPDATE_CHECK=1` (aplicación
ukhupi willakuy), `FONTES_NO_AUTO_UPDATE=1` (instaladorpa kikillanmanta musuqchayninkuna)
nisqakunata churay.

**2. Llamk'achiy yupaykuna (wañusqa, qam hap'ichinaykikama).** Ari nispaqa, p'unchawpi huk
kutita Fontesqa kachan:

- Fontes versiónta, sistema operativoykip ayllunta (macOS, Windows, Linux);
- sapa p'unchaw, sapa llamk'ana sapa jurisdicción códigopaq hayk'a kuti llamk'achisqa kasqanta,
  kayhina: "2026-11-10, nl, search_caselaw, 12".

Chayllam llapan willakuy. Manam hayk'appas apanchu maskasqaykikunata, qillqakunap utaq
casokunap identificadorninkunata, qillqakunap textonta, sutiykita, cuentata, nitaq qampaq
utaq computadoraykipaq ima identificadortapas. Yupaykunaqa computadoraykipim suyanku
(Fontespa caché carpetanpi, `stats.json`) kachakunankama; kachay pantanqa, hamuq
p'unchawkamam suyanku.

- **Ari niy (opt in)**: instalador tapuptin "y" nispa kutichiy, utaq Fontes servidorpaq
  `FONTES_STATS=1` nisqata churay.
- **Mana niy (opt out)**: instaladorta wakmanta purichiy, chay tapukuypitaq Enter ñit'iy, utaq
  `FONTES_STATS` nisqata qichuy. `stats.json` nisqata qichuspaqa manaraq kachasqa kaqtam
  chinkachin.

**3. Pantay willakuykuna (huk kachaptiykillam).** Mañakuptiyki (`fontes report-bug`, utaq IA
aplicacionniykita Fontesmanta huk pantayta willananpaq mañay), Fontesqa ñawpaqtam llapan
willakuyta rikuchisunki, ari nispaykillataq kachan. Kaykunatam apan: Fontes versión, sistema
operativoykip ayllun, qhipa kaq pantasqa llamk'ana waqyaypa jurisdicción códigon, llamk'anap
sutin, pantay willakuynin (maskay simiykikuna, identificadorkunapas qichusqa), huk notatapas
qillqanki chayqa. Ama notapi clientekunap datonkunata churaychu. Kayta yanapananpaq, Fontesqa
qhipa kaq pantayta computadoraykipi waqaychan (`last-error.json` caché carpetanpi, sapa kuti
rantisqa); manam hayk'appas sapallanmanta kachakunchu.

## Mayman rin, hayk'a unaytataq waqaychakun

Llamk'achiy yupaykuna, pantay willakuykunapas Fontes desarrolladorpa purichisqan huk huch'uy
servidormanmi rinku (`relay.kinetra.fit`). Manam IP direccionkunata waqaychanchu: memoriallapim,
pisi pachalla, llamk'achikun, achka mañakuykuna (floods) hark'anapaq, web servidortaq manam
paypaq yaykuy registrota (access log) waqaychanchu. Yupaykunaqa sapa p'unchaw totalkunamanmi
yapakun; sapalla kachasqakunaqa manam waqaychakunchu. Totalkunaqa 2 watakamam waqaychakun,
pantay willakuykunataq 1 watakama, chaymanta qichusqa. Manam imapas rantikunchu nitaq
rakinakunchu.

Chay servidorman mana chayayta atikunchu chayqa, manam imapas kachakunchu: yupaykunaqa
computadoraykipim qhipakun, pantay willakuykunataq issue tracker nisqamanmi pusasunki.

Jurisprudència i legislació per a la vostra aplicació d'IA, llegides en directe des de llocs web judicials i governamentals.

Beta · gratuït · codi obert · fonts comprovades cada dia

Fontes és un servidor MCP gratuït i de codi obert. Funciona en qualsevol aplicació que pugui executar un servidor local del Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio i altres. Feu una pregunta jurídica en llenguatge planer: la vostra aplicació d'IA cerca resolucions judicials i legislació en directe a llocs web judicials i governamentals, en 125 jurisdiccions i tribunals internacionals, i enllaça cada resultat amb l'original. També pot mostrar una llei tal com estava en una data passada, i llegir la legislació de 91 països més del registre de Lexifina (no és l'editor oficial). Està pensat per a advocats i investigadors jurídics, i per a qualsevol persona que vulgui llegir el dret a la seva font.

Aquesta és una traducció assistida per màquina. La versió anglesa és la que preval.

Què fa

  • Cerca jurisprudència i legislació en el moment en què pregunteu, des del lloc web o l'API del mateix editor.
  • Cada resultat indica la seva font i hi enllaça, perquè pugueu comprovar l'original.
  • Fontes no manté cap base de dades i no requereix cap compte. Les vostres preguntes van a la font on es cerca; per a les versions passades de les lleis, els 91 països addicionals i les lleis de l'Índia, van al servei públic de Lexifina, a més del lloc oficial o en lloc seu. Definiu WLM_LEXIFINA=0 per desactivar-ho. Els recomptes d'ús i els informes d'error són opcionals (opt-in).

Fontes és una eina de recerca, no assessorament jurídic, i utilitzar-lo no crea cap relació advocat-client. Es proporciona "tal com és", sense garantia (vegeu la llicència Apache 2.0). Algunes fonts són versions expressament no oficials, i cadascuna té les seves pròpies condicions d'ús; Fontes ho indica a les seves respostes. Llegiu la resolució o la disposició completa abans de confiar-hi. Fontes és independent i no està afiliat a cap tribunal, govern ni editor.

Instal·lació

  • Claude Desktop: baixeu el fitxer .mcpb de Fontes de la darrera versió, feu-hi doble clic i després feu clic a Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline i altres aplicacions: afegiu Fontes a la configuració MCP de l'aplicació. La majoria accepten aquesta entrada; la guia d'instal·lació indica el fitxer i el fragment per a cada aplicació.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx ve amb uv. A macOS o Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. A Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Després reinicieu l'aplicació i pregunteu: «En quines jurisdiccions pot cercar Fontes?»

En un Mac o un PC amb Windows, un instal·lador d'un clic configura Fontes a Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio i Cline, a cadascuna que tingueu a l'ordinador, i després us ofereix afegir les vostres claus. Baixeu-lo de la darrera versió i tanqueu aquestes aplicacions abans d'executar-lo. Detalls a la guia d'instal·lació. Algunes fonts necessiten una clau gratuïta: vegeu KEYS.md.

Fontes és de codi obert sota la llicència Apache 2.0. Els textos jurídics continuen subjectes a la llicència de cada editor.

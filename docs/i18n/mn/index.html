Юу хийдэг вэ

  • Таныг асуух мөчид шүүхийн практик, хууль тогтоомжийг нийтлэгчийн өөрийн вэбсайт эсвэл API-аас хайна.
  • Үр дүн бүр өөрийн эх сурвалжийг нэрлэж, түүн рүү холбоос өгдөг тул та эх хувийг шалгаж болно.
  • Мэдээллийн сан ч, бүртгэл ч байхгүй. Таны асуулт зөвхөн хайж буй эх сурвалж руу очно; ашиглалтын тоо ба алдааны тайлан зөвхөн таны зөвшөөрлөөр (opt-in) илгээгдэнэ.

Fontes бол судалгааны туслах хэрэгсэл болохоос хуулийн зөвлөгөө биш. Зарим эх сурвалж нь албан бус хувилбар гэдгээ шууд заасан байдаг бөгөөд тус бүр өөрийн ашиглалтын нөхцөлтэй; Fontes хариултдаа үүнийг хэлдэг. Шийдвэр эсвэл заалтад тулгуурлахаасаа өмнө бүтнээр нь уншина уу. Fontes бие даасан бөгөөд аль ч шүүх, засгийн газар эсвэл нийтлэгчтэй холбоогүй.

Суулгах

Програмист биш үү? Суулгах заавар-ыг дагана уу. Суулгагч нь Fontes-ийг Claude Desktop (болон OpenAI Codex)-д тохируулж, байнга шинэчилнэ.

Хөгжүүлэгчдэд: uv суулгасан бол үүнийг MCP клиентийнхээ тохиргоонд нэмнэ үү:

{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

Эсвэл Claude Code-д: claude mcp add fontes -- uvx fontes-mcp

Дараа нь Claude-аас асуу: "Fontes аль харьяаллуудад хайж чадах вэ?"

Fontes бол Apache 2.0 лицензтэй нээлттэй эхийн програм. Эрх зүйн текстүүд нийтлэгч бүрийн лицензийн дор хэвээр үлдэнэ.

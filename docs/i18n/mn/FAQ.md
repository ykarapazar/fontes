# Fontes: асуулт, хариулт

## Fontes гэж юу вэ

Үнэгүй, нээлттэй эхийн MCP сервер (Apache 2.0). Энэ нь Model Context Protocol ашигладаг аливаа аппад
(Claude, Codex, Cursor, VS Code, Gemini CLI болон бусад) 120+ харьяалал болон олон улсын шүүхийн
шүүх болон төрийн вэбсайтаас шүүхийн шийдвэр, хууль тогтоомжийг шууд хайх боломж олгодог (124 адаптер).
Үр дүн бүр эх сурвалжаа нэрлэж, эх хувь руу холбоос өгдөг.

## Текстүүд албан ёсных уу

Ихэнхдээ тийм, гэхдээ үргэлж биш.

- Ихэнх эх сурвалжийг шүүх, яам эсвэл албан ёсны сонин ажиллуулдаг.
- Нэмэлт өөрчлөлтийг нэгтгэсэн зарим текстийг засгийн газар нийтэлдэг ч албан бус гэж тодорхой заасан байдаг: зөвхөн
  албан ёсны сонин нь баталгаат.
- Цөөн хэдэн эх сурвалж огт төрийн сайт биш (жишээ нь LexiVox, LawPhil, Maqam,
  Wikisource).

Fontes эдгээрийн аль нэгээс ирсэн хариулт бүрт "Албан бус эх сурвалж" гэсэн анхааруулга нэмдэг. Юуны ч
иш татахаасаа өмнө албан ёсны нийтлэлийг шалгана уу. [README](README.md#хамрах-хүрээ) дахь хамрах хүрээний хүснэгт болон
`list_jurisdictions` харьяалал бүрийн эх сурвалжийг нэрлэдэг.

## Ямар харьяаллуудыг, хэр сайн хамардаг вэ

124 адаптер: НҮБ-ын 108 гишүүн улс, Хонконг, Косово, Палестин, Тайвань, DIFC Courts болон
олон улсын 11 шүүх, байгууллага (жишээ нь Хүний эрхийн Европын шүүх, ЕХ,
ОУШ болон ДХБ).

Хамрах хүрээ эрс ялгаатай. Хатуу дүрмээр (ерөнхий харьяаллын дээд шүүхийн прецедентүүд, эсвэл
үндсэн хууль ба үндсэн хуулиудад бүрэн хүрсэн байх) 124-өөс 72 нь хамрагдсан гэж тооцогддог.
[COVERAGE.md](../../COVERAGE.md) харьяалал бүрийн хувьд Fontes юунд хүрдэг, юунд хүрдэггүй, яагаад гэдгийг
жагсаасан.

## API түлхүүр хэрэгтэй юу

Бараг бүх харьяаллын хувьд хэрэггүй. Зарим эх сурвалжид үнэгүй түлхүүр хэрэгтэй: [KEYS.md](KEYS.md)-г үзнэ үү.

- **Франц:** тийм. `WLM_FR_PISTE_CLIENT_ID` болон
  `WLM_FR_PISTE_CLIENT_SECRET`-ийг тохируулах хүртэл Франц унтраалттай. Эдгээр нь Judilibre болон Légifrance-д
  бүртгүүлсэн апп бүхий үнэгүй PISTE бүртгэлээс (piste.gouv.fr) ирдэг.
- **Америкийн Нэгдсэн Улс:** заавал биш. Шүүхийн практикийн хайлт түлхүүргүй ажилладаг ч хуваалцсан демо түлхүүр
  IP хаяг тус бүрд өдөрт ойролцоогоор 10 хайлт л зөвшөөрдөг. `WLM_US_GOVINFO_KEY`-д үнэгүй api.data.gov түлхүүр
  оруулбал үүнийг нэмэгдүүлнэ.

Эдгээрийг аппынхаа MCP тохиргоонд Fontes серверийн орчны хувьсагч болгон тохируулна уу. Суулгагч
гарсны дараа суулгасны дараа тэдгээрийг асуух бөгөөд түүний **Add or change keys** эхлүүлэгч
дараа нь тэдгээрийг өөрчилнө.

Үүнээс тусдаа, цөөн хэдэн эх сурвалж нөхцөлдөө автомат хандалтад нийтлэгчийн
зөвшөөрөл шаардлагатай гэж заасан байдаг. Тэдгээрийг OFF гэж тэмдэглэсэн бөгөөд унтраалттай хэвээр байна. Түлхүүр үүнийг өөрчлөхгүй; зөвхөн
нийтлэгчийн зөвшөөрөл өөрчилнө (дараа нь `WLM_PERMITTED=<codes>`-ийг тохируулна).

## Миний компьютерээс юу гардаг вэ

Таны хайлт зөвхөн хайж буй эх сурвалж руу очдог. Fontes өгөгдлийн сан хадгалдаггүй, бүртгэл
шаарддаггүй.

Эх сурвалжуудаас гадна Fontes өдөрт нэг удаа PyPI-аас шинэ хувилбар байгаа эсэхийг асуудаг (үүнийг
`FONTES_NO_UPDATE_CHECK=1`-ээр унтраана). Ашиглалтын тоо та идэвхжүүлэхгүй бол унтраалттай бөгөөд алдааны тайланг
зөвхөн та харж, баталгаажуулсны дараа илгээнэ. Таны AI апп таны харилцан яриаг өөрийн
нөхцөлийн дор хардаг.

Бүрэн дэлгэрэнгүй: [PRIVACY.md](PRIVACY.md).

## Энэ хуулийн зөвлөгөө мөн үү

Үгүй. Fontes бол судалгааны хэрэгсэл. Энэ нь текст олдог; тэдгээр нь таны хэрэгт юу гэсэн үг болохыг хэлдэггүй,
мөн үүнийг ашиглах нь хэнтэй ч хуульч–үйлчлүүлэгчийн харилцаа үүсгэхгүй. AI апп текстийг буруу уншиж
болох тул найдахаасаа өмнө шийдвэр эсвэл заалтыг бүтнээр нь уншина уу. Зөвлөгөө авахын тулд таны асуулт үүссэн газарт
эрх бүхий хуульчаас асууна уу.

## Fontes нь байршуулсан (hosted) эрх зүйн судалгааны хэрэгслүүдээс юугаараа ялгаатай вэ

- **Таны компьютер дээр ажилладаг.** Fontes сервер, бүртгэл байхгүй. Энэ нь мөн зөвхөн
  локал MCP сервер эхлүүлж чаддаг аппуудад (Claude Desktop, Codex, Cursor, VS Code
  гэх мэт) ажиллана гэсэн үг бөгөөд зөвхөн байршуулсан холбогч хүлээн авдаг вэб аппуудад ажиллахгүй.
- **Өгөгдлийн сангүй.** Хайлт бүр нийтлэгчийн өөрийн вэбсайт эсвэл API руу шууд очдог тул
  үр дүн нь эх сурвалжийн адил шинэ бөгөөд хайлтын чанар нь эх сурвалжийн өөрийнх. Сонгон бүрдүүлсэн
  индекс дээрх семантик (утгын) хайлт байхгүй.
- **Ашиглалтын хязгаар тогтоодоггүй.** Fontes-д сарын дуудлагын дээд хязгаар байхгүй. Вэбсайт бүрт
  илгээх хүсэлтүүдээ завсарлуулдаг бөгөөд зарим эх сурвалж өөрөөс нь хэр хурдан эсвэл хэр олон удаа асууж болохыг хязгаарладаг.
- **Нээлттэй эх.** Та адаптер бүрийг уншиж, текст бүр яг хаанаас ирдгийг харж болно.
- **Ард нь нийлүүлэгч байхгүй.** Гэрээ, дэмжлэгийн алба эсвэл ажиллах хугацааны амлалт байхгүй ("Хэн
  хариуцдаг вэ?"-г үзнэ үү).

## Ямар апп, системтэй ажилладаг вэ

Локал (stdio) сервер ажиллуулж чаддаг аливаа MCP апп, жишээ нь Claude Desktop, Claude Code,
Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio болон Cline. Fontes
macOS, Windows болон Linux дээр, uv ажилладаг хаана ч (Python 3.13+) ажилладаг. Mac дээр нэг товшилтын суулгагч Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio болон Cline-ийг нэг дор тохируулна; Windows-ийн суулгагч удахгүй гарна. Апп бүрийн алхмууд: [INSTALL.md](INSTALL.md).

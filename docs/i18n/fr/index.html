Le droit de plus de 120 juridictions, à une question près.

Bêta · gratuit · open source · sources vérifiées chaque jour

Fontes est un serveur MCP gratuit et open source. Il fonctionne dans toute application capable d'exécuter un serveur Model Context Protocol local : Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio et d'autres. Posez une question juridique en langage courant : votre application d'IA recherche des décisions de justice et la législation en direct sur les sites des États et des juridictions, dans plus de 120 juridictions et cours internationales, et renvoie chaque résultat à l'original. Il est conçu pour les juristes et les chercheurs en droit, et pour toute personne qui veut lire le droit à sa source.

Ce qu'il fait

  • Recherche la jurisprudence et la législation au moment où vous posez la question, sur le site web ou l'API de l'éditeur lui-même.
  • Chaque résultat indique sa source et renvoie vers elle, pour que vous puissiez vérifier l'original.
  • Fontes ne tient aucune base de données et ne nécessite aucun compte. Vos questions ne vont qu'à la source interrogée. Les comptages d'utilisation et les rapports de bogue sont soumis à votre accord préalable (opt-in).

Fontes est une aide à la recherche, et non un conseil juridique, et son utilisation ne crée pas de relation avocat-client. Il est fourni en l'état, sans garantie (voir la licence Apache 2.0). Certaines sources sont des versions expressément non officielles, et chacune a ses propres conditions d'utilisation ; Fontes le signale dans ses réponses. Lisez la décision ou la disposition complète avant de vous y fier. Fontes est indépendant et n'est affilié à aucune juridiction, aucun gouvernement ni aucun éditeur.

Installation

Fontes n'est pas encore sur PyPI. Ces étapes fonctionneront dès la sortie de la première version.

  • Claude Desktop : téléchargez le fichier .mcpb de Fontes depuis la dernière version, double-cliquez dessus, puis cliquez sur Install.
  • Codex : codex mcp add fontes -- uvx fontes-mcp
  • Claude Code : claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline et autres applications : ajoutez Fontes aux paramètres MCP de l'application. La plupart acceptent cette entrée ; le guide d'installation donne le fichier et l'extrait pour chaque application.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx est fourni avec uv. Sous macOS ou Linux : curl -LsSf https://astral.sh/uv/install.sh | sh. Sous Windows (PowerShell) : powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Redémarrez ensuite l'application et demandez : « Dans quelles juridictions Fontes peut-il chercher ? »

Un programme d'installation en un clic pour Mac et Windows est en préparation. Il configure Fontes dans Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio et Cline, dans chacune de ces applications présente sur votre ordinateur, puis propose d'ajouter vos clés. Quittez ces applications avant de le lancer. Détails dans le guide d'installation. Certaines sources nécessitent une clé gratuite : voir KEYS.md.

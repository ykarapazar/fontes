Fontes ነፃና ክፍት ምንጭ (open-source) የሆነ የ MCP አገልጋይ ነው። የ AI መተግበሪያዎ ከ120 በላይ በሆኑ የሕግ ክልሎች
(jurisdictions) እና ዓለም አቀፍ ፍርድ ቤቶች **የፍርድ ቤት ውሳኔዎችንና ሕጎችን በመንግሥትና በፍርድ ቤት ድረ ገጾች ላይ በቀጥታ
እንዲፈልግ** ያስችለዋል። እያንዳንዱ ውጤት ከዋናው ጋር ያገናኛል። መደበኛ የ Model Context Protocol (MCP) አገልጋይ ስለሆነ፣
አካባቢያዊ (local) የ MCP አገልጋይ ማስኬድ በሚችል በማንኛውም መተግበሪያ ውስጥ ይሠራል፦ Claude Desktop፣ Claude Code፣
OpenAI Codex፣ Cursor፣ VS Code (GitHub Copilot)፣ Gemini CLI፣ Windsurf፣ Zed፣ LM Studio እና ሌሎችም።

- **ለጠበቆችና ለተመራማሪዎች:** በተራ ቋንቋ ይጠይቁ። የ AI መተግበሪያዎ ይፋዊውን ምንጭ ይፈልጋል፣ ካገኘውም ከምንጩ ሊንክ
  ጋር ይጠቅሳል።
- **ለአልሚዎች (developers):** ሰባት ቋሚ የጥናት መሣሪያዎች ያሉት አንድ የ MCP አገልጋይ (በተጨማሪ `report_bug`)፤ የሕግ
  ክልሉ መለኪያ (parameter) ስለሆነ፣ አገሮችን መጨመር መሣሪያዎችን አይጨምርም። Python፣ Apache 2.0።

   - **Codex:** `codex mcp add fontes -- uvx fontes-mcp`

   - **Cursor፣ VS Code፣ Gemini CLI፣ Zed፣ LM Studio፣ Cline እና ሌሎች መተግበሪያዎች:** ለመተግበሪያዎ የሚሆነውን ቅንጣቢ

   `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`።

  ጋር የሥሪት ፍተሻ ያደርጋል (በ `FONTES_NO_UPDATE_CHECK=1` ይጠፋል)፤ ሌላው ሁሉ (የአጠቃቀም ቆጠራዎች፣ የስህተት ሪፖርቶች)
  እርስዎ ሲፈቅዱ ብቻ (opt-in) የሚሠራ ሲሆን አስቀድሞ ይጠይቅዎታል።
- **አይሰጥም:** የሕግ ምክር አይሰጥም፣ የትኛው የጽሑፍ ቅጂ ገዢ እንደሆነም አይወስንም። ሽፋኑ ከአገር አገር በጣም ይለያያል፦
  አንዳንዶቹ የተሟሉ የፍርድ ቤት ውሳኔዎችና ማሻሻያዎች የተካተቱበት (consolidated) ሕግ አላቸው፣ አንዳንዶቹ አንድ ፍርድ
  ቤት ብቻ ወይም መጀመሪያ እንደታተሙት ያሉ ሕጎች ብቻ። ከታች ያሉት ሰንጠረዦችና `list_jurisdictions` እያንዳንዱ ምን
  እንደሚሸፍን በትክክል ይገልጻሉ።

### በአንድ ውጤት ላይ ከመመሥረትዎ በፊት ይህን ያንብቡ

- **ሁሉም ምንጭ ይፋዊና ትክክለኛ (authentic) ቅጂ አይደለም።** አብዛኞቹ የመንግሥት ወይም የፍርድ ቤት ድረ ገጾች ናቸው፣
  ነገር ግን አንዳንድ ማሻሻያዎች የተካተቱባቸው ጽሑፎች በግልጽ ይፋዊ ያልሆኑ ናቸው (ትክክለኛ የሆነው ይፋዊው ጋዜጣ ብቻ ነው)፣
  ጥቂት ምንጮችም መንግሥታዊ ያልሆኑ ናቸው (ለምሳሌ LexiVox፣ LawPhil፣ Maqam፣ Wikisource)። Fontes እነዚህን በመልሶቹ
  ውስጥ "ይፋዊ ያልሆነ ምንጭ" በሚል ማሳሰቢያ ምልክት ያደርጋቸዋል። ከመጥቀስዎ በፊት ይፋዊውን ኅትመት ያረጋግጡ።
- **እያንዳንዱ ምንጭ የራሱ ውሎች አሉት።** መረጃው በአሳታሚው ፈቃድ (licence) ሥር ይቆያል፤ አንዳንዶቹ የንግድ አጠቃቀምን
  ይከለክላሉ፣ አንዳንዶቹ ምንጩን መጥቀስ (attribution) ይጠይቃሉ (ለምሳሌ የ CC BY ምንጮች)፣ ጥቂቶቹም ያለፈቃድ በራስ-ሰር
  (automated) መድረስን ይከለክላሉ። ፈቃድ የሚያስፈልጋቸው ምንጮች በነባሪ (default) **ጠፍተዋል** (ከታች OFF ተብለው
  ተመልክተዋል)። [ምንጮች፣ ውሎች እና robots.txt](#ምንጮች-ውሎች-እና-robotstxt) ን ይመልከቱ።
- **AI በስሕተት ሊያነብ ይችላል።** በውሳኔው ወይም በድንጋጌው ላይ ከመመሥረትዎ በፊት ሙሉውን ያንብቡ፤ ከፍለጋ ቅንጣቢ ወይም
  ከ AI ማጠቃለያ ብቻ በመነሣት በፍጹም አይጥቀሱ።
- **ምንጮች ይዘገያሉ፣ ክፍተቶችም አሏቸው።** አንድ ፍርድ ቤት ዘግይቶ ወይም ከውሳኔዎቹ የተወሰኑትን ብቻ ሊያትም ይችላል፣
  ማሻሻያዎች የተካተቱበት ጽሑፍም የቅርብ ጊዜውን ማሻሻያ ገና ላያካትት ይችላል። የጽሑፉን ቀን እና `list_jurisdictions` ለዚያ
  የሕግ ክልል የሚዘረዝራቸውን ክፍተቶች ያረጋግጡ።
- **የሕግ ምክር አይደለም።** Fontes የጥናት መሣሪያ ነው። እሱን መጠቀም ከማንም ጋር የጠበቃና የደንበኛ ግንኙነት አይፈጥርም፣
  ጥያቄዎ በሚነሣበት ቦታ ብቁ ከሆነ ጠበቃ የሚገኝን ምክርም አይተካም።
- **ምንም ዋስትና የለም።** Fontes የሚቀርበው "እንዳለ" (as is) ነው፣ ምንም ዓይነት ዋስትና ሳይኖረው፣ ደራሲዎቹም ሕጉ
  በሚፈቅደው መጠን ለአጠቃቀሙ ተጠያቂ አይደሉም። ሙሉ ውሎቹ በ [LICENSE](../../../LICENSE) (Apache 2.0) ክፍል 7 እና 8
  ውስጥ ይገኛሉ።
- Fontes ራሱን የቻለ ክፍት ምንጭ ፕሮጀክት ነው። ከሚያነብባቸው ፍርድ ቤቶች፣ መንግሥታት ወይም አሳታሚዎች ከማንኛቸውም ጋር
  ግንኙነት የለውም፣ በእነርሱም የተደገፈ አይደለም።

## ይህን ለምን ሠራሁት

Fontes የተሠራው በአንድ ጠበቃ፣ ለጠበቆች ነው። =) እንዲሁም የሚመለከታቸውን ሕግ ማንበብ ለሚያስፈልጋቸው ሁሉ።

ሕግ የሕዝብ ነው። የፍርድ ቤት ውሳኔዎችና ሕጎች ሰዎች እንዲያነብቧቸው በፍርድ ቤቶችና በመንግሥታት ይታተማሉ። ነገር ግን እያንዳንዱ አገር በራሱ መንገድ፣ በራሱ ድረ ገጽ፣ በራሱ ቋንቋ ያትማል፤ ከእነዚያ ድረ ገጾች ብዙዎቹ የተሠሩት የት መፈለግ እንዳለባቸው አስቀድመው ለሚያውቁ ሰዎች ነው። የ AI ረዳቶች ሊረዱ ይችላሉ፣ ነገር ግን ምንጩን ማየት ሳይችሉ ሲቀሩ ይገምታሉ።

Fontes የ AI መተግበሪያዎን ከእነዚያ ይፋዊ ምንጮች ጋር ያገናኛል። የፍርድ ቤት ውሳኔዎችንና ሕጎችን ከሚያትሟቸው ፍርድ ቤቶችና መንግሥታት በቀጥታ ያመጣል፣ እያንዳንዱን ውጤት ከዋናው ጋር ያገናኛል፣ የራሱ የሆነ የመረጃ ቋት (database) አይይዝም።

እያንዳንዱ ጠበቃና እያንዳንዱ ዜጋ፣ የትም ቢሆን፣ የሚገዛውን ሕግ ማየትና መብቶቹን ለማስከበር ሊጠቀምበት መቻል አለበት ብዬ አምናለሁ። Fontes ለሕግ ባለሙያዎችም ለዜጎችም እኩል ነፃና ክፍት ምንጭ የሆነው ለዚህ ነው።

አንድ ነገር ከተበላሸ፣ ወይም የሚፈልጉት አገር ከጎደለ፣ እባክዎ [ጉዳይ (issue) ይክፈቱ](https://github.com/ykarapazar/fontes/issues)። ከሁሉ የበለጠ ጠቃሚ እርዳታ እሱ ነው።

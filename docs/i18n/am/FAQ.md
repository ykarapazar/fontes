# Fontes: ጥያቄዎችና መልሶች

## Fontes ምንድን ነው?

ነፃና ክፍት ምንጭ (open-source) የሆነ የ MCP አገልጋይ (Apache 2.0)። Model Context Protocol የሚናገር ማንኛውም መተግበሪያ
(Claude፣ Codex፣ Cursor፣ VS Code፣ Gemini CLI እና ሌሎች) የፍርድ ቤት ውሳኔዎችንና ሕጎችን በ125 የሕግ ክልሎች (jurisdictions) እና ዓለም አቀፍ ፍርድ ቤቶች ውስጥ በፍርድ ቤትና በመንግሥት ድረ ገጾች ላይ በቀጥታ እንዲፈልግ ያስችላል፤ በ Lexifina መዝገብ በኩል ደግሞ ከ91 ተጨማሪ አገሮች (ከታች ይመልከቱ)። እያንዳንዱ ውጤት ምንጩን ይጠቅሳል፣ ከዋናውም ጋር ያገናኛል።

## ጽሑፎቹ ይፋዊ ናቸው?

በአብዛኛው አዎ፣ ግን ሁልጊዜ አይደለም።

- አብዛኞቹ ምንጮች የሚተዳደሩት በፍርድ ቤት፣ በሚኒስቴር ወይም በይፋዊ ጋዜጣ ነው።
- አንዳንድ ማሻሻያዎች የተካተቱባቸው (consolidated) ጽሑፎች በመንግሥት የሚታተሙ ቢሆንም በግልጽ ይፋዊ ያልሆኑ ናቸው፦ ትክክለኛ
  (authentic) የሆነው ይፋዊው ጋዜጣ ብቻ ነው።
- ጥቂት ምንጮች ጨርሶ የመንግሥት ድረ ገጾች አይደሉም (ለምሳሌ LexiVox፣ LawPhil፣ Maqam፣ Wikisource)።

Fontes ከእነዚህ ከአንዱ በሚመጣ በእያንዳንዱ መልስ ላይ "ይፋዊ ያልሆነ ምንጭ" የሚል ማሳሰቢያ ያክላል። ማንኛውንም ነገር ከመጥቀስዎ
በፊት ይፋዊውን ኅትመት ያረጋግጡ። በ [README](README.md#ሽፋን) ውስጥ ያለው የሽፋን ሰንጠረዥና `list_jurisdictions` የእያንዳንዱን
የሕግ ክልል ምንጭ ይጠቅሳሉ።

## የትኞቹን የሕግ ክልሎች ይሸፍናል፣ በምን ያህል ደረጃስ?

ዓለም አቀፍ ፍርድ ቤቶችና አካላት (እንደ የአውሮፓ የሰብዓዊ መብቶች ፍርድ ቤት፣ የአውሮፓ ኅብረት (EU)፣ ICJ እና WTO ያሉ)።

ሽፋኑ በጣም ይለያያል። በጥብቅ መለኪያ (የከፍተኛው አጠቃላይ ፍርድ ቤት አስገዳጅ ውሳኔዎች (precedents)፣ ወይም ሕገ መንግሥቱና ዋና
ዋና ሕጎች፣ ሙሉ በሙሉ ሲደረስባቸው)፣ ከ125ቱ 72ቱ እንደተሸፈኑ ይቆጠራሉ። [COVERAGE.md](../../COVERAGE.md) (በእንግሊዝኛ)
ለእያንዳንዱ የሕግ ክልል Fontes ምን እንደሚደርስበት፣ ምን እንደማይደርስበት እና ለምን እንደሆነ ይዘረዝራል።

## ያለፉ ቅጂዎቹና ተጨማሪዎቹ አገሮች ከየት ይመጣሉ?

ከ [Lexifina](https://github.com/lexifina/global-law) ነው፣ እሱም ወደ 200 የሚጠጉ አገሮችን ሕግ እንደ git ታሪክ ያስቀምጣል፦ እያንዳንዱ ለውጥ ተፈጻሚ በሆነበት ቀን የተጻፈ ኮሚት ነው። Fontes ያነብበዋል በ Lexifina ነፃ የተስተናገደ አገልጋይ በኩል። ሁለት መሣሪያዎች ይጠቀሙበታል፦ `get_law_on_date` (ድንጋጌ ባለፈ ቀንም ጨምሮ ተፈጻሚ የነበረበት ሁኔታ፣ የለወጠው ሕግ ጋር) እና `get_law_history` (ድንጋጌ የለወጠው እያንዳንዱ ሕግ፣ ወይም በሁለት ቀኖች መካከል ቃል በቃል የተደረገው ለውጥ)። Fontes በዚሁ መንገድ 91 ተጨማሪ አገሮችንና ግዛቶችን ያነባል፣ ለሕግ ብቻ (ለምሳሌ ደቡብ አፍሪካ፣ ኬንያ፣ ሜክሲኮ፣ ኒው ዚላንድ፣ ሩሲያ፣ ደቡብ ኮሪያ፣ ቤልጂየም፣ ሊቱዌኒያ፣ ዩክሬን፣ ማሌዢያ፣ ታይላንድና ሳውዲ አረቢያ)። እነዚህ ከ125ቱ በቀጥታ ይፋዊ ሽፋን ካላቸው የሕግ ክልሎች (adapters) ተለይተው የተገለጹ ናቸው፣ ሽፋንም በየአገሩ በጣም ይለያያል (የኬንያ ብሔራዊ መዝገብ 9 ሕጎችን ይዟል)። የሕንድ ሕጎችም ከ Lexifina መዝገብ ይመጣሉ፣ ምክንያቱም የ India Code ውሎች አውቶማቲክ መድረስን ይከለክላሉ፤ የጠቅላይ ፍርድ ቤቷ ውሳኔዎች ግን በቀጥታ ይመጣሉ።

Lexifina ይፋዊ አሳታሚ አይደለም፣ መዝገቡም በቀጥታ (live) አይደለም፦ Lexifina ከጊዜ ወደ ጊዜ ያረጋግጣል፣ እና የራሱ ሪፖርት በ2026-11-26 ከ383 ብሔራዊ የሕግ አካላት 338ቱ ባለፉት 7 ቀናት ውስጥ ያልተፈተሹ እንደሆኑ ቆጥሯል። እያንዳንዱ መልስ Lexifinaን እንደ ምንጭ ይጠቅሳል፣ የይፋዊውን አሳታሚ ገጽ ያገናኛል፣ መዝገቡም እስከ የት እንደሚደርስ ይናገራል።

Lexifina ይፋዊ የሕግ ጽሑፎች በቅጂ መብት አይጠበቁም የሚል አቋም ይይዛል፣ ስለዚህ በአንዳንድ አገሮች ውሎቻቸውን ወይም robots.txt ን Fontes ራሱ የሚያከብራቸውን ድረ ገጾች ይገለብጣል። Fontes ራሱ ለሚያመጣቸው ሁሉ ማክበሩን ይቀጥላል፤ በ Lexifina በኩል የሚመጣው ግን የ Lexifina የራሱን ሕጋዊ ግምገማ ይከተላል፣ እርሱም በየአገሩ በማከማቻዎቹ ውስጥ ተመዝግቧል። ጥቂቶቹ አጠቃቀምን ይገድባሉ (የኬንያ አሳታሚ CC BY-NC ነው)። ለእነዚህ የፍለጋ ቃላትዎ፣ ማጣቀሻዎችዎና ቀኖችዎ ወደ Lexifina አገልጋይ ይሄዳሉ። ለማጥፋት `WLM_LEXIFINA=0` ያዘጋጁ። ቁልፍም ሆነ መለያ አያስፈልግም፤ ነፃው አገልጋይ በአንድ የኢንተርኔት አድራሻ በደቂቃ 60 ጥሪዎችንና በቀን 10,000 ይፈቅዳል። Fontes ከ Lexifina ጋር ግንኙነት የለውም።

## Fontes ከሚስተናገዱ (hosted) የሕግ ጥናት መሣሪያዎች በምን ይለያል?

- **በኮምፒውተርዎ ላይ ይሠራል።** የ Fontes አገልጋይም ሆነ መለያ የለም። ይህ ማለት ደግሞ የሚሠራው አካባቢያዊ የ MCP አገልጋይ
  ማስጀመር በሚችሉ መተግበሪያዎች (Claude Desktop፣ Codex፣ Cursor፣ VS Code እና መሰል) ውስጥ ብቻ ነው፤ የሚስተናገዱ
  ማገናኛዎችን (hosted connectors) ብቻ በሚቀበሉ በድር-ብቻ መተግበሪያዎች ውስጥ አይሠራም።
- **የመረጃ ቋት የለውም።** እያንዳንዱ ፍለጋ በቀጥታ ወደ አሳታሚው የራሱ ድረ ገጽ ወይም API ይሄዳል፤ ስለዚህ ውጤቶቹ እንደ ምንጩ
  ወቅታዊ ናቸው፣ የፍለጋው ጥራትም የምንጩ የራሱ ነው። በተመረጠ ማውጫ ላይ የትርጉም ፍለጋ (semantic search) የለም።
- **የአጠቃቀም ገደብ አያስቀምጥም።** Fontes ወርሃዊ የጥሪ ጣሪያ የለውም። ወደ እያንዳንዱ ድረ ገጽ የሚልካቸውን ጥያቄዎች ያራርቃል፣
  አንዳንድ ምንጮችም ምን ያህል በፍጥነት ወይም ምን ያህል ጊዜ ሊጠየቁ እንደሚችሉ ይገድባሉ።
- **ክፍት ምንጭ ነው።** እያንዳንዱን adapter ማንበብና እያንዳንዱ ጽሑፍ ከየት እንደሚመጣ በትክክል ማየት ይችላሉ።
- **ከጀርባው ሻጭ (vendor) የለም።** ውል፣ የድጋፍ ዴስክ ወይም የሥራ ጊዜ (uptime) ቃል ኪዳን የለም ("የሚያስተዳድረው ማን ነው?"
  የሚለውን ይመልከቱ)።

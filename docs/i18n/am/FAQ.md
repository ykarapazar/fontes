# Fontes: ጥያቄዎችና መልሶች

## Fontes ምንድን ነው?

ነፃና ክፍት ምንጭ (open-source) የሆነ የ MCP አገልጋይ (Apache 2.0)። Model Context Protocol የሚናገር ማንኛውም መተግበሪያ
(Claude፣ Codex፣ Cursor፣ VS Code፣ Gemini CLI እና ሌሎች) ከ120 በላይ በሆኑ የሕግ ክልሎች (jurisdictions) እና ዓለም አቀፍ
ፍርድ ቤቶች (124 adapters) የፍርድ ቤት ውሳኔዎችንና ሕጎችን በፍርድ ቤትና በመንግሥት ድረ ገጾች ላይ በቀጥታ እንዲፈልግ ያስችላል።
እያንዳንዱ ውጤት ምንጩን ይጠቅሳል፣ ከዋናውም ጋር ያገናኛል።

## ጽሑፎቹ ይፋዊ ናቸው?

በአብዛኛው አዎ፣ ግን ሁልጊዜ አይደለም።

- አብዛኞቹ ምንጮች የሚተዳደሩት በፍርድ ቤት፣ በሚኒስቴር ወይም በይፋዊ ጋዜጣ ነው።
- አንዳንድ ማሻሻያዎች የተካተቱባቸው (consolidated) ጽሑፎች በመንግሥት የሚታተሙ ቢሆንም በግልጽ ይፋዊ ያልሆኑ ናቸው፦ ትክክለኛ
  (authentic) የሆነው ይፋዊው ጋዜጣ ብቻ ነው።
- ጥቂት ምንጮች ጨርሶ የመንግሥት ድረ ገጾች አይደሉም (ለምሳሌ LexiVox፣ LawPhil፣ Maqam፣ Wikisource)።

Fontes ከእነዚህ ከአንዱ በሚመጣ በእያንዳንዱ መልስ ላይ "ይፋዊ ያልሆነ ምንጭ" የሚል ማሳሰቢያ ያክላል። ማንኛውንም ነገር ከመጥቀስዎ
በፊት ይፋዊውን ኅትመት ያረጋግጡ። በ [README](README.md#ሽፋን) ውስጥ ያለው የሽፋን ሰንጠረዥና `list_jurisdictions` የእያንዳንዱን
የሕግ ክልል ምንጭ ይጠቅሳሉ።

## የትኞቹን የሕግ ክልሎች ይሸፍናል፣ በምን ያህል ደረጃስ?

124 adapters፦ 108 የተባበሩት መንግሥታት አባል አገሮች፣ ሆንግ ኮንግ፣ ኮሶቮ፣ ፍልስጤም፣ ታይዋን፣ የ DIFC ፍርድ ቤቶች እና 11
ዓለም አቀፍ ፍርድ ቤቶችና አካላት (እንደ የአውሮፓ የሰብዓዊ መብቶች ፍርድ ቤት፣ የአውሮፓ ኅብረት (EU)፣ ICJ እና WTO ያሉ)።

ሽፋኑ በጣም ይለያያል። በጥብቅ መለኪያ (የከፍተኛው አጠቃላይ ፍርድ ቤት አስገዳጅ ውሳኔዎች (precedents)፣ ወይም ሕገ መንግሥቱና ዋና
ዋና ሕጎች፣ ሙሉ በሙሉ ሲደረስባቸው)፣ ከ124ቱ 72ቱ እንደተሸፈኑ ይቆጠራሉ። [COVERAGE.md](../../COVERAGE.md) (በእንግሊዝኛ)
ለእያንዳንዱ የሕግ ክልል Fontes ምን እንደሚደርስበት፣ ምን እንደማይደርስበት እና ለምን እንደሆነ ይዘረዝራል።

## የ API ቁልፍ ያስፈልገኛል?

ለሞላ ጎደል ለሁሉም የሕግ ክልሎች፣ አያስፈልግም። አንዳንድ ምንጮች ነፃ ቁልፍ ያስፈልጋቸዋል፦ [KEYS.md](KEYS.md) ን ይመልከቱ።

- **ፈረንሳይ:** አዎ። `WLM_FR_PISTE_CLIENT_ID` እና `WLM_FR_PISTE_CLIENT_SECRET` ን እስኪያዘጋጁ ድረስ ፈረንሳይ ጠፍቷል።
  እነዚህ የሚገኙት ለ Judilibre እና ለ Légifrance የተመዘገበ መተግበሪያ ካለው ነፃ የ PISTE መለያ (piste.gouv.fr) ነው።
- **አሜሪካ:** አማራጭ ነው። የፍርድ ቤት ውሳኔዎች ፍለጋ ያለ ቁልፍ ይሠራል፣ ነገር ግን የጋራው የማሳያ ቁልፍ (demo key) በአንድ
  የ IP አድራሻ በቀን ወደ 10 ፍለጋዎች ብቻ ይፈቅዳል። በ `WLM_US_GOVINFO_KEY` ውስጥ ያለ ነፃ የ api.data.gov ቁልፍ ይህን
  ገደብ ያሳድገዋል።

እነዚህን በመተግበሪያዎ የ MCP ቅንብሮች ውስጥ ለ Fontes አገልጋይ እንደ አካባቢ ተለዋዋጮች (environment variables) ያዘጋጁ።
መጫኛው (installer) ከወጣ በኋላ፣ ከተጫነ በኋላ ይጠይቅዎታል፣ የ **ቁልፎችን አክል ወይም ቀይር** ማስጀመሪያውም በኋላ ይቀይራቸዋል።

በተናጠል፣ ጥቂት ምንጮች በራስ-ሰር (automated) መድረስ የአሳታሚውን ፈቃድ እንደሚያስፈልገው በውሎቻቸው ውስጥ ይገልጻሉ። እነዚህ
OFF ተብለው ተመልክተዋል፣ ጠፍተውም ይቆያሉ። ቁልፍ ይህን አይለውጠውም፤ የሚለውጠው የአሳታሚው ፈቃድ ብቻ ነው (ከዚያም
`WLM_PERMITTED=<codes>` ን ያዘጋጁ)።

## ከኮምፒውተሬ ምን ይወጣል?

ፍለጋዎችዎ የሚሄዱት ወደሚፈለገው ምንጭ ብቻ ነው። Fontes የመረጃ ቋት አይይዝም፣ መለያም (account) አያስፈልገውም።

ከምንጮቹ ሌላ፣ Fontes አዲስ ሥሪት እንዳለ በቀን አንድ ጊዜ PyPIን ይጠይቃል (በ `FONTES_NO_UPDATE_CHECK=1` ያጥፉት)። የአጠቃቀም
ቆጠራዎች እርስዎ ካላበሯቸው በስተቀር ጠፍተዋል፣ የስህተት ሪፖርትም የሚላከው እርስዎ አይተው ካረጋገጡ በኋላ ብቻ ነው። የ AI
መተግበሪያዎ ውይይትዎን በራሱ ውሎች ሥር ያያል።

ሙሉ ዝርዝሩ: [PRIVACY.md](PRIVACY.md)።

## ይህ የሕግ ምክር ነው?

አይደለም። Fontes የጥናት መሣሪያ ነው። ጽሑፎችን ያገኛል፤ ለጉዳይዎ ምን ትርጉም እንዳላቸው አይነግርዎትም፣ እሱን መጠቀምም ከማንም
ጋር የጠበቃና የደንበኛ ግንኙነት አይፈጥርም። የ AI መተግበሪያው ጽሑፉን በስሕተት ሊያነብ ይችላል፤ ስለዚህ በውሳኔው ወይም በድንጋጌው
ላይ ከመመሥረትዎ በፊት ሙሉውን ያንብቡ። ምክር ለማግኘት፣ ጥያቄዎ በሚነሣበት ቦታ ብቁ የሆነ ጠበቃ ይጠይቁ።

  ማስጀመር በሚችሉ መተግበሪያዎች (Claude Desktop፣ Codex፣ Cursor፣ VS Code እና መሰል) ውስጥ ብቻ ነው፤ የሚስተናገዱ
  ማገናኛዎችን (hosted connectors) ብቻ በሚቀበሉ በድር-ብቻ መተግበሪያዎች ውስጥ አይሠራም።
- **የመረጃ ቋት የለውም።** እያንዳንዱ ፍለጋ በቀጥታ ወደ አሳታሚው የራሱ ድረ ገጽ ወይም API ይሄዳል፤ ስለዚህ ውጤቶቹ እንደ ምንጩ
  ወቅታዊ ናቸው፣ የፍለጋው ጥራትም የምንጩ የራሱ ነው። በተመረጠ ማውጫ ላይ የትርጉም ፍለጋ (semantic search) የለም።
- **የአጠቃቀም ገደብ አያስቀምጥም።** Fontes ወርሃዊ የጥሪ ጣሪያ የለውም። ወደ እያንዳንዱ ድረ ገጽ የሚልካቸውን ጥያቄዎች ያራርቃል፣
  አንዳንድ ምንጮችም ምን ያህል በፍጥነት ወይም ምን ያህል ጊዜ ሊጠየቁ እንደሚችሉ ይገድባሉ።
- **ክፍት ምንጭ ነው።** እያንዳንዱን adapter ማንበብና እያንዳንዱ ጽሑፍ ከየት እንደሚመጣ በትክክል ማየት ይችላሉ።
- **ከጀርባው ሻጭ (vendor) የለም።** ውል፣ የድጋፍ ዴስክ ወይም የሥራ ጊዜ (uptime) ቃል ኪዳን የለም ("የሚያስተዳድረው ማን ነው?"
  የሚለውን ይመልከቱ)።

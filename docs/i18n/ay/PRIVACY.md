# Fontes privacidad yatiyäwi

Fontes ukax computadoramanw irnaqi. Thaqäwinakamas, jist'arkta uka qillqatanakas
computadoramana, thaqkta uka jalsunaka (oficialanakampi, ukat CourtListener ukat Lexifina apnaqkta uka chiqanakan, qhipaxa uñjam), apnaqkta uka IA aplicaciona (uka aplicacionan
pachpa condicionanakapampi) taypinkakiwa. Fontes pachpax Fontes luririnakar **nayratpach
janiw kuns** apaykiti.

## Kunas computadoramat mistuspa, kunapachasa

**1. Versión uñakipaña (nayratpach naktata).** Sapa uru mä kuti, Fontes ukax PyPI ukaru,
Python paquetenakan público índice ukaru, kawkïris qhipa versión uk jiskt'i. Uka mayiwix
janiw kuns jumat jan ukax lurawimat apankiti; PyPI ukax IP direcciónam uñji, kuna apaqäwinsa
ukham uñjasi. Jiwt'ayañatakix `FONTES_NO_UPDATE_CHECK=1` (aplicación manqhan yatiyäwi) ukat
`FONTES_NO_AUTO_UPDATE=1` (instaladoran pachpa machaqtayäwipa) uchañam.

**2. Apnaqat jakhunaka (jiwt'ata, juma naktaykäta ukhakama).** Jïsa sasma ukhaxa, sapa uru
mä kuti Fontes ukax apayi:

- Fontes versión, sistema operativo familiamas (macOS, Windows, Linux);
- sapa urutaki, sapa irnaqañax sapa jurisdicción códigotak qhawqa kutis apnaqasi,
  amtañataki "2026-11-10, nl, search_caselaw, 12".

Ukakiw taqpach yatiyäwix. Janipuniw thaqäwinakam, qillqatanak jan ukax caso
identificadoranaka, qillqat arunaka, sutima, mä cuenta, ni kuna identificadorsa jumat jan
ukax computadoramat apankiti. Jakhunakax computadoraman suyt'apxi (Fontes caché carpetana,
`stats.json`) apayasiñapkama; apayäwix jan walt'chixa, jutïr urukamaw suyt'apxi.

- **Jïsa sañataki (opt in)**: instaladorax jiskt'kätam ukhax "y" jaysam, jan ukax Fontes
  servidoratak `FONTES_STATS=1` uchañam.
- **Jan sañataki (opt out)**: instalador wasitat irnaqayam ukat uka jiskt'äwin Enter
  limt'am, jan ukax `FONTES_STATS` apsum. `stats.json` chhaqtaysta ukhaxa, janïr apayat
  taqi kunas chhaqtawayi.

**3. Pantjat yatiyäwinaka (mä apaysta ukhaki).** Maya mayïta ukhaxa (`fontes report-bug`,
jan ukax IA aplicacionamar mä Fontes pantjat yatiyañap mayïta), Fontes ukax nayraqat
taqpach yatiyäw uñacht'ayätam, chiqapar sasma ukhakiw apayi. Fontes versión, sistema
operativo familiama, jan walt'at qhipa irnaqañ jawsäwin jurisdicción códigopa, irnaqañ
sutipa, pantjat yatiyäwipa (thaqañ arunakamas identificadoranakas apsutawa), ukat mä
qillqat qillqsta ukhaxa ukasa. Uka qillqatan clientenakam tuqit yatiyäwinak jan uchamti.
Akar yanapt'añataki, Fontes ukax qhipa pantjasïw computadoraman imi (`last-error.json`
caché carpetana, sapa kutiw lantisi); janipuniw pachpat apayaskiti.

**4. Lexifina (nayratpach utji).** `get_law_on_date`, `get_law_history`, 91 markanakax ukat India ukan kamachinakax Lexifina ukan qillqatap liyt'atarakiwa, ukatwa Lexifina ukar sarapxi, oficial web sitio ukat ukhamarak, jan ukax ukat sipansa. Thaqañ arunakamax, citas
ukanakamax ukat urunakamax Lexifina ukan jan pagani servidorar sarapxi, `global-law.lexifina.com`,
Lexifina lurat, Fontes luririnakat janiw. Lexifina uñacht'ayi: servidorax kuna tool mayt'ata ukat
mayt'ata ch'ama pacha ukanak qillqi, janiw kuns thaqat uk qillqkiti. Fontes janiw uk uñakipkti;
Lexifina ukan pachpa términos ukax katuqatäpxi. Lexifina ukax IP direccionam uñji, sapa web servidor
ukhama. Lexifina taqi kuna jiwt'ayañataki `WLM_LEXIFINA=0` uchañam; ukhamaxa ukat tools ukat markanakax
janiw irnaqkiti, ni kuna ukar sarkiti.

## Kawkirus saraski, qhawqa pachas imasi

Apnaqat jakhunakas pantjat yatiyäwinakas Fontes luririx irnaqayki uka mä jisk'a servidorar
sarapxi (`relay.kinetra.fit`). IP direcciónanakax janiw imaskiti: memoria ukankakiwa, mä
juk'a pachataki, walja mayiwinak jark'añataki, web servidorasti janiw akatak acceso log
imkiti. Jakhunakax sapa urun taqpach jakhuruw yapxatasi; sapa maynit apayäwinakax janiw
imaskiti. Taqpach jakhunakax 2 maratakama imasi, pantjat yatiyäwinakax 1 maratakama, ukat
chhaqtayasi. Janiw kunas aljaskiti ni yaqhanakar churaskiti.

Uka servidorar purt'añ jan puedkchixa, janiw kunas apayaskiti: jakhunakax computadoraman
qhiparapxi, pantjat yatiyäwisti issue tracker ukaruw irpätam.

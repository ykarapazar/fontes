El derecho de más de 120 jurisdicciones, a una pregunta de distancia.

Beta · gratuito · código abierto · fuentes comprobadas a diario

Fontes es un servidor MCP gratuito y de código abierto. Funciona en cualquier aplicación que pueda ejecutar un servidor local del Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio y otras. Haga una pregunta jurídica en lenguaje corriente: su aplicación de IA busca resoluciones judiciales y legislación en directo en sitios web gubernamentales y judiciales, en más de 120 jurisdicciones y tribunales internacionales, y enlaza cada resultado al original. Está pensado para abogados e investigadores jurídicos, y para cualquiera que quiera leer el derecho en su fuente.

Esta es una traducción asistida por máquina. La versión en inglés es la que prevalece.

Qué hace

  • Busca jurisprudencia y legislación en el momento en que usted consulta, desde el propio sitio web o API del editor.
  • Cada resultado indica su fuente y enlaza a ella, para que pueda comprobar el original.
  • Fontes no mantiene ninguna base de datos ni necesita cuenta. Sus preguntas solo van a la fuente en la que se busca. Los recuentos de uso y los informes de error son opcionales (solo si usted los activa).

Fontes es una ayuda para la investigación, no asesoramiento jurídico, y su uso no crea una relación abogado-cliente. Se proporciona tal cual, sin garantía (consulte la licencia Apache 2.0). Algunas fuentes son versiones expresamente no oficiales, y cada una tiene sus propias condiciones de uso; Fontes lo indica en sus respuestas. Lea la resolución o la disposición completa antes de confiar en ella. Fontes es independiente y no está afiliado a ningún tribunal, gobierno ni editor.

Instalación

  • Claude Desktop: descargue el archivo .mcpb de Fontes de la última versión, haga doble clic en él y luego haga clic en Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline y otras aplicaciones: añada Fontes a la configuración MCP de la aplicación. La mayoría aceptan esta entrada; la guía de instalación indica el archivo y el fragmento para cada aplicación.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx viene con uv. En macOS o Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. En Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Después reinicie la aplicación y pregunte: «¿En qué jurisdicciones puede buscar Fontes?»

En un Mac o un PC con Windows, un instalador en un clic configura Fontes en Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio y Cline, en cada una de ellas que haya en su ordenador, y después le ofrece añadir sus claves. Descargue el instalador para su ordenador de la última versión y cierre esas aplicaciones antes de ejecutarlo. Detalles en la guía de instalación. Algunas fuentes necesitan una clave gratuita: consulte KEYS.md.

Fontes es de código abierto bajo la licencia Apache 2.0. Los textos jurídicos siguen sujetos a la licencia de cada editor.

# Fontes 隱私權聲明

Fontes 佇你的電腦頂執行。你的檢索佮你拍開的文件，干焦佇你的電腦、你檢索的官方來源佮你用的 AI 應用程式
（受彼个應用程式家己的條款約束）之間來去。Fontes 本身**預設袂**傳送**任何物件**予 Fontes 的開發者。

## 佗一寡物件可能離開你的電腦，佮啥物時陣

**1. 更新檢查（預設拍開）。** Fontes 逐工一擺問 PyPI（公開的 Python 套件索引）上新的版本是佗一个。
彼个請求無包含任何有關你抑是你的工作的資訊；佮任何下載仝款，PyPI 會看著你的 IP 位址。欲關掉，請設定
`FONTES_NO_UPDATE_CHECK=1`（應用程式內底的通知）佮 `FONTES_NO_AUTO_UPDATE=1`（安裝程式的自動更新）。

**2. 使用次數統計（除非你拍開，若無就是關掉的）。** 若是你選擇加入，Fontes 逐工傳送一擺：

- Fontes 的版本佮你的作業系統類別（macOS、Windows、Linux）；
- 照日算的、逐个工具對逐个法域代碼的使用次數，比如
  「2026-11-10, nl, search_caselaw, 12」。

訊息的全部內容就是這寡。伊絕對袂包含你的檢索內容、文件抑是案件的 ID、文件內文、你的名、帳號，抑是任何
用來識別你抑是你電腦的 ID。統計會留佇你的電腦頂（Fontes 快取資料夾內底的 `stats.json`），到送出去為止；
若是傳送失敗，會等到隔工。

- **加入**：佇安裝程式問的時回答「y」，抑是為 Fontes 伺服器設定 `FONTES_STATS=1`。
- **退出**：閣執行一擺安裝程式，佇彼个問題揤 Enter，抑是移除 `FONTES_STATS`。刪掉 `stats.json` 會擲掉所有
  猶未送出去的內容。

**3. 錯誤回報（干焦佇你傳送的時）。** 你要求傳送錯誤回報的時（`fontes report-bug`，抑是請你的 AI
應用程式回報 Fontes 的錯誤），Fontes 會先予你看完整的回報，干焦佇你確認了後才會送出去。回報包含 Fontes
的版本、你的作業系統類別、上尾一擺失敗的工具呼叫的法域代碼、工具名稱佮錯誤訊息（已經刪掉你的檢索字詞
佮 ID），佮你寫的附註（若是有）。請毋通佇附註內底寫當事人的詳細資料。為著支援這个功能，Fontes 會佇你的
電腦頂保留上尾一擺的錯誤（伊快取資料夾內底的 `last-error.json`，逐擺攏會予人取代）；伊絕對袂單獨
送出去。

## 資料送去佗位，佮保存偌久

使用次數統計佮錯誤回報會送去 Fontes 開發者營運的一台細細仔伺服器（`relay.kinetra.fit`）。伊袂儲存 IP
位址：IP 位址干焦佇記憶體內底短短時間用來擋大量灌入的請求，而且彼个網頁伺服器無為伊保留存取紀錄。統計會
加總做逐工的總數；袂保留單一擺提交的內容。總數上濟保存 2 年，錯誤回報上濟保存 1 年，了後刪掉。任何內容
攏袂賣掉抑是分享。

若是連袂著彼个伺服器，就啥物攏袂送出去：統計會留佇你的電腦頂，錯誤回報會引導你改用問題追蹤系統。

## 由啥人負責，根據是啥物

使用次數統計佮錯誤回報的資料控制者是 Fontes 的開發者 Yüce Karapazar。聯絡：fontesmcp@proton.me。

法律依據是你的同意（英國 GDPR 佮歐盟 GDPR 第 6(1)(a) 條）。干焦佇你選擇加入的時才會傳送使用次數統計，
干焦佇你確認了後才會傳送錯誤回報。你會當隨時照頂面的方式退出來撤回同意；這袂影響以前已經送出去的內容。

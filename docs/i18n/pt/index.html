O direito de mais de 120 jurisdições, a uma pergunta de distância.

Beta · gratuito · código aberto · fontes verificadas diariamente

O Fontes é um servidor MCP gratuito e de código aberto. Ele funciona em qualquer app capaz de executar um servidor local do Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio e outros. Faça uma pergunta jurídica em linguagem comum: o seu app de IA pesquisa decisões judiciais e legislação ao vivo nos sites de governos e tribunais, em mais de 120 jurisdições e tribunais internacionais, e traz o link de cada resultado para o original. Ele foi feito para advogados e pesquisadores jurídicos, e para qualquer pessoa que queira ler o direito na sua fonte.

Esta é uma tradução feita com auxílio de máquina. A versão em inglês prevalece.

O que ele faz

  • Pesquisa jurisprudência e legislação no momento em que você pergunta, no próprio site ou API do publicador.
  • Cada resultado indica a sua fonte e traz o link para ela, para que você possa conferir o original.
  • O Fontes não mantém banco de dados e não exige conta. Suas perguntas vão apenas para a fonte pesquisada. As contagens de uso e os relatórios de erro dependem da sua autorização (opt-in).

O Fontes é um auxílio de pesquisa, não consultoria jurídica, e usá-lo não cria uma relação advogado-cliente. Ele é fornecido "no estado em que se encontra", sem garantia (veja a licença Apache 2.0). Algumas fontes são versões expressamente não oficiais, e cada uma tem os seus próprios termos de uso; o Fontes indica isso nas respostas. Leia a decisão ou o dispositivo na íntegra antes de confiar nele. O Fontes é independente e não tem vínculo com nenhum tribunal, governo ou publicador.

Instalação

  • Claude Desktop: baixe o arquivo .mcpb do Fontes na versão mais recente, clique duas vezes nele e depois clique em Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline e outros apps: adicione o Fontes às configurações MCP do app. A maioria aceita esta entrada; o guia de instalação indica o arquivo e o trecho para cada app.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

O uvx vem com o uv. No macOS ou Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. No Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Depois reinicie o app e pergunte: "Em quais jurisdições o Fontes pode pesquisar?"

No Mac, um instalador de um clique configura o Fontes no Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio e Cline, em cada um deles que estiver no seu computador, e depois oferece adicionar as suas chaves. Baixe-o da versão mais recente e feche esses apps antes de executá-lo. Um instalador para Windows está a caminho. Detalhes no guia de instalação. Algumas fontes precisam de uma chave gratuita: veja KEYS.md.

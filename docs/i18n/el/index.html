Το Fontes είναι ένας δωρεάν διακομιστής MCP ανοιχτού κώδικα. Λειτουργεί σε κάθε εφαρμογή που μπορεί να εκτελέσει τοπικό διακομιστή Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio και άλλες. Κάντε μια νομική ερώτηση σε απλή γλώσσα: η εφαρμογή ΤΝ σας αναζητά δικαστικές αποφάσεις και νομοθεσία σε πραγματικό χρόνο στους ιστότοπους κυβερνήσεων και δικαστηρίων, σε περισσότερες από 120 δικαιοδοσίες και διεθνή δικαστήρια, και συνδέει κάθε αποτέλεσμα με το πρωτότυπο. Είναι φτιαγμένο για νομικούς και ερευνητές του δικαίου, και για όποιον θέλει να διαβάζει το δίκαιο στην πηγή του.

Τι κάνει

  • Αναζητά νομολογία και νομοθεσία τη στιγμή που ρωτάτε, από τον ίδιο τον ιστότοπο ή το API του εκδότη.
  • Κάθε αποτέλεσμα κατονομάζει την πηγή του και παραπέμπει σε αυτήν, ώστε να μπορείτε να ελέγξετε το πρωτότυπο.
  • Το Fontes δεν διατηρεί βάση δεδομένων και δεν χρειάζεται λογαριασμό. Οι ερωτήσεις σας πηγαίνουν μόνο στην πηγή στην οποία γίνεται η αναζήτηση. Οι μετρήσεις χρήσης και οι αναφορές σφαλμάτων απαιτούν τη συναίνεσή σας (opt-in).

Το Fontes είναι βοήθημα έρευνας, όχι νομική συμβουλή, και η χρήση του δεν δημιουργεί σχέση δικηγόρου–πελάτη. Παρέχεται «ως έχει» (“as is”), χωρίς καμία εγγύηση (δείτε την άδεια Apache 2.0). Ορισμένες πηγές είναι ρητά ανεπίσημες εκδοχές, και καθεμία έχει τους δικούς της όρους χρήσης· το Fontes το αναφέρει στις απαντήσεις του. Διαβάστε ολόκληρη την απόφαση ή διάταξη πριν βασιστείτε σε αυτήν. Το Fontes είναι ανεξάρτητο και δεν συνδέεται με κανένα δικαστήριο, κυβέρνηση ή εκδότη.

Εγκατάσταση

Το Fontes δεν είναι ακόμη στο PyPI. Αυτά τα βήματα θα λειτουργούν μόλις κυκλοφορήσει η πρώτη έκδοση.

  • Claude Desktop: κατεβάστε το αρχείο .mcpb του Fontes από την τελευταία έκδοση, κάντε διπλό κλικ σε αυτό και έπειτα κάντε κλικ στο Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline και άλλες εφαρμογές: προσθέστε το Fontes στις ρυθμίσεις MCP της εφαρμογής. Οι περισσότερες δέχονται αυτήν την καταχώριση· ο οδηγός εγκατάστασης δίνει το αρχείο και το απόσπασμα για κάθε εφαρμογή.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

Το uvx περιλαμβάνεται στο uv. Σε macOS ή Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Σε Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Έπειτα επανεκκινήστε την εφαρμογή και ρωτήστε: «Σε ποιες δικαιοδοσίες μπορεί να αναζητήσει το Fontes;»

Ένα πρόγραμμα εγκατάστασης με ένα κλικ για Mac και Windows έρχεται σύντομα. Ρυθμίζει το Fontes στα Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio και Cline, σε καθένα που υπάρχει στον υπολογιστή σας, και έπειτα προσφέρεται να προσθέσει τα κλειδιά σας. Κλείστε αυτές τις εφαρμογές πριν το εκτελέσετε. Λεπτομέρειες στον οδηγό εγκατάστασης. Ορισμένες πηγές χρειάζονται δωρεάν κλειδί: δείτε το KEYS.md.

Το Fontes είναι ανοιχτού κώδικα με την άδεια Apache 2.0. Τα νομικά κείμενα εξακολουθούν να υπόκεινται στην άδεια κάθε εκδότη.

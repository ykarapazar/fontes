> Αυτή είναι μετάφραση με τη βοήθεια μηχανής. Υπερισχύει η αγγλική έκδοση.

# Εγκατάσταση του Fontes

Το Fontes επιτρέπει στην εφαρμογή ΤΝ σας να αναζητά δικαστικές αποφάσεις και νομοθεσία απευθείας
στους ιστότοπους δικαστηρίων και κυβερνήσεων σε περισσότερες από 120 δικαιοδοσίες. Κάθε
αποτέλεσμα παραπέμπει στο πρωτότυπο. Είναι ένας τυπικός διακομιστής MCP, οπότε λειτουργεί σε κάθε
εφαρμογή που μπορεί να εκτελέσει τοπικό διακομιστή MCP: Claude Desktop, Codex, Claude Code,
Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline και άλλες.

**Το Fontes δεν είναι ακόμη στο PyPI.** Τα παρακάτω βήματα θα λειτουργούν μόλις κυκλοφορήσει η
πρώτη έκδοση.

Επιλέξτε την εφαρμογή σας, ακολουθήστε τα βήματά της και έπειτα
[ελέγξτε ότι λειτουργεί](#πώς-να-ελέγξετε-ότι-λειτουργεί).

## Claude Desktop

1. Κατεβάστε το αρχείο `.mcpb` του Fontes από την
   [τελευταία έκδοση](https://github.com/ykarapazar/fontes/releases/latest).
2. Κάντε διπλό κλικ σε αυτό. Το Claude Desktop το ανοίγει.
3. Κάντε κλικ στο **Install**.

## Codex

Σε ένα τερματικό:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Το Codex CLI και η επέκταση Codex για IDE χρησιμοποιούν αυτήν την ίδια ρύθμιση
(`~/.codex/config.toml`). Χρειάζεστε το [uv](#χρειάζεστε-το-uv).

## Claude Code

Σε ένα τερματικό:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Χρειάζεστε το [uv](#χρειάζεστε-το-uv).

## Άλλες εφαρμογές

Καθεμία χρειάζεται το [uv](#χρειάζεστε-το-uv). Προσθέστε την καταχώριση, αποθηκεύστε, έπειτα
κλείστε την εφαρμογή και ανοίξτε την ξανά.

**Cursor:** στο `~/.cursor/mcp.json` (όλα τα έργα) ή στο `.cursor/mcp.json` (ένα έργο):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** στην παλέτα εντολών (Command Palette) εκτελέστε **MCP: Add
Server**, επιλέξτε **Command (stdio)**, πληκτρολογήστε `uvx fontes-mcp` και ονομάστε τον `fontes`.
Ή προσθέστε αυτό στο `~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

Παλαιότερες ρυθμίσεις του VS Code χρησιμοποιούν το `.vscode/mcp.json`, με κλειδί ανώτατου
επιπέδου `servers` αντί για `mcpServers`.

**Gemini CLI:** σε ένα τερματικό, `gemini mcp add -s user fontes uvx fontes-mcp`. Ή προσθέστε αυτό
στο `~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** ανοίξτε το αρχείο ρυθμίσεων (**zed: open settings file**) και προσθέστε:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** στη δεξιά πλαϊνή στήλη ανοίξτε την καρτέλα **Program**, κάντε κλικ στο
**Install → Edit mcp.json** και προσθέστε:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** κάντε κλικ στο εικονίδιο **MCP Servers**, ανοίξτε την καρτέλα **Configure**, κάντε
κλικ στο **Configure MCP Servers** και προσθέστε την ίδια καταχώριση `mcpServers` με το
LM Studio.

**Claude Desktop με το χέρι** (αντί για το αρχείο `.mcpb`): προσθέστε την ίδια καταχώριση
`mcpServers` στο `claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`,
Windows: `%APPDATA%\Claude\`).

**Οποιαδήποτε άλλη εφαρμογή MCP** (Windsurf και άλλες): η τεκμηρίωσή της αναφέρει πού
αποθηκεύει τους διακομιστές MCP. Οι περισσότερες δέχονται την ίδια καταχώριση: εντολή `uvx`,
όρισμα `fontes`.

Αν μια εφαρμογή δεν μπορεί να βρει το `uvx`, χρησιμοποιήστε την πλήρη διαδρομή του (σε macOS και
Linux την εμφανίζει το `which uvx`).

## Χρειάζεστε το uv

Το Codex, το Claude Code και οι άλλες εφαρμογές εκτελούν το Fontes με το `uvx`, που
περιλαμβάνεται στο **uv**, ένα μικρό δωρεάν εργαλείο της Astral. Για να το εγκαταστήσετε, δείτε
τον [οδηγό της Astral](https://docs.astral.sh/uv/getting-started/installation/) ή εκτελέστε:

- macOS ή Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## Κλειδιά

Ορισμένες πηγές χρειάζονται δωρεάν κλειδί: δείτε το [KEYS.md](KEYS.md).

## Πώς να ελέγξετε ότι λειτουργεί

Σε μια νέα συνομιλία ρωτήστε: *«Σε ποιες δικαιοδοσίες μπορεί να αναζητήσει το Fontes;»* Η
εφαρμογή θα πρέπει να απαντήσει με μια λίστα χωρών. Αν όχι, κλείστε ξανά την εφαρμογή και
ανοίξτε την πάλι.

## Πρόγραμμα εγκατάστασης με ένα κλικ (έρχεται σύντομα)

Ένα πρόγραμμα εγκατάστασης για Mac και Windows, που ρυθμίζει το Fontes σε όλες τις εφαρμογές σας
μονομιάς, έρχεται σύντομα. Ρυθμίζει τα Claude Desktop, Codex, Claude Code, Cursor, VS Code
(GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio και Cline. Μόλις κυκλοφορήσει:

**Πριν ξεκινήσετε:** κλείστε εντελώς καθεμία από αυτές τις εφαρμογές. Αυτό ισχύει κυρίως για το
Claude Code: όσο εκτελείται, ξαναγράφει το `~/.claude.json` και μπορεί να αναιρέσει την αλλαγή
του προγράμματος εγκατάστασης. Αν δεν μπορείτε να κλείσετε το Claude Code, προσθέστε του το
Fontes με το `claude mcp add` (δείτε [Claude Code](#claude-code)).

**Mac**

1. Ανοίξτε τον φάκελο **Fontes Installer** που κατεβάσατε.
2. Κάντε διπλό κλικ στο **Install Fontes.command**.
   - Αν το Mac σας αναφέρει ότι το αρχείο «δεν μπορεί να ανοίξει επειδή προέρχεται από μη
     αναγνωρισμένο προγραμματιστή»: κάντε δεξί κλικ (ή Control-κλικ) στο αρχείο, επιλέξτε
     **Open** και έπειτα ξανά **Open**. Αυτό χρειάζεται μόνο μία φορά.
3. Ανοίγει ένα παράθυρο και ρωτά αν θέλετε να στέλνονται ανώνυμες μετρήσεις χρήσης· πατήστε
   Enter για «όχι».
4. Ρωτά αν θέλετε να προσθέσετε κλειδιά τώρα. Πατήστε Enter για παράλειψη· δείτε
   [Το βήμα των κλειδιών](#το-βήμα-των-κλειδιών).
5. Όταν εμφανίσει **Done**, ανοίξτε ξανά τις εφαρμογές ΤΝ σας.

**Windows**

1. Αποσυμπιέστε το **Fontes Installer** που κατεβάσατε (δεξί κλικ → Extract All).
2. Κάντε διπλό κλικ στο **Install Fontes.cmd**.
   - Αν τα Windows εμφανίσουν «Windows protected your PC»: κάντε κλικ στο **More info** και
     έπειτα στο **Run anyway**.
3. Όταν ερωτηθείτε αν θέλετε να στέλνονται ανώνυμες μετρήσεις χρήσης, πατήστε Enter για «όχι».
4. Ρωτά αν θέλετε να προσθέσετε κλειδιά τώρα. Πατήστε Enter για παράλειψη· δείτε
   [Το βήμα των κλειδιών](#το-βήμα-των-κλειδιών).
5. Όταν εμφανίσει **Done**, ανοίξτε ξανά τις εφαρμογές ΤΝ σας. Αν κάποια εκτελούνταν ακόμη,
   κλείστε την εντελώς (και από την περιοχή ειδοποιήσεων, δίπλα στο ρολόι) και ανοίξτε την
   ξανά.

Στο τέλος, το πρόγραμμα εγκατάστασης απαριθμεί τις εφαρμογές που ρύθμισε.

### Ποιες εφαρμογές ρυθμίζει

Ρυθμίζει μια εφαρμογή μόνο αν ο φάκελος ρυθμίσεών της υπάρχει ήδη στον υπολογιστή σας. Το Claude
Code ρυθμίζεται μόνο αν υπάρχει το `~/.claude.json`. Το Claude Desktop ρυθμίζεται πάντα. Κάθε
εφαρμογή λαμβάνει μία καταχώριση `fontes` σε αυτό το αρχείο:

| Εφαρμογή | Αρχείο (Mac και Linux) | Αρχείο (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` και το ξεχωριστό αντίγραφο της έκδοσης Microsoft Store |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` ή, σε παλαιότερες εκδόσεις, `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` ή `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

Το VS Code ρυθμίζεται αν υπάρχει το `~/.copilot` ή ο φάκελος ρυθμίσεων του ίδιου του VS Code.

Δύο εφαρμογές χρειάζονται ένα επιπλέον βήμα:

- **Windsurf:** αφού το ανοίξετε ξανά, πατήστε ανανέωση (refresh) στο Cascade.
- **Cline στην παλαιότερη επέκταση του VS Code:** προσθέστε το Fontes με το χέρι (δείτε
  [Cline](#άλλες-εφαρμογές)).

### Το βήμα των κλειδιών

Αμέσως μετά την εγκατάσταση, το πρόγραμμα εγκατάστασης προσφέρεται να προσθέσει τα δωρεάν
κλειδιά για τη Γαλλία και τις ΗΠΑ. Για να τα προσθέσετε ή να τα αλλάξετε αργότερα:

- **Mac:** κάντε διπλό κλικ στο **Add or change keys.command** στον φάκελο του προγράμματος
  εγκατάστασης ή ανοίξτε ξανά την εφαρμογή Fontes Installer και επιλέξτε **Add or change keys**.
- **Windows:** κάντε διπλό κλικ στο **Add or change keys.cmd** στον φάκελο του προγράμματος
  εγκατάστασης.

Ό,τι πληκτρολογείτε δεν εμφανίζεται. Τα κλειδιά γράφονται σε κάθε εφαρμογή που έχει ήδη το
Fontes. Έπειτα κλείστε τις εφαρμογές και ανοίξτε τες ξανά. Πού θα βρείτε τα κλειδιά και τι
ξεκλειδώνουν: [KEYS.md](KEYS.md).

### Αντίγραφα ασφαλείας, επανεκτέλεση και αφαίρεση

Το πρόγραμμα εγκατάστασης αλλάζει μόνο την καταχώριση `fontes`. Όλες οι άλλες ρυθμίσεις και τα
σχόλια παραμένουν ως έχουν. Πριν αλλάξει ένα αρχείο, αποθηκεύει δίπλα του ένα αντίγραφο με το
όνομα `<file>.fontes-backup-<date>`. Τα αντίγραφα που δημιουργήθηκαν αφού προσθέσατε κλειδιά
περιέχουν αυτά τα κλειδιά: διαγράψτε όσα δεν χρειάζεστε πια. Εγκαθιστά επίσης το uv. Η
επανεκτέλεσή του είναι ασφαλής: επιδιορθώνει τη ρύθμιση και δεν αλλάζει τίποτε άλλο.

Για να αφαιρέσετε το Fontes, κάντε διπλό κλικ στο **Uninstall Fontes.command** (Mac) ή στο
**Uninstall Fontes.cmd** (Windows). Αφαιρεί την καταχώριση `fontes` από κάθε εφαρμογή, μαζί με
τα κλειδιά. Οι υπόλοιπες ρυθμίσεις σας και τα αντίγραφα ασφαλείας παραμένουν.

## Ενημερώσεις

- **Πρόγραμμα εγκατάστασης και αρχείο `.mcpb`:** δεν χρειάζεται να κάνετε τίποτα. Μία φορά την
  ημέρα, όταν ξεκινά η εφαρμογή, το Fontes ελέγχει στο παρασκήνιο αν υπάρχει νεότερη έκδοση και
  την προετοιμάζει· χρησιμοποιείται την επόμενη φορά που θα ξεκινήσει η εφαρμογή. Αν μια
  ενημέρωση δεν μπορεί να ληφθεί ή δεν λειτουργεί, το Fontes συνεχίζει να χρησιμοποιεί την
  έκδοση που λειτουργούσε.
- **`uvx`:** το Fontes ενημερώνει στην κορυφή της λίστας δικαιοδοσιών όταν υπάρχει νεότερη
  έκδοση. Για να εκτελείτε πάντα την πιο πρόσφατη έκδοση, χρησιμοποιήστε `fontes-mcp@latest` αντί
  για `fontes`.

Για τον σκοπό αυτό δεν αποστέλλεται πουθενά καμία πληροφορία για εσάς ή τις αναζητήσεις σας.

## Απόρρητο

Από προεπιλογή, το Fontes δεν στέλνει τίποτα για εσάς ή τις αναζητήσεις σας. Οι μετρήσεις χρήσης
αποστέλλονται μόνο με τη συναίνεσή σας (opt-in), και μια αναφορά σφάλματος αποστέλλεται μόνο
αφού τη δείτε και την επιβεβαιώσετε. Λεπτομέρειες: [PRIVACY.md](PRIVACY.md).

## Αφαίρεση

Αφαιρέστε την καταχώριση `fontes` από τις ρυθμίσεις MCP της εφαρμογής σας (Claude Code:
`claude mcp remove fontes`), έπειτα κλείστε την εφαρμογή και ανοίξτε την ξανά.

## Καλό να γνωρίζετε

Το Fontes διαβάζει δημόσιες πηγές, κυρίως ιστότοπους δικαστηρίων και κυβερνήσεων. Στις
απαντήσεις του επισημαίνει τις ανεπίσημες πηγές. Πριν βασιστείτε σε μια απόφαση ή διάταξη,
ανοίγετε πάντα τον σύνδεσμο της πηγής.

Αν κάτι δεν λειτουργεί, γράψτε τι κάνατε και ποιο σφάλμα είδατε στο fontesmcp@proton.me.

## Πριν βασιστείτε σε αυτό

- Το Fontes είναι εργαλείο έρευνας, όχι νομική συμβουλή. Η χρήση του δεν καθιστά κανέναν
  δικηγόρο σας.
- Παρέχεται «ως έχει» (“as is”), χωρίς καμία εγγύηση, και οι δημιουργοί του, στον βαθμό που
  επιτρέπει ο νόμος, δεν φέρουν ευθύνη για τον τρόπο χρήσης του. Οι πλήρεις όροι βρίσκονται
  στην [άδεια](../../../LICENSE) (Apache 2.0).

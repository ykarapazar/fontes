Fontes अनुसन्धानको सहायक साधन हो, कानुनी सल्लाह होइन, र यसको प्रयोगले कानुन व्यवसायी–ग्राहक सम्बन्ध सिर्जना गर्दैन। यो "जस्तो छ त्यस्तै" (as is), कुनै वारेन्टीबिना उपलब्ध गराइएको हो (Apache 2.0 इजाजतपत्र हेर्नुहोस्)। केही स्रोतहरू स्पष्ट रूपमा अनाधिकारिक संस्करण हुन्, र प्रत्येकका आफ्नै प्रयोगका सर्तहरू छन्; Fontes ले आफ्ना उत्तरहरूमा यो बताउँछ। भर पर्नुअघि पूरा फैसला वा दफा पढ्नुहोस्। Fontes स्वतन्त्र छ र कुनै पनि अदालत, सरकार वा प्रकाशकसँग सम्बद्ध छैन।

इन्स्टल

  • Claude Desktop: पछिल्लो रिलिज बाट Fontes को .mcpb फाइल डाउनलोड गर्नुहोस्, त्यसमा डबल-क्लिक गर्नुहोस्, अनि Install मा क्लिक गर्नुहोस्।
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline र अन्य एपहरू: एपको MCP सेटिङमा Fontes थप्नुहोस्। धेरैजसोले यो प्रविष्टि लिन्छन्; इन्स्टल गाइड मा प्रत्येक एपको फाइल र snippet छन्।

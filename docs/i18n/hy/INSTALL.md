> Սա մեքենայի օգնությամբ կատարված թարգմանություն է։ Վավերական է անգլերեն տարբերակը։

# Fontes-ի տեղադրում

Fontes-ը թույլ է տալիս ձեր AI հավելվածին դատական ակտեր և օրենսդրություն որոնել անմիջապես
դատական և պետական կայքերում ավելի քան 120 իրավազորություններում։ Յուրաքանչյուր արդյունք հղում է
բնօրինակին։ Այն ստանդարտ MCP սերվեր է, ուստի աշխատում է ցանկացած հավելվածում, որը կարող է
գործարկել տեղային MCP սերվեր՝ Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub
Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline և այլն։

Ընտրեք ձեր հավելվածը, կատարեք դրա քայլերը, ապա
[ստուգեք, որ այն աշխատում է](#ստուգում-որ-այն-աշխատում-է)։

## Claude Desktop

1. Ներբեռնեք Fontes-ի `.mcpb` ֆայլը
   [վերջին թողարկումից](https://github.com/ykarapazar/fontes/releases/latest)։
2. Կրկնակի սեղմեք դրա վրա։ Claude Desktop-ը կբացի այն։
3. Սեղմեք **Install**։

## Codex

Տերմինալում՝

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI-ը և Codex IDE ընդլայնումը կիսում են այս կարգավորումը (`~/.codex/config.toml`)։
Ձեզ անհրաժեշտ է [uv](#ձեզ-անհրաժեշտ-է-uv)։

## Claude Code

Տերմինալում՝

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Ձեզ անհրաժեշտ է [uv](#ձեզ-անհրաժեշտ-է-uv)։

## Այլ հավելվածներ

Դրանցից յուրաքանչյուրին անհրաժեշտ է [uv](#ձեզ-անհրաժեշտ-է-uv)։ Ավելացրեք գրառումը, պահպանեք,
ապա փակեք և նորից բացեք հավելվածը։

**Cursor.** `~/.cursor/mcp.json`-ում (բոլոր նախագծերի համար) կամ `.cursor/mcp.json`-ում (մեկ
նախագծի համար)՝

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot).** Հրամանների վահանակից (Command Palette) գործարկեք **MCP: Add
Server**, ընտրեք **Command (stdio)**, մուտքագրեք `uvx fontes-mcp` և սերվերն անվանեք `fontes`։ Կամ
ավելացրեք սա `~/.copilot/mcp-config.json`-ին՝

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code-ի ավելի հին կարգավորումներն օգտագործում են `.vscode/mcp.json`, որտեղ վերին մակարդակի
բանալին `servers`-ն է՝ `mcpServers`-ի փոխարեն։

**Gemini CLI.** տերմինալում՝ `gemini mcp add -s user fontes uvx fontes-mcp`։ Կամ ավելացրեք սա
`~/.gemini/settings.json`-ին՝

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed.** բացեք ձեր կարգավորումների ֆայլը (**zed: open settings file**) և ավելացրեք՝

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio.** աջ կողային վահանակում բացեք **Program** ներդիրը, սեղմեք **Install → Edit
mcp.json** և ավելացրեք՝

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline.** սեղմեք **MCP Servers** պատկերակը, բացեք **Configure** ներդիրը, սեղմեք **Configure
MCP Servers** և ավելացրեք նույն `mcpServers` գրառումը, ինչ LM Studio-ի համար։

**Claude Desktop, ձեռքով** (`.mcpb` ֆայլի փոխարեն). ավելացրեք նույն `mcpServers` գրառումը
`claude_desktop_config.json`-ին (macOS՝ `~/Library/Application Support/Claude/`, Windows՝
`%APPDATA%\Claude\`)։

**Ցանկացած այլ MCP հավելված** (Windsurf և այլն). դրա սեփական փաստաթղթերը նշում են, թե որտեղ է
այն պահում իր MCP սերվերները։ Մեծ մասն ընդունում է նույն գրառումը՝ հրաման `uvx`, արգումենտ
`fontes`։

Եթե հավելվածը չի կարողանում գտնել `uvx`-ը, օգտագործեք դրա ամբողջական ուղին (macOS-ում և
Linux-ում այն տպում է `which uvx`-ը)։

## Ձեզ անհրաժեշտ է uv

Codex-ը, Claude Code-ը և մյուս հավելվածները Fontes-ը գործարկում են `uvx`-ով, որը գալիս է
**uv**-ի հետ՝ Astral ընկերության փոքր անվճար գործիքի։ Այն տեղադրելու համար տե՛ս
[Astral-ի ուղեցույցը](https://docs.astral.sh/uv/getting-started/installation/) կամ գործարկեք՝

- macOS կամ Linux՝ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell)՝ `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## Բանալիներ

Որոշ աղբյուրներ պահանջում են անվճար բանալի. տե՛ս [KEYS.md](KEYS.md)։

## Ստուգում, որ այն աշխատում է

Նոր զրույցում հարցրեք. *«Ո՞ր իրավազորություններում կարող է որոնել Fontes-ը»։* Հավելվածը պետք է
պատասխանի երկրների ցանկով։ Եթե դա տեղի չունենա, ևս մեկ անգամ փակեք և նորից բացեք հավելվածը։

## Մեկ սեղմումով տեղադրիչ (շուտով)

Շուտով կլինի Mac-ի և Windows-ի տեղադրիչ, որը Fontes-ը միանգամից կարգավորում է ձեր բոլոր
հավելվածներում։ Այն կարգավորում է Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub
Copilot), Windsurf, Gemini CLI, Zed, LM Studio և Cline։ Թողարկվելուց հետո՝

**Նախքան սկսելը.** ամբողջությամբ փակեք այս հավելվածներից յուրաքանչյուրը։ Սա առավել կարևոր է
Claude Code-ի համար. աշխատելու ընթացքում այն վերագրում է `~/.claude.json`-ը և կարող է չեղարկել
տեղադրիչի կատարած փոփոխությունը։ Եթե չեք կարող փակել Claude Code-ը, Fontes-ն ավելացրեք դրան
`claude mcp add`-ով (տե՛ս [Claude Code](#claude-code))։

**Mac**

1. Բացեք ներբեռնված **Fontes Installer** թղթապանակը։
2. Կրկնակի սեղմեք **Install Fontes.command**-ի վրա։
   - Եթե ձեր Mac-ը հայտնում է, որ ֆայլը «cannot be opened because it is from an unidentified
     developer»՝ սեղմեք ֆայլի վրա մկնիկի աջ կոճակով (կամ Control-ը սեղմած պահելով), ընտրեք
     **Open**, ապա ևս մեկ անգամ **Open**։ Դա անում եք միայն մեկ անգամ։
3. Կբացվի պատուհան և կհարցնի՝ արդյոք ուղարկել օգտագործման անանուն հաշվարկներ. «ոչ»
   պատասխանելու համար սեղմեք Enter։
4. Այն կհարցնի՝ արդյոք հիմա ավելացնել բանալիները։ Բաց թողնելու համար սեղմեք Enter. տե՛ս
   [Բանալիների քայլը](#բանալիների-քայլը)։
5. Երբ այն ցույց տա **Պատրաստ է**, նորից բացեք ձեր AI հավելվածները։

**Windows**

1. Բացեք ներբեռնված **Fontes Installer** արխիվը (աջ սեղմում → Extract All)։
2. Կրկնակի սեղմեք **Install Fontes.cmd**-ի վրա։
   - Եթե Windows-ը ցույց տա «Windows protected your PC»՝ սեղմեք **More info**, ապա
     **Run anyway**։
3. Երբ հարցնի՝ արդյոք ուղարկել օգտագործման անանուն հաշվարկներ, «ոչ» պատասխանելու համար սեղմեք
   Enter։
4. Այն կհարցնի՝ արդյոք հիմա ավելացնել բանալիները։ Բաց թողնելու համար սեղմեք Enter. տե՛ս
   [Բանալիների քայլը](#բանալիների-քայլը)։
5. Երբ այն ցույց տա **Պատրաստ է**, նորից բացեք ձեր AI հավելվածները։ Եթե դրանցից որևէ մեկը դեռ
   աշխատում էր, ամբողջությամբ փակեք այն (նաև համակարգային սկուտեղից՝ ժամացույցի մոտ) և նորից
   բացեք։

Վերջում տեղադրիչը թվարկում է իր կարգավորած հավելվածները։

### Որ հավելվածներն է այն կարգավորում

Այն կարգավորում է հավելվածը միայն այն դեպքում, եթե այդ հավելվածի կարգավորումների թղթապանակն
արդեն կա ձեր համակարգչում։ Claude Code-ը կարգավորվում է միայն այն դեպքում, եթե գոյություն ունի
`~/.claude.json`-ը։ Claude Desktop-ը կարգավորվում է միշտ։ Յուրաքանչյուր հավելված ստանում է մեկ
գրառում՝ `fontes`, այս ֆայլում՝

| Հավելված | Ֆայլ (Mac և Linux) | Ֆայլ (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux՝ `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` և Microsoft Store-ի տարբերակի սեփական պատճենը |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`, կամ ավելի հին տարբերակներում՝ `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` կամ `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code-ը կարգավորվում է, եթե գոյություն ունի `~/.copilot`-ը կամ VS Code-ի սեփական
կարգավորումների թղթապանակը։

Երկու հավելվածի անհրաժեշտ է ևս մեկ քայլ՝

- **Windsurf.** նորից բացելուց հետո Cascade-ում սեղմեք թարմացում (refresh)։
- **Cline-ը VS Code-ի ավելի հին ընդլայնման մեջ.** Fontes-ն ավելացրեք ձեռքով (տե՛ս
  [Cline](#այլ-հավելվածներ))։

### Բանալիների քայլը

Տեղադրումից անմիջապես հետո տեղադրիչն առաջարկում է ավելացնել Ֆրանսիայի և ԱՄՆ-ի անվճար
բանալիները։ Դրանք ավելի ուշ ավելացնելու կամ փոխելու համար՝

- **Mac.** տեղադրիչի թղթապանակում կրկնակի սեղմեք **Add or change keys.command**-ի վրա կամ
  նորից բացեք Fontes Installer հավելվածը և ընտրեք **Ավելացնել կամ փոխել բանալիները**։
- **Windows.** տեղադրիչի թղթապանակում կրկնակի սեղմեք **Add or change keys.cmd**-ի վրա։

Մուտքագրվածը թաքցված է։ Բանալիները գրանցվում են յուրաքանչյուր հավելվածում, որն արդեն ունի
Fontes։ Դրանից հետո փակեք և նորից բացեք հավելվածները։ Որտեղից ստանալ բանալիները և ինչ են դրանք
բացում՝ [KEYS.md](KEYS.md)։

### Պահուստային պատճեններ, կրկնակի գործարկում և հեռացում

Տեղադրիչը փոխում է միայն `fontes` գրառումը։ Մնացած բոլոր կարգավորումներն ու մեկնաբանությունները
մնում են անփոփոխ։ Ֆայլը փոխելուց առաջ այն դրա կողքին պահպանում է պատճեն՝
`<file>.fontes-backup-<date>` անունով։ Բանալիներ ավելացնելուց հետո ստեղծված պատճենները
պարունակում են այդ բանալիները. ջնջեք նրանք, որոնք այլևս պետք չեն։ Այն նաև տեղադրում է uv-ն։
Կրկին գործարկելն անվտանգ է. այն վերականգնում է կարգավորումը և այլ բան չի փոխում։

Fontes-ը հեռացնելու համար կրկնակի սեղմեք **Uninstall Fontes.command**-ի (Mac) կամ
**Uninstall Fontes.cmd**-ի (Windows) վրա։ Այն բոլոր հավելվածներից հեռացնում է `fontes`
գրառումը՝ ներառյալ բանալիները։ Ձեր մյուս կարգավորումները և պահուստային պատճենները մնում են։

## Թարմացումներ

- **Տեղադրիչ և `.mcpb` ֆայլ.** ոչինչ անել պետք չէ։ Օրը մեկ անգամ, հավելվածը գործարկելիս,
  Fontes-ը ֆոնային ռեժիմում ստուգում է՝ արդյոք կա ավելի նոր տարբերակ, և պատրաստում է այն.
  հավելվածի հաջորդ գործարկման ժամանակ այն օգտագործվում է։ Եթե թարմացումը չի հաջողվում
  ներբեռնել կամ այն չի աշխատում, Fontes-ը շարունակում է օգտագործել աշխատած տարբերակը։
- **`uvx`.** Fontes-ը ձեզ տեղեկացնում է ավելի նոր տարբերակի առկայության մասին իր
  իրավազորությունների ցանկի սկզբում։ Միշտ ամենանոր տարբերակը գործարկելու համար `fontes`-ի
  փոխարեն օգտագործեք `fontes-mcp@latest`։

Դրա համար ձեր կամ ձեր որոնումների մասին որևէ տեղեկություն ոչ մի տեղ չի ուղարկվում։

## Գաղտնիություն

Fontes-ը լռելյայն ոչինչ չի ուղարկում ձեր կամ ձեր որոնումների մասին։ Օգտագործման հաշվարկները
կամավոր են (opt-in), իսկ սխալի մասին հաշվետվությունն ուղարկվում է միայն այն բանից հետո, երբ
դուք այն տեսնում և հաստատում եք։ Մանրամասները՝ [PRIVACY.md](PRIVACY.md)։

## Հեռացում

Հեռացրեք `fontes` գրառումը ձեր հավելվածի MCP կարգավորումներից (Claude Code-ում՝
`claude mcp remove fontes`), ապա փակեք և նորից բացեք հավելվածը։

## Լավ է իմանալ

Fontes-ը կարդում է հանրային աղբյուրներ՝ հիմնականում դատական և պետական կայքեր։ Ոչ պաշտոնական
աղբյուրներն այն նշում է իր պատասխաններում։ Որոշման կամ դրույթի վրա հենվելուց առաջ միշտ բացեք
աղբյուրի հղումը։

Եթե ինչ-որ բան սխալ ընթանա, գրեք fontesmcp@proton.me հասցեով՝ նշելով, թե ինչ եք արել և ինչ
սխալ եք տեսել։

# API ལྡེ་མིག

Fontes ནང་གི་ འབྱུང་ཁུངས་ ག་ཕལ་ཆེར་ ལྡེ་མིག་མེད་པར་ ལཱ་འབདཝ་ཨིན། གསུམ་ལུ་ རིན་མེད་ལྡེ་མིག་ཅིག་ དགོཔ་ཨིན:

| ལྡེ་མིག | ཁ་ཕྱེཝ་ཨིན | དེ་མེད་པ་ཅིན |
|---|---|---|
| `WLM_FR_PISTE_CLIENT_ID` + `WLM_FR_PISTE_CLIENT_SECRET` | ཕ་རཱན་སི: Judilibre (ཁྲིམས་ཁང་གི་ཁྲིམས་ཐག) དང་ Légifrance (ཁྲིམས་ཡིག) | ཕ་རཱན་སི་ ཁ་བསྡམས་ཡོད། `list_jurisdictions` གིས་ དེ་ ལཱ་མི་འབད་བ་སྦེ་ སྟོནམ་ཨིན། |
| `WLM_US_GOVINFO_KEY` | ཡུ་ནཱའི་ཊེཌ་ སི་ཊེཊསི: govinfo འཚོལ་ཞིབ (ཡོངས་ཁྱབ་ཁྲིམས་ཁང་གི་ཁྲིམས་ཐག, Statutes at Large, public laws) | Fontes གིས་ མཉམ་སྤྱོད་ `DEMO_KEY` ལག་ལེན་འཐབ་ཨིན: IP ཁ་བྱང་རེ་ལུ་ ཉིན་རེ་ལུ་ འཚོལ་ཞིབ་ 10 དེ་ཅིག། ཤེས་ཡོད་པའི་ཁྲིམས་ཐག་ཅིག་ ཁ་ཕྱེ་ནི་དང་ US Code ལུ་ ལྡེ་མིག་མི་དགོ། |

**གཞི་བཙུགས་ལས་རིམ་གྱི་ཐོག་ལས།** Fontes གཞི་སྒྲིག་འབད་ཚར་བའི་ཤུལ་ལུ་ གཞི་བཙུགས་ལས་རིམ་གྱིས་ ལྡེ་མིག་ཁ་སྐོང་རྐྱབ་ནི་ ཞུཝ་ཨིན། Mac གུ་

- Mac: Fontes Installer གློག་རིམ་ ལོག་སྟེ་ཁ་ཕྱེ་སྟེ་ **ལྡེ་མིག་ ཁ་སྐོང་ ཡང་ན་ སོར** གདམ།
- Windows: Start menu ཕྱེ་ནས་ **Fontes** → **ལྡེ་མིག་ ཁ་སྐོང ཡང་ན་ སོར** གདམ།

## ང་གིས་ འདི་ ག་ཅི་འབད་ བཟོ་ཡི་ག

Fontes འདི་ ཁྲིམས་རྩོད་པ་ཅིག་གིས་ ཁྲིམས་རྩོད་པ་ཚུ་གི་དོན་ལུ་ བཟོ་ཡོདཔ་ཨིན། =) དེ་ལས་ རང་ལུ་འབྲེལ་བའི་ཁྲིམས་ ལྷག་དགོ་པའི་ མི་གཞན་ག་ར་གི་དོན་ལུ་ཡང་ཨིན།

ཁྲིམས་འདི་ མི་མང་གི་ཨིན། ཁྲིམས་ཁང་གི་ཁྲིམས་ཐག་དང་ ཁྲིམས་ཡིག་ཚུ་ མི་ཚུ་གིས་ ལྷག་ཚུགས་ནིའི་དོན་ལུ་ ཁྲིམས་ཁང་དང་ གཞུང་ཚུ་གིས་ དཔར་བསྐྲུན་འབདཝ་ཨིན། ཨིན་རུང་ རྒྱལ་ཁབ་རེ་རེ་གིས་ རང་སོའི་ཐབས་ལམ་དང་ རང་སོའི་ཡོངས་འབྲེལ་ས་ཁོངས་ རང་སོའི་ཁ་སྐད་ནང་ དཔར་བསྐྲུན་འབདཝ་ཨིནམ་དང་ ཡོངས་འབྲེལ་ས་ཁོངས་དེ་ཚུ་ལས་ ལེ་ཤ་ཅིག་ ག་ཏེ་ལུ་ འཚོལ་དགོཔ་ཨིན་ན་ ཧ་གོ་སྟེ་ཡོད་མི་ མི་ཚུ་གི་དོན་ལུ་ བཟོ་ཡོདཔ་ཨིན། AI རོགས་རམ་པ་ཚུ་གིས་ གྲོགས་རམ་འབད་ཚུགས་ ཨིན་རུང་ འབྱུང་ཁུངས་ མཐོང་མ་ཚུགས་པ་ཅིན་ ཚོད་དཔག་བརྐྱབ་ཨིན།

Fontes གིས་ ཁྱོད་ཀྱི་ AI གློག་རིམ་ འབྱུང་ཁུངས་གཞུང་འབྲེལ་དེ་ཚུ་དང་ མཐུད་བྱིནམ་ཨིན། དེ་གིས་ ཁྲིམས་ཁང་གི་ཁྲིམས་ཐག་དང་ ཁྲིམས་ཡིག་ཚུ་ དཔར་བསྐྲུན་འབད་མི་ ཁྲིམས་ཁང་དང་ གཞུང་ཚུ་ལས་ ཐད་ཀར་དུ་ ལེནམ་ཨིནམ་དང་ གྲུབ་འབྲས་རེ་རེ་ མ་ཡིག་ལུ་ འབྲེལ་མཐུད་འབདཝ་ཨིན་ དེ་ལས་ རང་སོའི་གནས་སྡུད་མཛོད་ ག་ནི་ཡང་ མི་བཞག

ས་གནས་ག་ཏེ་ལུ་ཨིན་རུང་ ཁྲིམས་རྩོད་པ་རེ་རེ་དང་ མི་སེར་རེ་རེ་གིས་ རང་སོ་ལུ་ དབང་ཚད་ཡོད་པའི་ཁྲིམས་ འཚོལ་ཏེ་བལྟ་ཚུགས་ནི་དང་ རང་སོའི་ཐོབ་དབང་ ཉེན་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ཚུགས་དགོ་ཟེར་ ང་གིས་ ཡིད་ཆེས་ཡོད། དེ་འབདཝ་ལས་ Fontes འདི་ ཁྲིམས་ཀྱི་ལཱ་གཡོག་པ་དང་ མི་སེར་ ག་ར་གི་དོན་ལུ་ རིན་མེད་དང་ open source ཨིན།

ག་ཅི་ར་ཅིག་ ཆད་དེ་ཡོད་པ་ཅིན་ ཡང་ན་ ཁྱོད་ལུ་དགོ་པའི་ རྒྱལ་ཁབ་ཅིག་ མེད་པ་ཅིན་ ཞུ་གནང་སྟེ་ [issue ཅིག་ ཁ་ཕྱེ](https://github.com/ykarapazar/fontes/issues)། དེ་ ཕན་ཐོགས་ཅན་གྱི་ གྲོགས་རམ་ ཆེ་ཤོས་ཨིན།

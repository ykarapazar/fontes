# Fontes གཞི་བཙུགས་འབད་ནི

Fontes གིས་ ཁྱོད་ཀྱི་ AI གློག་རིམ་ལུ་ ཁྲིམས་ཀྱི་དབང་ཁོངས་ 125 ནང་ ཁྲིམས་ཁང་དང་ གཞུང་གི་ ཡོངས་འབྲེལ་ས་ཁོངས་གུ་
ཁྲིམས་ཁང་གི་ཁྲིམས་ཐག་དང་ ཁྲིམས་ཡིག་ཚུ་ ཐད་ཀར་དུ་ འཚོལ་ཚུགས་པ་ བཟོཝ་ཨིན། གྲུབ་འབྲས་རེ་རེ་ མ་ཡིག་ལུ་ འབྲེལ་མཐུད་ཡོདཔ་ཨིན། འདི་ ཚད་ལྡན་ MCP
སར་བར་ཅིག་ཨིནམ་ལས་ ས་གནས་ཀྱི་ MCP སར་བར་ཅིག་ གཡོག་བཀོལ་ཚུགས་པའི་ གློག་རིམ་ག་ཅི་རང་ཨིན་རུང་ནང་ ལཱ་འབདཝ་ཨིན: Claude Desktop, Codex, Claude
Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline དང་ གཞན་ཚུ།

ཁྱོད་ཀྱི་གློག་རིམ་ གདམ་ དེའི་རིམ་པ་ཚུ་ལུ་ བརྟེན་ཞིནམ་ལས་ [ལཱ་འབདཝ་ཨིན་ན་ བརྟག་ཞིབ་འབད](#ལཱའབདཝཨིནན-བརྟགཞིབ)།

## Claude Desktop

1. [འགྲེམ་སྤེལ་གསར་ཤོས](https://github.com/ykarapazar/fontes/releases/latest) ལས་ Fontes གི་ `.mcpb` ཡིག་སྣོད་
   ཕབ་ལེན་འབད།
2. དེ་ལུ་ ཚར་གཉིས་ཨེབ། Claude Desktop གིས་ དེ་ ཁ་ཕྱེཝ་ཨིན།
3. **Install** ཨེབ།

## Codex

terminal ཅིག་ནང:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI དང་ Codex IDE ཁ་སྐོང་གཉིས་ཀྱིས་ སྒྲིག་སྟངས་འདི་ (`~/.codex/config.toml`) མཉམ་སྤྱོད་འབདཝ་ཨིན།
ཁྱོད་ལུ་ [uv](#ཁྱོདལུ-uv-དགོ) དགོ།

## Claude Code

terminal ཅིག་ནང:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

ཁྱོད་ལུ་ [uv](#ཁྱོདལུ-uv-དགོ) དགོ།

## གློག་རིམ་གཞན

འདི་ཚུ་ རེ་རེ་ལུ་ [uv](#ཁྱོདལུ-uv-དགོ) དགོ། ཐོ་བཀོད་འདི་ ཁ་སྐོང་རྐྱབ་ སྲུང་ཞིནམ་ལས་ གློག་རིམ་ ཁ་བསྡམས་ཏེ་ ལོག་ཁ་ཕྱེ།

**Cursor:** `~/.cursor/mcp.json` (ལས་འགུལ་ག་ར) ཡང་ན་ `.cursor/mcp.json` (ལས་འགུལ་གཅིག) ནང:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette ལས་ **MCP: Add Server** གཡོག་བཀོལ་
**Command (stdio)** གདམ་ `uvx fontes-mcp` བཙུགས་ཞིནམ་ལས་ སར་བར་ལུ་ `fontes` ཟེར་ མིང་བཏགས། ཡང་ན་ འདི་
`~/.copilot/mcp-config.json` ལུ་ ཁ་སྐོང་རྐྱབ:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code གི་ གཞི་སྒྲིག་རྙིངམ་ཚུ་གིས་ `.vscode/mcp.json` ལག་ལེན་འཐབ་ཨིན་ དེ་ནང་ མཐོ་ཤོས་རིམ་པའི་ལྡེ་མིག་ (top-level key) འདི་
`mcpServers` གི་ཚབ་ལུ་ `servers` ཨིན།

**Gemini CLI:** terminal ཅིག་ནང་ `gemini mcp add -s user fontes uvx fontes-mcp`། ཡང་ན་ འདི་
`~/.gemini/settings.json` ལུ་ ཁ་སྐོང་རྐྱབ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** ཁྱོད་ཀྱི་ སྒྲིག་སྟངས་ཡིག་སྣོད་ (**zed: open settings file**) ཁ་ཕྱེ་སྟེ་ ཁ་སྐོང་རྐྱབ:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** གཡས་ཕྱོགས་ཀྱི་ ཟུར་ཕྲེང་ནང་ **Program** ཤོག་མཆན་ ཁ་ཕྱེ་ **Install → Edit
mcp.json** ཨེབ་ཞིནམ་ལས་ ཁ་སྐོང་རྐྱབ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** རྟགས་པར་ལུ་ ཨེབ་ **Configure** ཤོག་མཆན་ ཁ་ཕྱེ་ **Configure MCP
Servers** ཨེབ་ཞིནམ་ལས་ LM Studio གི་དོན་ལུ་ བཟུམ་སྦེ་ `mcpServers` ཐོ་བཀོད་ཅོག་འཐདཔ་ ཁ་སྐོང་རྐྱབ།

**Claude Desktop, ལག་པའི་ཐོག་ལས** (`.mcpb` ཡིག་སྣོད་ཀྱི་ཚབ་ལུ): `mcpServers` ཐོ་བཀོད་ཅོག་འཐདཔ་འདི་
`claude_desktop_config.json` ལུ་ ཁ་སྐོང་རྐྱབ (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`)།

**MCP གློག་རིམ་གཞན་ག་ཅི་རང་ཨིན་རུང** (Windsurf དང་ གཞན་ཚུ): དེ་རང་གི་ ཡིག་ཆ་ནང་ དེ་གིས་ MCP
སར་བར་ཚུ་ ག་ཏེ་ བཞགཔ་ཨིན་ན་ སླབ་ཨིན། མང་ཤོས་ཅིག་གིས་ ཐོ་བཀོད་ཅོག་འཐདཔ་ ལེནམ་ཨིན: བརྡ་བཀོད་ `uvx`, ཚད་བཟུང་ `fontes-mcp`.

གློག་རིམ་གྱིས་ `uvx` འཚོལ་མ་ཐོབ་པ་ཅིན་ དེའི་འགྲུལ་ལམ་ཆ་ཚང་ ལག་ལེན་འཐབ (macOS དང་ Linux གུ་ `which uvx` གིས་ དེ་ སྟོནམ་ཨིན)།

## ཁྱོད་ལུ་ uv དགོ

Codex, Claude Code དང་ གློག་རིམ་གཞན་ཚུ་གིས་ Fontes འདི་ `uvx` གིས་ འགོ་བཙུགསཔ་ཨིན་ དེ་ Astral ལས་ཐོན་མི་ རིན་མེད་ལག་ཆས་ཆུང་ཀུ་
**uv** དང་གཅིག་ཁར་ འོངམ་ཨིན། དེ་ གཞི་བཙུགས་འབད་ནིའི་དོན་ལུ་
[Astral's guide](https://docs.astral.sh/uv/getting-started/installation/) ལུ་ བལྟ་ ཡང་ན་ གཡོག་བཀོལ:

- macOS ཡང་ན་ Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## ལཱ་འབདཝ་ཨིན་ན་ བརྟག་ཞིབ

གཏམ་གླེང་གསརཔ་ཅིག་ནང་ འདྲི: *"Fontes གིས་ ཁྲིམས་ཀྱི་དབང་ཁོངས་ག་ཅི་ཚུ་ནང་ འཚོལ་ཞིབ་འབད་ཚུགས་ག?"* གློག་རིམ་གྱིས་
རྒྱལ་ཁབ་ཚུ་གི་ཐོ་ཅིག་གིས་ ལན་སླབ་དགོ། མ་སླབ་པ་ཅིན་ གློག་རིམ་ ཚར་གཅིག་ ཁ་བསྡམས་ཏེ་ ལོག་ཁ་ཕྱེ།

## ཨེབ་ཐེངས་གཅིག་གི་ གཞི་བཙུགས་ལས་རིམ (Mac དང་ Windows)

གཞི་བཙུགས་ལས་རིམ་གྱིས་ ཁྱོད་ཀྱི་གློག་རིམ་ག་ར་ནང་ ཚར་གཅིག་ལུ་ Fontes གཞི་སྒྲིག་འབདཝ་ཨིན: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio དང་ Cline།

**འགོ་མ་བཙུགས་པའི་ཧེ་མ:** གློག་རིམ་འདི་ཚུ་ རེ་རེ་ ཆ་ཚང་སྦེ་ ཁ་བསྡམས། འདི་ Claude Code གི་དོན་ལུ་ གལ་ཆེ་ཤོས་ཨིན:
དེ་ ལཱ་འབད་དེ་ཡོད་པའི་སྐབས་ དེ་གིས་ `~/.claude.json` ལོག་བྲིཝ་ཨིནམ་ལས་ གཞི་བཙུགས་ལས་རིམ་གྱི་ བསྒྱུར་བཅོས་ ཕྱིར་བཏོན་འབད་ཚུགས། ཁྱོད་ཀྱིས་
Claude Code ཁ་བསྡམས་མ་ཚུགས་པ་ཅིན་ དེའི་ཚབ་ལུ་ `claude mcp add` གིས་ Fontes ཁ་སྐོང་རྐྱབ ([Claude Code](#claude-code) ལུ་ བལྟ)།

**Mac**

1. Mac གི་ གཞི་བཙུགས་ལས་རིམ (`Fontes-Installer-…-mac.zip`) འདི་ [འགྲེམ་སྤེལ་གསར་ཤོས](https://github.com/ykarapazar/fontes/releases/latest) ལས་
   ཕབ་ལེན་འབད་ཞིནམ་ལས་ zip ཁ་ཕྱེ་ནིའི་དོན་ལུ་ དེ་ལུ་ ཚར་གཉིས་ཨེབ།
2. **Fontes Installer** ལུ་ ཚར་གཉིས་ཨེབ། ཁྱོད་ཀྱི་ Mac གིས་ ཨིན་ཊར་ནེཊ་ལས་ ཕབ་ལེན་འབད་ཡོད་པའི་ གློག་རིམ་ཅིག་ ཁ་ཕྱེ་ནི་ཨིན་ན་ འདྲི་བ་ཅིན་
   **Open** ཨེབ།
3. **གཞི་བཙུགས** གདམ་ཞིནམ་ལས་ **ལེགས་ཤོམ** ཨེབ། གཞི་སྒྲིག་འབད་ནི་ལུ་ སྐར་མ་གཅིག་ཙམ་ འགོརཝ་ཨིན།
4. འཕྲིན་དོན་ཅིག་གིས་ དེ་གིས་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ གློག་རིམ་ཚུ་ ཐོ་བཀོད་འབདཝ་ཨིན། **ཚར་ཡི** ཨེབ་ཞིནམ་ལས་ གློག་རིམ་དེ་ཚུ་ ལོག་སྟེ་ ཁ་ཕྱེ།
   གདམ་ཁའི་ རིན་མེད་ལྡེ་མིག་ཚུ་ ཧེ་མ་ ཁ་སྐོང་རྐྱབ་ནི་ཨིན་པ་ཅིན་ དེའི་ཚབ་ལུ་ **ལྡེ་མིག་ ཁ་སྐོང** ཨེབ། [ལྡེ་མིག་གི་རིམ་པ](#ལྡེམིགགིརིམཔ) ལུ་ བལྟ།

སྙན་ཞུ་ཅིག་ ཁྱོད་ཀྱིས་ མཐོང་སྟེ་ ངེས་གཏན་བཟོ་བའི་ཤུལ་ལུ་རྐྱངམ་ཅིག་ གཏངམ་ཨིན། རྒྱས་བཤད: [PRIVACY.md](PRIVACY.md)།

## བཏོན་ནི

ཁྱོད་ཀྱི་གློག་རིམ་གྱི་ MCP སྒྲིག་སྟངས་ལས་ `fontes` ཐོ་བཀོད་ བཏོན (Claude Code ནང:
`claude mcp remove fontes`) ཞིནམ་ལས་ གློག་རིམ་ ཁ་བསྡམས་ཏེ་ ལོག་ཁ་ཕྱེ།

## ཤེས་དགོཔ

Fontes གིས་ མི་མང་གི་འབྱུང་ཁུངས་ཚུ་ ལྷགཔ་ཨིན་ མང་ཤོས་ཅིག་ ཁྲིམས་ཁང་དང་ གཞུང་གི་ ཡོངས་འབྲེལ་ས་ཁོངས་ཚུ་ཨིན། དེ་གིས་ གཞུང་འབྲེལ་མེན་པ་ཚུ་
དེའི་ལན་ནང་ རྟགས་བཀལཝ་ཨིན། ཁྲིམས་ཐག་ ཡང་ན་ དོན་ཚན་ཅིག་ལུ་ མ་བརྟེན་པའི་ཧེ་མ་ ཨ་རྟག་ར་ འབྱུང་ཁུངས་ཀྱི་འབྲེལ་མཐུད་ ཁ་ཕྱེ།

ག་ཅི་ཅིག་ ནོར་བ་ཅིན་ ཁྱོད་ཀྱིས་ ག་ཅི་འབད་ཡི་ག་དང་ ཁྱོད་ཀྱིས་ མཐོང་མི་ འཛོལ་བ་འདི་ fontesmcp@proton.me ལུ་ གློག་འཕྲིན་གཏང་།

## དེ་ལུ་ མ་བརྟེན་པའི་ཧེ་མ

- Fontes འདི་ ཞིབ་འཚོལ་གྱི་ལག་ཆས་ཅིག་ཨིན་ ཁྲིམས་ཀྱི་བསླབ་བྱ་མེན། དེ་ ལག་ལེན་འཐབ་པ་ཅིན་ ག་ཡང་ ཁྱོད་ཀྱི་ ཁྲིམས་རྩོད་པ་ མི་འགྱོ།

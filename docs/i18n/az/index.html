Beta · pulsuz · açıq mənbəli · mənbələr hər gün yoxlanılır

Fontes pulsuz, açıq mənbəli MCP serveridir. O, yerli Model Context Protocol serverini işə sala bilən istənilən proqramda işləyir: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio və digərləri. Hüquqi sualı sadə dildə verin: süni intellekt proqramınız 125 yurisdiksiyada və beynəlxalq məhkəmədə məhkəmə qərarlarını və qanunvericiliyi dövlət və məhkəmə saytlarında canlı olaraq axtarır və hər nəticəni orijinala bağlayır. Bundan əlavə, qanunun keçmiş bir tarixdə necə olduğunu göstərə bilir və 91 digər ölkənin qanunvericiliyini Lexifina-nın qeydindən oxuya bilir (rəsmi nəşriyyatçı deyil). O, hüquqşünaslar və hüquq tədqiqatçıları, həmçinin hüququ mənbəyindən oxumaq istəyən hər kəs üçün yaradılıb.

Nə edir

  • Siz soruşduğunuz anda naşirin öz saytından və ya API-sindən məhkəmə təcrübəsi və qanunvericilik axtarır.
  • Hər nəticə öz mənbəyini göstərir və ona keçid verir, beləliklə orijinalı yoxlaya bilərsiniz.
  • Fontes verilənlər bazası saxlamır və hesab tələb etmir. Suallarınız axtarış aparılan mənbəyə gedir; qanunların keçmiş versiyaları, 91 əlavə ölkə və Hindistan qanunları üçün isə Lexifina-nın ictimai xidmətinə gedir, rəsmi saytla birlikdə və ya onun əvəzinə. Bunu söndürmək üçün WLM_LEXIFINA=0 təyin edin. İstifadə sayları və xəta hesabatları yalnız sizin razılığınızla (opt-in) göndərilir.

Fontes hüquqi məsləhət deyil, tədqiqat vasitəsidir və ondan istifadə vəkil–müştəri münasibəti yaratmır. O, heç bir zəmanət olmadan olduğu kimi təqdim olunur (bax Apache 2.0 lisenziyası). Bəzi mənbələr açıq şəkildə qeyri-rəsmi versiyalardır və hər birinin öz istifadə şərtləri var; Fontes bunu cavablarında bildirir. Qərara və ya müddəaya etibar etməzdən əvvəl onun tam mətnini oxuyun. Fontes müstəqildir və heç bir məhkəmə, hökumət və ya naşirlə əlaqəli deyil.

Quraşdırma

  • Claude Desktop: Fontes .mcpb faylını son buraxılışdan yükləyin, üzərinə iki dəfə klikləyin, sonra Install düyməsini klikləyin.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline və digər proqramlar: Fontes-i proqramın MCP parametrlərinə əlavə edin. Əksəriyyəti bu qeydi qəbul edir; quraşdırma bələdçisi hər proqram üçün faylı və fraqmenti verir.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx uv ilə birlikdə gəlir. macOS və ya Linux-da: curl -LsSf https://astral.sh/uv/install.sh | sh. Windows-da (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Sonra proqramı yenidən başladın və soruşun: "Fontes hansı yurisdiksiyalarda axtarış apara bilər?"

Mac və ya Windows kompüterdə bir kliklə quraşdırıcı Fontes-i Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio və Cline-da, kompüterinizdə olan hər birində quraşdırır, sonra açarlarınızı əlavə etməyi təklif edir. Kompüterinizə uyğun quraşdırıcını son buraxılışdan yükləyin və işə salmazdan əvvəl həmin proqramları bağlayın. Təfərrüatlar quraşdırma bələdçisindədir. Bəzi mənbələr pulsuz açar tələb edir: bax KEYS.md.

Fontes Apache 2.0 lisenziyası altında açıq mənbəlidir. Hüquqi mətnlər hər naşirin öz lisenziyası altında qalır.

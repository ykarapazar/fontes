یاسا و بڕیاری دادگا بۆ بەرنامەی AIەکەتان، بە زیندوویی لە ماڵپەڕەکانی دادگا و حکومەتەوە.

Beta · خۆڕایی · سەرچاوەکراوە · سەرچاوەکان ڕۆژانە دەپشکنرێن

Fontes ڕاژەکارێکی MCPی خۆڕایی و سەرچاوەکراوەیە. لە هەر بەرنامەیەکدا کار دەکات کە بتوانێت ڕاژەکارێکی Model Context Protocolی ناوخۆیی کار پێ بکات: Claude Desktop، Claude Code، Codex، Cursor، VS Code (GitHub Copilot)، Gemini CLI، Windsurf، Zed، LM Studio و ئەوانی تر. پرسیارێکی یاسایی بە زمانێکی سادە بکەن: بەرنامەی AI بڕیارەکانی دادگا و یاسا و ڕێساکان بە زیندوویی لە ماڵپەڕەکانی حکومەت و دادگاکاندا لە 125 ناوچەی دادوەری و دادگای نێودەوڵەتیدا دەگەڕێت، و هەر ئەنجامێک بە دەقە ڕەسەنەکەوە دەبەستێتەوە. هەروەها دەتوانێت یاسایەک پیشان بدات وەک لە بەرواریەکی ڕابردوودا بووە، و یاسای 91 وڵاتی تر لە تۆمارەکەی Lexifina بخوێنێتەوە (نەک بڵاوکەرەوەی فەرمی). بۆ پارێزەران و توێژەرانی یاسایی دروستکراوە، و بۆ هەر کەسێک کە دەیەوێت یاسا لە سەرچاوەکەیەوە بخوێنێتەوە.

ئەمە وەرگێڕانێکە بە یارمەتیی ئامێر کراوە. وەشانی ئینگلیزی وەشانی باوەڕپێکراوە.

چی دەکات

  • لە هەمان ساتی پرسیارکردنتاندا، لە ماڵپەڕ یان APIی خودی بڵاوکەرەوەدا بە دوای بڕیارەکانی دادگا و یاسا و ڕێساکاندا دەگەڕێت.
  • هەر ئەنجامێک ناوی سەرچاوەکەی دەبات و بەستەری بۆی هەیە، بۆ ئەوەی بتوانن دەقە ڕەسەنەکە بپشکنن.
  • Fontes هیچ بنکەدراوەیەک ناهێڵێتەوە و پێویستی بە هیچ هەژمارێک نییە. پرسیارەکانتان دەچن بۆ ئەو سەرچاوەیەی تێیدا دەگەڕێت؛ بۆ وەشانە پێشووەکانی یاساکان و بۆ 91 وڵاتی زیادە و یاسای هیندستان، دەچن بۆ خزمەتگوزاری گشتیی Lexifina، لەگەڵ ماڵپەڕی فەرمی یان لەجیاتی ئەو. بۆ کوژاندنەوەی ئەمە WLM_LEXIFINA=0 دابنێن. ژمارەکانی بەکارهێنان و ڕاپۆرتی هەڵەکان ئارەزوومەندانەن (opt-in).

Fontes ئامرازێکی یارمەتیدەری توێژینەوەیە، نەک ئامۆژگاریی یاسایی، و بەکارهێنانی پەیوەندیی پارێزەر و موەکیل دروست ناکات. «وەک خۆی» (as is)، بەبێ هیچ گەرەنتییەک پێشکەش دەکرێت (سەیری مۆڵەتی Apache 2.0 بکەن). هەندێک سەرچاوە بە ڕوونی کۆپیی نافەرمین، و هەر یەکێکیان مەرجی بەکارهێنانی خۆی هەیە؛ Fontes ئەمە لە وەڵامەکانیدا دەڵێت. پێش ئەوەی پشت بە بڕیارێک یان ماددەیەک ببەستن، دەقە تەواوەکەی بخوێننەوە. Fontes سەربەخۆیە و پەیوەندیی بە هیچ دادگا، حکومەت یان بڵاوکەرەوەیەکەوە نییە.

دامەزراندن

  • Claude Desktop: فایلی .mcpbی Fontes لە دوایین وەشان دابگرن، دوو جار کلیکی لەسەر بکەن، پاشان کلیک لەسەر Install بکەن.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor، VS Code، Gemini CLI، Zed، LM Studio، Cline و بەرنامەکانی تر: Fontes زیاد بکەن بۆ ڕێکخستنەکانی MCPی بەرنامەکە. زۆربەیان ئەم تۆمارە وەردەگرن؛ ڕێنماییی دامەزراندن فایل و پارچەکۆدی (snippet) هەر بەرنامەیەک دەدات.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx لەگەڵ uv دێت. لە macOS یان Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. لە Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

پاشان بەرنامەکە دووبارە دەست پێ بکەنەوە و بپرسن: «Fontes لە کام ناوچە دادوەرییەکاندا دەتوانێت بگەڕێت؟»

لەسەر Mac یان کۆمپیوتەری Windows، دامەزرێنەرێکی یەک-کلیک Fontes لە Claude Desktop، Codex، Claude Code، Cursor، VS Code، Windsurf، Gemini CLI، Zed، LM Studio و Cline ڕێکدەخات، لە هەر یەکێکیان کە لە کۆمپیوتەرەکەتاندا هەبێت، پاشان پێشنیاری زیادکردنی کلیلەکانتان دەکات. لە دوایین وەشان دایبگرن و پێش کارپێکردنی ئەو بەرنامانە دابخەن. وردەکاری: ڕێنماییی دامەزراندن. هەندێک سەرچاوە پێویستیان بە کلیلێکی (key) خۆڕایی هەیە: سەیری KEYS.md بکەن.

Fontes لە ژێر مۆڵەتی Apache 2.0 سەرچاوەکراوەیە. دەقە یاساییەکان لە ژێر مۆڵەتی هەر بڵاوکەرەوەیەکدا دەمێننەوە.

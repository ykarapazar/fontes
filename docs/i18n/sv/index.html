Rättspraxis och lagstiftning för din AI-app, läst direkt från domstolars och myndigheters webbplatser.

Beta · kostnadsfritt · öppen källkod · källorna kontrolleras dagligen

Fontes är en kostnadsfri MCP-server med öppen källkod. Den fungerar i alla appar som kan köra en lokal Model Context Protocol-server: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio med flera. Ställ en juridisk fråga med vanliga ord: din AI-app söker i domstolsavgöranden och lagstiftning direkt på myndigheters och domstolars webbplatser, i 125 jurisdiktioner och internationella domstolar, och länkar varje resultat till originalet. Den kan också visa en lag så som den gällde vid ett tidigare datum, och läsa lagstiftning från 91 fler länder, från Lexifinas register (inte den officiella utgivaren). Den är byggd för jurister och rättsvetenskapliga forskare, och för alla som vill läsa rätten vid källan.

Detta är en maskinstödd översättning. Den engelska versionen gäller.

Vad det gör

  • Söker i rättspraxis och lagstiftning i samma stund som du frågar, från utgivarens egen webbplats eller API.
  • Varje resultat anger sin källa och länkar till den, så att du kan kontrollera originalet.
  • Fontes har ingen databas och kräver inget konto. Dina frågor går till den källa som genomsöks; för tidigare versioner av lagar och för de 91 extra länderna (och Indiens lagar) går de till Lexifinas offentliga tjänst, antingen utöver eller i stället för den officiella webbplatsen. Ställ in WLM_LEXIFINA=0 för att stänga av det. Användningssiffror och felrapporter är opt-in.

Fontes är ett hjälpmedel för research, inte juridisk rådgivning, och att använda det skapar inte något klientförhållande med en advokat. Det tillhandahålls i befintligt skick, utan garanti (se licensen Apache 2.0). Vissa källor är uttryckligen inofficiella versioner, och var och en har sina egna användarvillkor; Fontes påpekar detta i sina svar. Läs hela avgörandet eller hela bestämmelsen innan du förlitar dig på det. Fontes är oberoende och inte knutet till någon domstol, myndighet eller utgivare.

Installation

  • Claude Desktop: ladda ned Fontes .mcpb-fil från den senaste versionen, dubbelklicka på den och klicka sedan på Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline och andra appar: lägg till Fontes i appens MCP-inställningar. De flesta tar den här posten; installationsguiden har filen och kodavsnittet för varje app.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx följer med uv. På macOS eller Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. På Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Starta sedan om appen och fråga: ”Vilka jurisdiktioner kan Fontes söka i?”

På en Mac eller Windows-dator konfigurerar ett installationsprogram med ett klick Fontes i Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio och Cline, i var och en som finns på din dator, och erbjuder sedan att lägga till dina nycklar. Ladda ner installationsprogrammet för din dator från den senaste versionen och avsluta de apparna innan du kör det. Detaljer i installationsguiden. Vissa källor kräver en kostnadsfri nyckel: se KEYS.md.

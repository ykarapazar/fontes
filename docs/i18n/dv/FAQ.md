> މިއީ މެޝިނުގެ އެހީގައި ތަރުޖަމާކޮށްފައިވާ ލިޔުމެކެވެ. ބާރުގަދަވާނީ އިނގިރޭސި ނުސްޚާއެވެ.

# Fontes: ސުވާލުތަކާއި ޖަވާބުތައް

## Fontes އަކީ ކޮބާ؟

ހިލޭ، އޯޕަން ސޯސް MCP ސަރވަރެކެވެ (Apache 2.0). މިއިން Model Context Protocol ބޭނުންކުރާ ކޮންމެ އެޕަކަށް (Claude،
Codex، Cursor، VS Code، Gemini CLI އަދި އެހެނިހެން) 120 އަށްވުރެ ގިނަ ޖުރިސްޑިކްޝަންތަކާއި ބައިނަލްއަޤްވާމީ ކޯޓުތަކުގެ
(124 އެޑެޕްޓަރ) ކޯޓުތަކާއި ސަރުކާރުތަކުގެ ވެބްސައިޓްތަކުން ކޯޓު ޙުކުމްތަކާއި ޤާނޫނުތައް ލައިވްކޮށް ސާޗްކުރުމުގެ ފުރުޞަތު
ލިބިދެއެވެ. ކޮންމެ ނަތީޖާއެއްގައި އޭގެ މަސްދަރުގެ ނަން ބަޔާންކޮށް، އަސްލަށް ލިންކްކުރެއެވެ.

## ލިޔުންތަކަކީ ރަސްމީ ލިޔުންތަކެއްތޯ؟

ގިނަގުނަ ފަހަރު އާނއެވެ، ނަމަވެސް އަބަދުއެއް ނޫނެވެ.

- ގިނަ މަސްދަރުތައް ހިންގަނީ ކޯޓަކުން، ވުޒާރާއަކުން ނުވަތަ ރަސްމީ ގެޒެޓަކުންނެވެ.
- ބައެއް އިޞްލާޙުތައް ގެނެވިފައިވާ (consolidated) ލިޔުންތައް ޝާއިޢުކުރަނީ ސަރުކާރަކުން ނަމަވެސް، އެއީ ސާފުކޮށް
  ބަޔާންކޮށްފައިވާ ގޮތުން ރަސްމީ ނޫން ލިޔުންތަކެވެ: ޞައްޙަވާނީ ހަމައެކަނި ރަސްމީ ގެޒެޓެވެ.
- މަދު މަސްދަރުތަކަކީ އަސްލުން ސަރުކާރުގެ ސައިޓްތަކެއް ނޫނެވެ (މިސާލަކަށް LexiVox، LawPhil، Maqam، Wikisource).

މިފަދަ މަސްދަރަކުން އަންނަ ކޮންމެ ޖަވާބަކަށް Fontes އިން "ރަސްމީ ނޫން މަސްދަރު" ނޯޓިސްއެއް އިތުރުކުރެއެވެ. އެއްވެސް
އެއްޗަކަށް ރިފަރކުރުމުގެ ކުރިން، ރަސްމީ ޝާއިޢުކުރުން ޗެކްކުރައްވާ. [README](README.md#ކަވަރޭޖް) ގައިވާ ކަވަރޭޖް
ތާވަލާއި `list_jurisdictions` އިން ކޮންމެ ޖުރިސްޑިކްޝަނެއްގެ މަސްދަރު ބަޔާންކުރެއެވެ.

## ހިމެނޭ ޖުރިސްޑިކްޝަންތަކަކީ ކޮބާ، އަދި ކިހާ ރަނގަޅަކަށް؟

124 އެޑެޕްޓަރ: ޔޫއެންގެ 108 މެމްބަރު ޤައުމު، ހޮންކޮންގް، ކޮސޮވޯ، ފަލަސްޠީނު،
ތައިވާން، DIFC ކޯޓުތައް، އަދި 11 ބައިނަލްއަޤްވާމީ ކޯޓާއި ޖަމާޢަތް (މިސާލަކަށް ޔޫރަޕިއަން ކޯޓް އޮފް ހިއުމަން ރައިޓްސް،
ޔޫރަޕިއަން ޔޫނިއަން، ICJ އަދި WTO).

ކަވަރޭޖް ވަރަށް ތަފާތުވެއެވެ. ހަރުކަށި ޤަވާއިދަކުން (އެންމެ މަތީ އާންމު ކޯޓުގެ ސާބިތު ޙުކުމްތައް (precedents)، ނުވަތަ ޤާނޫނުއަސާސީއާއި
އަސާސީ ޤާނޫނުތައް، މުޅިން ލިބުން)، 124 އިން 72 ހިމެނޭ ކަމަށް ބެލެވެއެވެ. [COVERAGE.md](../../COVERAGE.md) ގައި
ކޮންމެ ޖުރިސްޑިކްޝަނަކަށް، Fontes އަށް ލިބޭ ތަކެތި، ނުލިބޭ ތަކެތި، އަދި އޭގެ ސަބަބު ބަޔާންކުރެއެވެ.

## API ކީއެއް ބޭނުންވޭތޯ؟

ގާތްގަނޑަކަށް ހުރިހާ ޖުރިސްޑިކްޝަނަކަށް، ނުވޭ. ބައެއް މަސްދަރުތަކަށް ހިލޭ ކީއެއް ބޭނުންވެއެވެ: [KEYS.md](KEYS.md) ބައްލަވާ.

- **ފަރަންސޭސިވިލާތް:** އާނ. `WLM_FR_PISTE_CLIENT_ID` އާއި `WLM_FR_PISTE_CLIENT_SECRET` ސެޓްކުރައްވާނދެން
  ފަރަންސޭސިވިލާތް ބަންދެވެ. މިއީ Judilibre އާއި Légifrance އަށް ސަބްސްކްރައިބްކޮށްފައިވާ އެޕެއް ހުރި ހިލޭ PISTE
  އެކައުންޓަކުން (piste.gouv.fr) ލިބޭ ތަކެއްޗެވެ.
- **އެމެރިކާ:** އިޚްތިޔާރީ. ކީއަކާ ނުލައި ކޯޓު ޙުކުމްތަކުގައި ސާޗްކުރުން މަސައްކަތްކުރެއެވެ، ނަމަވެސް ހިއްސާކުރެވޭ ޑެމޯ
  ކީއިން ކޮންމެ IP އެޑްރެހަކަށް ދުވާލަކު ހުއްދަކުރަނީ ގާތްގަނޑަކަށް 10 ސާޗެވެ. `WLM_US_GOVINFO_KEY` ގައި ހިލޭ
  api.data.gov ކީއެއް ލުމުން އެ ހައްދު މައްޗަށް ދެއެވެ.

މިއީ ތިބާގެ އެޕުގެ MCP ސެޓިންގްސްގައި Fontes ސަރވަރަށް އެންވަޔަރަމަންޓް ވޭރިއަބަލްތަކެއްގެ ގޮތުގައި ސެޓްކުރައްވާ.
އިންސްޓޯލަރ ނެރުމުން، އިންސްޓޯލްކުރުމަށްފަހު އެ ސުވާލުކުރާނެއެވެ، އަދި އޭގެ **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން**
ލޯންޗަރުން ފަހުން އެ ބަދަލުކުރާނެއެވެ.

އޭގެ އިތުރުން، މަދު މަސްދަރުތަކެއްގެ ޝަރުޠުތަކުގައި ބުނެފައިވަނީ އޮޓޮމެޓިކް އެކްސެސްއަށް ޝާއިޢުކުރާ ފަރާތުގެ ހުއްދަ
ބޭނުންވާ ކަމަށެވެ. އެ މަސްދަރުތައް OFF ކަމަށް ފާހަގަކޮށް ބަންދުކޮށް ބަހައްޓައެވެ. ކީއަކުން އެކަން ބަދަލެއް ނުވެއެވެ؛ ބަދަލުވާނީ
ހަމައެކަނި ޝާއިޢުކުރާ ފަރާތުގެ ހުއްދައިންނެވެ (އޭރުން `WLM_PERMITTED=<codes>` ސެޓްކުރައްވާ).

## ތިމަންގެ ކޮމްޕިއުޓަރުން ބޭރަށް ދަނީ ކޮން ތަކެއްޗެއް؟

ތިބާގެ ސާޗްތައް ދަނީ ހަމައެކަނި ސާޗްކުރެވޭ މަސްދަރަށެވެ. Fontes ގައި އެއްވެސް ޑޭޓާބޭހެއް ނުބަހައްޓައެވެ، އަދި
އެކައުންޓެއްވެސް ނުބޭނުންވެއެވެ.

މަސްދަރުތަކަށް ފިޔަވައި، Fontes އިން ދުވާލަކު އެއްފަހަރު PyPI އިން އާ ވަރޝަނެއް ހުރިތޯ ސުވާލުކުރެއެވެ
(`FONTES_NO_UPDATE_CHECK=1` އިން ބަންދުކުރެވޭނެ). ބޭނުންކުރި އަދަދުތައް ތިބާ ހުޅުއްވައިފިނަމަ މެނުވީ ބަންދެވެ، އަދި ބަގް
ރިޕޯޓެއް ފޮނުވެނީ ތިބާއަށް އެ ފެނި ތިބާ ޔަޤީންކުރުމަށްފަހު ހަމައެކަނިއެވެ. ތިބާގެ AI އެޕަށް ތިބާގެ ވާހަކަ ފެނެނީ
އޭގެ އަމިއްލަ ޝަރުޠުތަކުގެ ދަށުންނެވެ.

ފުރިހަމަ ތަފްޞީލު: [PRIVACY.md](PRIVACY.md).

## މިއީ ޤާނޫނީ ލަފައެއްތޯ؟

ނޫން. Fontes އަކީ ދިރާސާ ޓޫލެކެވެ. މިއިން ލިޔުންތައް ހޯދައިދެއެވެ؛ ތިބާގެ މައްސަލައަށް އެ ލިޔުންތަކުގެ މާނައަކީ ކޮބައިކަން
ނުބުނެއެވެ، އަދި މިއީ ބޭނުންކުރުމުން އެއްވެސް މީހަކާ ވަކީލާއި ކްލަޔަންޓުގެ ގުޅުމެއް ނުއުފެދެއެވެ. AI އެޕަށް ލިޔުމެއް ގޯހަށް
ކިޔިދާނެއެވެ، އެހެންކަމުން ބަރޯސާވުމުގެ ކުރިން ފުރިހަމަ ޙުކުމް ނުވަތަ މާއްދާ ކިޔުއްވާ. ލަފައަށްޓަކައި، ތިބާގެ ސުވާލު
އުފެދޭ ތަނުގައި ޤާބިލުކަން ލިބިފައިވާ ވަކީލަކާ ސުވާލުކުރައްވާ.

## މިއީ ބަލަހައްޓަނީ ކާކު؟ ކުރިއަށް މަސައްކަތްކުރާނެތޯ؟

އެއް މީހެއް: Yüce Karapazar. Fontes ގެ ފަހަތުގައި އެއްވެސް ކުންފުންޏެއް، ސަޕޯޓް ކޮންޓްރެކްޓެއް، ނުވަތަ ޚިދުމަތުގެ
މިންވަރުގެ ވައުދެއް ނެތެވެ. އެއްވެސް ޤާނޫނީ ޚިދުމަތެއް ހުށަނާޅައެވެ.

މަސްދަރުތައް ދުވާލަކު އެއްފަހަރު ޗެކްކޮށް، ނަތީޖާތައް [ހާލަތުގެ ޞަފްޙާ](https://ykarapazar.github.io/fontes/status/?lang=dv)
ގައި ޝާއިޢުކުރެއެވެ. ކޯޓުތަކާއި ސަރުކާރުތަކުގެ ވެބްސައިޓްތައް ނޯޓިހަކާ ނުލައި ބަދަލުވާތީ، ކޮންމެ ވަގުތެއްގައިވެސް
މަސްދަރެއް ހަލާކުވެދާނެއެވެ. އެއްވެސް މަސްދަރެއް، ނުވަތަ Fontes އަމިއްލައަށް، ކުރިއަށް މަސައްކަތްކުރާނެ ކަމުގެ ޔަޤީންކަމެއް
ނެތެވެ. Fontes ދެނީ "as is"، ވޮރަންޓީއަކާ ނުލައެވެ ([LICENSE](../../../LICENSE) ގެ 7 އަދި 8 ވަނަ ސެކްޝަން).

## ލިޔުމެއް ގޯސް، ޒަމާނުއްވީ، ނުވަތަ މަސްދަރެއް ހަލާކުވެފައި. އެކަން ރިޕޯޓްކުރާނީ ކިހިނެއް؟

- "Broken or wrong source" ފޯމުން issue އެއް ހުޅުއްވާ:
  <https://github.com/ykarapazar/fontes/issues/new/choose>. ކޮން ޖުރިސްޑިކްޝަނެއް، ތިބާ ސުވާލުކުރެއްވީ ކީކޭ، ލިބުނީ
  ކީކޭ، އަދި ރަނގަޅު ލިޔުން ދައްކާ ރަސްމީ ޞަފްޙާ ބަޔާންކުރައްވާ.
- ނުވަތަ ތިބާގެ AI އެޕާ "Fontes ބަގެއް ރިޕޯޓްކުރުމަށް" އެދިވަޑައިގަންނަވާ (ނުވަތަ `fontes report-bug` ރަންކުރައްވާ).
  އެއްވެސް އެއްޗެއް ފޮނުވުމުގެ ކުރިން ރިޕޯޓް ތިބާއަށް ފެންނާނެއެވެ.
- ނުވަތަ fontesmcp@proton.me އަށް އީމެއިލްކުރައްވާ.

ރިޕޯޓެއްގައި ކްލަޔަންޓުގެ ތަފްޞީލު ނުވަތަ ސިއްރު ޙަޤީޤަތްތައް ނުހިމަނުއްވާ.

**މި މަސްދަރުތަކުން އެއް މަސްދަރެއް ތިބާ ހިންގަވާނަމަ** އަދި އެއްވެސް ކަމެއް ގޯސްނަމަ (ތިބާގެ ޝަރުޠުތައް، ތިބާގެ
robots.txt، ތިބާގެ ރޭޓް ލިމިޓްތައް)، fontesmcp@proton.me އަށް އީމެއިލްކުރައްވާ. މަސްދަރު ރަނގަޅުކުރެވޭނެ ނުވަތަ ބަންދުކުރެވޭނެއެވެ.

## ހޯސްޓްކުރެވިފައިވާ ޤާނޫނީ ދިރާސާ ޓޫލްތަކާ Fontes ތަފާތަކީ ކިހިނެއް؟

- **މިއީ ރަންވަނީ ތިބާގެ ކޮމްޕިއުޓަރުގައެވެ.** Fontes ސަރވަރެއް ނުވަތަ އެކައުންޓެއް ނެތެވެ. އޭގެ މާނައަކީ، މިއީ މަސައްކަތްކުރާނީ
  ލޯކަލް MCP ސަރވަރެއް ފެށޭ އެޕްތަކުގައި (Claude Desktop، Codex، Cursor، VS Code އަދި އެފަދަ) ހަމައެކަނި ކަމަށެވެ،
  ހަމައެކަނި ހޯސްޓްކުރެވިފައިވާ ކަނެކްޓަރުތައް ބަލައިގަންނަ، ހަމައެކަނި ވެބްގައިވާ އެޕްތަކުގައެއް ނޫނެވެ.
- **މިއީގައި ޑޭޓާބޭހެއް ނެތެވެ.** ކޮންމެ ސާޗެއް ލައިވްކޮށް ދަނީ ޝާއިޢުކުރާ ފަރާތުގެ އަމިއްލަ ވެބްސައިޓް ނުވަތަ API އަށެވެ،
  އެހެންކަމުން ނަތީޖާތައް މަސްދަރު ފަދައިން އާ ވާނެއެވެ، އަދި ސާޗުގެ ފެންވަރަކީ މަސްދަރުގެ އަމިއްލަ ފެންވަރެވެ. ތައްޔާރުކޮށްފައިވާ
  އިންޑެކްސެއްގައި ސެމަންޓިކް ސާޗެއް ނެތެވެ.
- **މިއިން ބޭނުންކުރުމުގެ ހައްދެއް ނުކަނޑައަޅައެވެ.** Fontes ގައި މަހަކަށް ކޯލްކުރުމުގެ ހައްދެއް ނެތެވެ. ކޮންމެ ވެބްސައިޓަކަށް
  ފޮނުވާ ރިކުއެސްޓްތަކުގެ މެދުގައި ވަގުތު ދޫކުރެއެވެ، އަދި ބައެއް މަސްދަރުތަކުން ސުވާލުކުރެވޭ ބާރުމިނާއި ފަހަރުތަކުގެ ހައްދު
  ކަނޑައަޅައެވެ.
- **މިއީ އޯޕަން ސޯސްއެވެ.** ކޮންމެ އެޑެޕްޓަރެއް ކިޔައި، ކޮންމެ ލިޔުމެއް އަންނަ ތަން ޞައްޙަކޮށް ބެލޭނެއެވެ.
- **މިއީގެ ފަހަތުގައި ވިއްކާ ފަރާތެއް ނެތެވެ.** ކޮންޓްރެކްޓެއް، ސަޕޯޓް ޑެސްކެއް ނުވަތަ އަޕްޓައިމްގެ ވައުދެއް ނެތެވެ
  ("މިއީ ބަލަހައްޓަނީ ކާކު؟" ބައްލަވާ).

## މިއީ މަސައްކަތްކުރާ އެޕްތަކާއި ސިސްޓަމްތަކަކީ ކޮބާ؟

ލޯކަލް (stdio) ސަރވަރެއް ރަންކުރެވޭ ކޮންމެ MCP އެޕެއް، މިސާލަކަށް Claude Desktop، Claude Code، Codex، Cursor،
VS Code (GitHub Copilot)، Gemini CLI، Windsurf، Zed، LM Studio އަދި Cline. Fontes ރަންވަނީ macOS، Windows އަދި
Linux ގައި، uv ރަންވާ ކޮންމެ ތަނެއްގައެވެ (Python 3.13+). Mac އާއި Windows އަށް އެއް ކްލިކުން އިންސްޓޯލްކުރާ އިންސްޓޯލަރެއް
އަންނަމުންދަނީއެވެ. އެއިން Claude Desktop، Codex، Claude Code، Cursor، VS Code، Windsurf، Gemini CLI، Zed،
LM Studio އަދި Cline އެއްފަހަރާ ސެޓަޕްކުރާނެއެވެ. ކޮންމެ އެޕަކަށް ފިޔަވަޅުތައް: [INSTALL.md](INSTALL.md).

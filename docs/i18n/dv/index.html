މިއިން ކުރާ ކަންތައްތައް

  • ތިބާ ސުވާލުކުރާ ވަގުތު، ޝާއިޢުކުރާ ފަރާތުގެ އަމިއްލަ ވެބްސައިޓް ނުވަތަ API އިން ކޯޓު ޙުކުމްތަކާއި ޤާނޫނުތަކުގައި ސާޗްކުރެއެވެ.
  • ކޮންމެ ނަތީޖާއެއްގައި އޭގެ މަސްދަރުގެ ނަން ބަޔާންކޮށް އެއަށް ލިންކްކުރެއެވެ، ތިބާއަށް އަސްލު ޗެކްކުރެވޭނެ ގޮތަށެވެ.
  • Fontes ގައި އެއްވެސް ޑޭޓާބޭހެއް ނުބަހައްޓައެވެ، އަދި އެކައުންޓެއްވެސް ނުބޭނުންވެއެވެ. ތިބާގެ ސުވާލުތައް ދަނީ ސާޗްކުރެވޭ މަސްދަރަށެވެ؛ ޤާނޫނުތަކުގެ ކުރީގެ ނުސްޚާތަކާއި 91 އިތުރު ޤައުމުތަކާއި ހިންދު ޤާނޫނުތަކަށް ނަމަ، ދަނީ Lexifina ގެ ޕަބްލިކް ސާވިސަށެވެ، ރަސްމީ ސައިޓާއެކު ނުވަތަ ރަސްމީ ސައިޓުގެ ބަދަލުގައި. އެކަން ނިއްވުމަށް WLM_LEXIFINA=0 ސެޓްކުރައްވާ. ބޭނުންކުރި އަދަދުތަކާއި ބަގް ރިޕޯޓްތައް ހަމައެކަނި އޮޕްޓް-އިން އެވެ.

Fontes އަކީ ދިރާސާއަށް އެހީތެރިވާ ޓޫލެކެވެ، ޤާނޫނީ ލަފައެއް ނޫނެވެ، އަދި މިއީ ބޭނުންކުރުމުން ވަކީލާއި ކްލަޔަންޓުގެ ގުޅުމެއް ނުއުފެދެއެވެ. މިއީ ދެނީ "as is"، ވޮރަންޓީއަކާ ނުލައެވެ (Apache 2.0 ލައިސަންސް ބައްލަވާ). ބައެއް މަސްދަރުތަކަކީ ސާފުކޮށް ބަޔާންކޮށްފައިވާ ގޮތުން ރަސްމީ ނޫން ނުސްޚާތަކެވެ، އަދި ކޮންމެ މަސްދަރެއްގެ އަމިއްލަ ޝަރުޠުތަކެއް ހުރެއެވެ؛ Fontes އިން އޭގެ ޖަވާބުތަކުގައި އެކަން ފާހަގަކުރެއެވެ. ބަރޯސާވުމުގެ ކުރިން ފުރިހަމަ ޙުކުމް ނުވަތަ މާއްދާ ކިޔުއްވާ.

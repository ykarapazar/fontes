> މިއީ މެޝިނުގެ އެހީގައި ތަރުޖަމާކޮށްފައިވާ ލިޔުމެކެވެ. ބާރުގަދަވާނީ އިނގިރޭސި ނުސްޚާއެވެ.

# Fontes އިންސްޓޯލްކުރުން

Fontes އިން ތިބާގެ AI އެޕަށް 120 އަށްވުރެ ގިނަ ޖުރިސްޑިކްޝަންތަކުގެ ކޯޓުތަކާއި ސަރުކާރުތަކުގެ ވެބްސައިޓްތަކުން
ކޯޓު ޙުކުމްތަކާއި ޤާނޫނުތައް ލައިވްކޮށް ހޯދުމުގެ ފުރުޞަތު ލިބިދެއެވެ. ކޮންމެ ނަތީޖާއެއްގައި އަސްލަށް ލިންކެއް ހުންނާނެއެވެ.
މިއީ ސްޓޭންޑަޑް MCP ސަރވަރެއް ކަމުން، ލޯކަލް MCP ސަރވަރެއް ރަންކުރެވޭ ކޮންމެ އެޕެއްގައި މަސައްކަތްކުރެއެވެ: Claude
Desktop، Codex، Claude Code، Cursor، VS Code (GitHub Copilot)، Gemini CLI، Windsurf، Zed، LM Studio، Cline
އަދި އެހެނިހެން.

ތިބާގެ އެޕް ހޮވައި، އޭގެ ފިޔަވަޅުތަކަށް ތަބާވެ، ދެން [މަސައްކަތްކުރާތޯ ޗެކްކުރައްވާ](#މަސައްކަތްކުރާތޯ-ޗެކްކުރުން).

## Claude Desktop

1. Fontes ގެ `.mcpb` ފައިލު [އެންމެ ފަހުގެ ރިލީސް](https://github.com/ykarapazar/fontes/releases/latest)
   އިން ޑައުންލޯޑްކުރައްވާ.
2. އޭގެ މަތީގައި ޑަބަލް-ކްލިކްކުރައްވާ. Claude Desktop އިން އެ ހުޅުވާނެއެވެ.
3. **Install** އަށް ކްލިކްކުރައްވާ.

## Codex

ޓާމިނަލެއްގައި:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI އާއި Codex IDE އެކްސްޓެންޝަން މި ސެޓިންގް (`~/.codex/config.toml`) ހިއްސާކުރެއެވެ.
[uv](#uv-ބޭނުންވާނެ) ބޭނުންވާނެއެވެ.

## Claude Code

ޓާމިނަލެއްގައި:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

[uv](#uv-ބޭނުންވާނެ) ބޭނުންވާނެއެވެ.

## އެހެން އެޕްތައް

މިއިން ކޮންމެ އެޕަކަށް [uv](#uv-ބޭނުންވާނެ) ބޭނުންވެއެވެ. އެންޓްރީ އިތުރުކޮށް، ސޭވްކޮށް، ދެން އެޕް ނިއްމާލައްވާފައި
އަލުން ހުޅުއްވާ.

**Cursor:** `~/.cursor/mcp.json` (ހުރިހާ ޕްރޮޖެކްޓަކަށް) ނުވަތަ `.cursor/mcp.json` (އެއް ޕްރޮޖެކްޓަކަށް) ގައި:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette އިން **MCP: Add Server** ރަންކޮށް، **Command (stdio)** ހޮވައި،
`uvx fontes-mcp` ޖައްސަވައި، ސަރވަރަށް `fontes` ކަމަށް ނަން ދެއްވާ. ނުވަތަ މިއީ `~/.copilot/mcp-config.json` އަށް
އިތުރުކުރައްވާ:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code ގެ ކުރީގެ ސެޓަޕްތަކުގައި ބޭނުންކުރަނީ `.vscode/mcp.json` އެވެ، އެތަނުގައި އެންމެ މަތީ ކީއަކީ `mcpServers` ގެ
ބަދަލުގައި `servers` އެވެ.

**Gemini CLI:** ޓާމިނަލެއްގައި، `gemini mcp add -s user fontes uvx fontes-mcp`. ނުވަތަ މިއީ
`~/.gemini/settings.json` އަށް އިތުރުކުރައްވާ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** ސެޓިންގްސް ފައިލު ހުޅުވައި (**zed: open settings file**) މިއީ އިތުރުކުރައްވާ:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** ކަނާތްފަރާތު ސައިޑްބާގައި **Program** ޓެބް ހުޅުވައި، **Install → Edit mcp.json** އަށް
ކްލިކްކޮށް، މިއީ އިތުރުކުރައްވާ:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** އައިކަނަށް ކްލިކްކޮށް، **Configure** ޓެބް ހުޅުވައި، **Configure MCP Servers** އަށް
ކްލިކްކޮށް، LM Studio އަށް އިތުރުކުރި ހަމަ އެ `mcpServers` އެންޓްރީ އިތުރުކުރައްވާ.

**Claude Desktop، އަތުން** (`.mcpb` ފައިލުގެ ބަދަލުގައި): ހަމަ އެ `mcpServers` އެންޓްރީ
`claude_desktop_config.json` އަށް އިތުރުކުރައްވާ (macOS: `~/Library/Application Support/Claude/`، Windows:
`%APPDATA%\Claude\`).

**އެހެން ކޮންމެ MCP އެޕެއް** (Windsurf އަދި އެހެނިހެން): އޭގެ MCP ސަރވަރުތައް ބަހައްޓާ ތަން އޭގެ އަމިއްލަ
ޑޮކިއުމެންޓޭޝަނުގައި ބަޔާންކޮށްފައި ހުރެއެވެ. ގިނަ އެޕްތަކުން ބަލައިގަންނަނީ ހަމަ އެ އެންޓްރީއެވެ: ކޮމާންޑް `uvx`،
އާގިއުމަންޓް `fontes-mcp`.

އެޕަށް `uvx` ނުފެނިއްޖެނަމަ، އޭގެ ފުރިހަމަ ޕާތު ބޭނުންކުރައްވާ (macOS އާއި Linux ގައި `which uvx` އިން އެ ދައްކައެވެ).

## uv ބޭނުންވާނެ

Codex، Claude Code އަދި އެހެން އެޕްތަކުން Fontes ފަށައިދެނީ `uvx` އިންނެވެ. އެ ލިބެނީ Astral ގެ ކުދި ހިލޭ
ޓޫލެއް ކަމަށްވާ **uv** އާއެކުގައެވެ. އެ އިންސްޓޯލްކުރުމަށް
[Astral ގެ ގައިޑް](https://docs.astral.sh/uv/getting-started/installation/) ބައްލަވާ، ނުވަތަ ރަންކުރައްވާ:

- macOS ނުވަތަ Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## ކީތައް

ބައެއް މަސްދަރުތަކަށް ހިލޭ ކީއެއް ބޭނުންވެއެވެ: [KEYS.md](KEYS.md) ބައްލަވާ.

## މަސައްކަތްކުރާތޯ ޗެކްކުރުން

އާ ޗެޓެއްގައި ސުވާލުކުރައްވާ: *"Fontes އަށް ސާޗްކުރެވޭނީ ކޮން ޖުރިސްޑިކްޝަންތަކެއްގައި؟"* އެޕުން ޖަވާބު ދޭންވާނީ
ޤައުމުތަކުގެ ލިސްޓަކުންނެވެ. ނުދީފިނަމަ، އެޕް އަނެއްކާވެސް ނިއްމާލައްވާފައި އަލުން ހުޅުއްވާ.

## އެއް ކްލިކުން އިންސްޓޯލްކުރާ އިންސްޓޯލަރ (Mac އާއި Windows)

އިންސްޓޯލަރުން ތިބާގެ ހުރިހާ އެޕެއްގައި Fontes އެއްފަހަރާ ސެޓަޕްކުރެއެވެ: Claude Desktop، Codex، Claude Code،
Cursor، VS Code (GitHub Copilot)، Windsurf، Gemini CLI، Zed، LM Studio އަދި Cline.

**ފެށުމުގެ ކުރިން:** މި ކޮންމެ އެޕެއް މުޅިން ނިއްމާލައްވާ. މިކަން އެންމެ މުހިންމީ Claude Code އަށެވެ: އެ ރަންވަމުންދާއިރު
`~/.claude.json` އަލުން ލިޔެ، އިންސްޓޯލަރުގެ ބަދަލު ފޮހެލެވިދާނެއެވެ. Claude Code ނިއްމާލެވޭކަށް ނެތްނަމަ، އޭގެ ބަދަލުގައި
`claude mcp add` އިން Fontes އެއަށް އިތުރުކުރައްވާ ([Claude Code](#claude-code) ބައްލަވާ).

**Mac**

1. Mac އިންސްޓޯލަރ (`Fontes-Installer-…-mac.zip`) [އެންމެ ފަހުގެ ރިލީސް](https://github.com/ykarapazar/fontes/releases/latest)
   އިން ޑައުންލޯޑްކޮށް، އަންޒިޕްކުރުމަށް އޭގެ މަތީގައި ޑަބަލް-ކްލިކްކުރައްވާ.
2. **Fontes Installer** ގެ މަތީގައި ޑަބަލް-ކްލިކްކުރައްވާ. އިންޓަނެޓުން ޑައުންލޯޑްކުރި އެޕެއް ހުޅުވާނީތޯ ތިބާގެ Mac
   އިން ސުވާލުކޮށްފިނަމަ، **Open** އަށް ކްލިކްކުރައްވާ.
3. **އިންސްޓޯލް** ހޮވައި **OK** އަށް ކްލިކްކުރައްވާ. ސެޓަޕްކުރުމަށް ގާތްގަނޑަކަށް އެއް މިނެޓު ނަގައެވެ.
4. ސެޓަޕްކުރި އެޕްތަކުގެ ލިސްޓު މެސެޖަކުން ދައްކާނެއެވެ. **ނިމުނީ** އަށް ކްލިކްކޮށް، ދެން އެ އެޕްތައް އަލުން ހުޅުއްވާ.
   ފުރަތަމަ އިޚްތިޔާރީ ހިލޭ ކީތައް އިތުރުކުރުމަށް، އޭގެ ބަދަލުގައި **ކީތައް އިތުރުކުރުން** އަށް ކްލިކްކުރައްވާ؛
   [ކީތަކުގެ ފިޔަވަޅު](#ކީތަކުގެ-ފިޔަވަޅު) ބައްލަވާ.

**Windows**

1. Windows އިންސްޓޯލަރ (`Fontes-Setup-….exe`) [އެންމެ ފަހުގެ ރިލީސް](https://github.com/ykarapazar/fontes/releases/latest)
   އިން ޑައުންލޯޑްކޮށް، އޭގެ މަތީގައި ޑަބަލް-ކްލިކްކުރައްވާ.
   - Windows އިން "Windows protected your PC" ދައްކައިފިނަމަ: **More info** އަށް ކްލިކްކޮށް، ދެން **Run anyway** އަށް ކްލިކްކުރައްވާ.
2. **އިންސްޓޯލް** އަށް ކްލިކްކުރައްވާ. ވިންޑޯއެއް ހުޅުވިގެން Fontes ސެޓަޕްކުރެއެވެ.
3. ނަން ނުފާހަގަކޮށް ބޭނުންކުރި އަދަދުތައް ފޮނުވާނީތޯ ސުވާލުކުރުމުން، ނޫން ކަމަށް Enter ފިއްތަވާ.
4. ކީތައް މިހާރު އިތުރުކުރާނީތޯ ސުވާލުކުރާނެއެވެ. ސްކިޕްކުރުމަށް Enter ފިއްތަވާ؛ [ކީތަކުގެ ފިޔަވަޅު](#ކީތަކުގެ-ފިޔަވަޅު) ބައްލަވާ.
5. **ނިމުނީ** ކަމަށް ބުނުމުން، ތިބާގެ AI އެޕްތައް އަލުން ހުޅުއްވާ. އެއްވެސް އެޕެއް އަދިވެސް ރަންވަމުން ދިޔައީނަމަ،
   އެ މުޅިން ބަންދުކޮށް (ގަޑީގެ ކައިރީގައިވާ ސިސްޓަމް ޓްރޭއިންވެސް) އަލުން ހުޅުއްވާ.

ނިމުމުގައި، އިންސްޓޯލަރ ސެޓަޕްކުރި އެޕްތަކުގެ ލިސްޓު ދައްކާނެއެވެ.

### ސެޓަޕްކުރާ އެޕްތައް

އެޕެއް ސެޓަޕްކުރަނީ އެ އެޕުގެ ސެޓިންގްސް ފޯލްޑަރު ތިބާގެ ކޮމްޕިއުޓަރުގައި ކުރިން ހުރިނަމަ ހަމައެކަނިއެވެ. Claude Code
ސެޓަޕްކުރަނީ `~/.claude.json` ހުރިނަމަ ހަމައެކަނިއެވެ. Claude Desktop އަބަދުވެސް ސެޓަޕްކުރެއެވެ. ކޮންމެ އެޕަކަށް
މި ފައިލުގައި `fontes` ކަމަށް އެއް އެންޓްރީ ލިބެއެވެ:

| އެޕް | ފައިލު (Mac އާއި Linux) | ފައިލު (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`، އަދި Microsoft Store ވަރޝަނުގެ އަމިއްލަ ކޮޕީ |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`، ނުވަތަ ކުރީގެ ވަރޝަންތަކުގައި `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json`، ނުވަތަ `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |

VS Code ސެޓަޕްކުރަނީ `~/.copilot` ނުވަތަ VS Code ގެ އަމިއްލަ ސެޓިންގްސް ފޯލްޑަރު ހުރިނަމައެވެ.

ދެ އެޕަކަށް އިތުރު އެއް ފިޔަވަޅެއް ބޭނުންވެއެވެ:

- **Windsurf:** އެ އަލުން ހުޅުވުމަށްފަހު، Cascade ގައި ރިފްރެޝް ފިއްތަވާ.
- **ކުރީގެ VS Code އެކްސްޓެންޝަންގެ ތެރޭގައިވާ Cline:** Fontes އަތުން އިތުރުކުރައްވާ ([Cline](#އެހެން-އެޕްތައް) ބައްލަވާ).

### ކީތަކުގެ ފިޔަވަޅު

އިންސްޓޯލްކުރި ވަގުތުން، ފަރަންސޭސިވިލާތާއި އެމެރިކާގެ ހިލޭ ކީތައް އިތުރުކުރަން އިންސްޓޯލަރ ހުށަހަޅައެވެ. ފަހުން އެ
އިތުރުކުރުމަށް ނުވަތަ ބަދަލުކުރުމަށް:

- **Mac:** **Fontes Installer** އަލުން ހުޅުވައި **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ހޮއްވަވާ.
- **Windows:** Start މެނޫ ހުޅުވާ، ދެން **Fontes** → **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ހޮއްވަވާ.

ޓައިޕްކުރާ އެއްޗެއް ފެނުން ފޮރުވިފައި ހުންނާނެއެވެ. ކީތައް ވަދެނީ ކުރިން Fontes ހުރި ކޮންމެ އެޕަކަށެވެ. އޭގެފަހުން
އެޕްތައް ނިއްމާލައްވާފައި އަލުން ހުޅުއްވާ. ކީތައް ލިބޭ ތަނާއި އެއިން ހުޅުވާ ތަކެތި: [KEYS.md](KEYS.md).

### ބެކަޕްތައް، އަލުން ރަންކުރުން އަދި ނައްތާލުން

އިންސްޓޯލަރުން ބަދަލުކުރަނީ ހަމައެކަނި `fontes` އެންޓްރީއެވެ. އެހެން ކޮންމެ ސެޓިންގަކާއި ކޮމެންޓެއް ހުރި ގޮތަށް
ހުންނާނެއެވެ. ފައިލެއް ބަދަލުކުރުމުގެ ކުރިން، އޭގެ ކައިރީގައި `<file>.fontes-backup-<date>` ކަމަށް ނަންދީފައިވާ ކޮޕީއެއް
ސޭވްކުރެއެވެ. ތިބާ ކީތައް އިތުރުކުރުމަށްފަހު ހެދޭ ކޮޕީތަކުގައި އެ ކީތައް ހުންނާނެއެވެ: ތިބާއަށް ބޭނުން ނުވާ ކޮޕީތައް
ފޮހެލައްވާ. އޭގެ އިތުރުން uv ވެސް އިންސްޓޯލްކުރެއެވެ. އަލުން ރަންކުރުމަކީ ރައްކާތެރި ކަމެކެވެ: އެއިން ސެޓަޕް
ރިޕެއާކޮށް، އެހެން އެއްވެސް އެއްޗެއް ބަދަލު ނުކުރެއެވެ.

Fontes ނައްތާލުމަށް، **Fontes Installer** ހުޅުވައި **ނައްތާލާ** ހޮއްވަވާ (Mac)، ނުވަތަ Settings → Apps ގައި **Fontes** ނައްތާލައްވާ (Windows). އެއިން ކޮންމެ އެޕަކުން `fontes` އެންޓްރީ، ކީތައް ހިމެނޭ ގޮތަށް، ނައްތާލައެވެ. ތިބާގެ އެހެން
ސެޓިންގްސްއާއި ބެކަޕް ކޮޕީތައް ހުންނާނެއެވެ.

## އަޕްޑޭޓްތައް

- **އިންސްޓޯލަރާއި `.mcpb` ފައިލު:** ތިބާ އެއްވެސް ކަމެއް ކުރައްވަން ނުޖެހެއެވެ. ދުވާލަކު އެއްފަހަރު، އެޕް ފެށޭއިރު،
  Fontes އިން ފަސްބިމުގައި އާ ވަރޝަނެއް ހުރިތޯ ޗެކްކޮށް އެ ތައްޔާރުކުރެއެވެ؛ އޭގެ ފަހުން އެޕް ފެށޭއިރު އެ ބޭނުންކުރެއެވެ.
  އަޕްޑޭޓެއް ޑައުންލޯޑް ނުކުރެވިއްޖެނަމަ ނުވަތަ މަސައްކަތް ނުކުރިއްޔާ، Fontes އިން މަސައްކަތްކުރި ވަރޝަން ބޭނުންކުރުން
  ކުރިއަށް ގެންދާނެއެވެ.
- **`uvx`:** އާ ވަރޝަނެއް ލިބެން ހުރިއިރު، Fontes އިން އޭގެ ޖުރިސްޑިކްޝަންތަކުގެ ލިސްޓުގެ މަތީގައި ތިބާއަށް
  އަންގާނެއެވެ. އަބަދުވެސް އެންމެ އާ ވަރޝަން ރަންކުރުމަށް، `fontes-mcp` ގެ ބަދަލުގައި `fontes-mcp@latest` ބޭނުންކުރައްވާ.

މިކަމަށްޓަކައި ތިބާއާ ނުވަތަ ތިބާގެ ސާޗްތަކާ ބެހޭ އެއްވެސް މަޢުލޫމާތެއް އެއްވެސް ތަނަކަށް ނުފޮނުވެއެވެ.

## ޕްރައިވެސީ

ޑިފޯލްޓުގައި Fontes އިން ތިބާއާ ނުވަތަ ތިބާގެ ސާޗްތަކާ ބެހޭ އެއްވެސް އެއްޗެއް ނުފޮނުވައެވެ. ބޭނުންކުރި އަދަދުތަކަކީ
އޮޕްޓް-އިން އެއްޗެކެވެ، އަދި ބަގް ރިޕޯޓެއް ފޮނުވެނީ ތިބާއަށް އެ ފެނި ތިބާ ޔަޤީންކުރުމުން ހަމައެކަނިއެވެ. ތަފްޞީލު:
[PRIVACY.md](PRIVACY.md).

## ނައްތާލުން

ތިބާގެ އެޕުގެ MCP ސެޓިންގްސްއިން `fontes` އެންޓްރީ ނައްތާލައްވާ (Claude Code ގައި:
`claude mcp remove fontes`)، ދެން އެޕް ނިއްމާލައްވާފައި އަލުން ހުޅުއްވާ.

## އެނގިހުރުން ރަނގަޅު ކަންތައްތައް

Fontes އިން ކިޔަނީ އާންމު މަސްދަރުތަކެވެ، ގިނަގުނަ ކޯޓުތަކާއި ސަރުކާރުތަކުގެ ވެބްސައިޓްތަކެވެ. ރަސްމީ ނޫން މަސްދަރުތައް
އޭގެ ޖަވާބުތަކުގައި ފާހަގަކުރެއެވެ. ޙުކުމަކަށް ނުވަތަ މާއްދާއަކަށް ބަރޯސާވުމުގެ ކުރިން އަބަދުވެސް މަސްދަރުގެ ލިންކް ހުޅުއްވާ.

އެއްވެސް ކަމެއް ގޯސްވެއްޖެނަމަ، ތިބާ ކުރެއްވި ކަމާއި ފެނުނު އެރަރ fontesmcp@proton.me އަށް އީމެއިލްކުރައްވާ.

## ބަރޯސާވުމުގެ ކުރިން

- Fontes އަކީ ދިރާސާ ޓޫލެކެވެ، ޤާނޫނީ ލަފައެއް ނޫނެވެ. މިއީ ބޭނުންކުރުމުން އެއްވެސް މީހަކު ތިބާގެ ވަކީލަކަށް ނުވެއެވެ.
- މިއީ ދެނީ "as is"، އެއްވެސް ވޮރަންޓީއަކާ ނުލައެވެ، އަދި ޤާނޫނު ހުއްދަކުރާ މިންވަރަށް، މިއީ ބޭނުންކުރާ ގޮތަށް
  އޭގެ ލިޔުންތެރިން ޒިންމާއެއް ނުނަގައެވެ. ފުރިހަމަ ޝަރުޠުތައް ހުރީ [ލައިސަންސް](../../../LICENSE) (Apache 2.0) ގައެވެ.

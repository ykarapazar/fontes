> މިއީ މެޝިނުގެ އެހީގައި ތަރުޖަމާކޮށްފައިވާ ލިޔުމެކެވެ. ބާރުގަދަވާނީ އިނގިރޭސި ނުސްޚާއެވެ.

# API ކީތައް

Fontes ގެ ގާތްގަނޑަކަށް ކޮންމެ މަސްދަރެއް ކީއަކާ ނުލައި މަސައްކަތްކުރެއެވެ. ދެ މަސްދަރަކަށް ހިލޭ ކީއެއް ބޭނުންވެއެވެ:

| ކީ | ހުޅުވާ ތަކެތި | އެ ނެތި |
|---|---|---|
| `WLM_FR_PISTE_CLIENT_ID` + `WLM_FR_PISTE_CLIENT_SECRET` | ފަރަންސޭސިވިލާތް: Judilibre (ކޯޓު ޙުކުމްތައް) އަދި Légifrance (ޤާނޫނުތައް) | ފަރަންސޭސިވިލާތް ބަންދު. `list_jurisdictions` ގައި އެ ދައްކަނީ ހަރަކާތްތެރި ނޫން ކަމަށެވެ. |
| `WLM_US_GOVINFO_KEY` | އެމެރިކާ: govinfo ސާޗް (ފެޑެރަލް ކޯޓުތަކުގެ ޙުކުމްތައް، Statutes at Large، public laws) | Fontes އިން ހިއްސާކުރެވޭ `DEMO_KEY` ބޭނުންކުރެއެވެ: ކޮންމެ IP އެޑްރެހަކަށް ދުވާލަކު ގާތްގަނޑަކަށް 10 ސާޗް. އެނގިފައިވާ ޙުކުމެއް ހުޅުވުމަށާއި US Code އަށް ކީއެއް ނުބޭނުންވެއެވެ. |

ކީތަކަކީ އިޚްތިޔާރީ ތަކެއްޗެވެ. ފަހުން އިތުރުކުރެވޭނެއެވެ.

## ކީއެއް އިތުރުކުރުން

**އިންސްޓޯލަރާއެކު.** Fontes ސެޓަޕްކުރުމަށްފަހު، ކީތައް އިތުރުކުރަން އިންސްޓޯލަރުން ހުށަހަޅައެވެ. Mac ގައި، **ކީތައް އިތުރުކުރުން**
އަށް ކްލިކްކުރައްވާ، ނުވަތަ ސްކިޕްކުރުމަށް **ނިމުނީ** އަށް؛ Windows ގައި، ސުވާލަށް ޖަވާބު ދެއްވާ (ސްކިޕްކުރުމަށް Enter
ފިއްތަވާ). ފަހުން ކީތައް އިތުރުކުރުމަށް ނުވަތަ ބަދަލުކުރުމަށް، **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ރަންކުރައްވާ:

- Mac: Fontes Installer އެޕް އަލުން ހުޅުވައި **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ހޮއްވަވާ.
- Windows: Start menu ހުޅުވައި، ދެން **Fontes** → **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ހޮއްވަވާ.

ޓައިޕްކުރާ އެއްޗެއް ފެނުން ފޮރުވިފައި ހުންނާނެއެވެ. ކޮންމެ ކީއަކަށް: އެ ޕޭސްޓްކުރައްވާ، ހުރި އެއްޗެއް ބެހެއްޓުމަށް Enter
ފިއްތަވާ، ނުވަތަ އެ ނައްތާލުމަށް `-` ޓައިޕްކުރައްވާ. ކީތައް ވަދެނީ ކުރިން Fontes ހުރި ކޮންމެ އެޕަކަށެވެ.

**Claude Desktop އެކްސްޓެންޝަން (.mcpb) އާއެކު.** Claude > Settings > Extensions > Fontes ހުޅުވައި ފީލްޑްތައް
ފުރުއްވާ. އެއިން ކޮންމެ ފީލްޑަކީ އިޚްތިޔާރީ ފީލްޑެކެވެ.

**އަތުން.** ތިބާގެ އެޕުގެ MCP ކޮންފިގްގައި `fontes` އެންޓްރީގެ `env` ބްލޮކަށް ވޭރިއަބަލްތައް އިތުރުކުރައްވާ:

```json
"fontes": {
  "command": "...",
  "args": ["..."],
  "env": { "WLM_US_GOVINFO_KEY": "your-key" }
}
```

ކޮންމެ ބަދަލަކަށްފަހު އެޕް އަލުން ފައްޓަވާ.

## ފަރަންސޭސިވިލާތް: PISTE (ހިލޭ)

1. [piste.gouv.fr](https://piste.gouv.fr) ގައި އެކައުންޓެއް ހައްދަވާ. އޭގެ މާނައަކީ PISTE ގެ ޝަރުޠުތައް (CGU) ޤަބޫލުކުރުމެވެ.
2. API > **Consentement CGU API** އަށް ވަޑައިގަންނަވާ. **JUDILIBRE** އާއި **Légifrance** (production) ގެ ޝަރުޠުތައް ޤަބޫލުކުރައްވާ.
3. **production application** އެއް ހައްދަވާ. ތިބާއަށް ހަދައިދީފައިވާ `APP_SANDBOX` އަށް production އަށް ނުދެވޭނެއެވެ.
   "Modifier l'application" ގެ ދަށުން، **JUDILIBRE (production)** އާއި **Légifrance (production)** ޓިކްކޮށް، ދެން އެޕްލައިކުރައްވާ.
4. އެޕުގެ **Authentification** ޓެބް ހުޅުއްވާ. `client_id` އާއި `client_secret` ކޮޕީކުރައްވާ.
5. **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ރަންކޮށް އެ ދެކަތި ޕޭސްޓްކުރައްވާ.

ޝަރުޠުތައް، ކުރުކޮށް:

- ޑޭޓާ: Licence Ouverte / Etalab 2.0. ވިޔަފާރީގެ ބޭނުން ހިމެނޭ ގޮތަށް، އަލުން ބޭނުންކުރުމުގެ ހުއްދަ ލިބެނީ ނަން ފާހަގަކުރުމާއެކުގައެވެ.
- ތިބާގެ ކްރެޑެންޝަލްތައް ޝާއިޢު ނުކުރައްވާ ނުވަތަ ހިއްސާ ނުކުރައްވާ. އެ ލީކުވެއްޖެނަމަ PISTE އަށް އަންގަވާ.
- Légifrance API އަކީ ބީޓާ ޚިދުމަތެކެވެ. އެ ހުއްޓާލެވިދާނެއެވެ، އަދި އޭގައި ކޯޓާތައް ހުރެއެވެ (ސިކުންތަކަށް، މިނިޓަކަށް އަދި ދުވަހަކަށް).
- Légifrance ގެ ލިޔުންތަކަކީ ޞައްޙަ ނުސްޚާއެއް ނޫނެވެ. ޞައްޙަވާނީ ހަމައެކަނި ސޮއިކޮށްފައިވާ Journal officiel ގެ PDF އެވެ.
- Judilibre: ފަނޑިޔާރުންނާއި ކްލާކުންގެ މަސައްކަތް ވަޒަންކުރުމަށް، އަޅާކިޔުމަށް ނުވަތަ ލަފާކުރުމަށް އެމީހުންގެ ނަންތައް ބޭނުން ނުކުރައްވާ
  (Code de l'organisation judiciaire art. L111-13؛ ޖިނާއީ ކުށެކެވެ).
- Judilibre: GDPR އަށް ތަބާވެވަޑައިގަންނަވާ. ފަރާތްތައް އަލުން ދެނެގަތުމަށް މަސައްކަތް ނުކުރައްވާ.

ތިބާގެ ކޯޓާތައް ހުރީ PISTE ގައި API Sélectionnées > Actions > Consulter les quotas ގެ ދަށުގައެވެ.

## އެމެރިކާ: api.data.gov (ހިލޭ)

1. [govinfo.gov/api-signup](https://www.govinfo.gov/api-signup) (ކީ ސްކްރީނުގައި ދައްކާނެ)
   ނުވަތަ [api.data.gov/signup](https://api.data.gov/signup/) (ކީ ތިބާއަށް އީމެއިލްކުރާނެ) އަށް ވަޑައިގަންނަވާ.
2. ތިބާގެ ނަމާއި އީމެއިލް ޖައްސަވާ. "how will you use it" ފީލްޑަކީ އިޚްތިޔާރީ ފީލްޑެކެވެ.
3. 40 އަކުރުގެ ކީ ކޮޕީކުރައްވާ.
4. **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ރަންކޮށް، އެ އެމެރިކާގެ ކީ ގޮތުގައި ޕޭސްޓްކުރައްވާ.

ޝަރުޠުތައް، ކުރުކޮށް:

- ތިބާގެ އަމިއްލަ ކީއާއެކު، govinfo އިން ގަޑިއިރަކު 36,000 ރިކުއެސްޓާ ހަމައަށް ހުއްދަކުރެއެވެ.
- API އަށް ހާއްސަ ޚިދުމަތުގެ ޝަރުޠުތަކެއް އަހަރެމެންނަށް ނުފެނުނެވެ (api.data.gov/terms/ ނެތެވެ). ތަޙްޤީޤު ނުކުރެވޭ.
  [govinfo ގެ ސިޔާސަތުތައް](https://www.govinfo.gov/about/policies) އާއި
  [data.gov ގެ ޕްރައިވެސީ ސިޔާސަތު](https://data.gov/privacy-policy/) ބައްލަވާ.
- ކީ ތިބާގެ އަތުގައި ބަހައްޓަވާ.

## ކީތައް ރައްކާކުރެވޭ ތަން

- **އިންސްޓޯލަރ ނުވަތަ އަތުން:** ކޮންމެ އެޕެއްގެ MCP ކޮންފިގް ފައިލުގައި، `fontes` އެންޓްރީގެ `env` ބްލޮކުގައި،
  ސާދާ ޓެކްސްޓެއްގެ ގޮތުގައި. ތިބާގެ ޔޫޒަރ ފައިލުތައް ކިޔޭ ކޮންމެ މީހަކަށް ކީތައް ކިޔޭނެއެވެ.
  - Claude Desktop: `~/Library/Application Support/Claude/claude_desktop_config.json` (Mac)،
    `%APPDATA%\Claude\claude_desktop_config.json` (Windows)
  - Claude Code: `~/.claude.json`
  - Codex: `~/.codex/config.toml`
  - Cursor: `~/.cursor/mcp.json`
  - VS Code (Copilot): `~/.copilot/mcp-config.json`
  - Windsurf: `~/.config/devin/mcp_config.json` ނުވަތަ `~/.codeium/windsurf/mcp_config.json`
    (Windows: `%APPDATA%\devin\mcp_config.json`)
  - Gemini CLI: `~/.gemini/settings.json`
  - Zed: `~/.config/zed/settings.json` (Windows: `%APPDATA%\Zed\settings.json`)
  - LM Studio: `~/.lmstudio/mcp.json`
  - Cline: `~/.cline/data/settings/cline_mcp_settings.json`
- **Claude Desktop އެކްސްޓެންޝަން (.mcpb):** Claude އިން މި ފީލްޑްތައް އޭގެ ސެޓިންގްސްގައި ބަހައްޓައި، ތިބާގެ ސިސްޓަމުގެ
  ރައްކާތެރި ސްޓޯރޭޖުން (Mac ގައި Keychain، Windows ގައި Credential Manager) ހިމާޔަތްކުރެއެވެ.

ކޮންމެ ބަދަލެއްގެ ކުރިން، އިންސްޓޯލަރުން ކޮންފިގް ފައިލުގެ ކޮޕީއެއް އޭގެ ކައިރީގައި ސޭވްކުރެއެވެ
(`<file>.fontes-backup-<time>`). ތިބާ ކީތައް އިތުރުކުރުމަށްފަހު ހެދޭ ކޮޕީތަކުގައިވެސް ކީތައް ހުންނާނެއެވެ. ތިބާއަށް
ބޭނުން ނުވާ ބާ ކޮޕީތައް ފޮހެލައްވާ.

## ކީއެއް ބަދަލުކުރުން ނުވަތަ ނައްތާލުން

- **ކީތައް އިތުރުކުރުން ނުވަތަ ބަދަލުކުރުން** ރަންކުރައްވާ. ބަދަލުކުރުމަށް އާ ކީއެއް ޕޭސްޓްކުރައްވާ، ނުވަތަ ނައްތާލުމަށް `-` ޓައިޕްކުރައްވާ.
- ނުވަތަ `env` ބްލޮކް އަތުން އެޑިޓްކޮށް އެޕް އަލުން ފައްޓަވާ.
- Fontes އަންއިންސްޓޯލްކުރުމުން، ކީތައް ހިމެނޭ ގޮތަށް، އޭގެ މުޅި އެންޓްރީ ނައްތާލެވެއެވެ. އެއިން ބެކަޕް ކޮޕީތައް ނުފޮހެލެއެވެ.
- ކީއެއް ލީކުވެއްޖެނަމަ، މަސްދަރުގައިވެސް އެ ބަދަލުކުރައްވާ: PISTE ގައި، ތިބާގެ އެޕަށް އާ ކްރެޑެންޝަލްތަކެއް ހައްދަވާ؛
  api.data.gov އަށް، އާ ކީއަކަށް ސައިން އަޕްކުރައްވާ.

## ހުއްދަތައް (WLM_PERMITTED)

މިއީ API ކީއެއް ނޫނެވެ، އަދި އިންސްޓޯލަރުން މިއީ ސެޓެއް ނުކުރެއެވެ. **މިއީ ސެޓްކުރައްވާނީ އެ ހުއްދަ ތިބާގެ އަމިއްލަ
އަތުގައި ހުރިނަމަ ހަމައެކަނިއެވެ.**

ބައެއް މަސްދަރުތައް ޑިފޯލްޓުގައި ބަންދީ، އެ މަސްދަރުތަކުގެ ޝަރުޠުތަކުން ނުވަތަ robots.txt އިން ހުއްދައަކާ ނުލައި
އޮޓޮމެޓިކް ބޭނުން މަނާކުރާތީއެވެ. ޝާއިޢުކުރާ ފަރާތުން ތިބާއަށް ހުއްދަ ލިބިފައިވާނަމަ، `env` ބްލޮކުގައި `WLM_PERMITTED` އަށް
އޭގެ ކޯޑު، ކޮމާއިން ވަކިކޮށް، އިތުރުކޮށްގެން މަސްދަރެއް ހުޅުއްވާ: `"WLM_PERMITTED": "in,de"`.

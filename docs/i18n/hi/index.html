Fontes एक मुफ़्त, ओपन-सोर्स MCP सर्वर है। यह किसी भी ऐसे ऐप में काम करता है जो स्थानीय Model Context Protocol सर्वर चला सकता है: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio और अन्य। सामान्य भाषा में कोई विधिक प्रश्न पूछें: आपका AI ऐप 120 से अधिक क्षेत्राधिकारों और अंतरराष्ट्रीय न्यायालयों में, सरकारी और न्यायालयों की वेबसाइटों पर न्यायालयों के निर्णय और विधान लाइव खोजता है, और हर परिणाम को मूल से जोड़ता है। यह वकीलों और विधिक शोधकर्ताओं के लिए, और हर उस व्यक्ति के लिए बना है जो कानून को उसके स्रोत पर पढ़ना चाहता है।

यह मशीन की सहायता से किया गया अनुवाद है। अंग्रेज़ी संस्करण ही प्रामाणिक है।

यह क्या करता है

  • आपके पूछने के क्षण में, प्रकाशक की अपनी वेबसाइट या API से केस लॉ और विधान खोजता है।
  • हर परिणाम अपने स्रोत का नाम बताता है और उसका लिंक देता है, ताकि आप मूल जाँच सकें।
  • Fontes कोई डेटाबेस नहीं रखता और उसे किसी खाते की आवश्यकता नहीं। आपके प्रश्न केवल खोजे जा रहे स्रोत तक जाते हैं। उपयोग-गणना और बग रिपोर्ट ऑप्ट-इन हैं।

Fontes शोध का साधन है, विधिक सलाह नहीं, और इसका उपयोग वकील–मुवक्किल संबंध नहीं बनाता। यह "जैसा है" के आधार पर, बिना किसी वारंटी के प्रदान किया जाता है (देखें Apache 2.0 लाइसेंस)। कुछ स्रोत स्पष्ट रूप से गैर-आधिकारिक संस्करण हैं, और प्रत्येक की अपनी उपयोग की शर्तें हैं; Fontes अपने उत्तरों में यह बताता है। किसी निर्णय या उपबंध पर भरोसा करने से पहले उसे पूरा पढ़ें। Fontes स्वतंत्र है और किसी न्यायालय, सरकार या प्रकाशक से संबद्ध नहीं है।

इंस्टॉल करें

Fontes अभी PyPI पर नहीं है। ये चरण पहली रिलीज़ आने के बाद काम करेंगे।

  • Claude Desktop: नवीनतम रिलीज़ से Fontes की .mcpb फ़ाइल डाउनलोड करें, उस पर डबल-क्लिक करें, फिर Install पर क्लिक करें।
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline और अन्य ऐप: Fontes को ऐप की MCP सेटिंग्स में जोड़ें। अधिकांश यही प्रविष्टि लेते हैं; इंस्टॉलेशन गाइड में हर ऐप की फ़ाइल और स्निपेट है।
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx, uv के साथ आता है। macOS या Linux पर: curl -LsSf https://astral.sh/uv/install.sh | sh। Windows (PowerShell) पर: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"।

फिर ऐप को पुनः आरंभ करें और पूछें: "Fontes किन क्षेत्राधिकारों में खोज सकता है?"

Mac और Windows के लिए एक-क्लिक इंस्टॉलर आने वाला है। यह आपके कंप्यूटर पर मौजूद Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio और Cline, हर एक में Fontes सेट अप करता है, फिर आपकी कुंजियाँ जोड़ने की पेशकश करता है। इसे चलाने से पहले उन ऐप को बंद करें। विवरण इंस्टॉलेशन गाइड में। कुछ स्रोतों के लिए मुफ़्त कुंजी चाहिए: देखें KEYS.md।

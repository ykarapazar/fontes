Beta · b'xejn · open source · sorsi ċċekkjati kuljum

Fontes huwa server MCP b'xejn u b'kodiċi miftuħ (open source). Jaħdem fi kwalunkwe app li tista' tħaddem server lokali tal-Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio u oħrajn. Staqsi mistoqsija legali b'lingwaġġ sempliċi: l-app tal-AI tiegħek tfittex deċiżjonijiet tal-qorti u leġiżlazzjoni direttament fuq is-siti web tal-gvern u tal-qrati, f'125 ġurisdizzjoni u qorti internazzjonali, u tagħti link għall-oriġinal ta' kull riżultat. Tista' wkoll turi liġi kif kienet fi dati ta' qabel, u taqra l-leġiżlazzjoni ta' 91 pajjiż ieħor mir-rekord ta' Lexifina (mhux il-pubblikatur uffiċjali). Huwa magħmul għall-avukati u r-riċerkaturi legali, u għal kull min irid jaqra l-liġi mis-sors tagħha.

X'jagħmel

  • Ifittex ġurisprudenza u leġiżlazzjoni fil-mument li tistaqsi, mis-sit web jew mill-API tal-pubblikatur innifsu.
  • Kull riżultat isemmi s-sors tiegħu u għandu link għalih, biex tkun tista' tiċċekkja l-oriġinal.
  • Fontes ma jżomm l-ebda database u ma jeħtieġ l-ebda kont. Il-mistoqsijiet tiegħek imorru lis-sors li qed jiġi mfittex; għal verżjonijiet ta' qabel tal-liġijiet u għall-91 pajjiż ieħor (u l-Atti tal-Indja), imorru fis-servizz pubbliku ta' Lexifina, kemm flimkien mas-sit uffiċjali kif ukoll minfloku. Issettja WLM_LEXIFINA=0 biex twaqqaf dan. L-għadd tal-użu u r-rapporti ta' żbalji jsiru biss bil-kunsens tiegħek (opt-in).

Fontes huwa għajnuna għar-riċerka, mhux parir legali, u l-użu tiegħu ma joħloq l-ebda relazzjoni bejn avukat u klijent. Huwa pprovdut "kif inhu", mingħajr garanzija (ara l-liċenzja Apache 2.0). Xi sorsi huma espressament verżjonijiet mhux uffiċjali, u kull wieħed għandu t-termini tal-użu tiegħu; Fontes jgħid dan fit-tweġibiet tiegħu. Aqra d-deċiżjoni jew id-dispożizzjoni kollha qabel ma tistrieħ fuqha. Fontes huwa indipendenti u mhuwiex affiljat mal-ebda qorti, gvern jew pubblikatur.

Installazzjoni

  • Claude Desktop: niżżel il-fajl .mcpb ta' Fontes mill-aħħar verżjoni, agħfas darbtejn fuqu, imbagħad agħfas Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline u apps oħra: żid Fontes mas-settings MCP tal-app. Il-biċċa l-kbira jieħdu din l-entrata; il-gwida tal-installazzjoni fiha l-fajl u s-silta għal kull app.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx jiġi ma' uv. Fuq macOS jew Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Fuq Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Imbagħad erġa' ibda l-app u staqsi: "F'liema ġurisdizzjonijiet jista' jfittex Fontes?"

Fuq Mac jew PC Windows, installer bi klikk waħda jissettja Fontes f'Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio u Cline, f'kull waħda minnhom li tinsab fuq il-kompjuter tiegħek, imbagħad joffri li jżid iċ-ċwievet tiegħek. Niżżlu mill-aħħar release u agħlaq dawk l-apps qabel ma tħaddmu. Dettalji fil-gwida tal-installazzjoni. Xi sorsi jeħtieġu ċavetta b'xejn: ara KEYS.md.

# Fontes 隐私声明

Fontes 在您的电脑上运行。您的检索以及您打开的文件，只在您的电脑、您所检索的来源（官方来源，以及您使用时的 CourtListener 和 Lexifina，见下文）和您使用的 AI 应用
（受该应用自己的条款约束）之间传递。Fontes 本身**默认不会**向 Fontes 开发者发送**任何内容**。

## 什么内容可能离开您的电脑，以及何时离开

**1. 更新检查（默认开启）。** Fontes 每天一次询问 PyPI（公开的 Python 软件包索引）最新版本是哪一个。
该请求不包含任何关于您或您的工作的信息；与任何下载一样，PyPI 会看到您的 IP 地址。若要关闭，请设置
`FONTES_NO_UPDATE_CHECK=1`（应用内提示）和 `FONTES_NO_AUTO_UPDATE=1`（安装程序的自动更新）。

**2. 使用计数（除非您开启，否则关闭）。** 如果您选择开启，Fontes 每天发送一次：

- Fontes 版本和您的操作系统类别（macOS、Windows、Linux）；
- 按天统计的、每个工具针对每个法域代码的使用次数，例如
  “2026-11-10, nl, search_caselaw, 12”。

这就是消息的全部内容。它绝不包含您的检索内容、文件或案件的 ID、文件文本、您的姓名、账户，或任何针对您
或您电脑的 ID。计数会保存在您的电脑上（Fontes 的缓存文件夹中的 `stats.json`），直到发送为止；如果发送
失败，会等到第二天。

- **开启**：在安装程序询问时回答“y”，或为 Fontes 服务器设置 `FONTES_STATS=1`。
- **关闭**：再次运行安装程序并在该问题处按 Enter，或删除 `FONTES_STATS`。删除 `stats.json` 会丢弃
  所有尚未发送的内容。

**3. 错误报告（仅在您发送时）。** 当您要求发送错误报告时（`fontes report-bug`，或让您的 AI 应用报告
Fontes 的错误），Fontes 会先向您显示完整报告，只有在您确认后才会发送。报告包含 Fontes 版本、您的操作系统
类别、最近一次失败的工具调用的法域代码、工具名称和错误信息（已删除您的检索词和 ID），以及您所写的备注
（如有）。请勿在备注中填写客户的详细信息。为支持此功能，Fontes 会在您的电脑上保存最近一次错误
（其缓存文件夹中的 `last-error.json`，每次都会被替换）；它绝不会被单独发送。

**4. Lexifina（默认开启）。** `get_law_on_date`、`get_law_history`、91 个国家及印度的 Acts 通过 Lexifina 的法律记录读取，因此它们会发往 Lexifina，同时或取代官方网站。您的检索词、引注和日期会发送至 Lexifina 的免费服务器 `global-law.lexifina.com`，该服务器由 Lexifina 运营，而非由 Fontes 开发者运营。Lexifina 说明其服务器记录的是调用了哪个工具以及耗时多久，从不记录询问的内容；Fontes 无法核实这一点，Lexifina 自身的条款适用。与任何网络服务器一样，Lexifina 会看到您的 IP 地址。若要完全关闭，请设置 `WLM_LEXIFINA=0`；此后这两个工具和这些国家将停止工作，且不会向那里发送任何内容。

## 数据发往何处以及保存多久

使用计数和错误报告会发往由 Fontes 开发者运营的一台小型服务器（`relay.kinetra.fit`）。它不存储 IP 地址：
IP 地址仅在内存中短暂使用，用于阻止流量洪泛，并且该网络服务器不为其保留访问日志。计数会被累加为每日总数；
不保留单次提交。总数最多保存 2 年，错误报告最多保存 1 年，之后删除。任何内容都不会出售或共享。

如果无法连接该服务器，则不会发送任何内容：计数会保留在您的电脑上，错误报告会引导您改用问题跟踪器。

确认后才会发送错误报告。您可以随时按上述方式关闭以撤回同意；这不影响此前已发送的内容。

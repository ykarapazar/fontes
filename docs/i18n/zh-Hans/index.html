Fontes 是一个免费、开源的 MCP 服务器。它可在任何能够运行本地 Model Context Protocol 服务器的应用中使用：Claude Desktop、Claude Code、Codex、Cursor、VS Code（GitHub Copilot）、Gemini CLI、Windsurf、Zed、LM Studio 等。用日常语言提出法律问题：您的 AI 应用会在政府和法院网站上实时检索 120 多个法域和国际法院的裁判文书和法律法规，并为每条结果附上原文链接。它为律师和法律研究人员而做，也为任何想从源头阅读法律的人而做。

它能做什么

  • 在您提问的那一刻，从发布者自己的网站或 API 检索判例和法律法规。
  • 每条结果都注明其来源并附有链接，以便您核对原文。
  • Fontes 不保存数据库，也无需账户。您的问题只会发往被检索的来源。使用计数和错误报告需要您主动选择开启。

Fontes 是研究辅助工具，不是法律意见，使用它也不会建立律师–委托人关系。它按原样提供，不附带任何担保（参见 Apache 2.0 许可）。有些来源明确是非官方版本，并且每个来源都有自己的使用条款；Fontes 会在回答中说明这一点。依赖某一裁判文书或条文之前，请阅读其全文。Fontes 是独立的，与任何法院、政府或发布者均无关联。

安装

  • Claude Desktop：从最新版本下载 Fontes 的 .mcpb 文件，双击它，然后点击 Install。
  • Codex：codex mcp add fontes -- uvx fontes-mcp
  • Claude Code：claude mcp add fontes -- uvx fontes-mcp
  • Cursor、VS Code、Gemini CLI、Zed、LM Studio、Cline 及其他应用：将 Fontes 添加到应用的 MCP 设置中。大多数应用使用以下条目；安装指南列出了每个应用的文件和配置片段。
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx 随 uv 一起提供。在 macOS 或 Linux 上：curl -LsSf https://astral.sh/uv/install.sh | sh。在 Windows（PowerShell）上：powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"。

然后重新启动应用并提问：“Fontes 可以检索哪些法域？”

在 Mac 或 Windows 电脑上，一键安装程序会在 Claude Desktop、Codex、Claude Code、Cursor、VS Code、Windsurf、Gemini CLI、Zed、LM Studio 和 Cline 中设置 Fontes（您电脑上有的每一个），然后提示您添加密钥。请从最新版本下载适合您电脑的安装程序，并在运行前先退出这些应用。详情见安装指南。有些来源需要免费密钥：参见 KEYS.md。

Fontes 是开源软件，采用 Apache 2.0 许可。法律文本仍受各发布者的许可约束。

# Установка Fontes

Fontes позволяет вашему ИИ-приложению находить судебные решения и законодательство в режиме
реального времени на сайтах судов и государственных органов более чем 120 юрисдикций. Каждый
результат содержит ссылку на оригинал. Это стандартный MCP-сервер, поэтому он работает в любом
приложении, способном запускать локальный MCP-сервер: Claude Desktop, Codex, Claude Code, Cursor,
VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline и других.

Выберите своё приложение, выполните его шаги, затем [проверьте работу](#проверка-работы).

## Claude Desktop

1. Скачайте файл Fontes `.mcpb` из
   [последнего релиза](https://github.com/ykarapazar/fontes/releases/latest).
2. Дважды щёлкните по нему. Claude Desktop откроет его.
3. Нажмите **Install**.

## Codex

В терминале:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI и расширение Codex для IDE используют эту настройку совместно (`~/.codex/config.toml`).
Вам нужен [uv](#вам-нужен-uv).

## Claude Code

В терминале:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Вам нужен [uv](#вам-нужен-uv).

## Другие приложения

Каждому из них нужен [uv](#вам-нужен-uv). Добавьте запись, сохраните, затем закройте и снова
откройте приложение.

**Cursor:** в `~/.cursor/mcp.json` (все проекты) или `.cursor/mcp.json` (один проект):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** выполните **MCP: Add Server** из Command Palette, выберите
**Command (stdio)**, введите `uvx fontes-mcp` и назовите сервер `fontes`. Или добавьте это в
`~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

В более старых конфигурациях VS Code используется `.vscode/mcp.json`, где ключ верхнего уровня —
`servers` вместо `mcpServers`.

**Gemini CLI:** в терминале `gemini mcp add -s user fontes uvx fontes-mcp`. Или добавьте это в
`~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** откройте файл настроек (**zed: open settings file**) и добавьте:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** на правой боковой панели откройте вкладку **Program**, нажмите **Install → Edit
mcp.json** и добавьте:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** нажмите значок **MCP Servers**, откройте вкладку **Configure**, нажмите **Configure MCP
Servers** и добавьте ту же запись `mcpServers`, что и для LM Studio.

**Claude Desktop вручную** (вместо файла `.mcpb`): добавьте ту же запись `mcpServers` в
`claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**Любое другое MCP-приложение** (Windsurf и другие): в его собственной документации сказано, где
оно хранит свои MCP-серверы. Большинство принимают ту же запись: команда `uvx`, аргумент `fontes-mcp`.

Если приложение не находит `uvx`, укажите полный путь к нему (в macOS и Linux его выводит
`which uvx`).

## Вам нужен uv

Codex, Claude Code и другие приложения запускают Fontes через `uvx`, который входит в состав
**uv** — небольшого бесплатного инструмента от Astral. Чтобы установить его, см.
[руководство Astral](https://docs.astral.sh/uv/getting-started/installation/) или выполните:

- macOS или Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## Ключи

Некоторым источникам нужен бесплатный ключ: см. [KEYS.md](KEYS.md).

## Проверка работы

В новом чате спросите: *«В каких юрисдикциях может искать Fontes?»* Приложение должно ответить
списком стран. Если этого не произошло, ещё раз закройте и снова откройте приложение.

## Установщик в один клик (Mac и Windows)

Установщик настраивает Fontes сразу во всех ваших приложениях: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio и Cline.

**Перед началом:** полностью закройте каждое из этих приложений. Особенно это важно для Claude
Code: пока он работает, он перезаписывает `~/.claude.json` и может отменить изменение,
внесённое установщиком. Если вы не можете закрыть Claude Code, добавьте в него Fontes командой
`claude mcp add` (см. [Claude Code](#claude-code)).

**Mac**

1. Скачайте установщик для Mac (`Fontes-Installer-…-mac.zip`) из
   [последнего релиза](https://github.com/ykarapazar/fontes/releases/latest) и дважды щёлкните его,
   чтобы распаковать.
2. Дважды щёлкните **Fontes Installer**. Если Mac спросит, открыть ли приложение, загруженное из
   интернета, нажмите **Open**.
3. Выберите **Установить** и нажмите **OK**. Настройка занимает около минуты.
4. Появится сообщение со списком настроенных приложений. Нажмите **Готово**, затем снова откройте
   эти приложения. Чтобы сначала добавить необязательные бесплатные ключи, нажмите вместо этого
   **Добавить ключи**; см. [Шаг с ключами](#шаг-с-ключами).

**Windows**

1. Скачайте установщик для Windows (`Fontes-Setup-….exe`) из
   [последнего релиза](https://github.com/ykarapazar/fontes/releases/latest) и дважды щёлкните его.
   - Если Windows показывает «Windows protected your PC»: нажмите **More info**, затем
     **Run anyway**.
2. Нажмите **Установить**. Откроется окно, которое настраивает Fontes.
3. На вопрос, отправлять ли анонимную статистику использования, нажмите Enter, чтобы
   отказаться.
4. Он спросит, добавить ли ключи сейчас. Нажмите Enter, чтобы пропустить; см.
   [Шаг с ключами](#шаг-с-ключами).
5. Когда появится **Done**, снова откройте свои ИИ-приложения. Если какое-то из них ещё
   работало, полностью закройте его (в том числе в области уведомлений, рядом с часами) и
   откройте снова.

В конце установщик перечисляет приложения, которые он настроил.

### Какие приложения он настраивает

Он настраивает приложение, только если папка настроек этого приложения уже есть на вашем
компьютере. Claude Code настраивается, только если существует `~/.claude.json`. Claude Desktop
настраивается всегда. Каждое приложение получает одну запись, `fontes`, в этом файле:

| Приложение | Файл (Mac и Linux) | Файл (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`, а также собственная копия версии из Microsoft Store |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` или `~/.codeium/windsurf/mcp_config.json` в старых версиях | `%APPDATA%\devin\mcp_config.json` или `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code настраивается, если существует `~/.copilot` или собственная папка настроек VS Code.

Двум приложениям нужен ещё один шаг:

- **Windsurf:** после повторного открытия нажмите кнопку обновления в Cascade.
- **Cline в старом расширении VS Code:** добавьте Fontes вручную (см. [Cline](#другие-приложения)).

### Шаг с ключами

Сразу после установки установщик предлагает добавить бесплатные ключи для Франции и США. Чтобы
добавить или изменить их позже:

- **Mac:** снова откройте **Fontes Installer** и выберите **Добавить или изменить ключи**.
- **Windows:** откройте меню «Пуск», затем выберите **Fontes** → **Добавить или изменить ключи**.

Вводимые символы скрыты. Ключи попадают в каждое приложение, в котором уже есть Fontes. После
этого закройте и снова откройте приложения. Где получить ключи и что они открывают:
[KEYS.md](KEYS.md).

### Резервные копии, повторные запуски и удаление

Установщик изменяет только запись `fontes`. Все остальные настройки и комментарии остаются как
были. Перед изменением файла он сохраняет рядом его копию с именем
`<file>.fontes-backup-<date>`. Копии, сделанные после добавления ключей, содержат эти ключи:
удалите те, что вам больше не нужны. Он также устанавливает uv. Повторный запуск безопасен: он
исправляет настройку и больше ничего не меняет.

Чтобы удалить Fontes, откройте **Fontes Installer** и выберите **Удалить** (Mac) или удалите
**Fontes** в Параметры → Приложения (Windows). Он удаляет запись `fontes` вместе с ключами из всех
приложений. Ваши остальные настройки и резервные копии остаются.

## Обновления

- **Установщик и файл `.mcpb`:** вам ничего не нужно делать. Раз в день при запуске приложения
  Fontes в фоновом режиме проверяет наличие новой версии и подготавливает её; при следующем
  запуске приложение использует её. Если обновление не удаётся загрузить или оно не работает,
  Fontes продолжает использовать версию, которая работала.
- **`uvx`:** Fontes сообщает о выходе новой версии в начале своего списка юрисдикций. Чтобы
  всегда запускать новейшую версию, используйте `fontes-mcp@latest` вместо `fontes-mcp`.

Никакие сведения о вас или ваших запросах для этого никуда не отправляются.

## Конфиденциальность

По умолчанию Fontes ничего не отправляет о вас или ваших запросах. Статистика использования
отправляется только с вашего согласия (opt-in), а отчёт об ошибке — только после того, как вы
его увидите и подтвердите. Подробности: [PRIVACY.md](PRIVACY.md).

## Удаление

Удалите запись `fontes` из MCP-настроек своего приложения (в Claude Code:
`claude mcp remove fontes`), затем закройте и снова откройте приложение.

## Полезно знать

Fontes читает общедоступные источники, в основном сайты судов и государственных органов.
Неофициальные источники он помечает в своих ответах. Всегда открывайте ссылку на источник,
прежде чем полагаться на решение или положение.

Если что-то пошло не так, напишите на fontesmcp@proton.me, что вы делали и какую ошибку увидели.

Fontes — бесплатный MCP-сервер с открытым исходным кодом. Он работает в любом приложении, способном запускать локальный сервер Model Context Protocol: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio и других. Задайте правовой вопрос обычным языком: ваше ИИ-приложение ищет судебные решения и законодательство в режиме реального времени на сайтах государственных органов и судов более чем 120 юрисдикций и международных судов и даёт ссылку на оригинал каждого результата. Он создан для юристов и исследователей права, а также для всех, кто хочет читать право в его источнике.

Что он делает

  • Ищет судебную практику и законодательство в момент вашего запроса — на собственном сайте или через API издателя.
  • Каждый результат называет свой источник и даёт на него ссылку, чтобы вы могли проверить оригинал.
  • Fontes не ведёт базу данных и не требует учётной записи. Ваши вопросы отправляются только в источник, в котором ведётся поиск. Статистика использования и отчёты об ошибках — только с вашего согласия (opt-in).

Fontes — вспомогательное средство для исследований, а не юридическая консультация, и его использование не создаёт отношений «адвокат — клиент». Он предоставляется «как есть», без гарантий (см. лицензию Apache 2.0). Некоторые источники прямо объявлены неофициальными версиями, и у каждого свои условия использования; Fontes сообщает об этом в своих ответах. Прочитайте решение или положение полностью, прежде чем на него полагаться. Fontes независим и не связан ни с одним судом, государственным органом или издателем.

Установка

  • Claude Desktop: скачайте файл Fontes .mcpb из последнего релиза, дважды щёлкните по нему, затем нажмите Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline и другие приложения: добавьте Fontes в MCP-настройки приложения. Большинство принимают эту запись; в руководстве по установке указаны файл и фрагмент для каждого приложения.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx входит в состав uv. В macOS или Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. В Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Затем перезапустите приложение и спросите: «В каких юрисдикциях может искать Fontes?»

На Mac или ПК с Windows установщик в один клик настраивает Fontes в Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio и Cline — в каждом из них, который есть на вашем компьютере, — а затем предлагает добавить ваши ключи. Скачайте установщик для своего компьютера из последнего релиза и перед запуском закройте эти приложения. Подробности — в руководстве по установке. Некоторым источникам нужен бесплатный ключ: см. KEYS.md.

Fontes распространяется с открытым исходным кодом по лицензии Apache 2.0. Правовые тексты остаются под лицензией каждого издателя.

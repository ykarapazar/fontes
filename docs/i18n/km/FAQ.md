## តើ Fontes ខុសពីឧបករណ៍ស្រាវជ្រាវផ្លូវច្បាប់ដែលដំណើរការលើម៉ាស៊ីនមេពីចម្ងាយ (hosted) យ៉ាងដូចម្ដេច?

- **វាដំណើរការនៅលើកុំព្យូទ័ររបស់អ្នក។** គ្មានម៉ាស៊ីនមេ Fontes និងគ្មានគណនីទេ។ នោះក៏មានន័យថាវា
  ដំណើរការតែនៅក្នុងកម្មវិធីដែលអាចចាប់ផ្ដើមម៉ាស៊ីនមេ MCP មូលដ្ឋានបាន (Claude Desktop, Codex, Cursor, VS Code
  និងកម្មវិធីស្រដៀងគ្នា) មិនមែននៅក្នុងកម្មវិធីតែលើគេហទំព័រ ដែលទទួលយកតែឧបករណ៍ភ្ជាប់ hosted ប៉ុណ្ណោះទេ។
- **វាគ្មានមូលដ្ឋានទិន្នន័យទេ។** ការស្វែងរកនីមួយៗទៅដោយផ្ទាល់កាន់គេហទំព័រ ឬ API ផ្ទាល់របស់អ្នកបោះពុម្ពផ្សាយ ដូច្នេះ
  លទ្ធផលមានភាពទាន់សម័យដូចប្រភព ហើយគុណភាពស្វែងរកគឺជាគុណភាពរបស់ប្រភពផ្ទាល់។ គ្មាន
  ការស្វែងរកតាមអត្ថន័យ (semantic search) លើសន្ទស្សន៍ដែលបានរៀបចំទេ។
- **វាមិនកំណត់ដែនកំណត់ការប្រើប្រាស់ទេ។** Fontes គ្មានដែនកំណត់ការហៅប្រចាំខែទេ។ វាពន្យារពេលសំណើរបស់វាទៅកាន់
  គេហទំព័រនីមួយៗ ហើយប្រភពមួយចំនួនកំណត់ល្បឿន ឬភាពញឹកញាប់ដែលអាចសួរវាបាន។
- **វាជាកូដចំហ។** អ្នកអាចអាន adapter នីមួយៗ ហើយមើលឃើញយ៉ាងច្បាស់ថាអត្ថបទនីមួយៗមកពីណា។
- **គ្មានអ្នកផ្គត់ផ្គង់នៅពីក្រោយវាទេ។** គ្មានកិច្ចសន្យា ផ្នែកគាំទ្រ ឬការសន្យាពេលវេលាដំណើរការទេ (សូមមើល "តើអ្នកណា
  ថែទាំវា?")។

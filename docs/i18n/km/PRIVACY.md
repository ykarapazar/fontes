# សេចក្ដីជូនដំណឹងអំពីឯកជនភាពរបស់ Fontes

រវាងកុំព្យូទ័ររបស់អ្នក ប្រភពដែលអ្នកស្វែងរក (ប្រភពផ្លូវការ ព្រមទាំង CourtListener និង Lexifina នៅពេលអ្នកប្រើពួកវា សូមមើលខាងក្រោម) និងកម្មវិធី AI ដែលអ្នកប្រើ (ក្រោមលក្ខខណ្ឌផ្ទាល់
របស់កម្មវិធីនោះ)។ Fontes ខ្លួនឯងផ្ញើ **គ្មានអ្វីសោះតាមលំនាំដើម** ទៅកាន់អ្នកអភិវឌ្ឍ Fontes។

## អ្វីដែលអាចចេញពីកុំព្យូទ័ររបស់អ្នក និងនៅពេលណា

**1. ការពិនិត្យការធ្វើបច្ចុប្បន្នភាព (បើកតាមលំនាំដើម)។** ម្ដងក្នុងមួយថ្ងៃ Fontes សួរ PyPI ដែលជាសន្ទស្សន៍កញ្ចប់ Python
សាធារណៈ ថាតើកំណែណាថ្មីបំផុត។ សំណើនេះមិនផ្ទុកអ្វីអំពីអ្នក ឬការងាររបស់អ្នកទេ; PyPI
ឃើញអាសយដ្ឋាន IP របស់អ្នក ដូចការទាញយកណាមួយដែរ។ ដើម្បីបិទវា សូមកំណត់ `FONTES_NO_UPDATE_CHECK=1`
(សេចក្ដីជូនដំណឹងនៅក្នុងកម្មវិធី) និង `FONTES_NO_AUTO_UPDATE=1` (ការធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិរបស់កម្មវិធីដំឡើង)។

**2. ចំនួននៃការប្រើប្រាស់ (បិទ លុះត្រាតែអ្នកបើកវា)។** ប្រសិនបើអ្នកជ្រើសរើសចូលរួម ម្ដងក្នុងមួយថ្ងៃ Fontes ផ្ញើ៖

- កំណែ Fontes និងប្រភេទប្រព័ន្ធប្រតិបត្តិការរបស់អ្នក (macOS, Windows, Linux);
- ក្នុងមួយថ្ងៃ ចំនួនដងដែលឧបករណ៍នីមួយៗត្រូវបានប្រើសម្រាប់កូដយុត្តាធិការនីមួយៗ ឧទាហរណ៍
  "2026-11-10, nl, search_caselaw, 12"។

នោះគឺជាសារទាំងមូល។ វាមិនដែលរួមបញ្ចូលការស្វែងរករបស់អ្នក លេខសម្គាល់ឯកសារ ឬរឿងក្ដី អត្ថបទឯកសារ
ឈ្មោះរបស់អ្នក គណនី ឬលេខសម្គាល់ណាមួយសម្រាប់អ្នក ឬកុំព្យូទ័ររបស់អ្នកទេ។ ចំនួនទាំងនោះរង់ចាំនៅលើកុំព្យូទ័ររបស់អ្នក
(នៅក្នុងថតឃ្លាំងសម្ងាត់របស់ Fontes, `stats.json`) រហូតដល់វាត្រូវបានផ្ញើ; ប្រសិនបើការផ្ញើបរាជ័យ វារង់ចាំ
ថ្ងៃបន្ទាប់។

- **ជ្រើសរើសចូលរួម**៖ ឆ្លើយ "y" នៅពេលកម្មវិធីដំឡើងសួរ ឬកំណត់ `FONTES_STATS=1` សម្រាប់ម៉ាស៊ីនមេ Fontes។
- **ជ្រើសរើសមិនចូលរួម**៖ ដំណើរការកម្មវិធីដំឡើងម្ដងទៀត ហើយចុច Enter នៅសំណួរនោះ ឬលុប
  `FONTES_STATS`។ ការលុប `stats.json` បោះបង់អ្វីដែលមិនទាន់បានផ្ញើ។

**3. របាយការណ៍កំហុស (តែនៅពេលអ្នកផ្ញើវាប៉ុណ្ណោះ)។** នៅពេលអ្នកស្នើរបាយការណ៍មួយ (`fontes report-bug` ឬសុំ
កម្មវិធី AI របស់អ្នកឱ្យរាយការណ៍កំហុសរបស់ Fontes) Fontes បង្ហាញរបាយការណ៍ពេញលេញដល់អ្នកជាមុនសិន ហើយផ្ញើវាតែប្រសិនបើ
អ្នកបញ្ជាក់ប៉ុណ្ណោះ។ វាមានកំណែ Fontes ប្រភេទប្រព័ន្ធប្រតិបត្តិការរបស់អ្នក កូដយុត្តាធិការ ឈ្មោះឧបករណ៍ និងសារកំហុស
នៃការហៅឧបករណ៍ចុងក្រោយដែលបានបរាជ័យ (ដោយកាត់ពាក្យស្វែងរក និងលេខសម្គាល់របស់អ្នកចេញ) និង
កំណត់ចំណាំមួយ ប្រសិនបើអ្នកសរសេរ។ កុំដាក់ព័ត៌មានលម្អិតរបស់កូនក្ដីនៅក្នុងកំណត់ចំណាំ។ ដើម្បីគាំទ្រការនេះ Fontes រក្សាទុក
កំហុសចុងក្រោយនៅលើកុំព្យូទ័ររបស់អ្នក (`last-error.json` នៅក្នុងថតឃ្លាំងសម្ងាត់របស់វា ដែលត្រូវបានជំនួសរាល់ពេល);
វាមិនដែលត្រូវបានផ្ញើដោយឡែកទេ។

# ការដំឡើង Fontes

Fontes អនុញ្ញាតឱ្យកម្មវិធី AI របស់អ្នកស្វែងរកសេចក្ដីសម្រេចរបស់តុលាការ និងលិខិតបទដ្ឋានគតិយុត្តដោយផ្ទាល់នៅលើគេហទំព័ររបស់តុលាការ និង
រដ្ឋាភិបាល នៅក្នុងយុត្តាធិការជាង 120។ លទ្ធផលនីមួយៗមានតំណភ្ជាប់ទៅកាន់ឯកសារដើម។ វាគឺជាម៉ាស៊ីនមេ MCP
ស្តង់ដារ ដូច្នេះវាដំណើរការក្នុងកម្មវិធីណាក៏ដោយដែលអាចដំណើរការម៉ាស៊ីនមេ MCP មូលដ្ឋានបាន៖ Claude Desktop, Codex, Claude
Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline និងកម្មវិធីផ្សេងទៀត។

ជ្រើសរើសកម្មវិធីរបស់អ្នក អនុវត្តតាមជំហានរបស់វា បន្ទាប់មក [ពិនិត្យថាវាដំណើរការ](#ពិនិត្យថាវាដំណើរការ)។

## Claude Desktop

1. ទាញយកឯកសារ `.mcpb` របស់ Fontes ពី
   [ការចេញផ្សាយចុងក្រោយបំផុត](https://github.com/ykarapazar/fontes/releases/latest)។
2. ចុចពីរដងលើវា។ Claude Desktop បើកវា។
3. ចុច **Install**។

## Codex

នៅក្នុង terminal៖

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI និងផ្នែកបន្ថែម Codex IDE ប្រើការកំណត់នេះរួមគ្នា (`~/.codex/config.toml`)។
អ្នកត្រូវការ [uv](#អ្នកត្រូវការ-uv)។

## Claude Code

នៅក្នុង terminal៖

```bash
claude mcp add fontes -- uvx fontes-mcp
```

អ្នកត្រូវការ [uv](#អ្នកត្រូវការ-uv)។

## កម្មវិធីផ្សេងទៀត

កម្មវិធីនីមួយៗខាងក្រោមត្រូវការ [uv](#អ្នកត្រូវការ-uv)។ បន្ថែមធាតុ រក្សាទុក បន្ទាប់មកបិទកម្មវិធី ហើយបើកវាម្ដងទៀត។

**Cursor៖** នៅក្នុង `~/.cursor/mcp.json` (គម្រោងទាំងអស់) ឬ `.cursor/mcp.json` (គម្រោងមួយ)៖

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot)៖** ដំណើរការ **MCP: Add Server** ពី Command Palette ជ្រើសរើស
**Command (stdio)** បញ្ចូល `uvx fontes-mcp` ហើយដាក់ឈ្មោះម៉ាស៊ីនមេថា `fontes`។ ឬបន្ថែមកូដនេះទៅក្នុង
`~/.copilot/mcp-config.json`៖

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

ការរៀបចំ VS Code ចាស់ៗប្រើ `.vscode/mcp.json` ដែលកូនសោកម្រិតកំពូលគឺ `servers` ជំនួសឱ្យ
`mcpServers`។

**Gemini CLI៖** នៅក្នុង terminal៖ `gemini mcp add -s user fontes uvx fontes-mcp`។ ឬបន្ថែមកូដនេះទៅក្នុង
`~/.gemini/settings.json`៖

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed៖** បើកឯកសារការកំណត់របស់អ្នក (**zed: open settings file**) ហើយបន្ថែម៖

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio៖** នៅក្នុងរបារចំហៀងខាងស្ដាំ បើកផ្ទាំង **Program** ចុច **Install → Edit
mcp.json** ហើយបន្ថែម៖

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline៖** ចុចរូបតំណាង **MCP Servers** បើកផ្ទាំង **Configure** ចុច **Configure MCP
Servers** ហើយបន្ថែមធាតុ `mcpServers` ដូចគ្នានឹងសម្រាប់ LM Studio។

**Claude Desktop ដោយដៃ** (ជំនួសឱ្យឯកសារ `.mcpb`)៖ បន្ថែមធាតុ `mcpServers` ដូចគ្នាទៅក្នុង
`claude_desktop_config.json` (macOS៖ `~/Library/Application Support/Claude/`, Windows៖
`%APPDATA%\Claude\`)។

**កម្មវិធី MCP ផ្សេងទៀត** (Windsurf និងកម្មវិធីផ្សេងទៀត)៖ ឯកសារណែនាំផ្ទាល់របស់វាប្រាប់ពីកន្លែងដែលវារក្សាទុកម៉ាស៊ីនមេ MCP
របស់វា។ ភាគច្រើនទទួលយកធាតុដូចគ្នា៖ ពាក្យបញ្ជា `uvx` អាគុយម៉ង់ `fontes-mcp`។

ប្រសិនបើកម្មវិធីរក `uvx` មិនឃើញ សូមប្រើផ្លូវពេញរបស់វា (នៅលើ macOS និង Linux `which uvx` បង្ហាញវា)។

## អ្នកត្រូវការ uv

Codex, Claude Code និងកម្មវិធីផ្សេងទៀតចាប់ផ្ដើម Fontes ជាមួយ `uvx` ដែលមកជាមួយ **uv** ជាឧបករណ៍តូចមួយ
ឥតគិតថ្លៃពី Astral។ ដើម្បីដំឡើងវា សូមមើល
[ការណែនាំរបស់ Astral](https://docs.astral.sh/uv/getting-started/installation/) ឬដំណើរការ៖

- macOS ឬ Linux៖ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell)៖ `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## ពិនិត្យថាវាដំណើរការ

នៅក្នុងការជជែកថ្មីមួយ សូមសួរ៖ *"តើ Fontes អាចស្វែងរកនៅក្នុងយុត្តាធិការណាខ្លះ?"* កម្មវិធីគួរតែឆ្លើយជាមួយ
បញ្ជីប្រទេសនានា។ ប្រសិនបើវាមិនឆ្លើយទេ សូមបិទ ហើយបើកកម្មវិធីម្ដងទៀត។

## កម្មវិធីដំឡើងចុចតែម្ដង (Mac និង Windows)

កម្មវិធីដំឡើងរៀបចំ Fontes នៅក្នុងកម្មវិធីទាំងអស់របស់អ្នកក្នុងពេលតែមួយ៖ Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio និង Cline។

**មុនពេលអ្នកចាប់ផ្ដើម៖** សូមបិទកម្មវិធីនីមួយៗទាំងនេះទាំងស្រុង។ ចំណុចនេះសំខាន់បំផុតសម្រាប់ Claude Code៖
ពេលវាកំពុងដំណើរការ វាសរសេរ `~/.claude.json` ឡើងវិញ ហើយអាចលុបចោលការផ្លាស់ប្ដូររបស់កម្មវិធីដំឡើង។ ប្រសិនបើអ្នកមិនអាច
បិទ Claude Code បានទេ សូមបន្ថែម Fontes ទៅក្នុងវាដោយប្រើ `claude mcp add` ជំនួសវិញ (សូមមើល [Claude Code](#claude-code))។

**Mac**

1. ទាញយកកម្មវិធីដំឡើងសម្រាប់ Mac (`Fontes-Installer-…-mac.zip`) ពី
   [កំណែចេញផ្សាយចុងក្រោយ](https://github.com/ykarapazar/fontes/releases/latest) ហើយចុចពីរដងលើវាដើម្បីពន្លា។
2. ចុចពីរដងលើ **Fontes Installer**។ ប្រសិនបើ Mac របស់អ្នកសួរថាតើត្រូវបើកកម្មវិធីដែលបានទាញយកពីអ៊ីនធឺណិតឬទេ
   សូមចុច **Open**។
3. ជ្រើសរើស **ដំឡើង** ហើយចុច **យល់ព្រម**។ ការរៀបចំចំណាយពេលប្រហែលមួយនាទី។
4. សារមួយរាយឈ្មោះកម្មវិធីដែលវាបានរៀបចំ។ ចុច **រួចរាល់** បន្ទាប់មកបើកកម្មវិធីទាំងនោះម្ដងទៀត។
   ដើម្បីបន្ថែមកូនសោឥតគិតថ្លៃជាជម្រើសជាមុនសិន សូមចុច **បន្ថែមកូនសោ** ជំនួសវិញ; សូមមើល [ជំហានកូនសោ](#ជំហានកូនសោ)។

**Windows**

1. ទាញយកកម្មវិធីដំឡើងសម្រាប់ Windows (`Fontes-Setup-….exe`) ពី[កំណែចេញផ្សាយចុងក្រោយ](https://github.com/ykarapazar/fontes/releases/latest) ហើយចុចពីរដងលើវា។
   - ប្រសិនបើ Windows បង្ហាញ "Windows protected your PC"៖ ចុច **More info** បន្ទាប់មក **Run anyway**។
2. ចុច **ដំឡើង**។ បង្អួចមួយនឹងបើក ហើយដំឡើង Fontes។
3. នៅពេលត្រូវបានសួរថាតើត្រូវផ្ញើចំនួននៃការប្រើប្រាស់អនាមិកឬទេ សូមចុច Enter ដើម្បីបដិសេធ។
4. វាសួរថាតើត្រូវបន្ថែមកូនសោឥឡូវនេះឬទេ។ ចុច Enter ដើម្បីរំលង; សូមមើល [ជំហានកូនសោ](#ជំហានកូនសោ)។
5. នៅពេលវាបង្ហាញ **Done** សូមបើកកម្មវិធី AI របស់អ្នកម្ដងទៀត។ ប្រសិនបើកម្មវិធីណាមួយនៅតែដំណើរការ សូមបិទវា
   ទាំងស្រុង (ក៏ពី system tray ក្បែរនាឡិកាដែរ) ហើយបើកវាម្ដងទៀត។

នៅចុងបញ្ចប់ កម្មវិធីដំឡើងរាយបញ្ជីកម្មវិធីដែលវាបានរៀបចំ។

### កម្មវិធីណាខ្លះដែលវារៀបចំ

វារៀបចំកម្មវិធីមួយ លុះត្រាតែថតការកំណត់របស់កម្មវិធីនោះមាននៅលើកុំព្យូទ័ររបស់អ្នករួចហើយ។ Claude Code
ត្រូវបានរៀបចំ លុះត្រាតែ `~/.claude.json` មាន។ Claude Desktop ត្រូវបានរៀបចំជានិច្ច។ កម្មវិធីនីមួយៗទទួលបាន
ធាតុមួយ `fontes` នៅក្នុងឯកសារនេះ៖

| កម្មវិធី | ឯកសារ (Mac និង Linux) | ឯកសារ (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux៖ `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` និងច្បាប់ចម្លងផ្ទាល់របស់កំណែ Microsoft Store |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` ឬ `~/.codeium/windsurf/mcp_config.json` នៅលើកំណែចាស់ៗ | `%APPDATA%\devin\mcp_config.json` ឬ `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |

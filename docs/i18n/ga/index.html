Is freastalaí MCP saor in aisce, foinse oscailte é Fontes. Oibríonn sé in aon aip ar féidir léi freastalaí Model Context Protocol áitiúil a rith: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio agus tuilleadh. Cuir ceist dlí i ngnáthchaint: cuardaíonn d'aip IS breithiúnais chúirte agus reachtaíocht beo ar shuíomhanna gréasáin rialtais agus cúirteanna, i 125 dlínse agus cúirt idirnáisiúnta, agus nascann sí gach toradh leis an mbunleagan. Is féidir léi freisin dlí a thaispeáint mar a bhí sé ar dháta san am atá caite, agus reachtaíocht a léamh ó 91 tír eile, ó thaifead Lexifina (ní an foilsitheoir oifigiúil). Tá sé déanta do dhlíodóirí agus do thaighdeoirí dlí, agus do dhuine ar bith ar mian leis an dlí a léamh ag a fhoinse.

Cad a dhéanann sé

  • Cuardaíonn sé cásdlí agus reachtaíocht ag an nóiméad a iarrann tú, ar shuíomh gréasáin nó API an fhoilsitheora féin.
  • Ainmníonn gach toradh a fhoinse agus tá nasc chuici ann, ionas gur féidir leat an bunleagan a sheiceáil.
  • Ní choinníonn Fontes bunachar sonraí agus ní theastaíonn cuntas uaidh. Téann do cheisteanna chuig an bhfoinse atá á cuardach; i gcás seanleaganacha de dhlíthe agus i gcás 91 tír eile (agus Achtanna na hIndia), téann siad chuig seirbhís phoiblí Lexifina chomh maith leis an suíomh oifigiúil nó ina ionad sin. Socraigh WLM_LEXIFINA=0 chun é sin a mhúchadh. Is ar bhonn roghnach (opt-in) atá comhairimh úsáide agus tuairiscí ar fhabhtanna.

Áis taighde é Fontes, ní comhairle dlí, agus ní chruthaíonn a úsáid caidreamh dlíodóra agus cliaint. Soláthraítear é mar atá, gan bharántas (féach an ceadúnas Apache 2.0). Is leaganacha neamhoifigiúla go sainráite cuid de na foinsí, agus tá a téarmaí úsáide féin ag gach ceann; deir Fontes é sin ina chuid freagraí. Léigh an breithiúnas nó an fhoráil iomlán sula mbraitheann tú air. Tá Fontes neamhspleách agus níl baint aige le haon chúirt, rialtas ná foilsitheoir.

Suiteáil

  • Claude Desktop: íoslódáil an comhad Fontes .mcpb ón eisiúint is déanaí, déchliceáil é, ansin cliceáil Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline agus aipeanna eile: cuir Fontes le socruithe MCP na haipe. Glacann formhór acu leis an iontráil seo; tá an comhad agus an sliocht do gach aip sa treoir suiteála.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

Tagann uvx le uv. Ar macOS nó Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Ar Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Ansin atosaigh an aip agus fiafraigh: "Cé na dlínsí ar féidir le Fontes a chuardach?"

Ar Mac nó PC Windows, socraíonn suiteálaí aon chliceáil Fontes in Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio agus Cline, i ngach ceann acu atá ar do ríomhaire, agus ansin tairgeann sé d'eochracha a chur leis. Íoslódáil suiteálaí do ríomhaire ón eisiúint is déanaí agus scoir de na haipeanna sin sula ritheann tú é. Sonraí sa treoir suiteála. Teastaíonn eochair saor in aisce ó roinnt foinsí: féach KEYS.md.

এটি কী করে

  • আপনি যে মুহূর্তে জিজ্ঞাসা করেন, সেই মুহূর্তে প্রকাশকের নিজস্ব ওয়েবসাইট বা API থেকে নজির ও আইন অনুসন্ধান করে।
  • প্রতিটি ফলাফল তার উৎসের নাম বলে ও তার লিংক দেয়, যাতে আপনি মূলটি মিলিয়ে দেখতে পারেন।
  • Fontes কোনো ডেটাবেস রাখে না এবং কোনো অ্যাকাউন্টের প্রয়োজন হয় না। আপনার প্রশ্ন কেবল সেই উৎসেই যায় যেখানে অনুসন্ধান হচ্ছে। ব্যবহার-গণনা ও বাগ রিপোর্ট অপ্ট-ইন।

Fontes গবেষণার সহায়ক, আইনি পরামর্শ নয়, এবং এটি ব্যবহার করলে আইনজীবী–মক্কেল সম্পর্ক তৈরি হয় না। এটি "যেমন আছে" ভিত্তিতে, কোনো ওয়ারেন্টি ছাড়াই দেওয়া হয় (দেখুন Apache 2.0 লাইসেন্স)। কিছু উৎস স্পষ্টভাবে অদাপ্তরিক সংস্করণ, এবং প্রতিটির নিজস্ব ব্যবহারের শর্ত আছে; Fontes তার উত্তরে তা জানায়। কোনো রায় বা বিধানের ওপর নির্ভর করার আগে পুরোটা পড়ুন। Fontes স্বাধীন এবং কোনো আদালত, সরকার বা প্রকাশকের সঙ্গে সংশ্লিষ্ট নয়।

ইনস্টল

  • Claude Desktop: সর্বশেষ রিলিজ থেকে Fontes-এর .mcpb ফাইলটি ডাউনলোড করুন, এতে ডাবল-ক্লিক করুন, তারপর Install-এ ক্লিক করুন।
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline ও অন্যান্য অ্যাপ: অ্যাপটির MCP সেটিংসে Fontes যোগ করুন। বেশিরভাগ অ্যাপ এই এন্ট্রি নেয়; ইনস্টলেশন নির্দেশিকায় প্রতিটি অ্যাপের ফাইল ও স্নিপেট আছে।
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx আসে uv-এর সঙ্গে। macOS বা Linux-এ: curl -LsSf https://astral.sh/uv/install.sh | sh। Windows-এ (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"।

তারপর অ্যাপটি রিস্টার্ট করুন এবং জিজ্ঞাসা করুন: "Fontes কোন কোন এখতিয়ারে অনুসন্ধান করতে পারে?"

Mac বা Windows-এ, এক-ক্লিকের একটি ইনস্টলার আপনার কম্পিউটারে থাকা Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio ও Cline-এর প্রতিটিতে Fontes সেট আপ করে, তারপর আপনার কী (key) যোগ করার প্রস্তাব দেয়। সর্বশেষ রিলিজ থেকে আপনার কম্পিউটারের ইনস্টলারটি ডাউনলোড করুন এবং এটি চালানোর আগে ওই অ্যাপগুলো বন্ধ করুন। বিস্তারিত ইনস্টলেশন নির্দেশিকায়। কিছু উৎসের জন্য বিনামূল্যের একটি কী প্রয়োজন: দেখুন KEYS.md।

Fontes, Apache 2.0 লাইসেন্সের অধীনে ওপেন সোর্স। আইনি পাঠগুলো প্রতিটি প্রকাশকের লাইসেন্সের অধীনেই থাকে।

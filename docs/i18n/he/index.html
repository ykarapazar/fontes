מה הוא עושה

  • מחפש בפסיקה ובחקיקה ברגע ששואלים, מהאתר או מה-API של המפרסם עצמו.
  • כל תוצאה מציינת את מקורה ומקשרת אליו, כדי שתוכלו לבדוק את המקור.
  • Fontes אינו מחזיק מסד נתונים ואינו דורש חשבון. השאלות שלכם מגיעות רק אל המקור שבו מחפשים. ספירות שימוש ודיווחי באגים הם בהסכמה מפורשת בלבד (opt-in).

Fontes הוא כלי עזר למחקר, לא ייעוץ משפטי, והשימוש בו אינו יוצר יחסי עורך דין–לקוח. הוא מסופק "כמות שהוא" (as is), ללא אחריות (ראו את רישיון Apache 2.0). חלק מהמקורות הם במפורש נוסחים לא רשמיים, ולכל אחד יש תנאי שימוש משלו; Fontes מציין זאת בתשובותיו. קראו את פסק הדין או ההוראה במלואם לפני שאתם מסתמכים עליהם. Fontes עצמאי ואין לו זיקה לשום בית משפט, ממשלה או מפרסם.

התקנה

  • Claude Desktop: הורידו את קובץ ה-.mcpb של Fontes מהגרסה האחרונה, לחצו עליו לחיצה כפולה, ואז לחצו על Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, ‏VS Code, ‏Gemini CLI, ‏Zed, ‏LM Studio, ‏Cline ויישומים אחרים: הוסיפו את Fontes להגדרות ה-MCP של היישום. רובם מקבלים את הרשומה הזו; מדריך ההתקנה כולל את הקובץ ואת קטע ההגדרות לכל יישום.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx מגיע עם uv. ב-macOS או ב-Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. ב-Windows ‏(PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

לאחר מכן הפעילו מחדש את היישום ושאלו: "באילו תחומי שיפוט Fontes יכול לחפש?"

תוכנית התקנה בלחיצה אחת ל-Mac ול-Windows נמצאת בדרך. היא מגדירה את Fontes ב-Claude Desktop, ‏Codex, ‏Claude Code, ‏Cursor, ‏VS Code, ‏Windsurf, ‏Gemini CLI, ‏Zed, ‏LM Studio ו-Cline, בכל אחד מהם שנמצא במחשב שלכם, ואז מציעה להוסיף את המפתחות שלכם. צאו מיישומים אלה לפני שאתם מפעילים אותה. פרטים במדריך ההתקנה. חלק מהמקורות דורשים מפתח חינמי: ראו KEYS.md.

Fontes הוא קוד פתוח ברישיון Apache 2.0. הטקסטים המשפטיים נשארים כפופים לרישיון של כל מפרסם.

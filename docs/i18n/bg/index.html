Инсталиране

  • Claude Desktop: изтеглете файла .mcpb на Fontes от последната версия, щракнете двукратно върху него, след това щракнете Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline и други приложения: добавете Fontes в MCP настройките на приложението. Повечето приемат този запис; ръководството за инсталиране съдържа файла и фрагмента за всяко приложение.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx идва с uv. На macOS или Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. На Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

След това рестартирайте приложението и попитайте: „В кои юрисдикции може да търси Fontes?“

На Mac или Windows компютър инсталатор с едно щракване настройва Fontes в Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio и Cline — във всяко от тях, което е на компютъра ви — и след това предлага да добави вашите ключове. Изтеглете го от последната версия и затворете тези приложения, преди да го стартирате. Подробности в ръководството за инсталиране. Някои източници изискват безплатен ключ: вижте KEYS.md.

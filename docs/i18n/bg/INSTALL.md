# Инсталиране на Fontes

Fontes позволява на вашето приложение с изкуствен интелект (ИИ) да търси съдебни решения и
законодателство на живо в сайтовете на съдилища и държавни институции в 125 юрисдикции.
Всеки резултат съдържа връзка към оригинала. Това е стандартен MCP сървър, затова работи във
всяко приложение, което може да стартира локален MCP сървър: Claude Desktop, Codex, Claude Code,
Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline и други.

Изберете приложението си, следвайте стъпките за него, след това
[проверете дали работи](#проверете-дали-работи).

## Claude Desktop

1. Изтеглете файла `.mcpb` на Fontes от
   [последната версия](https://github.com/ykarapazar/fontes/releases/latest).
2. Щракнете двукратно върху него. Claude Desktop ще го отвори.
3. Щракнете **Install**.

## Codex

В терминал:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI и разширението на Codex за IDE споделят тази настройка (`~/.codex/config.toml`).
Нужен ви е [uv](#нужен-ви-е-uv).

## Claude Code

В терминал:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Нужен ви е [uv](#нужен-ви-е-uv).

## Други приложения

На всяко от тях е нужен [uv](#нужен-ви-е-uv). Добавете записа, запазете, след това затворете и
отворете отново приложението.

**Cursor:** в `~/.cursor/mcp.json` (всички проекти) или `.cursor/mcp.json` (един проект):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** изпълнете **MCP: Add Server** от Command Palette, изберете
**Command (stdio)**, въведете `uvx fontes-mcp` и наименувайте сървъра `fontes`. Или добавете това в
`~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

По-старите настройки на VS Code използват `.vscode/mcp.json`, където ключът от най-горно ниво е
`servers` вместо `mcpServers`.

**Gemini CLI:** в терминал `gemini mcp add -s user fontes uvx fontes-mcp`. Или добавете това в
`~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** отворете файла с настройките (**zed: open settings file**) и добавете:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** в дясната странична лента отворете раздела **Program**, щракнете **Install → Edit
mcp.json** и добавете:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** щракнете иконата **MCP Servers**, отворете раздела **Configure**, щракнете **Configure
MCP Servers** и добавете същия запис `mcpServers` като за LM Studio.

**Claude Desktop ръчно** (вместо файла `.mcpb`): добавете същия запис `mcpServers` в
`claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**Всяко друго MCP приложение** (Windsurf и други): в собствената му документация е посочено
къде съхранява своите MCP сървъри. Повечето приемат същия запис: команда `uvx`, аргумент
`fontes-mcp`.

Ако приложението не намира `uvx`, посочете пълния път до него (на macOS и Linux `which uvx` го
извежда).

## Нужен ви е uv

Codex, Claude Code и другите приложения стартират Fontes чрез `uvx`, който идва с **uv** —
малък безплатен инструмент от Astral. За да го инсталирате, вижте
[ръководството на Astral](https://docs.astral.sh/uv/getting-started/installation/) или изпълнете:

- macOS или Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

Някои източници изискват безплатен ключ: вижте [KEYS.md](KEYS.md).

## Проверете дали работи

В нов чат попитайте: *„В кои юрисдикции може да търси Fontes?“* Приложението трябва да отговори
със списък на държави. Ако не го направи, затворете и отворете отново приложението още веднъж.

## Инсталатор с едно щракване (Mac и Windows)

Инсталаторът настройва Fontes във всичките ви приложения наведнъж: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio и Cline.
**Преди да започнете:** затворете напълно всяко от тези приложения. Това е особено важно за
Claude Code: докато работи, той презаписва `~/.claude.json` и може да отмени промяната, направена
от инсталатора. Ако не можете да затворите Claude Code, добавете Fontes в него с
`claude mcp add` (вижте [Claude Code](#claude-code)).

**Mac**

1. Изтеглете инсталатора за Mac (`Fontes-Installer-…-mac.zip`) от
   [последната версия](https://github.com/ykarapazar/fontes/releases/latest) и щракнете двукратно
   върху него, за да го разархивирате.
2. Щракнете двукратно върху **Fontes Installer**. Ако Mac попита дали да отвори приложение,
   изтеглено от интернет, щракнете върху **Open**.
3. Изберете **Инсталиране** и щракнете върху **OK**. Настройването отнема около минута.
4. Появява се съобщение със списък на настроените приложения. Щракнете върху **Готово**, след това
   отворете отново тези приложения. За да добавите първо незадължителните безплатни ключове,
   щракнете вместо това върху **Добавяне на ключове**; вижте
   [Стъпката с ключовете](#стъпката-с-ключовете).

**Windows**

1. Изтеглете инсталатора за Windows (`Fontes-Setup-….exe`) от [последната версия](https://github.com/ykarapazar/fontes/releases/latest) и щракнете двукратно върху него.
   - Ако Windows покаже „Windows protected your PC“: щракнете **More info**, след това
     **Run anyway**.
2. Щракнете **Инсталиране**. Отваря се прозорец и настройва Fontes.
3. Когато ви попита дали да се изпращат анонимни броячи за използването, натиснете Enter, за да
   откажете.
4. Пита дали да добавите ключове сега. Натиснете Enter, за да пропуснете; вижте
   [Стъпката с ключовете](#стъпката-с-ключовете).
5. Когато се появи **Done**, отворете отново приложенията си с ИИ. Ако някое от тях все още е
   работило, затворете го напълно (включително от системната област, до часовника) и го
   отворете отново.

Накрая инсталаторът изброява приложенията, които е настроил.

### Кои приложения настройва

Той настройва дадено приложение само ако папката с настройките на това приложение вече
съществува на компютъра ви. Claude Code се настройва само ако съществува `~/.claude.json`.
Claude Desktop се настройва винаги. Всяко приложение получава един запис, `fontes`, в този файл:

| Приложение | Файл (Mac и Linux) | Файл (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`, както и собственото копие на версията от Microsoft Store |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` или `~/.codeium/windsurf/mcp_config.json` в по-стари версии | `%APPDATA%\devin\mcp_config.json` или `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code се настройва, ако съществува `~/.copilot` или собствената папка с настройки на VS Code.

Две приложения изискват още една стъпка:

- **Windsurf:** след като го отворите отново, щракнете бутона за опресняване в Cascade.
- **Cline в старото разширение за VS Code:** добавете Fontes ръчно (вижте [Cline](#други-приложения)).

### Стъпката с ключовете

Веднага след инсталирането инсталаторът предлага да добави безплатни ключове за Франция и САЩ.
За да ги добавите или промените по-късно:

- **Mac:** отворете отново **Fontes Installer** и изберете **Добавяне или промяна на ключове**.
- **Windows:** отворете менюто Start, после **Fontes** → **Добавяне или промяна на ключове**.

Въвежданото не се показва. Ключовете се записват във всяко приложение, в което вече има Fontes.
След това затворете и отворете отново приложенията. Откъде да вземете ключовете и какво
отключват: [KEYS.md](KEYS.md).

### Резервни копия, повторни стартирания и премахване

Инсталаторът променя само записа `fontes`. Всички други настройки и коментари остават както са
си. Преди да промени даден файл, той запазва до него копие с име
`<file>.fontes-backup-<date>`. Копията, направени след добавянето на ключове, съдържат тези
ключове: изтрийте онези, които вече не ви трябват. Той инсталира и uv. Повторното стартиране е
безопасно: поправя настройката и не променя нищо друго.

За да премахнете Fontes, отворете **Fontes Installer** и изберете **Премахване** (Mac) или
премахнете **Fontes** от Settings → Apps (Windows). Той премахва записа `fontes`, заедно
с ключовете, от всяко приложение. Другите ви настройки и резервните копия остават.

## Актуализации

- **Инсталаторът и файлът `.mcpb`:** не е нужно да правите нищо. Веднъж дневно, когато
  приложението ви стартира, Fontes проверява във фонов режим за нова версия и я подготвя;
  следващото стартиране я използва. Ако актуализацията не може да бъде изтеглена или не работи,
  Fontes продължава да използва версията, която е работила.
- **`uvx`:** Fontes ви казва, когато излезе нова версия, в началото на списъка си с юрисдикции.
  За да стартирате винаги най-новата версия, използвайте `fontes-mcp@latest` вместо `fontes-mcp`.

Нищо за вас или за вашите търсения не се изпраща никъде за целта.

## Поверителност

По подразбиране Fontes не изпраща нищо за вас или за вашите търсения. Броячите за
използването се изпращат само с ваше съгласие (opt-in), а доклад за грешка — само след като сте
го видели и потвърдили. Подробности: [PRIVACY.md](PRIVACY.md).

## Деинсталиране

Изтрийте записа `fontes` от MCP настройките на приложението си (в Claude Code:
`claude mcp remove fontes`), след това затворете и отворете отново приложението.

## Добре е да знаете

Fontes чете публично достъпни източници, предимно сайтове на съдилища и държавни институции.
Неофициалните източници той отбелязва в отговорите си. Винаги отваряйте връзката към
източника, преди да разчитате на решение или разпоредба.

Ако нещо се обърка, пишете на fontesmcp@proton.me какво сте направили и каква грешка сте видели.

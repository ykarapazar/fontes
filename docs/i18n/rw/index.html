Amategeko y'amafasi y'ubutabera arenga 120, ku ntera y'ikibazo kimwe.

Beta · ubuntu · kode ifunguye · inkomoko zigenzurwa buri munsi

Fontes ni seriveri MCP y'ubuntu ifite kode ifunguye. Ikora muri porogaramu iyo ari yo yose ishobora gukoresha seriveri ya Model Context Protocol iri kuri mudasobwa: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio n'izindi. Baza ikibazo cy'amategeko mu rurimi rusanzwe: porogaramu yawe ya AI ishakisha ibyemezo by'inkiko n'amategeko ako kanya ku mbuga za Leta n'iz'inkiko, mu mafasi y'ubutabera arenga 120 no mu nkiko mpuzamahanga, kandi igaha buri gisubizo ihuza rijya ku nyandiko y'umwimerere. Yakorewe abanyamategeko n'abashakashatsi mu mategeko, n'umuntu wese ushaka gusoma amategeko aho akomoka.

Iyi ni inyandiko yahinduwe hifashishijwe imashini. Inyandiko y'Icyongereza ni yo ifite agaciro.

Icyo ikora

  • Ishakisha imanza n'amategeko mu gihe ubajije, ku rubuga cyangwa API by'utangaza ubwe.
  • Buri gisubizo kivuga inkomoko yacyo kandi gifite ihuza rijyayo, kugira ngo ubashe kugenzura inyandiko y'umwimerere.
  • Fontes ntibika ububiko bw'amakuru kandi ntikenera konti. Ibibazo byawe bijya gusa ku nkomoko irimo gushakishwamo. Imibare y'ikoreshwa na raporo z'amakosa ni ku bushake bwawe (opt-in).

Fontes ni ubufasha mu bushakashatsi, si inama mu by'amategeko, kandi kuyikoresha ntibitera umubano w'umunyamategeko n'umukiliya. Itangwa "uko iri", nta garanti (reba uruhushya rwa Apache 2.0). Inkomoko zimwe ni verisiyo zivuga ku mugaragaro ko atari iza Leta, kandi buri nkomoko ifite amabwiriza yayo y'ikoreshwa; Fontes ibivuga mu bisubizo byayo. Soma icyemezo cyose cyangwa ingingo yose mbere yo kuyishingiraho. Fontes irigenga kandi ntifitanye isano n'urukiko, Leta cyangwa utangaza uwo ari we wese.

Kuyishyiraho

  • Claude Desktop: kuramo dosiye .mcpb ya Fontes muri verisiyo iheruka, uyikandeho kabiri, hanyuma ukande Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline n'izindi porogaramu: ongeraho Fontes mu igenamiterere rya MCP rya porogaramu. Nyinshi zemera iki cyanditswe; ubuyobozi bwo kuyishyiraho butanga dosiye n'agace ka kode kuri buri porogaramu.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx iza hamwe na uv. Kuri macOS cyangwa Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Kuri Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Hanyuma ongera utangize porogaramu ubaze: "Ni ayahe mafasi y'ubutabera Fontes ishobora gushakishamo?"

Porogaramu yo gushyiraho ukanze rimwe ya Mac na Windows iri hafi. Ishyira Fontes muri Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio na Cline, muri buri imwe iri kuri mudasobwa yawe, hanyuma ikagusaba niba yakongeraho imfunguzo zawe. Funga izo porogaramu mbere yo kuyikoresha. Ibisobanuro biri mu buyobozi bwo kuyishyiraho. Inkomoko zimwe zikenera urufunguzo rw'ubuntu: reba KEYS.md.

Fontes ifite kode ifunguye, munsi y'uruhushya rwa Apache 2.0. Inyandiko z'amategeko zikomeza kugengwa n'uruhushya rwa buri uzitangaza.

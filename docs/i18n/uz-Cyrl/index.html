Нима қилади

  • Суд амалиёти ва қонунчиликни сиз сўраган пайтда нашр этувчининг ўз сайтидан ёки API'сидан қидиради.

  • Fontes маълумотлар базасини юритмайди ва ҳисоб қайдномаси талаб қилмайди. Саволларингиз фақат қидирилаётган манбага боради. Фойдаланиш ҳисоблари ва хатолик ҳисоботлари фақат розилигингиз билан юборилади.

Fontes — тадқиқот учун ёрдамчи восита, ҳуқуқий маслаҳат эмас, ва ундан фойдаланиш адвокат ва мижоз муносабатини юзага келтирмайди. У “борича”, ҳеч қандай кафолатсиз тақдим этилади (қаранг: Apache 2.0 лицензияси). Баъзи манбалар очиқдан-очиқ норасмий таҳрирлардир ва ҳар бирининг ўз фойдаланиш шартлари бор; Fontes буни жавобларида айтади. Таянишдан олдин қарор ёки моддани тўлиқ ўқинг. Fontes мустақил ва ҳеч қандай суд, давлат органи ёки нашр этувчи билан боғлиқ эмас.

  • Claude Desktop: Fontes .mcpb файлини охирги релиздан юклаб олинг, уни икки марта босинг, сўнг Install ни босинг.

  • Claude Code: claude mcp add fontes -- uvx fontes-mcp

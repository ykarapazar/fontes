# Fontes'ни ўрнатиш

Fontes AI иловангизга 120 дан ортиқ юрисдикцияда суд қарорлари ва қонунчиликни суд ва давлат
сайтларидан жонли қидириш имконини беради. Ҳар бир натижа асл нусхага ҳавола беради. Бу
стандарт MCP сервер, шунинг учун у маҳаллий MCP серверни ишга тушира оладиган ҳар қандай
иловада ишлайди: Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub Copilot), Gemini CLI,
Windsurf, Zed, LM Studio, Cline ва бошқалар.

Иловангизни танланг, унинг қадамларини бажаринг, сўнг [ишлаётганини текширинг](#ишлаётганини-текшириш).

## Claude Desktop

1. Fontes `.mcpb` файлини [охирги релиз](https://github.com/ykarapazar/fontes/releases/latest)
   саҳифасидан юклаб олинг.
2. Уни икки марта босинг. Claude Desktop уни очади.
3. **Install** тугмасини босинг.

## Codex

Терминалда:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI ва Codex IDE кенгайтмаси бу созламани биргаликда ишлатади (`~/.codex/config.toml`).
Сизга [uv](#uv-керак) керак.

## Claude Code

Терминалда:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Сизга [uv](#uv-керак) керак.

## Бошқа иловалар

Буларнинг ҳар бирига [uv](#uv-керак) керак. Ёзувни қўшинг, сақланг, сўнг иловани ёпиб, қайта
очинг.

**Cursor:** `~/.cursor/mcp.json` (барча лойиҳалар) ёки `.cursor/mcp.json` (битта лойиҳа) файлида:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette'дан **MCP: Add Server** ни ишга туширинг,
**Command (stdio)** ни танланг, `uvx fontes-mcp` ни киритинг ва серверга `fontes` деб ном беринг.
Ёки буни `~/.copilot/mcp-config.json` га қўшинг:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

VS Code'нинг эски созламаларида `.vscode/mcp.json` ишлатилади, у ерда юқори даражадаги калит
`mcpServers` эмас, `servers` бўлади.

**Gemini CLI:** терминалда `gemini mcp add -s user fontes uvx fontes-mcp`. Ёки буни
`~/.gemini/settings.json` га қўшинг:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** созламалар файлини очинг (**zed: open settings file**) ва қўшинг:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** ўнг томондаги панелда **Program** ёрлиғини очинг, **Install → Edit mcp.json**
ни босинг ва қўшинг:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** белгисини босинг, **Configure** ёрлиғини очинг, **Configure MCP
Servers** ни босинг ва LM Studio'дагидек `mcpServers` ёзувини қўшинг.

**Claude Desktop, қўлда** (`.mcpb` файли ўрнига): худди шу `mcpServers` ёзувини
`claude_desktop_config.json` га қўшинг (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**Бошқа ҳар қандай MCP илова** (Windsurf ва бошқалар): MCP серверларини қаерда сақлаши унинг
ўз ҳужжатларида кўрсатилган. Аксарияти худди шу ёзувни қабул қилади: буйруқ `uvx`, аргумент
`fontes-mcp`.

Агар илова `uvx` ни топа олмаса, унинг тўлиқ йўлидан фойдаланинг (macOS ва Linux'да `which uvx`
уни кўрсатади).

## uv керак

Codex, Claude Code ва бошқа иловалар Fontes'ни `uvx` билан ишга туширади; у Astral'нинг кичик,
бепул воситаси **uv** билан бирга келади. Уни ўрнатиш учун
[Astral қўлланмасига](https://docs.astral.sh/uv/getting-started/installation/) қаранг ёки
ишга туширинг:

- macOS ёки Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

Янги суҳбатда сўранг: *“Fontes қайси юрисдикцияларда қидира олади?”* Илова мамлакатлар

## Бир босишда ўрнатувчи (Mac ва Windows)

Ўрнатувчи Fontes'ни барча иловаларингизда бирданига созлайди: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio ва Cline.

**Бошлашдан олдин:** бу иловаларнинг ҳар бирини бутунлай ёпинг. Бу айниқса Claude Code учун
муҳим: у ишлаб турганда `~/.claude.json` ни қайта ёзади ва ўрнатувчининг ўзгаришини бекор
қилиши мумкин. Агар Claude Code'ни ёпа олмасангиз, Fontes'ни унга `claude mcp add` орқали
қўшинг (қаранг [Claude Code](#claude-code)).

**Mac**

1. Mac учун ўрнатувчини (`Fontes-Installer-…-mac.zip`)
   [охирги релиз](https://github.com/ykarapazar/fontes/releases/latest) саҳифасидан юклаб олинг ва архивдан чиқариш учун уни икки марта босинг.
2. **Fontes Installer** ни икки марта босинг. Агар Mac интернетдан юклаб олинган иловани
   очиш-очмасликни сўраса, **Open** ни босинг.
3. **Ўрнатиш** ни танланг ва **OK** ни босинг. Созлаш тахминан бир дақиқа давом этади.
4. Хабарда у созлаган иловалар рўйхати чиқади. **Тайёр** ни босинг, сўнг бу иловаларни қайта
   очинг. Аввал ихтиёрий бепул калитларни қўшиш учун эса **Калитларни қўшиш** ни босинг; қаранг
   [Калитлар босқичи](#калитлар-босқичи).

**Windows**

1. Windows ўрнатувчисини (`Fontes-Setup-….exe`) [охирги релиз](https://github.com/ykarapazar/fontes/releases/latest) саҳифасидан юклаб олинг ва уни икки марта босинг.
   - Агар Windows “Windows protected your PC” деб кўрсатса: **More info** ни, сўнг **Run anyway**
     ни босинг.
2. **Ўрнатиш** ни босинг. Ойна очилади ва Fontes'ни созлайди.
3. Аноним фойдаланиш ҳисобларини юбориш-юбормаслик сўралганда, “йўқ” учун Enter тугмасини
   босинг.
4. У калитларни ҳозир қўшиш-қўшмасликни сўрайди. Ўтказиб юбориш учун Enter тугмасини босинг;
   қаранг [Калитлар босқичи](#калитлар-босқичи).
5. У **Тайёр** деганда, AI иловаларингизни қайта очинг. Агар улардан бири ҳали ишлаб турган
   бўлса, уни бутунлай ёпинг (соат ёнидаги тизим трейидан ҳам) ва қайта очинг.

Охирида ўрнатувчи ўзи созлаган иловалар рўйхатини чиқаради.

### У қайси иловаларни созлайди

У иловани фақат шу илованинг созламалар жилди компьютерингизда аллақачон мавжуд бўлса
созлайди. Claude Code фақат `~/.claude.json` мавжуд бўлса созланади. Claude Desktop ҳар доим
созланади. Ҳар бир илова ушбу файлда битта `fontes` ёзувини олади:

| Илова | Файл (Mac ва Linux) | Файл (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` ва Microsoft Store версиясининг ўз нусхаси |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`, эски версияларда эса `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` ёки `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code, агар `~/.copilot` ёки VS Code'нинг ўз созламалар жилди мавжуд бўлса созланади.

Икки илова учун яна битта қадам керак:

- **Windsurf:** уни қайта очгандан кейин Cascade'да янгилаш тугмасини босинг.
- **Эски VS Code кенгайтмаси ичидаги Cline:** Fontes'ни қўлда қўшинг (қаранг [Cline](#бошқа-иловалар)).

### Калитлар босқичи

Ўрнатишдан сўнг дарҳол ўрнатувчи Франция ва АҚШ учун бепул калитларни қўшишни таклиф қилади.
Уларни кейинроқ қўшиш ёки ўзгартириш учун:

- **Mac:** **Fontes Installer** ни қайта очинг ва **Калитларни қўшиш ёки ўзгартириш** ни танланг.
- **Windows:** **Start** менюсини очинг, сўнг **Fontes** → **Калитларни қўшиш ёки ўзгартириш**.

Ёзилаётган матн яширин бўлади. Калитлар Fontes аллақачон мавжуд бўлган ҳар бир иловага
киритилади. Шундан сўнг иловаларни ёпиб, қайта очинг. Калитларни қаердан олиш ва улар нимани
очиши: [KEYS.md](KEYS.md).

### Заҳира нусхалар, қайта ишга тушириш ва олиб ташлаш

Ўрнатувчи фақат `fontes` ёзувини ўзгартиради. Бошқа барча созламалар ва изоҳлар қандай бўлса,
шундай қолади. Файлни ўзгартиришдан олдин у унинг ёнида `<file>.fontes-backup-<date>` номли
нусхасини сақлайди. Калитларни қўшганингиздан кейин яратилган нусхаларда шу калитлар бўлади:
кераги бўлмаганларини ўчиринг. У uv'ни ҳам ўрнатади. Уни қайта ишга тушириш хавфсиз: у
созламани тиклайди ва бошқа ҳеч нарсани ўзгартирмайди.

Fontes'ни олиб ташлаш учун **Fontes Installer** ни очинг ва **Олиб ташлаш** ни танланг (Mac) ёки
Windows'да Созламалар → Иловалар бўлимидан **Fontes**'ни ўчиринг. У `fontes` ёзувини калитлар билан бирга ҳар бир иловадан олиб
ташлайди. Бошқа созламаларингиз ва заҳира нусхалар қолади.

## Янгиланишлар

- **Ўрнатувчи ва `.mcpb` файли:** сиз ҳеч нарса қилишингиз шарт эмас. Кунига бир марта илова
  ишга тушганда Fontes фонда янги версияни текширади ва уни тайёрлаб қўяди; илова кейинги
  сафар ишга тушганда ундан фойдаланади. Агар янгиланишни юклаб олиб бўлмаса ёки у ишламаса,
  Fontes ишлаган версиядан фойдаланишда давом этади.
- **`uvx`:** янги версия мавжуд бўлганда Fontes бу ҳақда юрисдикциялар рўйхатининг бошида
  хабар беради. Ҳар доим энг янги версияни ишлатиш учун `fontes-mcp` ўрнига `fontes-mcp@latest` дан
  фойдаланинг.

Бунинг учун сиз ёки қидирувларингиз ҳақида ҳеч қандай маълумот ҳеч қаерга юборилмайди.

## Махфийлик

Fontes стандарт ҳолатда сиз ёки қидирувларингиз ҳақида ҳеч нарса юбормайди. Фойдаланиш
ҳисоблари фақат розилигингиз билан юборилади, хатолик ҳисоботи эса фақат уни кўриб,
тасдиқлаганингиздан кейин юборилади. Батафсил: [PRIVACY.md](PRIVACY.md).

## Олиб ташлаш

`fontes` ёзувини иловангизнинг MCP созламаларидан олиб ташланг (Claude Code'да:
`claude mcp remove fontes`), сўнг иловани ёпиб, қайта очинг.

## Билиш фойдали

Fontes очиқ манбаларни, асосан суд ва давлат сайтларини ўқийди. Жавобларида норасмий
манбаларни белгилайди. Қарор ёки моддага таянишдан олдин ҳар доим манба ҳаволасини очинг.

Агар бирор нарса нотўғри кетса, нима қилганингиз ва қандай хатони кўрганингизни
fontesmcp@proton.me манзилига ёзинг.

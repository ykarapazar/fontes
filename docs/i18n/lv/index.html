Fontes ir bezmaksas atvērtā koda MCP serveris. Tas darbojas jebkurā lietotnē, kas var palaist lokālu Model Context Protocol serveri: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio un citās. Uzdodiet juridisku jautājumu vienkāršā valodā: jūsu MI lietotne tiešsaistē meklē tiesu nolēmumus un tiesību aktus valsts iestāžu un tiesu tīmekļa vietnēs vairāk nekā 120 jurisdikcijās un starptautiskajās tiesās un katram rezultātam sniedz saiti uz oriģinālu. Tas ir radīts juristiem un tiesību pētniekiem, kā arī ikvienam, kas vēlas lasīt tiesības to avotā.

Ko tas dara

  • Meklē tiesu praksi un tiesību aktus brīdī, kad jūs jautājat, pašā izdevēja tīmekļa vietnē vai tā API.
  • Katrs rezultāts nosauc savu avotu un sniedz saiti uz to, lai jūs varētu pārbaudīt oriģinālu.
  • Fontes neuztur datubāzi, un tam nav vajadzīgs konts. Jūsu jautājumi nonāk tikai avotā, kurā tiek meklēts. Lietojuma skaitļi un kļūdu ziņojumi tiek sūtīti tikai ar jūsu piekrišanu (opt-in).

Fontes ir izpētes palīglīdzeklis, nevis juridiska konsultācija, un tā lietošana nenodibina advokāta un klienta attiecības. Tas tiek nodrošināts “tāds, kāds ir” (“as is”), bez garantijām (skatiet Apache 2.0 licenci). Daži avoti ir skaidri norādītas neoficiālas versijas, un katram ir savi lietošanas noteikumi; Fontes to norāda savās atbildēs. Pirms paļaujaties uz nolēmumu vai normu, izlasiet to pilnībā. Fontes ir neatkarīgs un nav saistīts ne ar vienu tiesu, valdību vai izdevēju.

Instalēšana

Fontes vēl nav PyPI. Šīs darbības darbosies, kad būs iznākusi pirmā versija.

  • Claude Desktop: lejupielādējiet Fontes .mcpb failu no jaunākās versijas, veiciet uz tā dubultklikšķi, pēc tam noklikšķiniet uz Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline un citas lietotnes: pievienojiet Fontes lietotnes MCP iestatījumiem. Lielākā daļa pieņem šo ierakstu; instalēšanas ceļvedī katrai lietotnei ir norādīts fails un fragments.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx ir iekļauts uv. macOS vai Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Pēc tam restartējiet lietotni un pajautājiet: “Kurās jurisdikcijās Fontes var meklēt?”

Drīzumā būs pieejams Mac un Windows instalētājs ar vienu klikšķi. Tas iestata Fontes programmās Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio un Cline – katrā, kas ir jūsu datorā –, pēc tam piedāvā pievienot jūsu atslēgas. Pirms tā palaišanas aizveriet šīs lietotnes. Sīkāk instalēšanas ceļvedī. Dažiem avotiem vajadzīga bezmaksas atslēga: skatiet KEYS.md.

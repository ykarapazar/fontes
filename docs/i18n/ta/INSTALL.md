> இது இயந்திர உதவியுடன் செய்யப்பட்ட மொழிபெயர்ப்பு. ஆங்கிலப் பதிப்பே அதிகாரப்பூர்வமானது.

# Fontes-ஐ நிறுவுதல்

120-க்கும் மேற்பட்ட அதிகார வரம்புகளில் நீதிமன்ற மற்றும் அரசு இணையதளங்களில் நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும்
நேரடியாகத் தேட Fontes உங்கள் AI செயலிக்கு உதவுகிறது. ஒவ்வொரு முடிவும் மூல ஆவணத்துக்கான இணைப்பைத் தருகிறது. இது ஒரு நிலையான MCP
server, எனவே உள்ளூர் MCP server-ஐ இயக்கக்கூடிய எந்தச் செயலியிலும் இது வேலை செய்கிறது: Claude Desktop, Codex, Claude
Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline மற்றும் பிற.

**Fontes இன்னும் PyPI-இல் இல்லை.** முதல் வெளியீடு வந்ததும் கீழே உள்ள படிகள் வேலை செய்யும்.

உங்கள் செயலியைத் தேர்ந்தெடுத்து, அதன் படிகளைப் பின்பற்றி, பின்னர் [இது வேலை செய்கிறதா எனச் சரிபார்க்கவும்](#இது-வேலை-செய்கிறதா-எனச்-சரிபார்த்தல்).

## Claude Desktop

1. [சமீபத்திய வெளியீட்டிலிருந்து](https://github.com/ykarapazar/fontes/releases/latest) Fontes `.mcpb` கோப்பைப்
   பதிவிறக்கவும்.
2. அதை இருமுறை சொடுக்கவும். Claude Desktop அதைத் திறக்கும்.
3. **Install** என்பதைச் சொடுக்கவும்.

## Codex

ஒரு முனையத்தில் (terminal):

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI-உம் Codex IDE நீட்டிப்பும் இந்த அமைப்பைப் (`~/.codex/config.toml`) பகிர்ந்துகொள்கின்றன.
உங்களுக்கு [uv](#உங்களுக்கு-uv-தேவை) தேவை.

## Claude Code

ஒரு முனையத்தில் (terminal):

```bash
claude mcp add fontes -- uvx fontes-mcp
```

உங்களுக்கு [uv](#உங்களுக்கு-uv-தேவை) தேவை.

## பிற செயலிகள்

இவை ஒவ்வொன்றுக்கும் [uv](#உங்களுக்கு-uv-தேவை) தேவை. பதிவைச் சேர்த்து, சேமித்து, பின்னர் செயலியை மூடி மீண்டும் திறக்கவும்.

**Cursor:** `~/.cursor/mcp.json` (அனைத்துத் திட்டங்களுக்கும்) அல்லது `.cursor/mcp.json` (ஒரு திட்டத்துக்கு) கோப்பில்:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** Command Palette-இலிருந்து **MCP: Add Server**-ஐ இயக்கி, **Command (stdio)**-ஐத்
தேர்ந்தெடுத்து, `uvx fontes-mcp` என உள்ளிட்டு, server-க்கு `fontes` எனப் பெயரிடவும். அல்லது இதை
`~/.copilot/mcp-config.json`-இல் சேர்க்கவும்:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

பழைய VS Code அமைப்புகள் `.vscode/mcp.json`-ஐப் பயன்படுத்துகின்றன; அங்கே மேல்நிலை key `mcpServers`-க்குப் பதிலாக
`servers` ஆகும்.

**Gemini CLI:** ஒரு முனையத்தில், `gemini mcp add -s user fontes uvx fontes-mcp`. அல்லது இதை
`~/.gemini/settings.json`-இல் சேர்க்கவும்:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** உங்கள் அமைப்புக் கோப்பைத் திறந்து (**zed: open settings file**) இதைச் சேர்க்கவும்:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** வலது பக்கப் பட்டியில் **Program** தாவலைத் திறந்து, **Install → Edit
mcp.json**-ஐச் சொடுக்கி, இதைச் சேர்க்கவும்:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** **MCP Servers** சின்னத்தைச் சொடுக்கி, **Configure** தாவலைத் திறந்து, **Configure MCP
Servers**-ஐச் சொடுக்கி, LM Studio-க்குச் சேர்த்த அதே `mcpServers` பதிவைச் சேர்க்கவும்.

**Claude Desktop, கையால்** (`.mcpb` கோப்புக்குப் பதிலாக): அதே `mcpServers` பதிவை
`claude_desktop_config.json`-இல் சேர்க்கவும் (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**வேறு எந்த MCP செயலியும்** (Windsurf மற்றும் பிற): அது தன் MCP server-களை எங்கே வைத்திருக்கிறது என்று அதன் சொந்த
ஆவணங்கள் கூறும். பெரும்பாலானவை அதே பதிவை ஏற்கின்றன: கட்டளை `uvx`, argument `fontes`.

செயலியால் `uvx`-ஐக் கண்டுபிடிக்க முடியவில்லை என்றால், அதன் முழுப் பாதையைப் பயன்படுத்தவும் (macOS மற்றும் Linux-இல், `which uvx` அதைக் காட்டும்).

## உங்களுக்கு uv தேவை

Codex, Claude Code மற்றும் பிற செயலிகள் Fontes-ஐ `uvx` மூலம் தொடங்குகின்றன; அது Astral வழங்கும் சிறிய இலவசக் கருவியான
**uv**-உடன் வருகிறது. அதை நிறுவ,
[Astral-இன் வழிகாட்டியைப்](https://docs.astral.sh/uv/getting-started/installation/) பார்க்கவும், அல்லது இயக்கவும்:

- macOS அல்லது Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## விசைகள்

சில மூலங்களுக்கு இலவச விசை தேவை: [KEYS.md](KEYS.md) பார்க்கவும்.

## இது வேலை செய்கிறதா எனச் சரிபார்த்தல்

ஒரு புதிய உரையாடலில் கேளுங்கள்: *"Fontes எந்த அதிகார வரம்புகளில் தேட முடியும்?"* செயலி நாடுகளின் பட்டியலுடன்
பதிலளிக்க வேண்டும். அவ்வாறு இல்லையென்றால், செயலியை இன்னொரு முறை மூடி மீண்டும் திறக்கவும்.

## ஒரே சொடுக்கு நிறுவி (வரவிருக்கிறது)

உங்கள் எல்லாச் செயலிகளிலும் ஒரே நேரத்தில் Fontes-ஐ அமைக்கும் Mac மற்றும் Windows நிறுவி வரவிருக்கிறது. அது
Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI,
Zed, LM Studio மற்றும் Cline ஆகியவற்றை அமைக்கிறது. அது வெளியிடப்பட்டதும்:

**தொடங்குவதற்கு முன்:** இந்தச் செயலிகள் ஒவ்வொன்றையும் முழுமையாக மூடவும். Claude Code-க்கு இது மிக முக்கியம்:
அது இயங்கும்போது `~/.claude.json`-ஐ மீண்டும் எழுதுகிறது, நிறுவியின் மாற்றத்தைச் செயல்தவிர்க்கக்கூடும். Claude Code-ஐ
மூட முடியாவிட்டால், அதற்குப் பதிலாக `claude mcp add` மூலம் Fontes-ஐ அதில் சேர்க்கவும் ([Claude Code](#claude-code) பார்க்கவும்).

**Mac**

1. பதிவிறக்கிய **Fontes Installer** கோப்புறையைத் திறக்கவும்.
2. **Install Fontes.command**-ஐ இருமுறை சொடுக்கவும்.
   - உங்கள் Mac அது "cannot be opened because it is from an unidentified developer" என்று கூறினால்:
     கோப்பின் மீது வலது-சொடுக்கு (அல்லது Control-சொடுக்கு) செய்து, **Open**-ஐத் தேர்ந்தெடுத்து, பின்னர் மீண்டும் **Open**-ஐத் தேர்ந்தெடுக்கவும்.
     இதை ஒருமுறை மட்டுமே செய்ய வேண்டும்.
3. ஒரு சாளரம் திறந்து, அநாமதேய பயன்பாட்டு எண்ணிக்கைகளை அனுப்பவா என்று கேட்கும்; வேண்டாம் என்பதற்கு Enter அழுத்தவும்.
4. இப்போது விசைகளைச் சேர்க்கவா என்று அது கேட்கும். தவிர்க்க Enter அழுத்தவும்; [விசைகளைச் சேர்க்கும் படி](#விசைகளைச்-சேர்க்கும்-படி) பார்க்கவும்.
5. அது **Done** என்று கூறியதும், உங்கள் AI செயலிகளை மீண்டும் திறக்கவும்.

**Windows**

1. பதிவிறக்கிய **Fontes Installer**-ஐ unzip செய்யவும் (வலது-சொடுக்கு → Extract All).
2. **Install Fontes.cmd**-ஐ இருமுறை சொடுக்கவும்.
   - Windows "Windows protected your PC" என்று காட்டினால்: **More info**-ஐச் சொடுக்கி, பின்னர் **Run anyway**-ஐச் சொடுக்கவும்.
3. அநாமதேய பயன்பாட்டு எண்ணிக்கைகளை அனுப்பவா என்று கேட்கப்படும்போது, வேண்டாம் என்பதற்கு Enter அழுத்தவும்.
4. இப்போது விசைகளைச் சேர்க்கவா என்று அது கேட்கும். தவிர்க்க Enter அழுத்தவும்; [விசைகளைச் சேர்க்கும் படி](#விசைகளைச்-சேர்க்கும்-படி) பார்க்கவும்.
5. அது **Done** என்று கூறியதும், உங்கள் AI செயலிகளை மீண்டும் திறக்கவும். ஏதேனும் ஒன்று இன்னும் இயங்கிக்கொண்டிருந்தால், அதை
   முழுமையாக மூடி (கடிகாரத்துக்கு அருகில் உள்ள system tray-இலிருந்தும்) மீண்டும் திறக்கவும்.

இறுதியில், தான் அமைத்த செயலிகளை நிறுவி பட்டியலிடும்.

### இது எந்தச் செயலிகளை அமைக்கிறது

ஒரு செயலியின் அமைப்புக் கோப்புறை ஏற்கெனவே உங்கள் கணினியில் இருந்தால் மட்டுமே அது அந்தச் செயலியை அமைக்கிறது. `~/.claude.json`
இருந்தால் மட்டுமே Claude Code அமைக்கப்படும். Claude Desktop எப்போதும் அமைக்கப்படும். ஒவ்வொரு செயலிக்கும் இந்தக் கோப்பில்
`fontes` என்ற ஒரு பதிவு கிடைக்கும்:

| செயலி | கோப்பு (Mac மற்றும் Linux) | கோப்பு (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`, மற்றும் Microsoft Store பதிப்பின் சொந்த நகல் |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json`, அல்லது பழைய பதிப்புகளில் `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json`, அல்லது `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

`~/.copilot` அல்லது VS Code-இன் சொந்த அமைப்புக் கோப்புறை இருந்தால் VS Code அமைக்கப்படும்.

இரண்டு செயலிகளுக்கு இன்னும் ஒரு படி தேவை:

- **Windsurf:** அதை மீண்டும் திறந்த பிறகு, Cascade-இல் refresh அழுத்தவும்.
- **பழைய VS Code நீட்டிப்புக்குள் உள்ள Cline:** Fontes-ஐக் கையால் சேர்க்கவும் ([Cline](#பிற-செயலிகள்) பார்க்கவும்).

### விசைகளைச் சேர்க்கும் படி

நிறுவிய உடனேயே, இலவச பிரான்ஸ் மற்றும் US விசைகளைச் சேர்க்க நிறுவி முன்வருகிறது. பின்னர் அவற்றைச் சேர்க்க அல்லது
மாற்ற:

- **Mac:** நிறுவி கோப்புறையில் உள்ள **Add or change keys.command**-ஐ இருமுறை சொடுக்கவும், அல்லது
  Fontes Installer செயலியை மீண்டும் திறந்து **Add or change keys**-ஐத் தேர்ந்தெடுக்கவும்.
- **Windows:** நிறுவி கோப்புறையில் உள்ள **Add or change keys.cmd**-ஐ இருமுறை சொடுக்கவும்.

தட்டச்சு செய்வது மறைக்கப்படும். Fontes ஏற்கெனவே உள்ள ஒவ்வொரு செயலியிலும் விசைகள் சேர்க்கப்படும். அதன்பின் செயலிகளை மூடி
மீண்டும் திறக்கவும். விசைகளை எங்கே பெறுவது, அவை எதைத் திறக்கின்றன: [KEYS.md](KEYS.md).

### காப்பு நகல்கள், மீண்டும் இயக்குதல் மற்றும் நீக்குதல்

நிறுவி `fontes` பதிவை மட்டுமே மாற்றுகிறது. மற்ற ஒவ்வொரு அமைப்பும் கருத்துரையும் (comment) முன்பு இருந்தபடியே இருக்கும்.
ஒரு கோப்பை மாற்றுவதற்கு முன், அது அதன் அருகில் `<file>.fontes-backup-<date>` என்ற பெயரில் ஒரு நகலைச் சேமிக்கிறது. நீங்கள்
விசைகளைச் சேர்த்த பிறகு உருவான நகல்களில் அந்த விசைகள் இருக்கும்: உங்களுக்கு இனி தேவையில்லாதவற்றை நீக்கவும். அது uv-ஐயும்
நிறுவுகிறது. அதை மீண்டும் இயக்குவது பாதுகாப்பானது: அது அமைப்பைச் சரிசெய்கிறது, வேறு எதையும் மாற்றுவதில்லை.

Fontes-ஐ நீக்க, **Uninstall Fontes.command** (Mac) அல்லது **Uninstall Fontes.cmd**
(Windows)-ஐ இருமுறை சொடுக்கவும். அது விசைகள் உட்பட `fontes` பதிவை ஒவ்வொரு செயலியிலிருந்தும் நீக்குகிறது. உங்கள் மற்ற அமைப்புகளும்
காப்பு நகல்களும் அப்படியே இருக்கும்.

## புதுப்பிப்புகள்

- **நிறுவி மற்றும் `.mcpb` கோப்பு:** நீங்கள் எதுவும் செய்ய வேண்டியதில்லை. நாளொன்றுக்கு ஒருமுறை, செயலி
  தொடங்கும்போது, Fontes பின்னணியில் புதிய பதிப்பு உள்ளதா எனச் சரிபார்த்து அதைத் தயார் செய்கிறது; அடுத்த முறை
  செயலி தொடங்கும்போது அதைப் பயன்படுத்துகிறது. ஒரு புதுப்பிப்பைப் பதிவிறக்க முடியாவிட்டால் அல்லது அது வேலை செய்யாவிட்டால், Fontes
  வேலை செய்த பதிப்பையே தொடர்ந்து பயன்படுத்துகிறது.
- **`uvx`:** புதிய பதிப்பு கிடைக்கும்போது, Fontes தன் அதிகார வரம்புப் பட்டியலின் மேலே அதை உங்களுக்குத் தெரிவிக்கிறது.
  எப்போதும் புதிய பதிப்பையே இயக்க, `fontes-mcp`-க்குப் பதிலாக `fontes-mcp@latest`-ஐப் பயன்படுத்தவும்.

இதற்காக உங்களைப் பற்றியோ உங்கள் தேடல்களைப் பற்றியோ எந்தத் தகவலும் எங்கும் அனுப்பப்படுவதில்லை.

## தனியுரிமை

Fontes இயல்பாக உங்களைப் பற்றியோ உங்கள் தேடல்களைப் பற்றியோ எதையும் அனுப்புவதில்லை. பயன்பாட்டு எண்ணிக்கைகள் நீங்கள் ஒப்புக்கொண்டால்
மட்டுமே (opt-in), பிழை அறிக்கை நீங்கள் அதைப் பார்த்து உறுதிப்படுத்திய பிறகு மட்டுமே அனுப்பப்படும். விவரங்கள்: [PRIVACY.md](PRIVACY.md).

## இதை நீக்குதல்

உங்கள் செயலியின் MCP அமைப்புகளிலிருந்து `fontes` பதிவை நீக்கவும் (Claude Code-இல்:
`claude mcp remove fontes`), பின்னர் செயலியை மூடி மீண்டும் திறக்கவும்.

## தெரிந்துகொள்ள வேண்டியவை

Fontes பொது மூலங்களைப் படிக்கிறது, பெரும்பாலும் நீதிமன்ற மற்றும் அரசு இணையதளங்கள். அதிகாரப்பூர்வமற்றவற்றை அது தன் பதில்களில்
குறிக்கிறது. ஒரு தீர்ப்பையோ சட்டப் பிரிவையோ நம்புவதற்கு முன் எப்போதும் மூல இணைப்பைத் திறக்கவும்.

ஏதாவது தவறாகப் போனால், நீங்கள் என்ன செய்தீர்கள், என்ன பிழையைப் பார்த்தீர்கள் என்பதை fontesmcp@proton.me-க்கு மின்னஞ்சல் அனுப்பவும்.

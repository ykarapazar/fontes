> இது இயந்திர உதவியுடன் செய்யப்பட்ட மொழிபெயர்ப்பு. ஆங்கிலப் பதிப்பே அதிகாரப்பூர்வமானது.

# Fontes: கேள்விகளும் பதில்களும்

## Fontes என்றால் என்ன?

இலவசமான, திறந்த மூல (open-source) MCP server (Apache 2.0). Model Context Protocol-ஐப் பேசும் எந்தச் செயலியும்
(Claude, Codex, Cursor, VS Code, Gemini CLI மற்றும் பிற) நீதிமன்ற மற்றும் அரசு இணையதளங்களில் நீதிமன்றத் தீர்ப்புகளையும்
சட்டவாக்கத்தையும் 125 அதிகார வரம்புகளிலும் சர்வதேச நீதிமன்றங்களிலும் நேரடியாகத் தேட இது உதவுகிறது; மேலும் Lexifina-வின்
பதிவு வழியாக 91 கூடுதல் நாடுகளிலும் (கீழே பார்க்கவும்). ஒவ்வொரு முடிவும் அதன் மூலத்தைப் பெயரிட்டு, மூல ஆவணத்துக்கான
இணைப்பைத் தருகிறது.

## உரைகள் அதிகாரப்பூர்வமானவையா?

பெரும்பாலும், ஆனால் எப்போதும் அல்ல.

- பெரும்பாலான மூலங்களை ஒரு நீதிமன்றம், ஓர் அமைச்சகம் அல்லது ஓர் அரசிதழ் நடத்துகிறது.
- சில ஒருங்கிணைக்கப்பட்ட (consolidated) உரைகள் அரசால் வெளியிடப்படுகின்றன, ஆனால் வெளிப்படையாகவே அதிகாரப்பூர்வமற்றவை:
  அரசிதழ் மட்டுமே மூலமானது (authentic).
- ஒரு சில மூலங்கள் அரசுத் தளங்களே அல்ல (எடுத்துக்காட்டாக LexiVox, LawPhil, Maqam,
  Wikisource).

இவற்றில் ஒன்றிலிருந்து வரும் ஒவ்வொரு பதிலிலும் Fontes "Unofficial source" (அதிகாரப்பூர்வமற்ற மூலம்) அறிவிப்பைச் சேர்க்கிறது.
எதையும் மேற்கோள் காட்டுவதற்கு முன், அதிகாரப்பூர்வ வெளியீட்டைச் சரிபார்க்கவும்.
[README](README.md#உள்ளடக்கம்)-இல் உள்ள உள்ளடக்க அட்டவணையும் `list_jurisdictions`-உம் ஒவ்வொரு அதிகார வரம்புக்குமான
மூலத்தைப் பெயரிடுகின்றன.

## இது எந்த அதிகார வரம்புகளை உள்ளடக்குகிறது, எவ்வளவு நன்றாக?

125 adapters: 108 ஐ.நா. உறுப்பு நாடுகள், ஹாங்காங், கொசோவோ, பாலஸ்தீனம், தைவான், DIFC Courts, அமெரிக்க மாநில நீதிமன்றங்கள் மற்றும் 11 சர்வதேச நீதிமன்றங்களும் அமைப்புகளும் (ஐரோப்பிய மனித உரிமைகள் நீதிமன்றம், EU, ICJ, WTO போன்றவை).

உள்ளடக்கம் பெரிதும் வேறுபடுகிறது. ஒரு கடுமையான விதியின் கீழ் (உச்ச பொது நீதிமன்றத்தின் முன்தீர்ப்புகள், அல்லது
அரசியலமைப்பும் முதன்மைச் சட்டங்களும், முழுமையாக எட்டப்பட்டால்), 125-இல் 72 உள்ளடக்கப்பட்டவையாகக் கணக்கிடப்படுகின்றன.
[COVERAGE.md](../../COVERAGE.md) ஒவ்வொரு அதிகார வரம்புக்கும், Fontes எதை எட்டுகிறது, எதை எட்டவில்லை,
ஏன் என்று பட்டியலிடுகிறது.

## எனக்கு API விசை தேவையா?

கிட்டத்தட்ட ஒவ்வொரு அதிகார வரம்புக்கும், தேவையில்லை. சில மூலங்களுக்கு இலவச விசை தேவை: [KEYS.md](KEYS.md) பார்க்கவும்.

- **பிரான்ஸ்:** ஆம். `WLM_FR_PISTE_CLIENT_ID`, `WLM_FR_PISTE_CLIENT_SECRET` ஆகியவற்றை நீங்கள் அமைக்கும் வரை
  பிரான்ஸ் முடக்கத்தில் இருக்கும். இவை Judilibre, Légifrance ஆகியவற்றுக்குச் சந்தா செய்யப்பட்ட ஒரு செயலியைக் கொண்ட
  இலவச PISTE கணக்கிலிருந்து (piste.gouv.fr) கிடைக்கின்றன.
- **அமெரிக்கா:** விருப்பத்தேர்வு. வழக்குச் சட்டத் தேடல் விசை இல்லாமலே செயல்படும், ஆனால் பகிரப்பட்ட demo விசை
  ஓர் IP முகவரிக்கு நாளொன்றுக்குச் சுமார் 10 தேடல்களை மட்டுமே அனுமதிக்கிறது. `WLM_US_GOVINFO_KEY`-இல் உள்ள
  இலவச api.data.gov விசை அந்த வரம்பை உயர்த்துகிறது.
- **அமெரிக்க மாநில நீதிமன்றங்கள்:** ஆம். மாநில வழக்குச் சட்டம் (`us-states`), `WLM_US_COURTLISTENER_KEY`-ஐ உங்கள் சொந்த இலவச CourtListener API token-க்கு அமைக்கும் வரை முடக்கத்தில் இருக்கும். CourtListener-ஐ இலாப நோக்கற்ற அமைப்பான Free Law Project நடத்துகிறது; இது அதிகாரப்பூர்வ மூலம் அல்ல, ஒவ்வொரு பதிலும் இதைத் தெரிவிக்கிறது.

இவற்றை உங்கள் செயலியின் MCP அமைப்புகளில் Fontes server-க்கான சூழல் மாறிகளாக (environment variables) அமைக்கவும்.
நிறுவிகள் நிறுவிய பிறகு இவற்றைக் கேட்கும்; அவற்றின் **Add or change keys** தொடக்கி பின்னர்
இவற்றை மாற்றும்.

தனியாக, ஒரு சில மூலங்கள் தானியங்கி அணுகலுக்கு வெளியீட்டாளரின் அனுமதி தேவை என்று தங்கள் நிபந்தனைகளில் கூறுகின்றன.
அவை OFF எனக் குறிக்கப்பட்டு, முடக்கத்திலேயே இருக்கும். விசை அதை மாற்றாது; வெளியீட்டாளரின் அனுமதி மட்டுமே
மாற்றும் (அப்போது `WLM_PERMITTED=<codes>` அமைக்கவும்).

## கடந்தகால பதிப்புகளும் கூடுதல் நாடுகளும் எங்கிருந்து வருகின்றன?

[Lexifina](https://github.com/lexifina/global-law) சுமார் 200 நாடுகளின் சட்டத்தை git வரலாறாக வைத்திருக்கிறது: ஒவ்வொரு மாற்றமும், அது நடைமுறைக்கு வந்த நாளில் தேதியிடப்பட்ட ஒரு commit. Fontes அதை Lexifina-வின் இலவச ஹோஸ்ட் செய்யப்பட்ட server வழியாகப் படிக்கிறது. இரண்டு கருவிகள் அதைப் பயன்படுத்துகின்றன: `get_law_on_date` (கடந்த ஒரு தேதியில் நடைமுறையிலிருந்த ஒரு பிரிவு, அதை மாற்றிய சட்டத்துடன்) மற்றும் `get_law_history` (ஒரு பிரிவை மாற்றிய ஒவ்வொரு சட்டமும், அல்லது இரண்டு தேதிகளுக்கு இடையிலான சொல்-சொல்லான மாற்றம்). Fontes இதன் வழியாக மேலும் 91 நாடுகளையும் பிரதேசங்களையும் படிக்கிறது, சட்டவாக்கத்துக்கு மட்டும் (எ.கா. தென்னாப்பிரிக்கா, கென்யா, மெக்சிகோ, நியூசிலாந்து, ரஷ்யா, தென் கொரியா, பெல்ஜியம், லிதுவேனியா, உக்ரைன், மலேசியா, தாய்லாந்து மற்றும் சவூதி அரேபியா). அவை நேரடி அதிகாரப்பூர்வ உள்ளடக்கம் கொண்ட 125 adapters-இலிருந்து தனியானவை; நாட்டுக்கு நாடு உள்ளடக்கம் பெரிதும் வேறுபடுகிறது (கென்யாவின் தேசியப் பதிவில் 9 சட்டங்கள் உள்ளன). இந்தியாவின் சட்டங்களும் Lexifina-வின் பதிவிலிருந்து வருகின்றன, ஏனெனில் India Code-இன் நிபந்தனைகள் தானியங்கி அணுகலைத் தடைசெய்கின்றன; அதன் உச்ச நீதிமன்றத் தீர்ப்புகள் நேரடியானவை.

Lexifina அதிகாரப்பூர்வ வெளியீட்டாளர் அல்ல, அதன் பதிவு நேரடியானதும் அல்ல: Lexifina ஒவ்வொரு நாட்டையும் அவ்வப்போது மீண்டும் சரிபார்க்கிறது, மேலும் அதன் சொந்த அறிக்கை (2026-11-26) தேசியச் சட்ட அமைப்புகளில் 383-இல் 338 கடந்த 7 நாட்களில் சரிபார்க்கப்படவில்லை என்று கணக்கிட்டது. Lexifina-விலிருந்து வரும் ஒவ்வொரு பதிலும் Lexifina-வை மூலமாகப் பெயரிடுகிறது, அதிகாரப்பூர்வ வெளியீட்டாளரின் பக்கத்தை இணைக்கிறது, பதிவு எந்த அளவு வரை செல்கிறது என்று சொல்கிறது.

Lexifina அதிகாரப்பூர்வ சட்ட உரைகளுக்குப் பதிப்புரிமை இல்லை என்ற கருத்தை எடுக்கிறது; எனவே சில நாடுகளில் அது, Fontes தானே மதிக்கும் விதிமுறைகளையோ robots.txt-ஐயோ கொண்ட தளங்களை நகலெடுக்கிறது. Fontes, தான் நேரடியாகப் பெறும் அனைத்துக்கும் அவற்றை இன்னும் மதிக்கிறது; Lexifina வழியாக வருவது Lexifina-வின் சொந்த தீர்ப்பின்படி பின்பற்றப்படுகிறது, அது அதன் களஞ்சியங்களில் நாட்டுக்கு நாடு பதிவாகியுள்ளது. சில நாடுகள் பயன்பாட்டைக் கட்டுப்படுத்துகின்றன (கென்யாவின் வெளியீட்டாளர்: CC BY-NC).

இவற்றுக்கு, உங்கள் தேடல் சொற்கள், மேற்கோள்கள் மற்றும் தேதிகள் Lexifina-வின் சேவையகத்துக்கும் (`global-law.lexifina.com`) செல்லும். அதை முடக்க `WLM_LEXIFINA=0` அமைக்கவும். விசையோ கணக்கோ தேவையில்லை. இலவச சேவையகம் ஒரு இணைய முகவரிக்கு நிமிடத்துக்கு 60 அழைப்புகளையும் நாளொன்றுக்கு 10,000 அழைப்புகளையும் அனுமதிக்கிறது. Fontes Lexifina-உடன் இணைக்கப்படவில்லை.

## என் கணினியிலிருந்து என்ன வெளியே செல்கிறது?

உங்கள் தேடல்கள் தேடப்படும் மூலத்துக்கு மட்டுமே செல்கின்றன (Lexifina கருவிகளுக்கும் நாடுகளுக்கும், அது Lexifina-வின் சேவையகம்).
Fontes தரவுத்தளம் எதையும் வைத்திருப்பதில்லை, கணக்கும் தேவையில்லை.

மூலங்களைத் தவிர, புதிய பதிப்பு உள்ளதா என்று Fontes நாளொன்றுக்கு ஒருமுறை PyPI-இடம் கேட்கிறது (இதை
`FONTES_NO_UPDATE_CHECK=1` மூலம் முடக்கலாம்). நீங்கள் இயக்காவிட்டால் பயன்பாட்டு எண்ணிக்கைகள் முடக்கத்திலேயே இருக்கும்;
பிழை அறிக்கை நீங்கள் அதைப் பார்த்து உறுதிப்படுத்திய பிறகே அனுப்பப்படும். உங்கள் AI செயலி உங்கள் உரையாடலை அதன்
சொந்த நிபந்தனைகளின் கீழ் பார்க்கிறது.

## இது சட்ட ஆலோசனையா?

இல்லை. Fontes ஓர் ஆய்வுக் கருவி. அது உரைகளைக் கண்டுபிடிக்கிறது; அவை உங்கள் வழக்குக்கு என்ன பொருள் தருகின்றன என்று
அது கூறுவதில்லை, அதைப் பயன்படுத்துவது யாருடனும் வழக்கறிஞர்–கட்சிக்காரர் உறவை உருவாக்குவதில்லை. AI செயலி ஓர் உரையைத்
தவறாகப் படிக்கக்கூடும், எனவே ஒரு தீர்ப்பையோ சட்டப் பிரிவையோ நம்புவதற்கு முன் அதை முழுமையாகப் படியுங்கள். ஆலோசனைக்கு,
உங்கள் கேள்வி எழும் இடத்தில் தகுதி பெற்ற ஒரு வழக்கறிஞரை அணுகவும்.

## இதைப் பராமரிப்பது யார்? இது தொடர்ந்து வேலை செய்யுமா?

ஒருவர்: Yüce Karapazar. Fontes-க்குப் பின்னால் எந்த நிறுவனமும் இல்லை, ஆதரவு ஒப்பந்தமும் இல்லை, சேவை நிலை
உறுதிமொழியும் (service-level promise) இல்லை. சட்டச் சேவைகள் எதுவும் வழங்கப்படுவதில்லை.

மூலங்கள் நாளொன்றுக்கு ஒருமுறை சரிபார்க்கப்பட்டு, முடிவுகள் [நிலைப் பக்கத்தில்](https://ykarapazar.github.io/fontes/status/?lang=ta)
வெளியிடப்படுகின்றன. நீதிமன்ற மற்றும் அரசு இணையதளங்கள் முன்னறிவிப்பின்றி மாறுகின்றன, எனவே ஒரு மூலம் எப்போது வேண்டுமானாலும்
செயலிழக்கலாம். எந்த மூலமோ Fontes-ஏ தொடர்ந்து வேலை செய்யும் என்பதற்கு எந்த உத்தரவாதமும் இல்லை. Fontes "உள்ளது உள்ளபடி"
("as is"), எந்த உத்தரவாதமும் இன்றி வழங்கப்படுகிறது ([LICENSE](../../../LICENSE)-இன் பிரிவுகள் 7
மற்றும் 8).

## ஓர் உரை தவறாக அல்லது காலாவதியாக உள்ளது, அல்லது ஒரு மூலம் செயலிழந்துள்ளது. அதை எப்படிப் புகாரளிப்பது?

- "Broken or wrong source" படிவத்துடன் ஒரு issue திறக்கவும்:
  <https://github.com/ykarapazar/fontes/issues/new/choose>. எந்த அதிகார வரம்பு, நீங்கள் என்ன கேட்டீர்கள்,
  உங்களுக்கு என்ன கிடைத்தது, சரியான உரையைக் காட்டும் அதிகாரப்பூர்வப் பக்கம் எது என்று குறிப்பிடவும்.
- அல்லது உங்கள் AI செயலியிடம் "report a Fontes bug" (Fontes பிழையைப் புகாரளி) என்று கேளுங்கள் (அல்லது `fontes report-bug` இயக்கவும்).
  எதுவும் அனுப்பப்படுவதற்கு முன் அறிக்கையை நீங்கள் பார்ப்பீர்கள்.
- அல்லது fontesmcp@proton.me-க்கு மின்னஞ்சல் அனுப்பவும்.

ஓர் அறிக்கையில் கட்சிக்காரர் விவரங்களையோ ரகசியமான உண்மைகளையோ சேர்க்க வேண்டாம்.

**நீங்கள் இந்த மூலங்களில் ஒன்றை நடத்துபவர் என்றால்** மற்றும் ஏதாவது தவறாக இருந்தால் (உங்கள் நிபந்தனைகள், உங்கள் robots.txt,
உங்கள் வேக வரம்புகள்), fontesmcp@proton.me-க்கு மின்னஞ்சல் அனுப்பவும். அந்த மூலம் சரிசெய்யப்படும் அல்லது முடக்கப்படும்.

## இணையத்தில் இயங்கும் (hosted) சட்ட ஆய்வுக் கருவிகளிலிருந்து Fontes எப்படி வேறுபடுகிறது?

- **இது உங்கள் கணினியில் இயங்குகிறது.** Fontes server எதுவும் இல்லை, கணக்கும் இல்லை. அதன் பொருள், உள்ளூர்
  (local) MCP server-ஐத் தொடங்கக்கூடிய செயலிகளில் (Claude Desktop, Codex, Cursor, VS Code மற்றும் இதுபோன்றவை)
  மட்டுமே இது வேலை செய்யும்; hosted connectors-ஐ மட்டுமே ஏற்கும் இணையம் மட்டுமேயான செயலிகளில் அல்ல.
- **இதற்குத் தரவுத்தளம் இல்லை.** ஒவ்வொரு தேடலும் வெளியீட்டாளரின் சொந்த இணையதளம் அல்லது API-க்கு நேரடியாகச் செல்கிறது;
  எனவே முடிவுகள் மூலம் எவ்வளவு புதுப்பித்ததோ அவ்வளவு புதுப்பித்தவை, தேடலின் தரமும் மூலத்தினுடையதே. தொகுக்கப்பட்ட
  குறியீட்டின் (curated index) மீது பொருள்சார் தேடல் (semantic search) எதுவும் இல்லை.
- **இது பயன்பாட்டு வரம்பு எதையும் விதிப்பதில்லை.** Fontes-க்கு மாதாந்திர அழைப்பு உச்சவரம்பு இல்லை. ஒவ்வொரு
  இணையதளத்துக்கும் அது தன் கோரிக்கைகளை இடைவெளி விட்டு அனுப்புகிறது, மேலும் சில மூலங்கள் தங்களை எவ்வளவு வேகமாக அல்லது
  எவ்வளவு அடிக்கடி வினவலாம் என்பதைக் கட்டுப்படுத்துகின்றன.
- **இது திறந்த மூலம்.** ஒவ்வொரு adapter-ஐயும் நீங்கள் படித்து, ஒவ்வொரு உரையும் சரியாக எங்கிருந்து வருகிறது என்று பார்க்கலாம்.
- **இதற்குப் பின்னால் விற்பனையாளர் (vendor) இல்லை.** ஒப்பந்தமோ, ஆதரவு மையமோ, இயக்க நேர உறுதிமொழியோ இல்லை
  ("இதைப் பராமரிப்பது யார்?" பார்க்கவும்).

## இது எந்தச் செயலிகளுடனும் அமைப்புகளுடனும் வேலை செய்கிறது?

உள்ளூர் (stdio) server-ஐ இயக்கக்கூடிய எந்த MCP செயலியும், எடுத்துக்காட்டாக Claude Desktop, Claude Code,
Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio மற்றும் Cline. Fontes
macOS, Windows, Linux ஆகியவற்றில், uv இயங்கும் எந்த இடத்திலும் (Python 3.13+) இயங்குகிறது. Mac அல்லது Windows PC-இல், ஒரே சொடுக்கு நிறுவி Claude Desktop, Codex,
Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio மற்றும் Cline ஆகியவற்றை ஒரே முறையில்
அமைக்கிறது. ஒவ்வொரு செயலிக்குமான படிகள்: [INSTALL.md](INSTALL.md).

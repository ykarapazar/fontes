Fontes இலவசமான, திறந்த மூல MCP server. உள்ளூர் Model Context Protocol server-ஐ இயக்கக்கூடிய எந்தச் செயலியிலும் இது வேலை செய்கிறது: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio மற்றும் பிற. ஒரு சட்டக் கேள்வியை எளிய மொழியில் கேளுங்கள்: 120-க்கும் மேற்பட்ட அதிகார வரம்புகளிலும் சர்வதேச நீதிமன்றங்களிலும் அரசு மற்றும் நீதிமன்ற இணையதளங்களில் உங்கள் AI செயலி நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும் நேரடியாகத் தேடி, ஒவ்வொரு முடிவையும் மூல ஆவணத்துடன் இணைக்கிறது. இது வழக்கறிஞர்களுக்காகவும் சட்ட ஆய்வாளர்களுக்காகவும், சட்டத்தை அதன் மூலத்திலேயே படிக்க விரும்பும் எவருக்காகவும் உருவாக்கப்பட்டது.

இது என்ன செய்கிறது

  • நீங்கள் கேட்கும் நேரத்திலேயே, வெளியீட்டாளரின் சொந்த இணையதளம் அல்லது API-இலிருந்து வழக்குச் சட்டத்தையும் சட்டவாக்கத்தையும் தேடுகிறது.
  • ஒவ்வொரு முடிவும் அதன் மூலத்தைப் பெயரிட்டு அதற்கான இணைப்பைத் தருகிறது; எனவே நீங்கள் மூல ஆவணத்தைச் சரிபார்க்கலாம்.
  • Fontes தரவுத்தளம் எதையும் வைத்திருப்பதில்லை, கணக்கும் தேவையில்லை. உங்கள் கேள்விகள் தேடப்படும் மூலத்துக்கு மட்டுமே செல்கின்றன. பயன்பாட்டு எண்ணிக்கைகளும் பிழை அறிக்கைகளும் opt-in ஆகும்.

Fontes ஓர் ஆய்வு உதவி, சட்ட ஆலோசனை அல்ல; அதைப் பயன்படுத்துவது வழக்கறிஞர்–கட்சிக்காரர் உறவை உருவாக்குவதில்லை. அது "உள்ளது உள்ளபடி", எந்த உத்தரவாதமும் இன்றி வழங்கப்படுகிறது (Apache 2.0 உரிமத்தைப் பார்க்கவும்). சில மூலங்கள் வெளிப்படையாகவே அதிகாரப்பூர்வமற்ற பதிப்புகள், ஒவ்வொன்றுக்கும் அதன் சொந்தப் பயன்பாட்டு நிபந்தனைகள் உள்ளன; Fontes தன் பதில்களில் இதைக் கூறுகிறது. ஒரு தீர்ப்பையோ சட்டப் பிரிவையோ நம்புவதற்கு முன் அதை முழுமையாகப் படியுங்கள். Fontes சுயாதீனமானது; எந்த நீதிமன்றம், அரசாங்கம் அல்லது வெளியீட்டாளருடனும் இணைக்கப்படவில்லை.

உங்கள் AI செயலிக்கான வழக்குச் சட்டமும் சட்டவாக்கமும், நீதிமன்ற மற்றும் அரசு இணையதளங்களிலிருந்து நேரடியாகப் படிக்கப்பட்டவை.

Beta · இலவசம் · திறந்த மூலம் · மூலங்கள் தினமும் சரிபார்க்கப்படுகின்றன

Fontes இலவசமான, திறந்த மூல MCP server. உள்ளூர் Model Context Protocol server-ஐ இயக்கக்கூடிய எந்தச் செயலியிலும் இது வேலை செய்கிறது: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio மற்றும் பிற. ஒரு சட்டக் கேள்வியை எளிய மொழியில் கேளுங்கள்: 125 அதிகார வரம்புகளிலும் சர்வதேச நீதிமன்றங்களிலும் அரசு மற்றும் நீதிமன்ற இணையதளங்களில் உங்கள் AI செயலி நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும் நேரடியாகத் தேடி, ஒவ்வொரு முடிவையும் மூல ஆவணத்துடன் இணைக்கிறது. ஒரு சட்டம் கடந்த ஒரு தேதியில் நடைமுறையில் இருந்தவாறு காட்டவும், Lexifina-வின் பதிவிலிருந்து (அதிகாரப்பூர்வ வெளியீட்டாளர் அல்ல) 91 கூடுதல் நாடுகளின் சட்டவாக்கத்தைப் படிக்கவும் இது முடியும். இது வழக்கறிஞர்களுக்காகவும் சட்ட ஆய்வாளர்களுக்காகவும், சட்டத்தை அதன் மூலத்திலேயே படிக்க விரும்பும் எவருக்காகவும் உருவாக்கப்பட்டது.

இது என்ன செய்கிறது

  • நீங்கள் கேட்கும் நேரத்திலேயே, வெளியீட்டாளரின் சொந்த இணையதளம் அல்லது API-இலிருந்து வழக்குச் சட்டத்தையும் சட்டவாக்கத்தையும் தேடுகிறது.
  • ஒவ்வொரு முடிவும் அதன் மூலத்தைப் பெயரிட்டு அதற்கான இணைப்பைத் தருகிறது; எனவே நீங்கள் மூல ஆவணத்தைச் சரிபார்க்கலாம்.
  • Fontes தரவுத்தளம் எதையும் வைத்திருப்பதில்லை, கணக்கும் தேவையில்லை. உங்கள் கேள்விகள் தேடப்படும் மூலத்துக்குச் செல்கின்றன; சட்டங்களின் கடந்த பதிப்புகளுக்கும் 91 கூடுதல் நாடுகளுக்கும் (இந்தியச் சட்டங்களுக்கும்) அவை அதிகாரப்பூர்வ தளத்துடன் கூடுதலாகவோ அதற்குப் பதிலாகவோ Lexifina-வின் பொதுச் சேவைக்குச் செல்கின்றன. அதை அணைக்க WLM_LEXIFINA=0 என அமைக்கவும். பயன்பாட்டு எண்ணிக்கைகளும் பிழை அறிக்கைகளும் opt-in ஆகும்.

Fontes ஓர் ஆய்வு உதவி, சட்ட ஆலோசனை அல்ல; அதைப் பயன்படுத்துவது வழக்கறிஞர்–கட்சிக்காரர் உறவை உருவாக்குவதில்லை. அது "உள்ளது உள்ளபடி", எந்த உத்தரவாதமும் இன்றி வழங்கப்படுகிறது (Apache 2.0 உரிமத்தைப் பார்க்கவும்). சில மூலங்கள் வெளிப்படையாகவே அதிகாரப்பூர்வமற்ற பதிப்புகள், ஒவ்வொன்றுக்கும் அதன் சொந்தப் பயன்பாட்டு நிபந்தனைகள் உள்ளன; Fontes தன் பதில்களில் இதைக் கூறுகிறது. ஒரு தீர்ப்பையோ சட்டப் பிரிவையோ நம்புவதற்கு முன் அதை முழுமையாகப் படியுங்கள். Fontes சுயாதீனமானது; எந்த நீதிமன்றம், அரசாங்கம் அல்லது வெளியீட்டாளருடனும் இணைக்கப்படவில்லை.

Mac அல்லது Windows கணினியில், ஒரே சொடுக்கு நிறுவி Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio மற்றும் Cline ஆகியவற்றில், உங்கள் கணினியில் உள்ள ஒவ்வொன்றிலும், Fontes-ஐ அமைத்து, பின்னர் உங்கள் விசைகளைச் சேர்க்க முன்வருகிறது. உங்கள் கணினிக்கான நிறுவியைச் சமீபத்திய வெளியீட்டிலிருந்து பதிவிறக்கி, இயக்குவதற்கு முன் அந்தச் செயலிகளை மூடவும். விவரங்கள் நிறுவல் வழிகாட்டியில் உள்ளன. சில மூலங்களுக்கு இலவச விசை தேவை: KEYS.md பார்க்கவும்.

Fontes இலவசமான, திறந்த மூல (open-source) MCP server. இது உங்கள் AI செயலியை **அரசு மற்றும் நீதிமன்ற இணையதளங்களில் நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும் நேரடியாகத் தேட** அனுமதிக்கிறது; 125 அதிகார வரம்புகளிலும் சர்வதேச நீதிமன்றங்களிலும். ஒவ்வொரு முடிவும் மூல ஆவணத்துக்கான இணைப்பைத் தருகிறது. ஒரு சட்டம் கடந்த ஒரு தேதியில் நடைமுறையில் இருந்தவாறு காட்டவும் இது முடியும்; மேலும் Lexifina-வின் பதிவிலிருந்து (அதிகாரப்பூர்வ வெளியீட்டாளர் அல்ல) 91 கூடுதல் நாடுகளின் சட்டவாக்கத்தையும் படிக்க முடியும். இது ஒரு நிலையான Model Context Protocol (MCP) server, எனவே உள்ளூர் MCP server-ஐ இயக்கக்கூடிய எந்தச் செயலியிலும் இது வேலை செய்கிறது: Claude Desktop, Claude Code, OpenAI Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio மற்றும் பிற.

- **வழக்கறிஞர்களுக்கும் ஆய்வாளர்களுக்கும்:** எளிய மொழியில் கேளுங்கள். உங்கள் AI செயலி அதிகாரப்பூர்வ மூலத்தில்
  தேடி, கண்டதிலிருந்து மூல இணைப்புடன் மேற்கோள் காட்டுகிறது.
- **உருவாக்குநர்களுக்கு (developers):** ஒன்பது நிலையான ஆய்வுக் கருவிகளைக் கொண்ட ஒரு MCP server (கூடவே `report_bug`);
  அதிகார வரம்பு ஓர் அளவுரு (parameter), எனவே நாடுகளைச் சேர்ப்பதால் கருவிகள் கூடுவதில்லை. Python, Apache 2.0.
- **அதிகாரப்பூர்வ உரையுடன் சரிபார்க்கப்பட்டது:** இன்றைய டச்சு மற்றும் UK சட்டவாக்கம், US Code பிரிவுகளின் உரைக்கு,
  `get_law_on_date` அதிகாரப்பூர்வ பக்கத்தையும் பெற்று, Lexifina-வின் பதிவு அதனுடன் பொருந்துகிறதா என்று சொல்கிறது,
  வேறுபடும் பத்திகளை மேற்கோள் காட்டுகிறது. மற்ற நாடுகள் ஒப்பிடப்படுவதில்லை.

இயந்திரங்களுக்காக: [llms.txt](https://ykarapazar.github.io/fontes/llms.txt).

- **செய்கிறது:** நீங்கள் கேட்கும் அந்த நேரத்திலேயே, வெளியீட்டாளரின் சொந்த இணையதளம் அல்லது API-இலிருந்து நேரடியாகப்
  பெறுகிறது. ஒவ்வொரு முடிவும் அதன் மூலத்தைப் பெயரிட்டு, அதன் URL அல்லது அதிகாரப்பூர்வ அடையாளங்காட்டியைக் கொண்டிருக்கும்;
  எனவே நீங்கள் மூல ஆவணத்தைத் திறக்கலாம்.
- **செய்யாது:** தரவுத்தளம் வைத்திருப்பதில்லை, மொத்தமாகப் பதிவிறக்குவதில்லை, உரைகளை வட்டில் (disk) cache செய்வதில்லை,
  அல்லது தேடப்படும் மூலத்தைத் தவிர (Lexifina-வின் பதிவுக்கு, அது Lexifina-வின் சேவையகம்; கீழே பார்க்கவும்) வேறு எங்கும் உங்கள் கேள்விகளை அனுப்புவதில்லை. கணக்கு தேவையில்லை. மூலங்களைத் தவிர,
  Fontes நாளொன்றுக்கு ஒருமுறை PyPI-இல் பதிப்புச் சரிபார்ப்பு செய்கிறது (`FONTES_NO_UPDATE_CHECK=1` மூலம் முடக்கலாம்);
  மற்ற எதுவும் (பயன்பாட்டு எண்ணிக்கைகள், பிழை அறிக்கைகள்) opt-in ஆகும், முதலில் உங்களிடம் கேட்கப்படும்.
- **Lexifina-வின் பதிவு விதிவிலக்கு.** `get_law_on_date`, `get_law_history` மற்றும் மேலும் 91 நாடுகள் [Lexifina](https://github.com/lexifina/global-law)-இன் இலவச ஹோஸ்ட் செய்யப்பட்ட server மூலம் படிக்கப்படுகின்றன; அதிகாரப்பூர்வ தளத்திலிருந்து அல்ல. கீழே பார்க்கவும்.
- **செய்யாது:** சட்ட ஆலோசனை வழங்குவதில்லை, அல்லது ஓர் உரையின் எந்தப் பதிப்பு அதிகாரபூர்வமானது என்று தீர்மானிப்பதில்லை.
  உள்ளடக்கம் நாட்டுக்கு நாடு பெரிதும் வேறுபடுகிறது: சிலவற்றுக்கு முழு வழக்குச் சட்டமும் ஒருங்கிணைக்கப்பட்ட (consolidated)
  சட்டவாக்கமும் உள்ளன, சிலவற்றுக்கு ஒரே ஒரு நீதிமன்றம் அல்லது முதலில் வெளியிடப்பட்டபடியான சட்டங்கள் மட்டுமே. கீழே உள்ள
  அட்டவணைகளும் `list_jurisdictions`-உம் ஒவ்வொன்றும் சரியாக எதை உள்ளடக்குகிறது என்று கூறுகின்றன.

### கடந்தகால பதிப்புகளும் கூடுதல் நாடுகளும், Lexifina-விலிருந்து

[Lexifina](https://github.com/lexifina/global-law) சுமார் 200 நாடுகளின் சட்டத்தை git வரலாறாக வைத்திருக்கிறது: ஒவ்வொரு மாற்றமும், அது நடைமுறைக்கு வந்த நாளில் தேதியிடப்பட்ட ஒரு commit. Fontes அதை Lexifina-வின் இலவச ஹோஸ்ட் செய்யப்பட்ட MCP server வழியாகப் படிக்கிறது (`https://global-law.lexifina.com/mcp`); அது இவற்றைச் சேர்க்கிறது:
- `get_law_on_date` மற்றும் `get_law_history`: கடந்த ஒரு தேதியில் நடைமுறையில் இருந்த ஒரு பிரிவு, மற்றும் அதை மாற்றிய சட்டங்கள்; Lexifina-வின் பதிவில் உள்ள எந்த நாட்டுக்கும்.
- நான்கு சட்டவாக்கக் கருவிகள் வழியாக 91 கூடுதல் நாடுகளும் பிரதேசங்களும் (எ.கா. தென்னாப்பிரிக்கா, கென்யா, மெக்சிகோ, நியூசிலாந்து, ரஷ்யா, தென் கொரியா, பெல்ஜியம், லிதுவேனியா, உக்ரைன், மலேசியா, தாய்லாந்து, சவூதி அரேபியா). சட்டவாக்கம் மட்டும்; வழக்குச் சட்டம் இல்லை. நாட்டுக்கு நாடு உள்ளடக்கம் பெரிதும் வேறுபடுகிறது (கென்யாவின் தேசியப் பதிவில் 9 சட்டங்கள் உள்ளன); `list_jurisdictions` ஒவ்வொன்றிலும் என்ன உள்ளது என்று காட்டுகிறது. இவை நேரடியான அதிகாரப்பூர்வ உள்ளடக்கம் கொண்ட 125 அதிகார வரம்புகளிலிருந்து தனியாக விவரிக்கப்படுகின்றன. இந்தியா அந்த 125-இல் ஒன்று (உச்ச நீதிமன்றத் தீர்ப்புகள், நேரடியாக); அதன் சட்டங்களும் Lexifina-வின் பதிவிலிருந்தே படிக்கப்படுகின்றன.

Lexifina அதிகாரப்பூர்வ வெளியீட்டாளர் அல்ல, அதன் பதிவு நேரடியானதும் அல்ல. Lexifina ஒவ்வொரு நாட்டையும் அவ்வப்போது அதன் அதிகாரப்பூர்வ மூலத்துடன் மீண்டும் சரிபார்க்கிறது; 2026-11-26 அன்று அதன் சொந்த புத்துணர்ச்சி அறிக்கை, தேசியச் சட்ட அமைப்புகளில் 383-இல் 338 கடந்த 7 நாட்களில் சரிபார்க்கப்படவில்லை என்று கணக்கிட்டது. Lexifina-விலிருந்து வரும் ஒவ்வொரு பதிலும் Lexifina-வை மூலமாகப் பெயரிடுகிறது, அதிகாரப்பூர்வ வெளியீட்டாளரின் பக்கத்தை இணைக்கிறது, பதிவு எந்த அளவு வரை செல்கிறது என்று சொல்கிறது. அதை நம்புவதற்கு முன் அதிகாரப்பூர்வ உரையைச் சரிபார்க்கவும்.

Lexifina-வின் மூலக் கொள்கை Fontes-இன் கொள்கையிலிருந்து வேறுபடுகிறது. அதிகாரப்பூர்வ சட்ட உரைகளுக்குப் பதிப்புரிமை இல்லை என்ற கருத்து அதற்கு உண்டு; எனவே சில நாடுகளில் அது, Fontes தானே மதிக்கும் விதிமுறைகளையோ robots.txt-ஐயோ கொண்ட தளங்களை நகலெடுக்கிறது (சில நேரங்களில் Internet Archive நகல்கள் வழியாக). Fontes, தான் நேரடியாகப் பெறும் அனைத்துக்கும் robots.txt-ஐயும் விதிமுறைகளையும் இன்னும் மதிக்கிறது; Lexifina வழியாக வருவது Lexifina-வின் சொந்த சட்டத் தீர்ப்பின்படி பின்பற்றப்படுகிறது, அது அதன் களஞ்சியங்களில் (LICENSE/SOURCES.md) நாட்டுக்கு நாடு பதிவாகியுள்ளது. சில நாடுகள் பயன்பாட்டைக் கட்டுப்படுத்துகின்றன: கென்யாவின் வெளியீட்டாளர் CC BY-NC; சில மூலங்கள் வணிகரீதியற்ற பயன்பாட்டைக் கோருகின்றன.

இந்த இரண்டு கருவிகளுக்கும், இந்த நாடுகளுக்கும், உங்கள் தேடல் சொற்கள், மேற்கோள்கள் மற்றும் தேதிகள் அதிகாரப்பூர்வ மூலத்துக்கு மட்டுமல்ல, Lexifina-வின் சேவையகத்துக்கும் (`global-law.lexifina.com`) செல்லும். இது இயல்பாக இயக்கத்தில் உள்ளது; அதை முடக்க `WLM_LEXIFINA=0` அமைக்கவும். விசையோ கணக்கோ தேவையில்லை. இலவச சேவையகம் ஒரு இணைய முகவரிக்கு நிமிடத்துக்கு 60 அழைப்புகளையும் நாளொன்றுக்கு 10,000 அழைப்புகளையும் அனுமதிக்கிறது. Fontes Lexifina-உடன் இணைக்கப்படவில்லை; பதிவை உருவாக்கிப் பராமரிப்பது Lexifina. [PRIVACY.md](PRIVACY.md) பார்க்கவும்.

### ஒரு முடிவை நம்புவதற்கு முன் இதைப் படியுங்கள்

- **ஒவ்வொரு மூலமும் அதிகாரப்பூர்வ, மூலமான (authentic) பதிப்பு அல்ல.** பெரும்பாலானவை அரசு அல்லது நீதிமன்றத் தளங்கள்,
  ஆனால் சில ஒருங்கிணைக்கப்பட்ட உரைகள் வெளிப்படையாகவே அதிகாரப்பூர்வமற்றவை (அரசிதழ் மட்டுமே மூலமானது), மேலும் சில
  மூலங்கள் அரசு சாராதவை (எ.கா. LexiVox, LawPhil, Maqam, Wikisource). Fontes தன் பதில்களில் இவற்றை
  "Unofficial source" (அதிகாரப்பூர்வமற்ற மூலம்) அறிவிப்புடன் குறிக்கிறது. மேற்கோள் காட்டுவதற்கு முன் அதிகாரப்பூர்வ
  வெளியீட்டைச் சரிபார்க்கவும்.
- **ஒவ்வொரு மூலத்துக்கும் அதன் சொந்த நிபந்தனைகள் உள்ளன.** தரவு அதன் வெளியீட்டாளரின் உரிமத்தின் கீழேயே இருக்கும்; சில
  வணிகப் பயன்பாட்டைத் தடைசெய்கின்றன, சில மூலத்தைக் குறிப்பிடுவதைக் (attribution) கோருகின்றன (எ.கா. CC BY மூலங்கள்),
  மேலும் சில அனுமதியின்றித் தானியங்கி அணுகலைத் தடைசெய்கின்றன. அனுமதி தேவைப்படும் மூலங்கள் இயல்பாக **முடக்கப்பட்டுள்ளன**
  (கீழே OFF எனக் குறிக்கப்பட்டுள்ளன). பார்க்க [மூலங்கள், நிபந்தனைகள் மற்றும் robots.txt](#மூலங்கள்-நிபந்தனைகள்-மற்றும்-robotstxt).
- **AI தவறாகப் படிக்கக்கூடும்.** ஒரு தீர்ப்பையோ சட்டப் பிரிவையோ நம்புவதற்கு முன் அதை முழுமையாகப் படியுங்கள்; தேடல்
  துணுக்கிலிருந்தோ AI-இன் சுருக்கத்திலிருந்து மட்டுமோ ஒருபோதும் மேற்கோள் காட்ட வேண்டாம்.
- **மூலங்கள் தாமதமாகின்றன, இடைவெளிகளும் உள்ளன.** ஒரு நீதிமன்றம் தாமதமாக வெளியிடலாம் அல்லது தன் தீர்ப்புகளில் சிலவற்றை
  மட்டுமே வெளியிடலாம், மேலும் ஓர் ஒருங்கிணைக்கப்பட்ட உரையில் சமீபத்திய திருத்தம் இன்னும் சேர்க்கப்படாமல் இருக்கலாம். உரையின்
  தேதியையும், அந்த அதிகார வரம்புக்கு `list_jurisdictions` பட்டியலிடும் இடைவெளிகளையும் சரிபார்க்கவும்.
- **சட்ட ஆலோசனை அல்ல.** Fontes ஓர் ஆய்வுக் கருவி. அதைப் பயன்படுத்துவது யாருடனும் வழக்கறிஞர்–கட்சிக்காரர் உறவை
  உருவாக்குவதில்லை, மேலும் உங்கள் கேள்வி எழும் இடத்தில் தகுதி பெற்ற வழக்கறிஞரின் ஆலோசனைக்கு அது மாற்றாகாது.
- **உத்தரவாதம் இல்லை.** Fontes "உள்ளது உள்ளபடி" ("as is"), எவ்வகையான உத்தரவாதமும் இன்றி வழங்கப்படுகிறது; சட்டம்
  அனுமதிக்கும் அளவுக்கு, அது எவ்வாறு பயன்படுத்தப்படுகிறது என்பதற்கு அதன் ஆசிரியர்கள் பொறுப்பல்ல. முழு நிபந்தனைகள்

- Fontes ஒரு சுயாதீனத் திறந்த மூலத் திட்டம். அது படிக்கும் நீதிமன்றங்கள், அரசாங்கங்கள் அல்லது வெளியீட்டாளர்கள்
  எவற்றுடனும் அது இணைக்கப்படவில்லை, அவற்றால் அங்கீகரிக்கப்படவும் இல்லை.

## இதை ஏன் உருவாக்கினேன்

Fontes ஒரு வழக்கறிஞரால், வழக்கறிஞர்களுக்காக உருவாக்கப்பட்டது. =) தங்களுக்குப் பொருந்தும் சட்டத்தைப் படிக்க வேண்டிய தேவை எப்போதாவது ஏற்பட்ட மற்ற அனைவருக்காகவும்தான்.

சட்டம் பொதுவானது. மக்கள் படிப்பதற்காகவே நீதிமன்றங்களும் அரசுகளும் நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும் வெளியிடுகின்றன. ஆனால் ஒவ்வொரு நாடும் தன் சொந்த வழியில், தன் சொந்த இணையதளத்தில், தன் சொந்த மொழியில் வெளியிடுகிறது; அவற்றில் பல இணையதளங்கள், எங்கே தேட வேண்டும் என்று ஏற்கெனவே தெரிந்தவர்களுக்காகவே உருவாக்கப்பட்டவை. AI உதவியாளர்கள் உதவ முடியும், ஆனால் மூலத்தைப் பார்க்க முடியாதபோது அவை ஊகிக்கின்றன.

Fontes உங்கள் AI செயலியை அந்த அதிகாரப்பூர்வ மூலங்களுடன் இணைக்கிறது. நீதிமன்றத் தீர்ப்புகளையும் சட்டவாக்கத்தையும் அவற்றை வெளியிடும் நீதிமன்றங்களிடமிருந்தும் அரசுகளிடமிருந்தும் நேரடியாகப் பெறுகிறது, ஒவ்வொரு முடிவையும் மூல ஆவணத்துடன் இணைக்கிறது, தனக்கென எந்தத் தரவுத்தளத்தையும் வைத்திருப்பதில்லை.

எங்கிருந்தாலும், ஒவ்வொரு வழக்கறிஞரும் ஒவ்வொரு குடிமகனும் தங்களை ஆளும் சட்டத்தைத் தேடிப் பார்க்கவும், தங்கள் உரிமைகளைப் பாதுகாக்க அதைப் பயன்படுத்தவும் முடிய வேண்டும் என்று நான் நம்புகிறேன். அதனால்தான் Fontes, சட்டத் தொழில் புரிவோருக்கும் குடிமக்களுக்கும் ஒரே மாதிரி, இலவசமானதாகவும் திறந்த மூலமாகவும் உள்ளது.

ஏதாவது பழுதாக இருந்தால், அல்லது உங்களுக்குத் தேவையான நாடு இல்லையென்றால், தயவுசெய்து [ஓர் issue திறக்கவும்](https://github.com/ykarapazar/fontes/issues). அதுவே மிகவும் பயனுள்ள உதவி.

## கருவிகள்

| கருவி | அது என்ன செய்கிறது |
|---|---|
| `list_jurisdictions(query?)` | குறியீடுகள், பெயர்கள், மூலங்கள், ஆதரிக்கப்படும் கருவிகள் மற்றும் ஒவ்வொரு அதிகார வரம்பின் கூடுதல் வடிகட்டிகள். முதலில் இதை அழைக்கவும். |
| `search_caselaw(jurisdiction, query, limit=10, page=1, filters={})` | நீதிமன்றத் தீர்ப்புகளின் முழு உரைத் தேடல். |
| `get_decision(jurisdiction, id, max_chars=60000, offset=0)` | ஒரு தீர்ப்பு, markdown வடிவில் (nl: ECLI; gb: neutral citation அல்லது slug). |

| `get_legislation_toc(jurisdiction, id, keyword?)` | ஒரு சட்டத்தின் கட்டமைப்பு, சட்டப் பிரிவுகளின் குறிப்புகளுடன். |
| `get_legislation_provision(jurisdiction, id, provision)` | ஓர் உறுப்புரை / பிரிவு / ஒழுங்குமுறை. |

| `get_law_history(provision, jurisdiction?, date_a?, date_b?)` | ஒரு பிரிவை மாற்றிய ஒவ்வொரு சட்டமும், அல்லது இரண்டு தேதிகளுக்கு இடையிலான சொல்-சொல்லான மாற்றம். Lexifina-வின் பதிவிலிருந்து (அதிகாரப்பூர்வ வெளியீட்டாளரிடமிருந்து அல்ல). |

## நிறுவுதல்

ஒவ்வொரு செயலிக்குமான படிப்படியான வழிமுறைகள் (Claude Desktop, Codex, Claude Code, Cursor, VS Code, Gemini CLI,

**உருவாக்குநர்கள்:** உங்களுக்கு [uv](https://docs.astral.sh/uv/getting-started/installation/) தேவை.

```bash
uvx fontes-mcp                 # from PyPI
uvx --from git+https://github.com/ykarapazar/fontes fontes   # straight from GitHub
uvx fontes-mcp --only nl,gb    # expose only some jurisdictions
```

Fontes ஒரு stdio MCP server: ஒரு MCP client அதைத் தொடங்குகிறது, நீங்கள் அதைக் கையால் இயக்குவதில்லை.
`nl-legal-mcp` மற்றும் `uk-legal-mcp` (பழைய பெயர்கள்) என்பவை `fontes --only nl` / `--only gb`-க்கான மாற்றுப் பெயர்கள்.

<details>
<summary>விருப்பத்தேர்வுச் சூழல் மாறிகள்</summary>

விருப்பத்தேர்வுச் சூழல் மாறிகள் (environment variables): `WLM_US_GOVINFO_KEY` (US வழக்குச் சட்டத் தேடலுக்கான

`research/fr.md`-இல்), `WLM_PERMITTED=<codes>` (நிபந்தனைகளுக்கு அனுமதி தேவைப்படும் மூலங்களை இயக்க; அனுமதி
கிடைத்த பின்னரே), `FONTES_NO_UPDATE_CHECK=1`, `WLM_LEXIFINA=0` (Lexifina-வின் பதிவை முடக்கும்: `get_law_on_date`, `get_law_history` மற்றும் அதன் வழியாகப் படிக்கப்படும் 91 நாடுகள்).

</details>

<details>
<summary>படிகளும் விதிகளும்</summary>

1. குறியீட்டைத் தேர்ந்தெடுக்கவும்: ISO 3166-1 alpha-2 சிற்றெழுத்து (`de`), துணை-தேசிய `us-ca`, சர்வதேச
   `eu`, `echr`. `src/world_legal_mcp/jurisdictions/<code>.py`-ஐ உருவாக்கவும் (செல்லுபடியான module பெயரைப்
   பயன்படுத்தவும், எ.கா. `code = "us-ca"` உடன் `us_ca.py`). அது தானாகவே கண்டறியப்படும்.
2. `Jurisdiction`-இன் subclass-ஐ உருவாக்கி `code`, `name`, `languages`, `aliases`, `notes`, `samples`,
   `min_interval = {host: seconds}` மற்றும் `sources` ஆகியவற்றை அமைக்கவும்: ஒவ்வொரு `Source`-க்கும் அதன் உரிமம்,
   `commercial_use`, `ai_use`, `auth`, `rate_limit` (அதை நீங்கள் எப்படி அறிவீர்கள் என்பதும்) மற்றும் `terms_url`.
3. அதிகாரப்பூர்வ மூலம் ஆதரிக்கும் async முறைகளை (methods) மட்டுமே செயல்படுத்தவும் (`search_caselaw`,
   `get_decision`, `search_legislation`, `get_legislation_toc`, `get_legislation_provision`,
   `get_legislation_text`). markdown அல்ல, `models.py`-இலிருந்து records-ஐத் திருப்பி அனுப்பவும்; தோல்வியின்போது
   `NotFound` / `BadRequest` / `SourceError`-ஐ எழுப்பவும் (raise). இல்லாத முறைகள் ஆதரிக்கப்படாதவை எனத்
   தெரிவிக்கப்படும்.
4. கூடுதல் தேடல் விருப்பங்களை `caselaw_filters` / `legislation_filters`-இல் அறிவித்து, அவற்றை
   `filters`-இலிருந்து படிக்கவும். `_http.get/post` (திட்டத்தின் சொந்த User-Agent, ஒவ்வொரு host-க்குமான வேகக்
   கட்டுப்பாடு) மற்றும் பகிரப்பட்ட `_http` உதவிகளைப் பயன்படுத்தவும்.
5. `tests/live/test_<code>.py`-ஐச் சேர்த்து,
   `uv run pytest tests/test_registry.py -q` மற்றும்
   `uv run pytest tests/live/test_conformance.py -k "[<code>]" -s` ஆகியவற்றை இயக்கவும் (அடைப்புக்குறிகளுடன்: வெறும்
   `-k <code>` பிற சோதனைகளுடனும் பொருந்திவிடும்).

விதிகள்: அதிகாரப்பூர்வ அல்லது பொது அமைப்பு மூலங்கள் மட்டுமே; robots.txt அல்லது நிபந்தனைகள் தடைசெய்வதை ஒருபோதும் scrape
செய்ய வேண்டாம்; அடையாளங்காட்டிகள் மூலத்திலிருந்து வருகின்றன, ஒருபோதும் புனையப்படுவதில்லை. தானியங்கிப் பயன்பாட்டுக்கு
நிபந்தனைகள் அனுமதி கோரும் மூலத்துக்கு `needs_permission=True` மற்றும் ஒரு `warning` அமைக்கப்படும்: இயக்குநர் அந்தக்
குறியீட்டை `WLM_PERMITTED`-இல் பட்டியலிடாவிட்டால் server அதை ஒருபோதும் அழைக்காது (எ.கா. `WLM_PERMITTED=in,de`).

## மூலங்கள், நிபந்தனைகள் மற்றும் robots.txt

ஒவ்வொரு கோரிக்கையும் தன் User-Agent-இல் இந்தத் திட்டத்தைப் பெயரிடுகிறது
(`Fontes/<version> (+https://github.com/ykarapazar/fontes; fontesmcp@proton.me)`); அது ஒருபோதும் உலாவி
(browser) போல் நடிப்பதில்லை. ஒரு பயனர் ஏதாவது கேட்கும்போது கோரிக்கைகள் ஒவ்வொன்றாக அனுப்பப்படுகின்றன,
crawling மூலம் அல்ல. நீங்கள் சுயமாக host செய்தால், ஒவ்வொரு மூலமும் காணும் இயக்குநர் (operator) நீங்களே, எனவே
deploy செய்வதற்கு முன் வலப்பக்க நெடுவரிசையைச் சரிபார்க்கவும். சரிபார்க்கப்பட்டது 2026-11-05/06.

**இந்த மூலங்களில் ஒன்றை நீங்கள் நடத்துபவர் என்றால்**, நாங்கள் ஏதாவது தவறாகப் புரிந்திருந்தால் (உங்கள் நிபந்தனைகள், உங்கள்
robots.txt, உங்கள் வேக வரம்புகள், அல்லது வேறு எதுவும்), fontesmcp@proton.me-க்கு மின்னஞ்சல் அனுப்பவும். நாங்கள் அதைச்
சரிசெய்வோம் அல்லது அந்த மூலத்தை முடக்குவோம்.

"AI பயன்பாடு" என்பது மூலத்தின் நிபந்தனைகள் அல்லது robots.txt, AI/TDM பயன்பாட்டுக்கு எதிராக ஏதாவது கூறுகின்றனவா என்பதாகும்
("குறிப்பிடப்படவில்லை" என்றால் மௌனம், அனுமதி அல்ல). "documented" எனக் குறிக்கப்பட்ட வேக வரம்புகள் மூலத்திடமிருந்து
வருகின்றன; மற்றவை எல்லாம் எங்கள் சொந்த இடைவெளி. `list_jurisdictions` அதே தரவைத் தருகிறது.

## இந்த பீட்டா பதிப்பில் அறியப்பட்ட சிக்கல்கள்

18 நவம்பர் 2026 நிலவரப்படி. [மூலங்களின் நிலை](https://ykarapazar.github.io/fontes/status/?lang=ta) பக்கம் ஒவ்வொரு மூலத்தின் இன்றைய நிலையைக் காட்டுகிறது.

- **செயலிழப்பு அல்லது தடுக்கப்பட்டது.** சுவிட்சர்லாந்தின் கூட்டாட்சி உச்ச நீதிமன்றத் தளம் bot சரிபார்ப்பைக்
  காட்டுகிறது; Fontes நின்று, அதை உலாவியில் தேடுவதற்கான இணைப்பை உங்களுக்குத் தருகிறது. ஜோர்டானின்
  அரசியலமைப்பு நீதிமன்றம் ஒரு வாரமாகப் பதிலளிக்கவில்லை, செனகலின் அரசு சட்டவாக்கத் தளங்களை அடிக்கடி அணுக
  முடிவதில்லை.
- **சில தளங்கள் அருகிலிருந்து மட்டுமே பதிலளிக்கின்றன.** ஜெர்மனியின் Gesetze im Internet, ருமேனியாவின்
  பிரதிநிதிகள் சபை மற்றும் உயர் நீதிமன்றம், ஸ்லோவாக்கியாவின் உச்ச நீதிமன்றம், போர்ச்சுகலின் அரசியலமைப்பு
  நீதிமன்றம் ஆகியவை ஐரோப்பாவிலிருந்து வேலை செய்கின்றன; ஆனால் நிலைப் பக்கத்தின் தினசரிச் சோதனை நடக்கும்
  அமெரிக்காவிலிருந்து அடிக்கடி நேரம் கடந்துவிடுகிறது.
- **இயல்பாக முடக்கப்பட்டவை.** பஹ்ரைன், கொலம்பியா ஆகியவற்றின் நிபந்தனைகள் அனுமதியின்றித் தானியங்கி அணுகலைத்
  தடைசெய்கின்றன, எனவே நீங்கள் அவற்றை இயக்காதவரை Fontes அவற்றைத் தொடுவதில்லை.
- **சட்டவாக்க மூலம் இல்லை.** எகிப்து, ஐஸ்லாந்து, லாவோஸ், மங்கோலியா: வழக்குச் சட்டம் மட்டும்.
- **நீங்கள் எதிர்பார்ப்பதைவிடப் பலவீனமான தேடல்.** நைஜீரியா, டிரினிடாட் மற்றும் டொபாகோ, பிலிப்பைன்ஸ், பெலீஸ் ஆகியவை
  தலைப்புகளில் மட்டுமே தேடுகின்றன, எனவே உரையின் உள்ளே உள்ள சொல் கண்டுபிடிக்கப்படாது. பெனின், பார்படோஸ் ஆகியவை ஸ்கேன் செய்த
  PDF-களை வெளியிடுகின்றன, எனவே உரை விடுபட்டிருக்கலாம் அல்லது சிதைந்திருக்கலாம். பல நாடுகளில் (அவற்றில் UK-யும் ஜெர்மனியும்)
  சில முடிவுகள் உங்கள் சொற்களைப் போகிற போக்கில் மட்டுமே குறிப்பிடுகின்றன; முடிந்த இடங்களில் Fontes இவற்றைக் குறிக்கிறது.
- **காலாவதியாகியிருக்கக்கூடிய உரைகள்.** பிலிப்பைன்ஸ் சட்டங்கள் முதலில் நிறைவேற்றப்பட்ட வடிவிலேயே உள்ளன, பிந்தைய
  திருத்தங்கள் இல்லாமல் (Fontes ஒவ்வொரு சட்டப் பிரிவிலும் இதைக் குறிப்பிடுகிறது). சிலியின் ஒருங்கிணைக்கப்பட்ட உரை தாமதமாகலாம்; Fontes
  தான் கண்டறியும் பிந்தைய திருத்தச் சட்டங்களைக் குறிக்கிறது. மங்கோலியாவின் மூலம் சில தீர்ப்புகளில் தவறான தேதிகளைக் காட்டுகிறது.
- **மெதுவான தேடல்கள்.** சில செக் வழக்குச் சட்டத் தேடல்களுக்கு 60 வினாடிகள் வரை ஆகும்; அதற்கு முன்பே உங்கள் AI செயலி
  கைவிடக்கூடும். ஒவ்வொரு தீர்ப்பின் பொருளையும் சரிபார்க்கும்போது துருக்கிக்குச் சுமார் 40 வினாடிகள் வரை ஆகும்.
  கோரிக்கைகளுக்கு இடையே 10 வினாடிகள் இடைவெளி வேண்டும் என்று பார்படோஸ் கேட்கிறது, எனவே ஒரு தேடல் அதிகபட்சம் 20 முடிவுகளைத் தரும்.
- **பக்கம் 2-இல் ஒரு முடிவு மீண்டும் வரலாம் அல்லது விடுபடலாம்.** ஹங்கேரி, போலந்து, பிரான்ஸ் ஆகியவை ஒரே தேடலுக்குச் சில நேரங்களில்
  வேறு வரிசையைத் தருகின்றன; செக் குடியரசும் ஸ்வீடனும் 100-ஆவது முடிவுக்குப் பிறகு இப்படிச் செய்யலாம். Fontes இதை முடிவுகளில் குறிப்பிடுகிறது.
- **சிறிய விஷயங்கள்.** உருகுவேயில் தீர்ப்புகளுக்கு நிரந்தர இணைப்புகள் இல்லை. ஆர்மீனியா (சட்டவாக்கம், நடைமுறையில் உள்ளவை
  வடிகட்டி), மடகாஸ்கர் (வழக்குச் சட்டம்) ஆகியவை ஒன்று அல்லது இரண்டு முடிவுகள் குறைவான பக்கத்தைத் தரலாம்.
- **உள்ளடக்க இடைவெளிகள்.** ஒவ்வொரு அதிகார வரம்பும் தன் இடைவெளிகளை `list_jurisdictions`-இல் பட்டியலிடுகிறது (எடுத்துக்காட்டாக,
  UK-யின் Find Case Law 2003-இல் தொடங்குகிறது; பழைய தீர்ப்புகளும் பல முதல்நிலை நீதிமன்றத் தீர்ப்புகளும்
  BAILII-இல் மட்டுமே உள்ளன). உங்களுக்கு முக்கியமான தேதிக்கு ஒருங்கிணைக்கப்பட்ட உரை புதுப்பிக்கப்பட்டுள்ளதா எனச் சரிபார்க்கவும்.

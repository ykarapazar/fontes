# Fontes: саволҳо ва ҷавобҳо

## Fontes чист?

Сервери ройгон ва манбаъкушоди MCP (Apache 2.0). Он ба ҳар барномае, ки бо Model Context
Protocol кор мекунад (Claude, Codex, Cursor, VS Code, Gemini CLI ва дигарон), имкон медиҳад,
ки қарорҳои судӣ ва қонунгузориро мустақиман дар сомонаҳои судӣ ва давлатӣ дар зиёда аз 120
юрисдиксия ва судҳои байналмилалӣ (125 адаптер) ҷустуҷӯ кунад. Ҳар натиҷа манбаи худро номбар
мекунад ва ба матни аслӣ пайванд медиҳад.

## Оё матнҳо расмӣ мебошанд?

Асосан ҳа, вале на ҳамеша.

- Аксари манбаъҳоро суд, вазорат ё нашрияи расмӣ идора мекунад.
- Баъзе матнҳои ҷамъбастшударо ҳукумат нашр мекунад, вале онҳо ошкоро ғайрирасмӣ мебошанд:
  танҳо нашрияи расмӣ аслӣ ба ҳисоб меравад.
- Чанд манбаъ умуман сомонаҳои давлатӣ нестанд (масалан, LexiVox, LawPhil, Maqam, Wikisource).

Fontes ба ҳар ҷавобе, ки аз яке аз инҳо меояд, огоҳии "Unofficial source" илова мекунад. Пеш
аз иқтибос овардани чизе нашри расмиро санҷед. Ҷадвали фарогирӣ дар
[README](README.md#фарогирӣ) ва `list_jurisdictions` манбаи ҳар юрисдиксияро номбар мекунанд.

## Кадом юрисдиксияҳоро фаро мегирад ва то чӣ андоза хуб?

125 адаптер: 108 давлати узви СММ, Ҳонгконг, Косово, Фаластин, Тайван, DIFC Courts, судҳои иёлотии ИМА ва 11 суд
ва мақоми байналмилалӣ (масалан, Суди аврупоии ҳуқуқи инсон, ИА, Суди байналмилалии СММ ва
СУҶ).

Фарогирӣ хеле фарқ мекунад. Тибқи қоидаи қатъӣ (прецедентҳои олитарин суди умумӣ ё
конститутсия ва санадҳои асосӣ, ки пурра дастрасанд), 72-то аз 125 фарогирифта ҳисоб
мешаванд. [COVERAGE.md](../../COVERAGE.md) барои ҳар юрисдиксия нишон медиҳад, ки Fontes ба
чӣ мерасад, ба чӣ намерасад ва чаро.

## Оё ба ман калиди API лозим аст?

Барои қариб ҳар юрисдиксия, не. Баъзе манбаъҳо калиди ройгон талаб мекунанд: [KEYS.md](KEYS.md)-ро
бинед.

- **Фаронса:** ҳа. То шумо `WLM_FR_PISTE_CLIENT_ID` ва `WLM_FR_PISTE_CLIENT_SECRET`-ро
  муқаррар накунед, Фаронса хомӯш аст. Онҳо аз ҳисоби ройгони PISTE (piste.gouv.fr) бо
  барномае, ки ба Judilibre ва Légifrance обуна шудааст, гирифта мешаванд.
- **Иёлоти Муттаҳидаи Амрико:** ихтиёрӣ. Ҷустуҷӯи таҷрибаи судӣ бе калид кор мекунад, вале
  калиди умумии намоишӣ барои як суроғаи IP танҳо тақрибан 10 ҷустуҷӯ дар як рӯз иҷозат
  медиҳад. Калиди ройгони api.data.gov дар `WLM_US_GOVINFO_KEY` онро зиёд мекунад.
- **Судҳои иёлотии ИМА:** ҳа. Таҷрибаи судии иёлотҳо (`us-states`) то он даме хомӯш аст, ки шумо `WLM_US_COURTLISTENER_KEY`-ро ба токени ройгони API-и CourtListener-и худатон муқаррар кунед. CourtListener-ро созмони ғайритиҷоратии Free Law Project идора мекунад; он манбаи расмӣ нест ва ҳар посух инро мегӯяд.

Инҳоро ҳамчун тағйирёбандаҳои муҳит барои сервери Fontes дар танзимоти MCP-и барномаи худ
муқаррар кунед. Насбкунандаҳо пас аз насб онҳоро мепурсанд ва оғозкунандаи
**Add or change keys**-и онҳо баъдтар онҳоро тағйир медиҳад.

Ҷудогона, чанд манбаъ дар шартҳояшон мегӯянд, ки дастрасии худкор иҷозати нашркунандаро талаб
мекунад. Онҳо ҳамчун ХОМӮШ қайд шудаанд ва хомӯш мемонанд. Калид инро тағйир намедиҳад; танҳо
иҷозати нашркунанда тағйир медиҳад (сипас `WLM_PERMITTED=<codes>`-ро муқаррар кунед).

## Чӣ аз компютери ман берун меравад?

Ҷустуҷӯҳои шумо танҳо ба манбаи ҷустуҷӯшаванда мераванд. Fontes пойгоҳи додаҳо нигоҳ
намедорад ва ҳисоб талаб намекунад.

Ғайр аз манбаъҳо, Fontes рӯзе як бор аз PyPI мепурсад, ки оё версияи навтар ҳаст (онро бо
`FONTES_NO_UPDATE_CHECK=1` хомӯш кунед). Шумораи истифода то шумо фаъол накунед, хомӯш аст ва
гузориши хато танҳо пас аз он ки шумо онро дидед ва тасдиқ кардед, фиристода мешавад. Барномаи
зеҳни сунъии шумо сӯҳбати шуморо тибқи шартҳои худ мебинад.

Тафсилоти пурра: [PRIVACY.md](PRIVACY.md).

## Оё ин маслиҳати ҳуқуқӣ аст?

Не. Fontes абзори таҳқиқотӣ аст. Он матнҳоро меёбад; он намегӯяд, ки онҳо барои парвандаи
шумо чӣ маъно доранд ва истифодаи он бо ҳеҷ кас муносибати адвокат ва мизоҷро ба вуҷуд
намеорад. Барномаи зеҳни сунъӣ метавонад матнро нодуруст хонад, бинобар ин пеш аз такя кардан
қарор ё моддаро пурра хонед. Барои маслиҳат ба адвокати соҳибихтисос дар ҷое, ки саволи шумо ба
миён омадааст, муроҷиат кунед.

## Кӣ онро нигоҳубин мекунад? Оё он кор карданро идома медиҳад?

Як нафар: Yüce Karapazar. Дар паси Fontes ягон ширкат, шартномаи дастгирӣ ё ваъдаи сатҳи
хизматрасонӣ нест. Ягон хизматрасонии ҳуқуқӣ пешниҳод намешавад.

Манбаъҳо рӯзе як бор санҷида мешаванд ва натиҷаҳо дар
[саҳифаи вазъ](https://ykarapazar.github.io/fontes/status/?lang=tg) нашр мешаванд. Сомонаҳои
судӣ ва давлатӣ бе огоҳӣ тағйир меёбанд, бинобар ин манбаъ метавонад дар ҳар вақт вайрон
шавад. Ягон кафолат нест, ки ягон манбаъ ё худи Fontes кор карданро идома диҳад. Fontes
"чунон ки ҳаст" ("as is"), бе кафолат пешниҳод мешавад (бахшҳои 7 ва 8-и
[LICENSE](../../../LICENSE)).

## Матн нодуруст, кӯҳна ё манбаъ вайрон аст. Чӣ тавр хабар диҳам?

- Бо шакли "Broken or wrong source" issue кушоед:
  <https://github.com/ykarapazar/fontes/issues/new/choose>. Нависед, ки кадом юрисдиксия, чӣ
  пурсидед, чӣ гирифтед ва саҳифаи расмие, ки матни дурустро нишон медиҳад.
- Ё аз барномаи зеҳни сунъии худ хоҳиш кунед, ки "дар бораи хатои Fontes гузориш диҳад" (ё
  `fontes report-bug`-ро иҷро кунед). Шумо гузоришро пеш аз фиристодани ҳар чизе мебинед.
- Ё ба fontesmcp@proton.me нависед.

Дар гузориш маълумоти мизоҷон ё далелҳои махфиро дохил накунед.

**Агар шумо яке аз манбаъҳоро идора кунед** ва чизе нодуруст бошад (шартҳои истифодаи шумо,
robots.txt-и шумо, маҳдудиятҳои дархости шумо), ба fontesmcp@proton.me нависед. Манбаъ ислоҳ ё
хомӯш карда мешавад.

## Fontes аз абзорҳои таҳқиқоти ҳуқуқии дар абр ҷойгиршуда чӣ фарқ дорад?

- **Он дар компютери шумо кор мекунад.** Сервери Fontes ва ҳисоб нест. Ин инчунин маънои онро
  дорад, ки он танҳо дар барномаҳое кор мекунад, ки сервери маҳаллии MCP-ро оғоз карда
  метавонанд (Claude Desktop, Codex, Cursor, VS Code ва монанди инҳо), на дар барномаҳои танҳо
  веб, ки фақат пайвасткунакҳои дар абр ҷойгиршударо қабул мекунанд.
- **Он пойгоҳи додаҳо надорад.** Ҳар ҷустуҷӯ мустақиман ба сомона ё API-и худи нашркунанда
  меравад, бинобар ин натиҷаҳо ҳамон қадар наванд, ки манбаъ, ва сифати ҷустуҷӯ сифати худи
  манбаъ аст. Ҷустуҷӯи маъноӣ дар индекси интихобшуда нест.
- **Он маҳдудияти истифода муқаррар намекунад.** Fontes маҳдудияти моҳонаи даъватҳо надорад. Он
  дархостҳояшро ба ҳар сомона бо фосила мефиристад ва баъзе манбаъҳо маҳдуд мекунанд, ки ба
  онҳо то чӣ андоза зуд ё чӣ қадар зуд-зуд муроҷиат кардан мумкин аст.
- **Он манбаъкушод аст.** Шумо метавонед ҳар адаптерро хонед ва дақиқ бинед, ки ҳар матн аз
  куҷо меояд.
- **Дар паси он фурӯшанда нест.** Шартнома, хадамоти дастгирӣ ё ваъдаи вақти корӣ нест ("Кӣ
  онро нигоҳубин мекунад?"-ро бинед).

## Бо кадом барномаҳо ва системаҳо кор мекунад?

Ҳар барномаи MCP, ки сервери маҳаллиро (stdio) иҷро карда метавонад, масалан Claude Desktop,
Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio ва
Cline. Fontes дар macOS, Windows ва Linux, дар ҳар ҷое, ки uv кор мекунад (Python 3.13+), кор
мекунад. Дар Mac ё Windows PC насбкунанда бо як пахш Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio ва Cline-ро якбора танзим мекунад.
Қадамҳо барои ҳар барнома: [INSTALL.md](INSTALL.md).

Ҳоло не. Issue-ҳо, гузоришҳо дар бораи манбаъҳо ва дархостҳо барои юрисдиксияҳо пазируфта
мешаванд. [CONTRIBUTING.md](../../../CONTRIBUTING.md)-ро бинед.

# Насби Fontes

Fontes ба барномаи зеҳни сунъии шумо имкон медиҳад, ки қарорҳои судӣ ва қонунгузориро
мустақиман дар сомонаҳои судӣ ва давлатӣ дар зиёда аз 120 юрисдиксия ҷустуҷӯ кунад. Ҳар
натиҷа ба матни аслӣ пайванд медиҳад. Ин сервери стандартии MCP аст, бинобар ин дар ҳар
барномае, ки сервери маҳаллии MCP-ро иҷро карда метавонад, кор мекунад: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio, Cline ва
дигарон.

Барномаи худро интихоб кунед, қадамҳои онро иҷро кунед, сипас [санҷед, ки кор мекунад](#санҷидани-кор).

## Claude Desktop

1. Файли `.mcpb`-и Fontes-ро аз
   [нашри охирин](https://github.com/ykarapazar/fontes/releases/latest) боргирӣ кунед.
2. Ба он ду бор пахш кунед. Claude Desktop онро мекушояд.
3. **Install**-ро пахш кунед.

## Codex

Дар терминал:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI ва васеъкунандаи Codex IDE ин танзимро якҷоя истифода мебаранд (`~/.codex/config.toml`).
Ба шумо [uv](#uv-лозим-аст) лозим аст.

## Claude Code

Дар терминал:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Ба шумо [uv](#uv-лозим-аст) лозим аст.

## Барномаҳои дигар

Ба ҳар яке аз инҳо [uv](#uv-лозим-аст) лозим аст. Сабтро илова кунед, захира кунед, сипас
барномаро пурра пӯшед ва аз нав кушоед.

**Cursor:** дар `~/.cursor/mcp.json` (ҳамаи лоиҳаҳо) ё `.cursor/mcp.json` (як лоиҳа):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** аз Command Palette **MCP: Add Server**-ро иҷро кунед,
**Command (stdio)**-ро интихоб кунед, `uvx fontes-mcp`-ро ворид кунед ва серверро `fontes` ном
гузоред. Ё инро ба `~/.copilot/mcp-config.json` илова кунед:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

Танзимоти кӯҳнаи VS Code `.vscode/mcp.json`-ро истифода мебаранд, ки дар он калиди сатҳи боло
ба ҷои `mcpServers` `servers` аст.

**Gemini CLI:** дар терминал `gemini mcp add -s user fontes uvx fontes-mcp`. Ё инро ба
`~/.gemini/settings.json` илова кунед:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** файли танзимоти худро кушоед (**zed: open settings file**) ва илова кунед:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** дар панели тарафи рост ҷадвалаки **Program**-ро кушоед, **Install → Edit
mcp.json**-ро пахш кунед ва илова кунед:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** нишонаи **MCP Servers**-ро пахш кунед, ҷадвалаки **Configure**-ро кушоед,
**Configure MCP Servers**-ро пахш кунед ва ҳамон сабти `mcpServers`-ро, ки барои LM Studio
буд, илова кунед.

**Claude Desktop, дастӣ** (ба ҷои файли `.mcpb`): ҳамон сабти `mcpServers`-ро ба
`claude_desktop_config.json` илова кунед (macOS: `~/Library/Application Support/Claude/`,
Windows: `%APPDATA%\Claude\`).

**Ҳар барномаи дигари MCP** (Windsurf ва дигарон): ҳуҷҷатҳои худи он мегӯянд, ки он серверҳои
MCP-ро дар куҷо нигоҳ медорад. Аксарашон ҳамон сабтро қабул мекунанд: фармон `uvx`, аргумент
`fontes`.

Агар барнома `uvx`-ро ёфта натавонад, роҳи пурраи онро истифода баред (дар macOS ва Linux
`which uvx` онро нишон медиҳад).

## uv лозим аст

Codex, Claude Code ва барномаҳои дигар Fontes-ро бо `uvx` оғоз мекунанд, ки бо **uv**, абзори
хурди ройгони Astral, меояд. Барои насб кардани он
[дастури Astral](https://docs.astral.sh/uv/getting-started/installation/)-ро бинед ё иҷро
кунед:

- macOS ё Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

Баъзе манбаъҳо калиди ройгон талаб мекунанд: [KEYS.md](KEYS.md)-ро бинед.

## Санҷидани кор

Дар чати нав пурсед: *"Fontes дар кадом юрисдиксияҳо ҷустуҷӯ карда метавонад?"* Барнома бояд
бо рӯйхати кишварҳо ҷавоб диҳад. Агар ҷавоб надиҳад, барномаро боз як бор пурра пӯшед ва аз
нав кушоед.

## Насбкунанда бо як пахш (Mac)

Насбкунандаи Mac Fontes-ро якбора дар ҳамаи барномаҳои шумо танзим мекунад: Claude Desktop, Codex,
Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio ва Cline.
Насбкунандаи Windows ба наздикӣ мебарояд; то он вақт қадамҳои барномаи худро дар боло истифода
баред.

**Пеш аз оғоз:** ҳар яке аз ин барномаҳоро пурра пӯшед. Ин бештар барои Claude Code муҳим
аст: ҳангоми кор он `~/.claude.json`-ро аз нав менависад ва метавонад тағйироти насбкунандаро
бекор кунад. Агар Claude Code-ро пӯшида натавонед, ба ҷои ин Fontes-ро ба он бо
`claude mcp add` илова кунед ([Claude Code](#claude-code)-ро бинед).

**Mac**

1. Насбкунандаи Mac-ро (`Fontes-Installer-…-mac.zip`) аз [нашри
   охирин](https://github.com/ykarapazar/fontes/releases/latest) боргирӣ кунед ва барои кушодани
   архив ба он ду бор пахш кунед.
2. Ба **Fontes Installer** ду бор пахш кунед. Агар Mac-и шумо пурсад, ки оё барномаи аз интернет
   боргиришударо кушояд, **Open**-ро пахш кунед.
3. **Насб кардан**-ро интихоб кунед ва **OK**-ро пахш кунед. Танзим тақрибан як дақиқа вақт мегирад.
4. Паём барномаҳоеро, ки танзим шуданд, номбар мекунад. **Тайёр**-ро пахш кунед, сипас он
   барномаҳоро аз нав кушоед. Барои аввал илова кардани калидҳои ройгони ихтиёрӣ, ба ҷои он **Илова
   кардани калидҳо**-ро пахш кунед; [Қадами калидҳо](#қадами-калидҳо)-ро бинед.

**Windows** (пас аз баромадани насбкунандаи Windows)

1. **Fontes Installer**-и боргиришударо аз архив бароред (тугмаи рост → Extract All).
2. Ба **Install Fontes.cmd** ду бор пахш кунед.
   - Агар Windows "Windows protected your PC"-ро нишон диҳад: **More info**-ро, сипас
     **Run anyway**-ро пахш кунед.
3. Вақте ки мепурсад, ки оё шумораи беноми истифодаро фиристад, барои "не" Enter-ро пахш
   кунед.
4. Он мепурсад, ки оё ҳозир калидҳоро илова кунад. Барои гузаштан Enter-ро пахш кунед;
   [Қадами калидҳо](#қадами-калидҳо)-ро бинед.
5. Вақте ки он **Тайёр** мегӯяд, барномаҳои зеҳни сунъии худро аз нав кушоед. Агар яке ҳанӯз
   кор мекард, онро пурра пӯшед (инчунин аз минтақаи системавӣ, дар назди соат) ва аз нав
   кушоед.

Дар охир насбкунанда барномаҳоеро, ки танзим кард, номбар мекунад.

### Кадом барномаҳоро танзим мекунад

Он барномаро танҳо агар ҷузвдони танзимоти он барнома аллакай дар компютери шумо бошад,
танзим мекунад. Claude Code танҳо агар `~/.claude.json` мавҷуд бошад, танзим мешавад. Claude
Desktop ҳамеша танзим мешавад. Ҳар барнома дар ин файл як сабт, `fontes`, мегирад:

| Барнома | Файл (Mac ва Linux) | Файл (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json` ва нусхаи худи версияи Microsoft Store |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` ё дар версияҳои кӯҳна `~/.codeium/windsurf/mcp_config.json` | `%APPDATA%\devin\mcp_config.json` ё `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code танзим мешавад, агар `~/.copilot` ё ҷузвдони танзимоти худи VS Code мавҷуд бошад.

Ба ду барнома боз як қадам лозим аст:

- **Windsurf:** пас аз аз нав кушодан, дар Cascade навсозиро пахш кунед.
- **Cline дар дохили васеъкунандаи кӯҳнаи VS Code:** Fontes-ро дастӣ илова кунед
  ([Cline](#барномаҳои-дигар)-ро бинед).

### Қадами калидҳо

Дарҳол пас аз насб, насбкунанда пешниҳод мекунад, ки калидҳои ройгони Фаронса ва ИМА-ро илова
кунад. Барои баъдтар илова ё тағйир додани онҳо:

- **Mac:** **Fontes Installer**-ро аз нав кушоед ва **Илова ё тағйир додани калидҳо**-ро интихоб
  кунед.
- **Windows:** ба **Add or change keys.cmd** дар ҷузвдони насбкунанда ду бор пахш кунед.

Матни чопшаванда пинҳон аст. Калидҳо ба ҳар барномае, ки аллакай Fontes дорад, ворид
мешаванд. Баъд барномаҳоро пурра пӯшед ва аз нав кушоед. Калидҳоро аз куҷо гирифтан ва онҳо
чиро мекушоянд: [KEYS.md](KEYS.md).

### Нусхаҳои эҳтиётӣ, иҷрои такрорӣ ва хориҷ кардан

Насбкунанда танҳо сабти `fontes`-ро тағйир медиҳад. Ҳамаи танзимот ва шарҳҳои дигар ҳамон тавре
ки буданд, мемонанд. Пеш аз тағйир додани файл, он нусхаи онро дар паҳлӯяш бо номи
`<file>.fontes-backup-<date>` захира мекунад. Нусхаҳое, ки пас аз илова кардани калидҳо сохта
шудаанд, он калидҳоро низ доранд: онҳоеро, ки дигар лозим нестанд, нест кунед. Он инчунин uv-ро
насб мекунад. Аз нав иҷро кардани он бехатар аст: он танзимро таъмир мекунад ва чизи дигареро
тағйир намедиҳад.

Барои хориҷ кардани Fontes **Fontes Installer**-ро кушоед ва **Хориҷ кардан**-ро интихоб кунед (Mac) ё ба **Uninstall Fontes.cmd** (Windows) ду бор пахш кунед. Он сабти `fontes`-ро, бо калидҳо, аз ҳар барнома хориҷ мекунад.
Танзимоти дигари шумо ва нусхаҳои эҳтиётӣ мемонанд.

## Навсозиҳо

- **Насбкунанда ва файли `.mcpb`:** ба шумо ҳеҷ кор кардан лозим нест. Рӯзе як бор, вақте ки
  барнома оғоз мешавад, Fontes дар пасзамина версияи навтарро месанҷад ва онро омода мекунад;
  дафъаи дигар, ки барнома оғоз мешавад, онро истифода мебарад. Агар навсозӣ боргирӣ нашавад ё
  кор накунад, Fontes истифодаи версияеро, ки кор мекард, идома медиҳад.
- **`uvx`:** Fontes ба шумо дар болои рӯйхати юрисдиксияҳояш хабар медиҳад, ки версияи навтар
  мавҷуд аст. Барои ҳамеша иҷро кардани версияи навтарин, ба ҷои `fontes-mcp` `fontes-mcp@latest`-ро
  истифода баред.

Барои ин ҳеҷ маълумот дар бораи шумо ё ҷустуҷӯҳои шумо ба ҳеҷ ҷо фиристода намешавад.

## Махфият

Fontes бо нобаёнӣ дар бораи шумо ё ҷустуҷӯҳои шумо ҳеҷ чиз намефиристад. Шумораи истифода
танҳо бо розигии шумо фаъол мешавад ва гузориши хато танҳо пас аз он ки шумо онро дидед ва
тасдиқ кардед, фиристода мешавад. Тафсилот: [PRIVACY.md](PRIVACY.md).

## Хориҷ кардан

Сабти `fontes`-ро аз танзимоти MCP-и барномаи худ хориҷ кунед (дар Claude Code:
`claude mcp remove fontes`), сипас барномаро пурра пӯшед ва аз нав кушоед.

## Донистан муфид аст

Fontes манбаъҳои оммавиро, асосан сомонаҳои судӣ ва давлатиро, мехонад. Он манбаъҳои
ғайрирасмиро дар ҷавобҳояш қайд мекунад. Пеш аз такя кардан ба қарор ё модда ҳамеша пайванди
манбаъро кушоед.

Агар чизе нодуруст шавад, он чиро, ки кардед, ва хатоеро, ки дидед, ба fontesmcp@proton.me
нависед.

## Пеш аз такя кардан

- Fontes абзори таҳқиқотӣ аст, на маслиҳати ҳуқуқӣ. Истифодаи он касеро адвокати шумо
  намегардонад.
- Он "чунон ки ҳаст" ("as is"), бе ягон кафолат пешниҳод мешавад ва муаллифонаш, то ҳадде ки
  қонун иҷозат медиҳад, барои тарзи истифодаи он ҷавобгар нестанд. Шартҳои пурра дар
  [иҷозатнома](../../../LICENSE) (Apache 2.0) мебошанд.

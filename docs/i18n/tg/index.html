Қарорҳои судӣ ва қонунгузорӣ барои барномаи зеҳни сунъии шумо, ки мустақиман аз сомонаҳои судӣ ва давлатӣ хонда мешаванд.

Beta · ройгон · манбаъкушод · манбаъҳо ҳар рӯз санҷида мешаванд

Fontes сервери ройгон ва манбаъкушоди MCP аст. Он дар ҳар барномае, ки сервери маҳаллии Model Context Protocol-ро иҷро карда метавонад, кор мекунад: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio ва дигарон. Саволи ҳуқуқиро бо забони оддӣ диҳед: барномаи зеҳни сунъии шумо қарорҳои судӣ ва қонунгузориро мустақиман дар сомонаҳои давлатӣ ва судӣ дар 125 юрисдиксия ва судҳои байналмилалӣ ҷустуҷӯ мекунад ва ҳар натиҷаро ба матни аслӣ пайванд медиҳад. Он инчунин метавонад қонунро чунон нишон диҳад, ки дар санаи гузашта буд, ва қонунгузориро аз 91 кишвари дигар аз сабти Lexifina (на аз нашри расмӣ) хонад. Он барои ҳуқуқшиносон ва муҳаққиқони ҳуқуқ ва барои ҳар касе, ки мехоҳад қонунро аз манбаи худаш хонад, сохта шудааст.

Ин тарҷума бо ёрии мошин омода шудааст. Нусхаи англисӣ асосӣ ба ҳисоб меравад.

Чӣ кор мекунад

  • Таҷрибаи судӣ ва қонунгузориро дар лаҳзаи пурсиши шумо дар сомона ё API-и худи нашркунанда ҷустуҷӯ мекунад.
  • Ҳар натиҷа манбаи худро номбар мекунад ва ба он пайванд медиҳад, то шумо матни аслиро санҷида тавонед.
  • Fontes пойгоҳи додаҳо нигоҳ намедорад ва ҳисоб талаб намекунад. Саволҳои шумо ба манбаи ҷустуҷӯшаванда мераванд; барои нусхаҳои пешинаи қонунҳо ва 91 кишвари иловагӣ (ва қонунҳои Ҳиндустон) онҳо ба хидмати ҷамъиятии Lexifina мераванд, ҳамчун сомонаи расмӣ ё ба ҷои он. Барои хомӯш кардани ин WLM_LEXIFINA=0 гузоред. Шумораи истифода ва гузоришҳои хато танҳо бо розигии шумо фиристода мешаванд.

Fontes маслиҳати ҳуқуқӣ нест, балки абзори ёрирасон барои таҳқиқот аст ва истифодаи он муносибати адвокат ва мизоҷро ба вуҷуд намеорад. Он "чунон ки ҳаст" ("as is"), бе ягон кафолат пешниҳод мешавад (иҷозатномаи Apache 2.0-ро бинед). Баъзе манбаъҳо версияҳои ошкоро ғайрирасмӣ мебошанд ва ҳар кадом шартҳои истифодаи худро дорад; Fontes инро дар ҷавобҳояш мегӯяд. Пеш аз такя кардан қарор ё моддаро пурра хонед. Fontes мустақил аст ва бо ягон суд, ҳукумат ё нашркунанда вобаста нест.

Насб

  • Claude Desktop: файли .mcpb-и Fontes-ро аз нашри охирин боргирӣ кунед, ба он ду бор пахш кунед, сипас Install-ро пахш кунед.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline ва барномаҳои дигар: Fontes-ро ба танзимоти MCP-и барнома илова кунед. Аксарашон ин сабтро қабул мекунанд; дар дастури насб файл ва порча барои ҳар барнома ҳаст.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx бо uv меояд. Дар macOS ё Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Дар Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Сипас барномаро аз нав оғоз кунед ва пурсед: "Fontes дар кадом юрисдиксияҳо ҷустуҷӯ карда метавонад?"

Дар Mac ё компютери Windows насбкунанда бо як пахш Fontes-ро дар Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio ва Cline, дар ҳар кадоме, ки дар компютери шумост, танзим мекунад, сипас пешниҳод мекунад, ки калидҳои шуморо илова кунад. Насбкунандаи компютери худро аз нашри охирин боргирӣ кунед ва пеш аз иҷро кардани он ин барномаҳоро пӯшед. Тафсилот дар дастури насб. Баъзе манбаъҳо калиди ройгон талаб мекунанд: KEYS.md-ро бинед.

Fontes тибқи иҷозатномаи Apache 2.0 манбаъкушод аст. Матнҳои ҳуқуқӣ зери иҷозатномаи ҳар нашркунанда боқӣ мемонанд.

# Fontes: よくある質問

## Fontes とは何ですか？

無料のオープンソース MCP サーバー（Apache 2.0）です。Model Context Protocol に対応したアプリ（Claude、
Codex、Cursor、VS Code、Gemini CLI など）が、120 以上の法域と国際裁判所（124 のアダプター）について、
裁判所や政府のウェブサイトで裁判例と法令をリアルタイムで検索できるようにします。すべての結果に情報源が
明記され、原文へのリンクが付きます。

## テキストは公式のものですか？

ほとんどはそうですが、常にではありません。

- ほとんどの情報源は、裁判所、省庁、または官報が運営しています。
- 一部の現行統合版は政府が公開していますが、明示的に非公式とされています。正本は官報だけです。
- 政府のサイトではない情報源もわずかにあります（例: LexiVox、LawPhil、Maqam、Wikisource）。

これらの情報源から得た回答には、Fontes が必ず「非公式の情報源」という注記を付けます。何かを引用する前に、
公式の公布版を確認してください。[README](README.md#収録範囲) の収録範囲の表と `list_jurisdictions` が、
各法域の情報源を示します。

## どの法域を、どの程度収録していますか？

124 のアダプター: 国連加盟国 108 か国、香港、コソボ、パレスチナ、台湾、DIFC 裁判所、そして 11 の国際裁判所・
国際機関（欧州人権裁判所、EU、国際司法裁判所、WTO など）。

収録の程度は大きく異なります。厳格な基準（最上位の通常裁判所の先例、または憲法と主要な法律に完全に
アクセスできること）では、124 のうち 72 が収録済みとみなされます。[COVERAGE.md](../../COVERAGE.md) に、
各法域について Fontes がアクセスできるもの、できないもの、その理由が記載されています。

## API キーは必要ですか？

ほとんどすべての法域で不要です。一部の情報源には無料のキーが必要です: [KEYS.md](KEYS.md) をご覧ください。

- **フランス:** 必要です。`WLM_FR_PISTE_CLIENT_ID` と `WLM_FR_PISTE_CLIENT_SECRET` を設定するまで、
  フランスはオフです。これらは、Judilibre と Légifrance を購読したアプリを持つ無料の PISTE アカウント
  （piste.gouv.fr）から取得します。
- **米国:** 任意です。判例検索はキーなしでも動作しますが、共有のデモキーでは IP アドレスごとに 1 日約 10 回
  しか検索できません。`WLM_US_GOVINFO_KEY` に無料の api.data.gov キーを設定すると、この上限が上がります。

これらは、アプリの MCP 設定で Fontes サーバーの環境変数として設定します。インストーラーの公開後は、
インストール後にこれらを尋ね、後から **Add or change keys** ランチャーで変更できるようになります。

これとは別に、自動アクセスには発行元の許可が必要だと利用条件に定めている情報源がわずかにあります。これらは
OFF と表示され、オフのままです。キーでは変わりません。変わるのは発行元の許可を得た場合だけです（その場合は
`WLM_PERMITTED=<codes>` を設定します）。

## 何がコンピューターの外に送られますか？

検索内容は、検索している情報源にだけ送られます。Fontes はデータベースを持たず、アカウントも不要です。

情報源のほかには、Fontes は 1 日 1 回 PyPI に新しいバージョンがあるかを問い合わせます
（`FONTES_NO_UPDATE_CHECK=1` でオフ）。利用回数はオンにしない限りオフで、バグ報告は内容を見て確認した後にのみ
送信されます。AI アプリは、そのアプリ自身の利用条件に従って会話を見ます。

詳細: [PRIVACY.md](PRIVACY.md)。

## これは法的助言ですか？

いいえ。Fontes は調査ツールです。テキストを見つけますが、それがあなたの案件にとって何を意味するかは
伝えません。また、利用しても誰とも弁護士・依頼者関係は生じません。AI アプリはテキストを読み違えることが
あるので、依拠する前に判決や条文の全文を読んでください。助言が必要な場合は、質問に関係する地で資格を持つ
弁護士に相談してください。

## テキストが誤っている、古い、または情報源が動かない。どう報告すればよいですか？

- 「Broken or wrong source」フォームで issue を作成してください:
  <https://github.com/ykarapazar/fontes/issues/new/choose>。どの法域か、何を質問したか、何が返ってきたか、
  正しいテキストを示す公式のページを書いてください。
- または、AI アプリに「Fontes のバグを報告して」と頼んでください（または `fontes report-bug` を実行）。
  何かが送信される前に報告の内容が表示されます。
- または、fontesmcp@proton.me までメールしてください。

報告に依頼者の詳細や機密の事実を含めないでください。

**情報源を運営している方へ:** 誤り（利用条件、robots.txt、レート制限）があれば、fontesmcp@proton.me まで
メールしてください。その情報源を修正するか、オフにします。

## Fontes はホスト型のリーガルリサーチツールとどう違いますか？

- **お使いのコンピューター上で動作します。** Fontes のサーバーもアカウントもありません。そのため、ローカルの
  MCP サーバーを起動できるアプリ（Claude Desktop、Codex、Cursor、VS Code など）でのみ動作し、ホスト型の
  コネクターしか受け付けないウェブ専用アプリでは動作しません。
- **データベースを持ちません。** 検索のたびに発行元自身のウェブサイトや API にリアルタイムでアクセスするので、
  結果は情報源と同じだけ新しく、検索の質も情報源次第です。選別されたインデックスに対するセマンティック検索は
  ありません。
- **利用上限を設けていません。** Fontes には月ごとの呼び出し回数の上限はありません。各ウェブサイトへの
  リクエストには間隔を空けており、問い合わせの速さや回数を制限している情報源もあります。
- **オープンソースです。** すべてのアダプターを読んで、各テキストがどこから来ているかを正確に確認できます。
- **背後にベンダーはいません。** 契約、サポート窓口、稼働率の約束はありません（「誰が保守していますか？」を
  参照）。

## どのアプリやシステムで動作しますか？

ローカル（stdio）サーバーを実行できる MCP アプリならどれでも。たとえば Claude Desktop、Claude Code、Codex、
Cursor、VS Code（GitHub Copilot）、Gemini CLI、Windsurf、Zed、LM Studio、Cline。Fontes は macOS、Windows、
Linux で、uv が動く環境ならどこでも動作します（Python 3.13+）。Mac または Windows PC では、ワンクリックインストーラーが Claude Desktop、
Codex、Claude Code、Cursor、VS Code、Windsurf、Gemini CLI、Zed、LM Studio、Cline を一度に設定します。
アプリごとの手順: [INSTALL.md](INSTALL.md)。

# Fontes プライバシーに関するお知らせ

Fontes はお使いのコンピューター上で動作します。検索内容と開いた文書は、あなたのコンピューター、検索する
公式の情報源、使っている AI アプリ（そのアプリ自身の利用条件に従います）の間だけでやり取りされます。
Fontes 自体は、**デフォルトでは** Fontes の開発者に**何も送信しません**。

## コンピューターの外に送られる可能性があるものと、そのタイミング

**1. アップデートの確認（デフォルトでオン）。** 1 日 1 回、Fontes は公開の Python パッケージインデックス
である PyPI に最新のバージョンを問い合わせます。このリクエストには、あなたやあなたの作業に関する情報は
含まれません。ほかのダウンロードと同じく、PyPI にはあなたの IP アドレスが見えます。オフにするには、
`FONTES_NO_UPDATE_CHECK=1`（アプリ内のお知らせ）と `FONTES_NO_AUTO_UPDATE=1`（インストーラーの自動
アップデート）を設定します。

**2. 利用回数（オンにしない限りオフ）。** オプトインした場合、Fontes は 1 日 1 回、次の内容を送信します:

- Fontes のバージョンと OS の種類（macOS、Windows、Linux）
- 1 日ごとの、各ツールが各法域コードについて使われた回数。例:
  「2026-11-10, nl, search_caselaw, 12」

送信される内容はこれだけです。検索内容、文書や事件の ID、文書のテキスト、あなたの名前、アカウント、
あなたやあなたのコンピューターを識別する ID が含まれることは決してありません。回数は送信されるまで
あなたのコンピューター上（Fontes のキャッシュフォルダー内の `stats.json`）に保存され、送信に失敗した場合は
翌日まで待ちます。

- **オプトイン**: インストーラーに尋ねられたときに「y」と答えるか、Fontes サーバーに `FONTES_STATS=1` を
  設定します。
- **オプトアウト**: インストーラーをもう一度実行してその質問で Enter を押すか、`FONTES_STATS` を削除
  します。`stats.json` を削除すると、まだ送信されていない内容は破棄されます。

**3. バグ報告（送信したときのみ）。** バグ報告を求めると（`fontes report-bug`、または AI アプリに Fontes の
バグ報告を依頼）、Fontes はまず報告の全文を表示し、確認した場合にのみ送信します。報告には、Fontes の
バージョン、OS の種類、最後に失敗したツール呼び出しの法域コード、ツール名とエラーメッセージ（検索語と
ID は除去済み）、そしてメモ（書いた場合）が含まれます。メモに依頼者の詳細を書かないでください。この機能の
ため、Fontes は最後のエラーをあなたのコンピューター上に保存します（キャッシュフォルダー内の
`last-error.json`。毎回置き換えられます）。これが単独で送信されることはありません。

## 送信先と保存期間

利用回数とバグ報告は、Fontes の開発者が運営する小さなサーバー（`relay.kinetra.fit`）に送られます。
IP アドレスは保存しません。大量のリクエストを止めるためにメモリ上で短時間使うだけで、ウェブサーバーは
これについてアクセスログを残しません。回数は日ごとの合計に加算され、個々の送信内容は保存されません。
合計は最長 2 年、バグ報告は最長 1 年保存した後、削除します。何も販売・共有しません。

そのサーバーに接続できない場合は何も送信されません。回数はあなたのコンピューター上に残り、バグ報告は
代わりに issue トラッカーに案内されます。

## 責任者と法的根拠

利用回数とバグ報告のデータ管理者は、Fontes の開発者である Yüce Karapazar です。連絡先:
fontesmcp@proton.me。

法的根拠はあなたの同意です（英国 GDPR および EU GDPR の第 6 条第 1 項 (a)）。利用回数はオプトインした
場合にのみ、バグ報告は確認した後にのみ送信されます。上記の方法でオプトアウトすることで、いつでも同意を
撤回できます。撤回は、それ以前に送信された内容には影響しません。

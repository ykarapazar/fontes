Fontes は無料のオープンソース MCP サーバーです。ローカルの Model Context Protocol サーバーを実行できるアプリならどれでも動作します: Claude Desktop、Claude Code、Codex、Cursor、VS Code（GitHub Copilot）、Gemini CLI、Windsurf、Zed、LM Studio など。普段の言葉で法律の質問をすると、AI アプリが 120 以上の法域と国際裁判所について、政府や裁判所のウェブサイトから裁判例と法令をリアルタイムで検索し、すべての結果に原文へのリンクを付けます。弁護士や法律研究者のために、そして法律を原典で読みたいすべての人のために作られています。

できること

  • 質問したその時点で、発行元自身のウェブサイトまたは API から裁判例と法令を検索します。
  • すべての結果に情報源が明記され、リンクが付くので、原文を確認できます。
  • Fontes はデータベースを持たず、アカウントも不要です。質問は検索中の情報源にだけ送られます。利用回数とバグ報告はオプトインです。

Fontes は調査の補助であり、法的助言ではありません。利用しても弁護士・依頼者関係は生じません。「現状のまま」、いかなる保証もなく提供されます（Apache 2.0 ライセンスを参照）。一部の情報源は明示的に非公式であり、情報源ごとに独自の利用条件があります。Fontes は回答の中でそのことを示します。裁判例や条文に依拠する前に、その全文を読んでください。Fontes は独立しており、いずれの裁判所、政府、発行元とも提携していません。

インストール

  • Claude Desktop: 最新リリースから Fontes の .mcpb ファイルをダウンロードしてダブルクリックし、Install をクリックします。
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor、VS Code、Gemini CLI、Zed、LM Studio、Cline、その他のアプリ: アプリの MCP 設定に Fontes を追加します。ほとんどのアプリは下のエントリーを使います。各アプリのファイルとスニペットはインストールガイドにあります。
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx は uv に含まれています。macOS または Linux では: curl -LsSf https://astral.sh/uv/install.sh | sh。Windows（PowerShell）では: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"。

その後アプリを再起動して、「Fontes はどの法域を検索できますか？」と質問してください。

Mac または Windows PC では、ワンクリックインストーラーが Claude Desktop、Codex、Claude Code、Cursor、VS Code、Windsurf、Gemini CLI、Zed、LM Studio、Cline のうち、お使いのコンピューターにあるものすべてに Fontes を設定し、キーを追加するかどうかを尋ねます。お使いのコンピューター用のインストーラーを最新リリースからダウンロードし、実行する前にこれらのアプリを終了してください。詳細はインストールガイドをご覧ください。一部の情報源には無料のキーが必要です: KEYS.md をご覧ください。

Fontes は Apache 2.0 ライセンスのオープンソースソフトウェアです。法令テキストは引き続き各発行元のライセンスに従います。

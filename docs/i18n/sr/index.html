Fontes је бесплатан MCP сервер отвореног кода. Ради у свакој апликацији која може да покрене локални Model Context Protocol сервер: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio и другима. Поставите правно питање обичним језиком: ваша AI апликација претражује судске одлуке и прописе уживо на сајтовима државних органа и судова, у више од 120 јурисдикција и међународних судова, и даје везу ка оригиналу сваког резултата. Направљен је за правнике и истраживаче права, као и за свакога ко жели да чита право на његовом извору.

Шта ради

  • Претражује судску праксу и прописе у тренутку када питате, са сопственог сајта или API-ја издавача.
  • Сваки резултат наводи свој извор и даје везу ка њему, како бисте могли да проверите оригинал.
  • Fontes не води базу података и није му потребан налог. Ваша питања иду само извору који се претражује. Бројеви коришћења и пријаве грешака су само уз ваш пристанак (opt-in).

Fontes је помоћно средство за истраживање, а не правни савет, и његово коришћење не ствара однос адвокат–клијент. Пружа се „такав какав јесте“, без гаранције (погледајте лиценцу Apache 2.0). Неки извори су изричито незваничне верзије, и сваки има своје услове коришћења; Fontes то наводи у својим одговорима. Прочитајте целу одлуку или одредбу пре него што се на њу ослоните. Fontes је независан и није повезан ни са једним судом, државним органом нити издавачем.

Инсталација

  • Claude Desktop: преузмите Fontes датотеку .mcpb из најновијег издања, двапут кликните на њу, па кликните Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline и друге апликације: додајте Fontes у MCP подешавања апликације. Већина прихвата овај унос; упутство за инсталацију садржи датотеку и исечак за сваку апликацију.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx долази уз uv. На macOS-у или Linux-у: curl -LsSf https://astral.sh/uv/install.sh | sh. На Windows-у (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Затим поново покрените апликацију и питајте: „У којим јурисдикцијама Fontes може да претражује?“

На Mac-у, инсталациони програм на један клик подешава Fontes у Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio и Cline — у свакој од њих која је на вашем рачунару — а затим нуди да дода ваше кључеве. Преузмите га из најновијег издања и затворите те апликације пре него што га покренете. Инсталациони програм за Windows је у припреми. Детаљи у упутству за инсталацију. Неким изворима је потребан бесплатан кључ: погледајте KEYS.md.

Fontes је отвореног кода, под лиценцом Apache 2.0. Правни текстови остају под лиценцом сваког издавача.

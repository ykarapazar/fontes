# Инсталација програма Fontes

Fontes омогућава вашој AI апликацији да претражује судске одлуке и прописе уживо на сајтовима
судова и државних органа у више од 120 јурисдикција. Сваки резултат садржи везу ка оригиналу.
То је стандардни MCP сервер, па ради у свакој апликацији која може да покрене локални MCP
сервер: Claude Desktop, Codex, Claude Code, Cursor, VS Code (GitHub Copilot), Gemini CLI,
Windsurf, Zed, LM Studio, Cline и другима.

Изаберите своју апликацију, пратите њене кораке, а затим
[проверите да ли ради](#проверите-да-ли-ради).

## Claude Desktop

1. Преузмите Fontes датотеку `.mcpb` из
   [најновијег издања](https://github.com/ykarapazar/fontes/releases/latest).
2. Двапут кликните на њу. Claude Desktop ће је отворити.
3. Кликните **Install**.

## Codex

У терминалу:

```bash
codex mcp add fontes -- uvx fontes-mcp
```

Codex CLI и Codex проширење за IDE деле ово подешавање (`~/.codex/config.toml`).
Потребан вам је [uv](#потребан-вам-је-uv).

## Claude Code

У терминалу:

```bash
claude mcp add fontes -- uvx fontes-mcp
```

Потребан вам је [uv](#потребан-вам-је-uv).

## Друге апликације

Свакој од њих је потребан [uv](#потребан-вам-је-uv). Додајте унос, сачувајте, а затим
затворите и поново отворите апликацију.

**Cursor:** у `~/.cursor/mcp.json` (сви пројекти) или `.cursor/mcp.json` (један пројекат):

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**VS Code (GitHub Copilot):** покрените **MCP: Add Server** из Command Palette, изаберите
**Command (stdio)**, унесите `uvx fontes-mcp` и назовите сервер `fontes`. Или ово додајте у
`~/.copilot/mcp-config.json`:

```json
{
  "mcpServers": {
    "fontes": { "type": "stdio", "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

Старија подешавања за VS Code користе `.vscode/mcp.json`, где је кључ највишег нивоа `servers`
уместо `mcpServers`.

**Gemini CLI:** у терминалу `gemini mcp add -s user fontes uvx fontes-mcp`. Или ово додајте у
`~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Zed:** отворите датотеку подешавања (**zed: open settings file**) и додајте:

```json
{
  "context_servers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**LM Studio:** на десној бочној траци отворите картицу **Program**, кликните **Install → Edit
mcp.json** и додајте:

```json
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}
```

**Cline:** кликните икону **MCP Servers**, отворите картицу **Configure**, кликните **Configure
MCP Servers** и додајте исти унос `mcpServers` као за LM Studio.

**Claude Desktop ручно** (уместо датотеке `.mcpb`): додајте исти унос `mcpServers` у
`claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`, Windows:
`%APPDATA%\Claude\`).

**Свака друга MCP апликација** (Windsurf и друге): њена документација наводи где чува своје MCP
сервере. Већина прихвата исти унос: команда `uvx`, аргумент `fontes`.

Ако апликација не може да пронађе `uvx`, наведите пуну путању до њега (на macOS-у и Linux-у
приказује је `which uvx`).

## Потребан вам је uv

Codex, Claude Code и друге апликације покрећу Fontes преко `uvx`, који долази уз **uv**, мали
бесплатан алат компаније Astral. Да бисте га инсталирали, погледајте
[упутство компаније Astral](https://docs.astral.sh/uv/getting-started/installation/) или покрените:

- macOS или Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

## Кључеви

Неким изворима је потребан бесплатан кључ: погледајте [KEYS.md](KEYS.md).

## Проверите да ли ради

У новом разговору питајте: *„У којим јурисдикцијама Fontes може да претражује?“* Апликација
треба да одговори списком држава. Ако не одговори, још једном затворите и поново отворите
апликацију.

## Инсталациони програм на један клик (Mac)

Инсталациони програм за Mac подешава Fontes у свим вашим апликацијама одједном: Claude Desktop,
Codex, Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, Zed, LM Studio и Cline.
Инсталациони програм за Windows је у припреми; до тада користите кораке за своју апликацију изнад.

**Пре него што почнете:** потпуно затворите сваку од ових апликација. То је посебно важно за
Claude Code: док ради, он преписује `~/.claude.json` и може поништити измену коју је направио
инсталациони програм. Ако не можете да затворите Claude Code, додајте Fontes у њега помоћу
`claude mcp add` (погледајте [Claude Code](#claude-code)).

**Mac**

1. Преузмите инсталациони програм за Mac (`Fontes-Installer-…-mac.zip`) из [најновијег
   издања](https://github.com/ykarapazar/fontes/releases/latest) и двапут кликните на њега да бисте
   га распаковали.
2. Двапут кликните на **Fontes Installer**. Ако Mac пита да ли желите да отворите апликацију
   преузету са интернета, кликните на **Open**.
3. Изаберите **Инсталирај** и кликните на **У реду**. Подешавање траје око минут.
4. Порука наводи апликације које је подесио. Кликните на **Готово**, па поново отворите те
   апликације. Да бисте прво додали опционе бесплатне кључеве, уместо тога кликните на **Додај
   кључеве**; погледајте [Корак са кључевима](#корак-са-кључевима).

**Windows** (када изађе инсталациони програм за Windows)

1. Распакујте преузети **Fontes Installer** (десни клик → Extract All).
2. Двапут кликните на **Install Fontes.cmd**.
   - Ако Windows прикаже „Windows protected your PC“: кликните **More info**, па
     **Run anyway**.
3. Када пита да ли да се шаљу анонимни бројеви коришћења, притисните Enter да бисте одбили.
4. Пита да ли желите да сада додате кључеве. Притисните Enter да бисте прескочили; погледајте
   [Корак са кључевима](#корак-са-кључевима).
5. Када се појави **Done**, поново отворите своје AI апликације. Ако је нека од њих још
   радила, потпуно је затворите (укључујући и из системске траке, поред сата) и поново је
   отворите.

На крају инсталациони програм наводи апликације које је подесио.

### Које апликације подешава

Подешава апликацију само ако фасцикла са подешавањима те апликације већ постоји на вашем
рачунару. Claude Code се подешава само ако постоји `~/.claude.json`. Claude Desktop се увек
подешава. Свака апликација добија један унос, `fontes`, у овој датотеци:

| Апликација | Датотека (Mac и Linux) | Датотека (Windows) |
|---|---|---|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (Linux: `~/.config/Claude/`) | `%APPDATA%\Claude\claude_desktop_config.json`, као и сопствена копија верзије из Microsoft Store-а |
| Codex | `~/.codex/config.toml` | `%USERPROFILE%\.codex\config.toml` |
| Claude Code | `~/.claude.json` | `%USERPROFILE%\.claude.json` |
| Cursor | `~/.cursor/mcp.json` | `%USERPROFILE%\.cursor\mcp.json` |
| VS Code (Copilot) | `~/.copilot/mcp-config.json` | `%USERPROFILE%\.copilot\mcp-config.json` |
| Windsurf | `~/.config/devin/mcp_config.json` или `~/.codeium/windsurf/mcp_config.json` у старијим верзијама | `%APPDATA%\devin\mcp_config.json` или `%USERPROFILE%\.codeium\windsurf\mcp_config.json` |
| Gemini CLI | `~/.gemini/settings.json` | `%USERPROFILE%\.gemini\settings.json` |
| Zed | `~/.config/zed/settings.json` | `%APPDATA%\Zed\settings.json` |
| LM Studio | `~/.lmstudio/mcp.json` | `%USERPROFILE%\.lmstudio\mcp.json` |
| Cline | `~/.cline/data/settings/cline_mcp_settings.json` | `%USERPROFILE%\.cline\data\settings\cline_mcp_settings.json` |

VS Code се подешава ако постоји `~/.copilot` или сопствена фасцикла подешавања за VS Code.

Двема апликацијама је потребан још један корак:

- **Windsurf:** након поновног отварања кликните дугме за освежавање у Cascade-у.
- **Cline у старом VS Code проширењу:** додајте Fontes ручно (погледајте [Cline](#друге-апликације)).

### Корак са кључевима

Одмах након инсталације, инсталациони програм нуди да дода бесплатне кључеве за Француску и
САД. Да бисте их касније додали или променили:

- **Mac:** поново отворите **Fontes Installer** и изаберите **Додај или промени кључеве**.
- **Windows:** двапут кликните на **Add or change keys.cmd** у фасцикли инсталационог програма.

Унос је скривен. Кључеви се уписују у сваку апликацију која већ има Fontes. Након тога затворите
и поново отворите апликације. Где се добијају кључеви и шта откључавају: [KEYS.md](KEYS.md).

### Резервне копије, поновна покретања и уклањање

Инсталациони програм мења само унос `fontes`. Сва остала подешавања и коментари остају
непромењени. Пре него што измени датотеку, поред ње чува копију под именом
`<file>.fontes-backup-<date>`. Копије направљене након што сте додали кључеве садрже те
кључеве: обришите оне које вам више нису потребне. Он инсталира и uv. Поновно покретање је
безбедно: исправља подешавање и не мења ништа друго.

Да бисте уклонили Fontes, отворите **Fontes Installer** и изаберите **Уклони** (Mac) или двапут
кликните на **Uninstall Fontes.cmd** (Windows). Он уклања унос `fontes`, заједно са кључевима, из сваке
апликације. Ваша остала подешавања и резервне копије остају.

## Ажурирања

- **Инсталациони програм и датотека `.mcpb`:** не морате ништа да радите. Једном дневно, када
  ваша апликација покрене Fontes, он у позадини проверава да ли постоји новија верзија и
  припрема је; следеће покретање је користи. Ако ажурирање не може да се преузме или не ради,
  Fontes наставља да користи верзију која је радила.
- **`uvx`:** Fontes вам на почетку свог списка јурисдикција јавља када изађе новија верзија. Да
  бисте увек покретали најновију, користите `fontes-mcp@latest` уместо `fontes-mcp`.

Ништа о вама или вашим претрагама се ради овога никуда не шаље.

## Приватност

Подразумевано, Fontes не шаље ништа о вама или вашим претрагама. Бројеви коришћења шаљу се
само уз ваш пристанак (opt-in), а пријава грешке тек када је видите и потврдите. Детаљи:
[PRIVACY.md](PRIVACY.md).

## Деинсталација

Обришите унос `fontes` из MCP подешавања своје апликације (у Claude Code-у:
`claude mcp remove fontes`), а затим затворите и поново отворите апликацију.

## Добро је знати

Fontes чита јавно доступне изворе, углавном сајтове судова и државних органа. Незваничне
изворе означава у својим одговорима. Увек отворите везу ка извору пре него што се ослоните на
одлуку или одредбу.

Ако нешто пође наопако, пошаљите на fontesmcp@proton.me шта сте урадили и коју сте грешку
видели.

## Пре него што се ослоните на њега

- Fontes је алат за истраживање, а не правни савет. Његово коришћење никога не чини вашим
  правником.
- Пружа се „такав какав јесте“, без гаранције, и његови аутори нису одговорни за начин на који
  се користи, у мери у којој закон то допушта. Потпуни услови налазе се у

ما يفعله

  • يبحث في الأحكام القضائية والتشريعات لحظة سؤالك، من الموقع الإلكتروني أو واجهة البرمجة (API) الخاصة بالناشر نفسه.
  • كل نتيجة تذكر مصدرها وتربط إليه، حتى تتمكن من مراجعة الأصل.
  • لا يحتفظ Fontes بقاعدة بيانات ولا يحتاج إلى حساب. لا تذهب أسئلتك إلا إلى المصدر الذي يجري البحث فيه. أعداد الاستخدام وبلاغات الأخطاء اختيارية.

Fontes أداة مساعدة في البحث، وليس استشارة قانونية، واستخدامه لا يُنشئ علاقة محامٍ بموكّل. يُقدَّم كما هو، دون أي ضمان (راجع ترخيص Apache 2.0). بعض المصادر نسخ غير رسمية صراحةً، ولكلٍّ منها شروط استخدام خاصة به؛ ويذكر Fontes ذلك في إجاباته. اقرأ الحكم أو النص كاملًا قبل أن تعتمد عليه. Fontes مستقل وغير تابع لأي محكمة أو حكومة أو ناشر.

التثبيت

  • Claude Desktop: نزّل ملف Fontes بصيغة .mcpb من أحدث إصدار، وانقر عليه نقرًا مزدوجًا، ثم انقر Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor وVS Code وGemini CLI وZed وLM Studio وCline وتطبيقات أخرى: أضِف Fontes إلى إعدادات MCP في التطبيق. يقبل معظمها هذا الإدخال؛ ويتضمن دليل التثبيت الملف والمقطع الخاصين بكل تطبيق.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

يأتي uvx مع uv. على macOS أو Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. وعلى Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

ثم أعِد تشغيل التطبيق واسأل: «ما الولايات القضائية التي يستطيع Fontes البحث فيها؟»

على جهاز Mac أو كمبيوتر Windows، تُعدّ أداة تثبيت بنقرة واحدة Fontes في Claude Desktop وCodex وClaude Code وCursor وVS Code وWindsurf وGemini CLI وZed وLM Studio وCline، في كلٍّ منها موجود على حاسوبك، ثم تعرض إضافة مفاتيحك. نزّل الأداة المناسبة لجهازك من أحدث إصدار وأغلق تلك التطبيقات قبل تشغيلها. التفاصيل في دليل التثبيت. بعض المصادر تحتاج إلى مفتاح مجاني: راجع KEYS.md.

Fontes مفتوح المصدر بموجب ترخيص Apache 2.0. تبقى النصوص القانونية خاضعة لترخيص كل ناشر.

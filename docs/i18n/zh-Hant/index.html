Fontes 是免費、開放原始碼的 MCP 伺服器。它可在任何能執行本機 Model Context Protocol 伺服器的應用程式中使用：Claude Desktop、Claude Code、Codex、Cursor、VS Code（GitHub Copilot）、Gemini CLI、Windsurf、Zed、LM Studio 等。用一般日常用語提出法律問題：您的 AI 應用程式會在政府與法院網站上即時檢索 120 多個法域及國際法院的法院裁判與法規，並為每筆結果附上原文連結。它是為律師與法律研究人員而做，也為任何想從源頭閱讀法律的人而做。

它能做什麼

  • 在您提問的當下，從發布者自己的網站或 API 檢索裁判與法規。
  • 每筆結果都註明其來源並附有連結，讓您可以核對原文。
  • Fontes 不建立資料庫，也不需要帳號。您的問題只會傳送到正在檢索的來源。使用次數統計與錯誤回報須由您選擇加入。

Fontes 是研究輔助工具，並非法律意見，使用它也不會成立律師與當事人間的委任關係。它依現狀提供，不附帶任何擔保（請參閱 Apache 2.0 授權條款）。有些來源明確是非官方版本，而且每個來源都有自己的使用條款；Fontes 會在回答中說明這一點。依賴某則裁判或條文之前，請閱讀其全文。Fontes 是獨立的，與任何法院、政府或發布者均無隸屬關係。

安裝

  • Claude Desktop：從最新版本下載 Fontes 的 .mcpb 檔案，按兩下該檔案，然後點選 Install。
  • Codex：codex mcp add fontes -- uvx fontes-mcp
  • Claude Code：claude mcp add fontes -- uvx fontes-mcp
  • Cursor、VS Code、Gemini CLI、Zed、LM Studio、Cline 及其他應用程式：將 Fontes 加入應用程式的 MCP 設定。大多數應用程式使用以下項目；安裝指南列出每個應用程式的檔案與設定片段。
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx 隨 uv 一併提供。在 macOS 或 Linux 上：curl -LsSf https://astral.sh/uv/install.sh | sh。在 Windows（PowerShell）上：powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"。

然後重新啟動應用程式並提問：「Fontes 可以檢索哪些法域？」

在 Mac 或 Windows 電腦上，一鍵安裝程式會在 Claude Desktop、Codex、Claude Code、Cursor、VS Code、Windsurf、Gemini CLI、Zed、LM Studio 與 Cline 中設定 Fontes（您電腦上有的每一個），然後提供新增金鑰的選項。請從最新發行版本下載適合您電腦的安裝程式，並在執行前先結束這些應用程式。詳情請見安裝指南。部分來源需要免費金鑰：請參閱 KEYS.md。

Fontes 是開放原始碼軟體，採用 Apache 2.0 授權條款。法律文本仍受各發布者的授權條款約束。

# Fontes 隱私權聲明

Fontes 在您的電腦上執行。您的檢索以及您開啟的文件，只在您的電腦、您所檢索的來源（官方來源，以及您使用時的 CourtListener 與 Lexifina，見下文）與您使用的 AI 應用程式
（受該應用程式本身的條款約束）之間傳遞。Fontes 本身**預設不會**向 Fontes 開發者傳送**任何內容**。

## 哪些內容可能離開您的電腦，以及何時離開

**1. 更新檢查（預設開啟）。** Fontes 每天一次詢問 PyPI（公開的 Python 套件索引）最新版本是哪一個。
該請求不包含任何關於您或您工作的資訊；與任何下載一樣，PyPI 會看到您的 IP 位址。若要關閉，請設定
`FONTES_NO_UPDATE_CHECK=1`（應用程式內的通知）與 `FONTES_NO_AUTO_UPDATE=1`（安裝程式的自動更新）。

**2. 使用次數統計（除非您開啟，否則關閉）。** 如果您選擇加入，Fontes 每天傳送一次：

- Fontes 版本與您的作業系統類別（macOS、Windows、Linux）；
- 按日計算的、每個工具針對每個法域代碼的使用次數，例如
  「2026-11-10, nl, search_caselaw, 12」。

這就是訊息的全部內容。它絕不包含您的檢索內容、文件或案件的 ID、文件內文、您的姓名、帳號，或任何用以識別您
或您電腦的 ID。統計會保留在您的電腦上（Fontes 快取資料夾中的 `stats.json`），直到傳送為止；如果傳送失敗，
會等到隔天。

- **加入**：在安裝程式詢問時回答「y」，或為 Fontes 伺服器設定 `FONTES_STATS=1`。
- **退出**：再次執行安裝程式並在該問題按 Enter，或移除 `FONTES_STATS`。刪除 `stats.json` 會捨棄所有
  尚未傳送的內容。

**3. 錯誤回報（僅在您傳送時）。** 當您要求傳送錯誤回報時（`fontes report-bug`，或請您的 AI 應用程式回報
Fontes 的錯誤），Fontes 會先向您顯示完整回報，只有在您確認後才會傳送。回報包含 Fontes 版本、您的作業系統
類別、最近一次失敗的工具呼叫的法域代碼、工具名稱與錯誤訊息（已刪除您的檢索字詞與 ID），以及您所寫的附註
（如有）。請勿在附註中填寫當事人的詳細資料。為支援此功能，Fontes 會在您的電腦上保留最近一次錯誤
（其快取資料夾中的 `last-error.json`，每次都會被取代）；它絕不會被單獨傳送。

**4. Lexifina（預設開啟）。** `get_law_on_date`、`get_law_history`、91 個國家及印度的 Acts 透過 Lexifina 的法律紀錄讀取，因此會前往 Lexifina，同時或取代官方網站。您的搜尋詞、引註與日期會傳送到 Lexifina 的免費伺服器 `global-law.lexifina.com`，該伺服器由 Lexifina 營運，而非由 Fontes 開發者營運。Lexifina 記載其伺服器會記錄呼叫了哪個工具以及耗時多久，但絕不記錄所查詢的內容；Fontes 無法查核此點，適用 Lexifina 自身的條款。與任何網路伺服器一樣，Lexifina 會看到您的 IP 位址。若要完全關閉，請設定 `WLM_LEXIFINA=0`；這兩個工具與這些國家便會停止運作，且不會向該處傳送任何內容。

## 資料傳送到哪裡，以及保存多久

使用次數統計與錯誤回報會傳送到由 Fontes 開發者營運的一台小型伺服器（`relay.kinetra.fit`）。它不儲存 IP 位址：
IP 位址僅在記憶體中短暫使用，用於阻擋大量灌入的請求，而且該網頁伺服器不為其保留存取紀錄。統計會被加總為
每日總數；不保留單次提交的內容。總數最多保存 2 年，錯誤回報最多保存 1 年，之後刪除。任何內容都不會出售或分享。

如果無法連線到該伺服器，就不會傳送任何內容：統計會保留在您的電腦上，錯誤回報則會引導您改用問題追蹤系統。

## 由誰負責，依據為何

使用次數統計與錯誤回報的資料控制者是 Fontes 的開發者 Yüce Karapazar。聯絡方式：fontesmcp@proton.me。

法律依據是您的同意（英國 GDPR 與歐盟 GDPR 第 6(1)(a) 條）。只有在您選擇加入時才會傳送使用次數統計，只有在您
確認後才會傳送錯誤回報。您可以隨時依上述方式退出以撤回同意；這不影響先前已傳送的內容。

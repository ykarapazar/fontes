# Fontes 隱私權聲明

Fontes 在你个電腦頂執行。你个檢索同你打開个文件，單淨在你个電腦、你檢索个官方來源同你用个 AI 應用程式
（受該應用程式自家个條款約束）之間來去。Fontes 本身**預設毋會**傳送**任何東西**分 Fontes 个開發者。

## 哪兜東西可能離開你个電腦，同麼个時節

**1. 更新檢查（預設打開）。** Fontes 逐日一擺問 PyPI（公開个 Python 套件索引）最新个版本係哪一个。
該請求無包含任何有關你或者你个工作个資訊；同任何下載共樣，PyPI 會看著你个 IP 位址。愛關忒，請設定
`FONTES_NO_UPDATE_CHECK=1`（應用程式肚項个通知）同 `FONTES_NO_AUTO_UPDATE=1`（安裝程式个自動更新）。

**2. 使用次數統計（除非你打開，無就係關忒个）。** 若係你選擇加入，Fontes 逐日傳送一擺：

- Fontes 个版本同你个作業系統類別（macOS、Windows、Linux）；
- 照日算个、每一个工具對每一个法域代碼个使用次數，例如
  「2026-11-10, nl, search_caselaw, 12」。

訊息个全部內容就係這兜。佢絕對毋會包含你个檢索內容、文件或者案件个 ID、文件內文、你个名、帳號，或者任何
用來識別你或者你電腦个 ID。統計會留在你个電腦頂（Fontes 快取資料夾肚項个 `stats.json`），到送出去為止；
若係傳送失敗，會等到第二日。

- **加入**：在安裝程式問个時節回答「y」，或者為 Fontes 伺服器設定 `FONTES_STATS=1`。
- **退出**：再執行一擺安裝程式，在該問題撳 Enter，或者移除 `FONTES_STATS`。刪忒 `stats.json` 會丟忒所有
  還吂送出去个內容。

**3. 錯誤回報（單淨在你傳送个時節）。** 你要求傳送錯誤回報个時節（`fontes report-bug`，或者請你个 AI
應用程式回報 Fontes 个錯誤），Fontes 會先分你看完整个回報，單淨在你確認以後正會送出去。回報包含 Fontes
个版本、你个作業系統類別、最尾一擺失敗个工具呼叫个法域代碼、工具名稱同錯誤訊息（已經刪忒你个檢索字詞
同 ID），同你寫个附註（若係有）。請毋好在附註肚項寫當事人个詳細資料。為著支援這个功能，Fontes 會在你个
電腦頂保留最尾一擺个錯誤（佢快取資料夾肚項个 `last-error.json`，每一擺都會分人取代）；佢絕對毋會單獨
送出去。

## 資料送到哪位，同保存幾久

使用次數統計同錯誤回報會送到 Fontes 開發者營運个一台細細个伺服器（`relay.kinetra.fit`）。佢毋會儲存 IP
位址：IP 位址單淨在記憶體肚項短短時間用來擋大量灌入个請求，而且該網頁伺服器無為佢保留存取紀錄。統計會
加總做逐日个總數；毋會保留單一擺提交个內容。總數最多保存 2 年，錯誤回報最多保存 1 年，以後刪忒。任何內容
都毋會賣忒或者分享。

若係連毋著該伺服器，就麼个都毋會送出去：統計會留在你个電腦頂，錯誤回報會帶你改用問題追蹤系統。

單淨在你確認以後正會傳送錯誤回報。你做得隨時照頂高个方式退出來撤回同意；這毋會影響以前已經送出去个內容。

Fontes on tasuta avatud lähtekoodiga MCP-server. See töötab igas rakenduses, mis suudab käivitada kohalikku Model Context Protocoli serverit: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio ja teised. Esitage õigusküsimus tavakeeles: teie tehisintellekti rakendus otsib kohtulahendeid ja õigusakte reaalajas valitsuste ja kohtute veebisaitidelt 125 jurisdiktsioonis ja rahvusvahelistes kohtutes ning lingib iga tulemuse originaalile. Samuti saab see näidata seadust sellisena, nagu see kehtis varasemal kuupäeval, ja lugeda õigusakte veel 91 riigist Lexifina registrist (see ei ole ametlik avaldaja). See on loodud juristidele ja õigusteadlastele ning kõigile, kes soovivad lugeda õigust selle allikast.

Mida see teeb

  • Otsib kohtupraktikat ja õigusakte teie küsimise hetkel avaldaja enda veebisaidilt või API-st.
  • Iga tulemus nimetab oma allika ja lingib sellele, et saaksite originaali kontrollida.
  • Fontes ei pea andmebaasi ega vaja kontot. Teie küsimused lähevad otsitavale allikale; seaduste varasemate redaktsioonide ja 91 lisariigi (ning India seaduste) puhul lähevad need Lexifina avalikku teenusesse, kas ametliku saidi kõrval või selle asemel. Selle väljalülitamiseks määrake WLM_LEXIFINA=0. Kasutuskordade arvud ja veateated on vabatahtlikud (opt-in).

Fontes on uurimistöö abivahend, mitte õigusnõu, ja selle kasutamine ei loo advokaadi ja kliendi suhet. See antakse nagu on, ilma garantiita (vt Apache 2.0 litsentsi). Mõned allikad on sõnaselgelt mitteametlikud versioonid ja igaühel on oma kasutustingimused; Fontes ütleb seda oma vastustes. Lugege kogu lahendit või sätet, enne kui sellele tuginete. Fontes on sõltumatu ega ole seotud ühegi kohtu, valitsuse ega avaldajaga.

Paigaldamine

  • Claude Desktop: laadige Fontese .mcpb-fail alla viimasest väljalaskest, tehke sellel topeltklõps ja klõpsake seejärel Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline ja muud rakendused: lisage Fontes rakenduse MCP-seadetesse. Enamik kasutab seda kirjet; paigaldusjuhendis on iga rakenduse fail ja koodilõik.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx tuleb koos tööriistaga uv. macOS-is või Linuxis: curl -LsSf https://astral.sh/uv/install.sh | sh. Windowsis (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Seejärel taaskäivitage rakendus ja küsige: „Millistes jurisdiktsioonides saab Fontes otsida?“

Macis või Windowsi arvutis seadistab ühe klõpsuga paigaldaja Fontese rakendustes Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio ja Cline, igaühes neist, mis teie arvutis on, ja pakub seejärel teie võtmete lisamist. Laadige paigaldaja oma arvutile alla viimasest väljalaskest ja sulgege need rakendused enne selle käivitamist. Üksikasjad paigaldusjuhendis. Mõni allikas vajab tasuta võtit: vt KEYS.md.

Fontes on avatud lähtekoodiga Apache 2.0 litsentsi all. Õigustekstid jäävad iga avaldaja litsentsi alla.

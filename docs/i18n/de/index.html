Beta · kostenlos · Open Source · Quellen täglich geprüft

Fontes ist ein kostenloser Open-Source-MCP-Server. Er funktioniert in jeder App, die einen lokalen Model-Context-Protocol-Server ausführen kann: Claude Desktop, Claude Code, Codex, Cursor, VS Code (GitHub Copilot), Gemini CLI, Windsurf, Zed, LM Studio und weiteren. Stellen Sie eine juristische Frage in natürlicher Sprache: Ihre KI-App durchsucht Gerichtsentscheidungen und Rechtsvorschriften live auf Websites von Behörden und Gerichten, in über 120 Rechtsordnungen und internationalen Gerichten, und verlinkt jedes Ergebnis auf das Original. Fontes ist für Juristinnen und Juristen und für die juristische Forschung gemacht, und für alle, die das Recht an seiner Quelle lesen wollen.

Was es tut

  • Durchsucht Rechtsprechung und Rechtsvorschriften in dem Moment, in dem Sie fragen, auf der eigenen Website oder API des Herausgebers.
  • Jedes Ergebnis nennt seine Quelle und verlinkt auf sie, damit Sie das Original prüfen können.
  • Fontes führt keine Datenbank und braucht kein Konto. Ihre Fragen gehen nur an die durchsuchte Quelle. Nutzungszahlen und Fehlerberichte sind Opt-in.

Fontes ist eine Recherchehilfe, keine Rechtsberatung, und seine Nutzung begründet kein Mandatsverhältnis. Es wird wie besehen bereitgestellt, ohne Gewährleistung (siehe die Lizenz Apache 2.0). Manche Quellen sind ausdrücklich nichtamtliche Fassungen, und jede hat ihre eigenen Nutzungsbedingungen; Fontes weist in seinen Antworten darauf hin. Lesen Sie die vollständige Entscheidung oder Vorschrift, bevor Sie sich darauf verlassen. Fontes ist unabhängig und mit keinem Gericht, keinem Staat und keinem Herausgeber verbunden.

Installation

  • Claude Desktop: Laden Sie die Fontes-Datei .mcpb aus dem neuesten Release herunter, doppelklicken Sie darauf und klicken Sie dann auf Install.
  • Codex: codex mcp add fontes -- uvx fontes-mcp
  • Claude Code: claude mcp add fontes -- uvx fontes-mcp
  • Cursor, VS Code, Gemini CLI, Zed, LM Studio, Cline und andere Apps: Fügen Sie Fontes zu den MCP-Einstellungen der App hinzu. Die meisten nehmen diesen Eintrag; die Installationsanleitung nennt für jede App die Datei und den passenden Eintrag.
{
  "mcpServers": {
    "fontes": { "command": "uvx", "args": ["fontes-mcp"] }
  }
}

uvx gehört zu uv. Unter macOS oder Linux: curl -LsSf https://astral.sh/uv/install.sh | sh. Unter Windows (PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex".

Starten Sie dann die App neu und fragen Sie: „Welche Rechtsordnungen kann Fontes durchsuchen?“

Auf einem Mac oder einem Windows-PC richtet ein Ein-Klick-Installationsprogramm Fontes in Claude Desktop, Codex, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI, Zed, LM Studio und Cline ein, in jeder dieser Apps auf Ihrem Computer, und bietet dann an, Ihre Schlüssel hinzuzufügen. Laden Sie das Installationsprogramm für Ihren Computer aus dem neuesten Release herunter und beenden Sie diese Apps, bevor Sie es ausführen. Einzelheiten in der Installationsanleitung. Einige Quellen benötigen einen kostenlosen Schlüssel: siehe KEYS.md.

Fontes ist Open Source unter der Lizenz Apache 2.0. Rechtstexte bleiben unter der Lizenz des jeweiligen Herausgebers.

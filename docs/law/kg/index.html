Kyrgyzstan: case law for your AI app

Fontes lets your AI app search Kyrgyzstan case law at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Constitutional Court of the Kyrgyz Republic (constsot.kg): case law

What it covers

Constitutional Court acts only (1998-now, Russian/Kyrgyz, full text from the signed PDF). No legislation (codes, statutes) through this server: the Ministry of Justice database cbd.minjust.gov.kg refuses this client, so read codes there directly; general-court acts (act.sot.kg) are unreachable abroad. To see how the Criminal or Civil Code is applied, search_caselaw (Constitutional Court rulings on its articles).

What it does not cover

  • Legislation (Ministry of Justice database cbd.minjust.gov.kg): blocks our client (connection dropped, 2026-11-06)
  • General-court case law (sot.kg / act.sot.kg): site down / unreachable from outside Kyrgyzstan (2026-11-06)

Serbia: case law and legislation for your AI app

Fontes lets your AI app search Serbia case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Vrhovni sud (Supreme Court of Serbia): Baza sudske prakse: case law
  • Ustavni sud (Constitutional Court): Ustav RS i propisi: legislation

What it covers

Case law: selected, anonymised Supreme Court decisions (Vrhovni sud and its predecessors). Legislation: only the consolidated Constitution, the 2006 Constitutional Law and the Law on the Constitutional Court (Cyrillic, by article); the state legal information system's terms forbid automated access.

What it does not cover

  • Consolidated legislation (pravno-informacioni-sistem.rs): terms forbid automated use without written consent ('Строго је забрањено')
  • Laws as adopted (parlament.gov.rs PDFs): not built: current convocation (2024-) only, amending acts as passed, never consolidated
  • Appellate and first-instance courts (sudskapraksa.sud.rs): connection timed out (2026-11-06)
  • Supreme Court decisions outside the court's selection: not published online
  • Constitutional Court: not researched yet

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

Jurisdiction code: rs. Whether each source is working today: source status, checked daily.

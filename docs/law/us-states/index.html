United States (state courts): case law for your AI app

Fontes lets your AI app search United States (state courts) case law at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • CourtListener (Free Law Project, a non-profit): opinions of state supreme and appellate courts: case law (unofficial; every answer says so)

What it covers

Inactive: needs your own free CourtListener API token. Create an account at courtlistener.com and set WLM_US_COURTLISTENER_KEY (see docs/KEYS.md).

What it does not cover

  • State statutes and codes: not in CourtListener; each legislature publishes its own (not built yet)
  • State trial courts: mostly not published online, so mostly not covered
  • Free accounts allow 5 requests a minute and 125 a day: a search is 1 request, a decision 2
  • Federal courts: use jurisdiction 'us' (official sources: govinfo, supremecourt.gov)

Questions to try

Ask in any language; the search words work best in the language of the source.

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

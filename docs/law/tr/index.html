Türkiye: case law and legislation for your AI app

Fontes lets your AI app search Türkiye case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Bedesten (Adalet Bakanlığı, mevzuat.adalet.gov.tr backend): case law and legislation
  • Anayasa Mahkemesi Kararlar Bilgi Bankası: case law
  • Uyuşmazlık Mahkemesi Karar Arama: case law
  • Sayıştay Kararlar (Genel Kurul, Temyiz Kurulu, Daire): case law
  • Rekabet Kurumu Kurul Kararı Arama: case law
  • Gelir İdaresi Başkanlığı Özelgeler: case law

What it covers

Yargıtay, Danıştay, BAM civil chambers, first-instance civil and AYM decisions (AYM norm review is read from normkararlarbilgibankasi.anayasa.gov.tr, same terms as the individual-application bank), plus Uyuşmazlık Mahkemesi, Sayıştay, Rekabet Kurulu and GİB özelge banks (court=...); consolidated legislation with per-article text. Quote multi-word phrases: unquoted words are OR-ed. Bedesten is slow on purpose (3.5 s between requests); an Uyuşmazlık text search takes ~20 s server-side and sometimes over 60 s (2026-11-10). Newest Yargıtay data lags ~5 weeks (2026-11-07).

What it does not cover

  • Yargıtay decisions from the last ~5 weeks: not yet in Bedesten (source lag, 2026-11-07)
  • KİK (public procurement board) decisions: ekapv2.kik.gov.tr API requires AES-signed request headers (anti-automation); not built
  • BTK board decisions: the only search is www.btk.tr/api/, which robots.txt disallows for all user agents
  • BDDK board decisions, Sigorta Tahkim Komisyonu awards: no official search endpoint (yargi-mcp uses a third-party web-search API); not built
  • Yargıtay Karar Arama (karararama.yargitay.gov.tr), which could fill the Bedesten lag: connection times out from a UK IP (2026-11-10)
  • Resmî Gazete (as-published texts, daily index): source exists (HTML only) but not built yet
  • KVKK decisions: kvkk.gov.tr has no search endpoint (yargi-mcp uses a third-party web-search API); mostly decision summaries; not built
  • SPK, EPDK, RTÜK, BDDK and Ombudsman decisions: not researched yet
  • Professional-body rules never published in the Resmî Gazete, e.g. the TBB Meslek Kuralları (Türkiye Barolar Birliği): not in Bedesten (no title match, 2026-11-11); the TBB publishes them itself
  • Regional administrative courts (Bölge İdare Mahkemeleri): not researched yet (Bedesten item types unverified)
  • Regional appeal criminal chambers (BAM ceza daireleri) and first-instance criminal courts: no Bedesten item type queried (only ISTINAFHUKUK and YERELHUKUK, civil)

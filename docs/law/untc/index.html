UN Treaty Collection (multilateral treaties deposited with the UN Secretary-General): legislation for your AI app

Fontes lets your AI app search UN Treaty Collection (multilateral treaties deposited with the UN Secretary-General) legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • United Nations Treaty Collection (treaties.un.org), MTDSG status records and certified true copies: legislation

What it covers

Multilateral treaties deposited with the UN Secretary-General (MTDSG), by MTDSG number (IV-4 = ICCPR, XXI-6 = UNCLOS). Status, parties, reservations and objections as provisions; treaty text from the certified true copy PDF where it has a text layer. First unfiltered search takes ~70 s (Crawl-delay 2).

What it does not cover

  • Treaty text when the certified copy has no usable text layer or is too large: scans only, no text (status record instead)
  • Treaties registered but not deposited with the Secretary-General (UNTS, incl. bilateral): not researched yet
  • Full-text search across treaty texts: the site's search is a multi-step ASP.NET form; not built yet
  • Articles in French and the other official languages: only English headings are cut out; not built yet

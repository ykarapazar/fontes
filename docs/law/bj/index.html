Benin: case law and legislation for your AI app

Fontes lets your AI app search Benin case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Cour constitutionnelle du Bénin: décisions (courconstitutionnelle.bj): case law
  • Secrétariat général du Gouvernement du Bénin: lois, décrets, ordonnances (sgg.gouv.bj): legislation

What it covers

Cour constitutionnelle decisions (~6,500 DCC plus electoral; search by decision number or applicant name, the site's keyword search is broken) and laws/decrees/ordinances from the SGG (as promulgated, PDF; many recent scans have no text layer). French.

What it does not cover

  • Cour suprême decisions: not published online (coursupreme.bj is a static page only)
  • CDIJ law database (legis.cdij.bj): terms forbid reproduction 'sans l'accord écrit'; needs permission
  • Text of many recent laws and decrees: image-only scans, no text layer (no OCR here)
  • Keyword search of Constitutional Court decisions: broken at the source (Algolia HTTP 500)
  • Assemblée nationale texts: site in maintenance (503, 2026-11-06)
  • Code pénal (Loi 2018-16) and the 1990 Constitution (Loi 90-32): not on sgg.gouv.bj as searchable text (2026-11); the 1990 Constitution and some decisions are scanned PDFs
  • Lower courts: not researched yet
  • Arrêtés: the law-id pattern accepts 'arrete-' but search never queries that SGG type

Questions to try

Ask in any language; the search words work best in the language of the source.

  • Find Benin legislation: code

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

Jurisdiction code: bj. Whether each source is working today: source status, checked daily.

Fontes is a research aid, not legal advice. Read the full decision or provision at the source before you rely on it.

Greece: case law and legislation for your AI app

Fontes lets your AI app search Greece case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Άρειος Πάγος – Νομολογία (Supreme Civil and Criminal Court): case law
  • Εθνικό Τυπογραφείο – Αναζήτηση ΦΕΚ (Government Gazette, Presidency of the Government): legislation (off unless you hold the publisher's permission)

What it covers

Case law: Areios Pagos only (2006 onward, anonymised), searched by number ('1/2020'), year ('2024', large), or words matched to the subject index's fixed headings (first 3 matching headings; index mostly 2007–2010); no free text. Legislation: ΦΕΚ gazette text as published, NOT consolidated; ids are ΦΕΚ labels ('Α 137/2019'), laws also as 'ν. 4624/2019'. Council of State: bot-challenged, not covered.

What it does not cover

  • ΦΕΚ legislation when hosted for others: needs permission (terms: 'personal, informational, non-commercial use')
  • Council of State (administrative) case law: bot check / blocks our client
  • Consolidated legislation: not published online officially (only the ΦΕΚ gazette as published)
  • ΦΕΚ issues before ~2000: scans only, no text (no OCR)
  • Areios Pagos before 2006, and appeal/first-instance courts: not researched yet

Questions to try

Ask in any language; the search words work best in the language of the source.

  • Find Greece case law on Μίσθωση εργασίας
  • Find Greece legislation: Αστικός Κώδικας

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

Ecuador: case law for your AI app

Fontes lets your AI app search Ecuador case law at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Corte Constitucional del Ecuador – Buscador de Sentencias (public JSON backend) and signed decision PDFs (esacc storage): case law

What it covers

Case law: Corte Constitucional (2008 onwards), full-text search, full text from the signed PDF. No legislation: no official source offers per-norm text without login or OCR.

What it does not cover

  • Legislation: Registro Oficial's site search (?s=) matches edition summaries only and returns whole gazette PDFs, no per-norm text or consolidation; its REST API needs authorization
  • Laws via Asamblea Nacional 'Leyes aprobadas': the gazette law pages are scans only, no text
  • Constitution: Asamblea Nacional's text-layer PDF (constitucion_de_bolsillo.pdf) is the 2011 edition, stale (later amendments missing), so not wired (2026-11-10)
  • Regulations (gob.ec/regulaciones): needs a login
  • Corte Nacional de Justicia: busquedasentencias.cortenacional.gob.ec sends a reCAPTCHA v3 token (X-reCAPTCHA-Token) with every search call; Gaceta Judicial buscador answers HTTP 500 (2026-11-10)
  • Lower-court decisions: not researched yet
  • Former Tribunal Constitucional decisions (before 2008): not researched yet

Questions to try

Ask in any language; the search words work best in the language of the source.

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

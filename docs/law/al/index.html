Albania: case law and legislation for your AI app

Fontes lets your AI app search Albania case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Qendra e Botimeve Zyrtare (qbz.gov.al, Ministry of Justice): legislation
  • Gjykata e Lartë (High Court of Albania, gjykataelarte.gov.al): case law

What it covers

Albanian only. Legislation: acts in the Fletorja Zyrtare from qbz.gov.al, with the latest consolidated version where QBZ has one; search matches titles and numbers, not full text; 1990s base laws (Constitution 8417/1998, Civil, Penal, Labour Codes) are missing: a search for their number returns only amending acts. Case law: High Court decisions 2005 on, full-text search; Joint Colleges unifying decisions 1999 on (category=joint); 1999-2019 monthly volumes (archive_year); not anonymised. The Constitutional Court is not covered.

What it does not cover

  • Constitutional Court (gjykatakushtetuese.gov.al): WordPress pages with PDFs, Imunify bot check present; not built yet
  • Appeal, first-instance and administrative courts: not researched yet
  • High Court decisions 1999-2004: only in the monthly volumes (archive_year), which are read whole and are not full-text searchable
  • 1990s base laws (Constitution 8417/1998, Civil Code 7850/1994, Penal Code 7895/1995, Labour Code 7961/1995): not in QBZ's act archive, only their amendments
  • Full-text search of legislation: QBZ's API matches title, number and institution only

Past versions

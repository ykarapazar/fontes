EFTA Court: case law for your AI app

Fontes lets your AI app search EFTA Court case law at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • EFTA Court website (eftacourt.int, api.eftacourt.int): case law

What it covers

Case law only, no legislation (search_legislation is not available for this jurisdiction): EFTA Court judgments, advisory opinions and orders since 1994 (PDF text). Ids are the court's case ids (c-wp-10023); case numbers like E-25/24 also work.

What it does not cover

  • Case documents other than the judgment or order (in the Court's downloads list): source works but not built
  • Non-English versions of judgments: listed by the source, English preferred; not built
  • Full-text search of judgments: no server-side search on api.eftacourt.int; search is over case metadata
  • EEA Agreement and EEA-incorporated acts (legislation): not available here, only EFTA Court case law is. The EU text of a directive or regulation can be searched under jurisdiction 'eu'; the EEA-adapted version is not covered

Questions to try

Ask in any language; the search words work best in the language of the source.

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

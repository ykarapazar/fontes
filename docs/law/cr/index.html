Costa Rica: legislation for your AI app

Fontes lets your AI app search Costa Rica legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • SINALEVI – Sistema Nacional de Legislación Vigente (Procuraduría General de la República, SCIJ): legislation

What it covers

Consolidated laws, decrees and treaties from SINALEVI (PGR), updated daily; search is newest-first. No case law: the Poder Judicial's Nexus PJ forbids robotic/AI database building.

What it does not cover

  • Case law (all courts, incl. Sala Constitucional; Nexus PJ): terms ban databases built with 'herramientas robotizadas'
  • Earlier versions of a norm: SINALEVI serves them (version parameter); only the latest is built
  • Municipal regulations: not researched yet
  • Tribunal Supremo de Elecciones case law: not researched yet
  • La Gaceta (Diario Oficial): not researched yet

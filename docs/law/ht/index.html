Haiti: legislation for your AI app

Fontes lets your AI app search Haiti legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Conseil Supérieur du Pouvoir Judiciaire (CSPJ): document library: legislation
  • Cour de cassation d'Haïti: Constitution PDF (1987 original): legislation

What it covers

Legislation only, and only a small set: ~17 laws and decree-laws (French) from the judiciary council's (CSPJ) library, text from the PDFs where they have a text layer. No case law online.

What it does not cover

  • Most Haitian legislation (only ~17 laws are in the CSPJ library): Le Moniteur has no live site; Parliament TLS broken
  • 6 of the ~17 laws: scans only, no text (no OCR)
  • Constitution: only the 1987 original is readable (court site); the 2011 amended PDF is a scan
  • Case law (Cour de cassation): not published online (its database is empty, 2026-11)

Questions to try

Ask in any language; the search words work best in the language of the source.

  • Find Haiti legislation: loi

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

Jurisdiction code: ht. Whether each source is working today: source status, checked daily.

Iceland: case law for your AI app

Fontes lets your AI app search Iceland case law at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Ísland.is court rulings (Stafrænt Ísland; Hæstiréttur, Landsréttur, héraðsdómstólar): case law

What it covers

Case law only, Icelandic: Hæstiréttur, Landsréttur, district courts. Ids look like 's-<GUID>' (Supreme Court) or 'g-<uuid>' (other courts). No legislation: althingi.is/lagas sits behind a Cloudflare challenge.

What it does not cover

  • Legislation (consolidated law collection, althingi.is/lagas): bot check / blocks our client (Cloudflare JS challenge)
  • Regulations and the official gazette (Stjórnartíðindi): not researched yet

Questions to try

Ask in any language; the search words work best in the language of the source.

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

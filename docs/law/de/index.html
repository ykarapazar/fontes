Germany (federal): case law and legislation for your AI app

Fontes lets your AI app search Germany (federal) case law and legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • NeuRIS – Rechtsinformationsportal des Bundes (API, trial service): case law (off unless you hold the publisher's permission)
  • Bundesfinanzhof – Entscheidungen online (bundesfinanzhof.de): case law
  • Gesetze im Internet (Bundesamt für Justiz / BMJV): legislation

What it covers

Federal level only. Case law: NeuRIS (all federal courts, needs WLM_PERMITTED=de); otherwise the Federal Fiscal Court (BFH) from its own site, 1 request/min. Legislation: current consolidated texts from gesetze-im-internet.de; ids are GII slugs ('bgb', 'gg', 'stgb').

What it does not cover

  • BGH, BVerfG, BVerwG, BAG, BSG, BPatG case law: only via NeuRIS, whose robots.txt says 'Disallow: /'; off unless WLM_PERMITTED=de (needs permission)
  • Federal courts' own sites (checked 2026-11-10): BGH and BSG searches sit under robots-disallowed /SiteGlobals/; BVerwG search is behind a bot challenge; BAG terms need permission for any use of texts/database; rechtsprechung-im-internet.de robots 'Disallow: /'
  • BFH without permission: only decisions the court publishes online (V and NV), 2010 on; slow (robots Crawl-Delay 60 = 1 request/min)
  • Land (state) court decisions (OLG, LG, AG, Land admin courts): no official API; per-Land portals not researched yet
  • Land (state) legislation of the 16 Länder: per-Land portals not researched yet
  • Earlier versions of federal laws: gesetze-im-internet.de serves the current version only

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

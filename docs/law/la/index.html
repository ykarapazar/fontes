Laos: legislation for your AI app

Fontes lets your AI app search Laos legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Official Gazette of the Lao PDR (Ministry of Justice): search index: legislation

What it covers

Legislation index only: title search over the Official Gazette (laws, decrees, decisions, ~2,600 acts, Lao), with links to the scanned PDFs. No text, no case law.

What it does not cover

  • Full text of all legislation: scans only, no text (Gazette PDFs are images; no OCR); titles and metadata only
  • Case law (People's Supreme Court): site down / unreachable (spc.gov.la does not resolve, peoplecourt.gov.la timed out, 2026-11-06)
  • English versions: not published online (English PDF column empty in every row seen)

Questions to try

Ask in any language; the search words work best in the language of the source.

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

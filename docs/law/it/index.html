Italy: legislation for your AI app

Fontes lets your AI app search Italy legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Normattiva open-data API (Istituto Poligrafico e Zecca dello Stato): legislation
  • Normattiva — www.normattiva.it (texts by URN:NIR): legislation

What it covers

National legislation from Normattiva, text in force today. Law id = URN:NIR (Codice civile: urn:nir:stato:regio.decreto:1942-03-16;262; Costituzione: urn:nir:stato:costituzione:1947-12-27, transitional provisions as 'art. XVIII (all. 1)'). Search ORs words and sorts by date; cite as 'legge 241/1990' or use type/number/year filters. No case law: Cassazione (Italgiure) is unreachable from outside Italy; Corte costituzionale search works (no captcha, 2026-11) but is not built yet.

What it does not cover

  • Corte costituzionale decisions: source exists and works but not built yet (2026-11 validation: POST search works, no captcha)
  • Corte di cassazione case law (Italgiure): site down / unreachable from outside Italy (2026-11)
  • Administrative, appeal and lower-court case law: not researched yet
  • Regional legislation: not researched yet (Normattiva is national law only)

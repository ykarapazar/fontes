Romania: legislation for your AI app

Fontes lets your AI app search Romania legislation at the source and link every result to the original. It is a free, open-source MCP server for Claude Desktop, Claude Code, Codex, Cursor, VS Code and other apps.

Sources

  • Înalta Curte de Casaţie şi Justiţie (High Court of Cassation and Justice), scj.ro: case law
  • Camera Deputaţilor, Baza de date legislativă (cdep.ro), metadata only: legislation
  • Camera Deputaţilor, Constituţia României (cdep.ro), revised text 2003: legislation

What it covers

ÎCCJ decisions by scj.ro id only (robots.txt blocks scj.ro search). Legislation: index search on cdep.ro (number, date, status, Monitorul Oficial); full text only for the Constitution (id 15346, revised 2003). Other texts: legislatie.just.ro is unreachable/down. CCR and ReJust sit behind bot checks.

What it does not cover

  • ÎCCJ case-law search: robots.txt disallows scj.ro's /home/getpage, so decisions are fetched by id only
  • Text of laws, codes and ordinances (consolidated and as published; the Constitution is covered): legislatie.just.ro drops our HTTPS connections and its SOAP search backend is down (2026-11-05, rechecked 2026-11-10)
  • Constitutional Court (ccr.ro) and iccj.ro: 'Verifying your browser' bot check
  • Lower courts (ReJust, all courts): Blazor app behind a Cloudflare Turnstile bot check

Past versions

get_law_on_date and get_law_history read Lexifina's record (not the official publisher).

Install

Claude Code: claude mcp add fontes -- uvx fontes-mcp. Codex: codex mcp add fontes -- uvx fontes-mcp. Claude Desktop and one-click installers for Mac and Windows: the latest release. Other apps: the installation guide.

Jurisdiction code: ro. Whether each source is working today: source status, checked daily.

Fontes is a research aid, not legal advice. Read the full decision or provision at the source before you rely on it.

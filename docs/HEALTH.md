## Where this runs

GitHub (`.github/workflows/health.yml`, daily 05:17 UTC) is the canonical run: it commits `research/health/<date>.json`, this file and `docs/status/index.html` (the status page; GitHub Pages serves it at `/status/` once the repo is public).

`scripts/health_daily.sh` runs daily on a maintainer's machine: it probes every source, keeps a timestamped report in `research/health/` (not committed), writes `status/HEALTH.md`, copies GitHub's status page from `origin/main` to `status/index.html` (or builds one from the local reports until GitHub has published), and shows a notification when a source changes status.

```sh
# install (daily 09:00, log: ~/Library/Logs/fontes-health.log)
cp scripts/launchd/io.github.ykarapazar.fontes-health.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/io.github.ykarapazar.fontes-health.plist
launchctl kickstart gui/$(id -u)/io.github.ykarapazar.fontes-health   # optional: run once now
# uninstall
launchctl bootout gui/$(id -u)/io.github.ykarapazar.fontes-health
rm ~/Library/LaunchAgents/io.github.ykarapazar.fontes-health.plist
```
